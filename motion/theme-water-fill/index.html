注水指示(液面高度表进度/深度) Theme Water Fill

water fill · liquid fill · 注水进度 · 液面指示 · wave fill · 水位指示

以液面上升/下降表达进度或主题深浅:双正弦叠加液面(频率比 1:1.618 的拍效应防机械循环)+ SVG 波形 path 相位平移,外层以圆环裁剪;reduced-motion 降级为静态液面高度。

%

代码拆解

结构与 DOM

以「液面高度」表达量值:一个被圆环裁剪的液层,液面由双正弦叠加采样成闭合 path,相位持续平移;液位档位(而非完成弧)承载主题深浅/容量语义(调研 20§2.6/§6.1):

<div class="vessel">
  <svg aria-hidden="true">
    <defs>
      <clipPath id="vessel-clip"><circle r="110"/></clipPath><!-- 外层圆环裁剪 -->
    </defs>
    <path class="water" clip-path="url(#vessel-clip)"/><!-- 逐帧重算的液面 path -->
    <circle class="ring"/><!-- 容器描边 -->
  </svg>
</div>

关键点:

  • 液面 path 是逐帧几何:η(x,t) = A1·sin(k1x−ω1t) + A2·sin(k2x−ω2t+φ) 沿 x 采样连折线、底边出血后闭合——相位项 −ωt 即「水平循环平移」;它不受 clip-path url() 不可插值限制(§1.2),也不依赖 startViewTransition 与滤镜;
  • 双正弦叠加的物理出处(Wikipedia Dispersion (water waves)):两列波长略异的正弦波叠加 → 拍/波群;demo 取不可通约的频率比 1:1.618,合成波形永不精确重复——单正弦的机械循环感由此消除;
  • 量值语义:液面高度是「量」的空间隐喻(容量、深度、余量),不是任务完成度——完成弧语义归 motion/progress-motion;
  • 液位数值同时由文字读数承载,波形只是增强(HIG:动效不得是重要信息的唯一通道);
  • 纯 CSS 先例(fill-water-animation / Water-Wave-Text-Animation)用两条背景波形平移代替算术叠加——通路可行,但双正弦算术叠加必须逐帧重算 path。

样式与参数

五个参数全部为 JS 型,demo 订阅 store 后驱动逐帧循环与液位过渡:

// 液面采样(§6.1 配方骨架;A/λ 档位为调研记录值)
const surf = (x, t) =>
  A1 * Math.sin(k1 * x - w1 * t) +            // 主波 k1 = 2π/λ1
  A2 * Math.sin(k2 * x - w2 * t + phi);       // 次波:A2=A1×3/8、λ2=λ1×2/3、ω2/ω1=1.618
// 每帧:M 起点 → 沿 x 采样连折线 → 底边出血闭合;液面均值 = cy+R − level%·2R

数值出处:

  • A1=8px、A2=3px(3/8)、λ≈宽度/2 与 /3(2:3)、角速比 1.618 = 调研 §6.1 记录值;波数 k=2π/λ;
  • ω1=2π(主波周期 1s)是 demo 调参值——调研只核验比值,不核验绝对角速度;
  • 液位过渡 500ms = M3「按过渡面积定时长」大容器档(§5);缓动取 §6.3 液块曲线 cubic-bezier(0.3, 0, 0.2, 1);
  • deepLevel 75% / shallowLevel 35% 是 demo 设计值——「液面高度即主题深度」出自调研 §8 候扩清单(设计推断),不是核验值;『深色=深水=低』的方向沿用 Helmholtz 类比(腔大→频率低,§3.2 的物理类比;跨模态感知对应未核验);
  • 振幅纪律:A 守在容器直径的 1/8–1/12,否则波峰顶出裁剪圈或露出液下底。

动效与交互

  • 点击 → 注水/排水:液位按缓动从当前档向目标档过渡(时长 = duration,data-fx-duration 与之一致),主题在液位到位瞬间原子提交;波形相位是持续环境动画,不计入该时长——rAF 在页面隐藏时自动暂停;
  • 进行中再次点击:旧过渡原子收尾(液位直落上一目标档、主题提交)、新过渡完整播放——不卡死不停半途;
  • reduced-motion(规格原文降级):prefers-reduced-motion: reduce 时相位冻结,降级为静态液面高度(渲染一帧不动的波形),液位瞬时落到目标档(时长视作 0,data-fx-duration 同步为 0);
  • 降级:无 rAF/SVG 环境显示静态水平线液面;液位读数不依赖动画,信息零损失;
  • 文字注水变体:把圆环裁剪换成文本裁剪(先例 Water-Wave-Text-Animation 技法),标题随液位上升被「灌满」——同一套液面公式,只换裁剪外层。

真实产品案例

  • coiger/fill-water-animation(22★,「Fill wavy water in circle with pure css code」):圆内容器注水的纯 CSS 实现——两条波形层平移的技法先例(GitHub API 核实;星数低,标注为技法旁证而非权威,调研 20§4);
  • codeaashu/Water-Wave-Text-Animation(20★,HTML/CSS 水波文字):文字裁剪注水的旁证——文本外层裁剪的可行性与流行度佐证(GitHub API 核实,同上标注);
  • 「液面高度即主题深度」的网页端产品级公开实现未找到可打开且确定的先例(§4 未证实清单)——demo 的深浅两档液位是设计推断的演示,不冒充产品先例。

参数敏感度

参数调大会…调小会…
amplitude液面更汹涌;接近容器半径时波峰顶出裁剪圈趋近 2px 接近静水——合法但失去「活水」感
wavelength波峰稀疏,液面像整体倾斜;接近容器直径时只剩一个峰低于 80px 在小容器里毛躁;采样点数需求增大
duration注水更从容、过程感完整;超过 800ms 等待感上升低于 300ms 液位变化读不出过程,接近直切
deepLevel深档更满;95% 时波峰贴圈沿,注意余量深浅两档差距缩小,「深度」叙事变弱;低于浅档则叙事颠倒
shallowLevel浅档变满,深浅差距缩小更空;5% 时容器近乎见底,适合「待充填」隐喻

经验区间:A = 容器直径 1/8–1/12、λ = 容器宽度 1/2–2/3、时长 400–600ms、深浅两档差 ≥ 30%;频率比守 1:1.618 这类不可通约比,整数比会让波形周期性自我重复。

适用场景 4
  • 主题档位指示:液面高度表达当前主题「深浅」(深色=深水、浅色=浅水),切换时注水/排水(调研 §8 候扩 5)
  • 容量/余量类量值指示:水箱、储能、内存、配额——量是空间隐喻,不是任务完成度(与 progress-motion 互补)
  • 品牌性加载/注水瞬间:上传、导入、冲泡类叙事的进度表达
  • 文字注水变体:以文本裁剪替代圆环(先例 Water-Wave-Text-Animation 技法),标题随液位上升被『灌满』
何时不要用 4
  • 任务完成度指示用液面——完成弧/百分比才是任务语义;液面表达的是『量』,两者混用会让用户把余量读成进度(motion/progress-motion 条目同族告诫)
  • reduced-motion 用户仍看波动液面——规格明确降级为静态液面高度;整屏/大件波动属前庭触发源(WCAG 2.3.3/C39)
  • 振幅接近容器半径仍不收——波峰会顶出裁剪圈或露出液面下的底;A 守在容器直径 1/8–1/12
  • 频率比取整数比(如 1:2)——叠加会周期性自我重复(拍效应消失);守 1:1.618 这类不可通约比(§2.6)
无障碍

液位数值由文字读数同步承载(本 demo 用 chip 实时显示当前液位),波形只是增强——液面高度不得是量值的唯一通道(HIG:Make motion optional)。主题状态由 data-fx-theme 与颜色承载。prefers-reduced-motion: reduce → 相位冻结、静态液面高度、液位瞬时落档(规格原文降级);波形是持续环境动画,页面隐藏时 rAF 自动暂停,不按帧率空转。高频切换遵守 HIG『高频交互避免加动效』:液位过渡可被再次点击中断并原子收尾,不排队。

浏览器支持

rAF + SVG path d 逐帧重算 + clipPath 裁剪,全浏览器可用,不依赖 startViewTransition、不依赖滤镜(S5 反证滤镜不能挂过渡伪元素,本条目不碰)。液面 path 是逐帧几何,不受 clip-path url() 不可插值限制(调研 20§1.2)。纯 CSS 通路(两条背景波形平移)也可行(先例仓库即此做法),但算术叠加双正弦(本条目)只能逐帧重算 path;波形相位是持续环境动画,rAF 在页面隐藏时自动暂停。

兼容回退

prefers-reduced-motion: reduce → 波形相位冻结,降级为静态液面高度(渲染一帧不动的波形,液位瞬时落到目标档,时长视作 0,data-fx-duration 同步为 0)——规格原文的降级路径。无 rAF/SVG 环境 → 显示静态水平线液面;液位数值同时由文字读数承载,信息不依赖动画(HIG:动效不得是重要信息的唯一通道)。与 progress-motion 条目的区别:液面高度是「量」的空间隐喻,完成弧是「进度」——量值类指示优先本条目,任务完成度优先完成弧。

来源 3

起源波数学核验自 Wikipedia《Dispersion (water waves)》:两列波长略异的正弦波叠加产生拍/波群——「主波+次波双正弦叠加、各自不同速度推进」的物理出处;设计上双波取不可通约的频率比 1:1.618 即近似真实水面(调研 20§2.6)。配方骨架同调研 §6.1:η(x,t) = A1·sin(k1x−ω1t) + A2·sin(k2x−ω2t+φ) 采样后连折线闭合,A1=8px、A2=3px(3/8 比例)、λ≈宽度/2 与 /3(2:3 比例)、角速比 1.618;以「液面高度」而非完成弧表达量值,与 motion/progress-motion 条目互补。纯 CSS 先例:coiger/fill-water-animation(22★)、codeaashu/Water-Wave-Text-Animation(20★,GitHub API 核实,星数低,标注为技法旁证)。
