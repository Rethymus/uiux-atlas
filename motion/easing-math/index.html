缓动函数数学 Easing Math

cubic bezier solver · Newton iteration · linear() sampling · parametric curve

缓动曲线的求解数学:cubic-bezier 是参数化三次曲线(浏览器用牛顿迭代由 x 反解 t),linear() 把曲线采样成折线数据(先钳制、再两点一线)——demo 画出曲线、迭代次数与采样误差。

关键点:

  • 两条曲线同一来源:精确曲线由 x(t),y(t) 直接画;折线由 n 段采样点连成——偏差就是「linear() 编译的代价」;
  • 当前时刻读数分两栏:bezier 模式牛顿迭代(t、轮数、y);linear 模式段内插值(段号、公式)——同一点两条路径可对账;
  • 时间滑杆 + 「回放」小点;prefers-reduced-motion 时回放禁用,滑杆照常。

样式与参数

三个参数(curve/segments/mode),数学零依赖。公式逐步(调研 14§6.1,算法逐字核对自 CSS Easing 2 规范):

① 参数化三次曲线(x、y 各一条,共享参数 t):

// P0=(0,0)、P3=(1,1) 固定;x1,x2 ∈[0,1](规范约束),y 可越界
const bez = (t, c1, c2) => {
  const u = 1 - t;
  return 3 * u * u * t * c1 + 3 * u * t * t * c2 + t * t * t;
};
// x(t)、y(t) 即 bez(t, x1, x2) 与 bez(t, y1, y2)

② 牛顿迭代:给定时间进度 p,反解参数 t(浏览器引擎同款思路):

const bezD = (t, c1, c2) => 3 * (1 - t) ** 2 * c1 + 6 * (1 - t) * t * (c2 - c1) + 3 * t * t * (1 - c2);
function solveT(p, x1, x2) {           // p = 时间进度
  let t = p;                            // 初值 t = x
  for (let i = 0; i < 8; i++) {         // 牛顿 8 轮(浏览器量级)
    const err = bez(t, x1, x2) - p;
    if (Math.abs(err) < 1e-6) return { t, iters: i };
    const d = bezD(t, x1, x2);
    if (Math.abs(d) < 1e-6) break;      // 垂直切线 → 二分兜底
    t = Math.min(1, Math.max(0, t - err / d));
  }
  let lo = 0, hi = 1;                   // 二分兜底
  for (let i = 0; i < 24; i++) {
    const mid = (lo + hi) / 2;
    (bez(mid, x1, x2) < p ? (lo = mid) : (hi = mid));
  }
  return { t: (lo + hi) / 2, iters: 8 };
}
const progress = (p, x1, y1, x2, y2) => bez(solveT(p, x1, x2).t, y1, y2);

③ linear() 采样与求值(规范 §2.1.4:先钳制,再两点一线):

const sampleLinear = (n, x1, y1, x2, y2) =>
  Array.from({ length: n + 1 }, (_, i) => {
    const t = i / n;
    return [bez(t, x1, x2), bez(t, y1, y2)];   // (x(tᵢ), y(tᵢ)) 二元组——采样的是坐标对,不是 t 本身
  });
const evalLinear = (pts, p) => {
  p = Math.min(1, Math.max(0, p));              // 规范要求先钳制
  let i = 0;
  while (i < pts.length - 2 && pts[i + 1][0] <= p) i++;
  const [ax, ay] = pts[i], [bx, by] = pts[i + 1];
  return bx === ax ? by : ay + ((p - ax) / (bx - ax)) * (by - ay);
};

数值出处:默认 (0,0,0.58,1) = CSS ease-out 关键字的规范固定控制点;关键字四条 ease(0.25,0.1,0.25,1)/ease-in(0.42,0,1,1)/ease-out(0,0,0.58,1)/ease-in-out(0.42,0,0.58,1) 同出自 CSS Easing 2;linear(0.1, 0.3 50%, 1) 的「未定位点均摊」规则亦为规范条文(调研 14§6.1)。

动效与交互

  • 拖时间滑杆:当前点沿曲线滑动,两条求值路径的读数同步——牛顿的 t 与 linear() 的段插值在同一时刻几乎重合(偏差读数给出差距);
  • 切 mode:bezier 模式读「几轮收敛」(典型 2–5 轮),linear 模式读「落在第几段」——同一曲线的两种求值观感;
  • 调 segments:从 12 降到 2,折线逐渐偏离精确曲线,偏差读数上蹿——「采样是精度换体积」的直观交易;曲线带过冲(如 ease-in-back 风格)时低段数直接削平回弹;
  • 回放:小点按 1s 时长跑一遍;prefers-reduced-motion 时禁用回放按钮,滑杆与读数不受影响。

真实产品案例

  • 浏览器引擎的 cubic-bezier 求值:CSS Easing 2 把「由输入进度反解 t」写成 normative 算法,WebKit/Blink 的 UnitBezier 实现正是牛顿(或近似)迭代——所有 CSS transition/animation 的缓动都过这一遍求解;
  • CSS 关键字缓动:ease/ease-in/ease-out/ease-in-out 是规范里写死的四组控制点——「ease-out=(0,0,0.58,1)」是数值,不是感觉;本站 cubic-bezier 条目的参数面板就是它们的可调版;
  • linear() 编译管线(linear-easing 条目):把弹簧物理按固定步长采样成 linear(...) 关键帧数组,浏览器端零运行时插值——「曲线是数据不是函数库」的生产化,Baseline 2023-12。

公式的量纲与边界

变量量纲取值边界退化情形
x1, x2无单位(时间轴份额)必须 ∈[0,1](规范硬约束,CSS 拒绝越界声明)x1=0/x2=1 产生端点垂直切线,牛顿导数为 0 → 二分兜底
y1, y2无单位(输出轴份额)可越界 0,1y 越界曲线不能用于位置映射(会越过目标);opacity/color 可用(过冲即闪烁)
t(参数)无单位[0,1];是曲线参数不是时间t 与时间进度只在 (0,0)↔(1,1) 直线时相等——「参数 ≠ 时间」是本条核心
p(时间进度)无单位[0,1],linear() 求值先钳制(规范)bezier 端点外规范按平切处理(p<0 → 0 段切线,实现常直接钳制)
牛顿轮数无单位整数≤8(参考实现);典型 2–5初值 t=x 对常见曲线收敛;垂直切线触发二分(24 轮封顶)
采样段数 n无单位整数2–12(demo);量产 60–120(linear-easing)n=1 退化为单段直线;过冲曲线 n<6 削平回弹形状
linear() 未定位点无单位未标 input 的点在前后锚点间线性均摊linear(0.1, 0.3 50%, 1):0.3 定位在 50%,其余按等分(规范 §2.1.2)
采样偏差无单位随 n 指数下降;读数条实时给出偏差非均匀:曲率大处(端点、过冲峰)偏差集中——段数按最坏处预算

经验口径:参数 ≠ 时间,求值必经反解;编译 linear() 采样 (x,y) 对、钳制在求值端;过冲曲线只给 transform/opacity 用。姊妹条目:cubic-bezier(曲线的 CSS 形态与手调)、linear-easing(采样编译的完整管线)、handoff-curves(进出曲线对的设计层)、spring-integrator(弹簧的另一半数学:数值积分)。

适用场景 4
  • 缓动曲线采样编译:把任意 bezier/弹簧采样成 linear() 关键帧数组(linear-easing 的上游数学)
  • 自研动效引擎的进度求值:给定真实流逝时间,牛顿迭代反解曲线参数
  • 设计工具的曲线编辑器:拖控制点实时重绘 + 求解预览
  • 教学与评审:展示『ease-out 到底快在哪』——曲线斜率随时可见
何时不要用 4
  • x 控制点越界 [0,1]——规范直接判非法(CSS 校验拒绝该声明)
  • 用时间均匀采样参数 t 编译 linear()——应采样 (x(t),y(t)) 二元组,否则时间轴错位
  • 低段数(2–3)硬拟合带过冲的曲线——回弹形状直接丢失;过冲至少 6 段起
  • 把 y 越界(过冲)曲线用于滚动/拖拽位置映射——位置类插值越界会超出容器或越过目标
无障碍

缓动本身是纯映射,但输出端必须遵守 prefers-reduced-motion(整段动画跳过或直落终态,而非仅换缓动);y 越界的过冲曲线在长距离位移上放大前庭刺激——reduced-motion 用户与大规模移动场景优先线性/淡出;缓动选择不改变动画时长语义,读屏用户依赖的是时长与中断性,不是曲线形状。

浏览器支持

cubic-bezier 全 evergreen(CSS Transitions Level 1 起即是基础特性);linear() 自 2023-12 起全 evergreen(Chrome 113、Safari 17.2、Firefox 112,Baseline 2023-12,linear-easing 条目核验口径)。牛顿求解是浏览器内部的实现细节,JS 复刻仅用于教学与采样编译。

兼容回退

linear() 不支持时回退到最接近的关键字缓动或 cubic-bezier(损耗:自定义折线形状丢失);牛顿迭代不收敛(垂直切线等退化)时回退二分法——参考实现 Newton 8 轮 + 二分兜底,任何合法曲线都收敛。

来源 3

起源参数化形式与求值算法取自 CSS Easing Level 2 规范(css-easing-2:cubic-bezier easing 创建/求值算法,调研抓取规范原文;linear() 求值算法逐字提取自 §2.1.2/§2.1.4:输入进度先钳制到 [0,1],A.x=B.x 时直接返回 B.y);四条关键字缓动(ease/ease-in/ease-out/ease-in-out)为同规范定义的固定控制点;『弹簧→linear() 采样编译』的工程模式见 linear-easing 条目(调研 14§6.1)。
