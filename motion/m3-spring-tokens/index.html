M3 弹簧令牌 M3 Spring Tokens

Material 3 弹簧 token · MotionScheme · spring composite tokens

M3 Expressive 的 motion physics 系统:scheme(expressive/standard)× speed(fast/default/slow)× type(spatial/effects) 共 12 枚 spring composite token,官方同步给出 Web 端 cubic-bezier 换算曲线与时长。

Material 3 ★★★
实例演示 官方默认
参数
动效▾
schemeexpressive

MotionScheme 预设(官方两套):expressive=空间弹簧过冲带回弹、整体更张扬(M3 Expressive 主打);standard=低回弹偏功能(调研 02§B1)。选 scheme 即整体切换 12 枚 token 的曲线与时长。

speeddefault

速度分档,同时决定官方换算曲线的时长与 Compose 弹簧的 stiffness:fast 150–350ms / default 200–500ms / slow 300–750ms(随 type 不同,调研 02§B2);Compose 侧 fast=高 stiffness、slow=低 stiffness(调研 02§B3)。

typespatial

spatial=空间弹簧,用于位移/尺寸等空间属性(曲线可过冲、y>1);effects=效果弹簧,用于颜色/透明度等状态反馈(damping=1.0 临界阻尼无过冲、时长更短,调研 02§B2/B3)。

代码拆解

结构与 DOM

演示是「动画 + 读数」一体的小工作台:一颗芯片沿轨道位移(消费当前 token 的 Web 换算曲线与时长),右侧 SVG 画出同一条曲线并带同步示踪点,下方读数条并列展示 Web 曲线/时长与 Compose 侧 damping/stiffness。核心 DOM:

<div class="m3-track"><div class="m3-chip"></div></div>
<svg viewBox="0 -40 100 180">
  <path class="m3-curve" d="M 0 100 C …" />          <!-- 当前 token 曲线 -->
  <g class="m3-dot-x"><circle class="m3-dot-y" /></g> <!-- 外层线性X + 内层贝塞尔Y -->
</svg>
<dl class="m3-readout">cubic-bezier / duration / damping / stiffness</dl>

关键点:

  • 三个参数都是 JS 型枚举,demo 订阅 store 后查 12 枚 token 表,把「曲线 + 时长」喂给动画——切换即换动画,没有过渡态;
  • Compose 的 damping/stiffness 是并排参照而非驱动源:同一枚 token 在 Android 上是物理弹簧、在 Web 上是官方换算曲线,两套数值来自两份官方材料。

样式与参数

Web 端消费方式就是把官方换算写进普通 CSS:

.m3-chip {
  animation: m3-run var(--m3-dur) cubic-bezier(var(--m3-curve)) both;
}
@keyframes m3-run {
  from { transform: translateX(0); }
  to   { transform: translateX(var(--m3-dist)); }
}

12 枚 token 的官方数值(曲线为 Web cubic-bezier 换算,时长为 ms;demo 内置同表,出处 m3.material.io/styles/motion/overview/specs,调研 02§B2):

Token曲线时长
Expressive fast spatial(0.42, 1.67, 0.21, 0.90)350ms
Expressive default spatial(0.38, 1.21, 0.22, 1.00)500ms
Expressive slow spatial(0.39, 1.29, 0.35, 0.98)650ms
Expressive fast/default/slow effects(0.31, 0.94, 0.34, 1) / (0.34, 0.80, 0.34, 1) / (0.34, 0.88, 0.34, 1)150/200/300ms
Standard fast/default spatial(0.27, 1.06, 0.18, 1.00)350/500/750ms
Standard fast/default/slow effects同 Expressive effects 三枚曲线150/200/300ms

Compose MotionScheme 侧的 damping/stiffness(官方 androidx 源码 ExpressiveMotionTokens.kt / StandardMotionTokens.kt,调研 02§B3):Expressive spatial default 0.8/380、fast 0.6/800、slow 0.8/200;Expressive effects 1.0/1600(default)、1.0/3800(fast)、1.0/800(slow);Standard spatial 0.9/700、0.9/1400、0.9/300;Standard effects 1.0/1600、1.0/3800、1.0/800。

如实标注:Standard spatial 在官方表中以同一曲线行覆盖(fast/default 列出、slow 时长 750ms 在同一行),调研未捕获 slow spatial 的独立曲线;demo 对 standard+slow+spatial 沿用 (0.27, 1.06, 0.18, 1.00) 配 750ms,并在读数条注明。Expressive emphasized easing 在旧体系无 CSS 等价贝塞尔(官方标注 N/A,Standard 兜底,调研 04§1.4)——本条目用的是被官方取代旧体系后的新 spring 换算表,不受该限制。

动效与交互

  • 切换即换动画:任一枚枚举改动,element.animate() 以新曲线/时长立即重跑一次——没有残留的旧动画(先 controls.cancel());
  • 曲线可视化:示踪点与芯片共享曲线形状,y>1 的过冲在预览中直观可见(expressive spatial 的 (0.42, 1.67, …) 起步即冲出);
  • 读数对齐:读数条显示 token 全名(如 Expressive fast spatial)、cubic-bezier、时长、Compose damping/stiffness——参数轴与数值轴一一对应;
  • 重播:点轨道或「重播」重跑当前 token;
  • reduced-motion:跳过动画直出终态,读数照常;
  • 性能:芯片只动 transform。

参数敏感度

参数调大会…调小会…
schemeexpressive:曲线带过冲(y1 最高 1.67)、动效张扬,spatial 弹簧低 stiffness(380)更「弹」standard:曲线过冲收敛(y1=1.06)、更克制,spatial 弹簧高 stiffness(700/1400/300)更「利落」
speedslow:时长升到 300–750ms,Compose stiffness 降到 200–800,适合大面积少频次转场fast:压到 150–350ms,stiffness 升到 800–3800,适合小控件即时反馈;default 居中
typespatial:允许过冲、时长更长,服务位移/尺寸effects:damping=1.0 临界阻尼无过冲、时长更短,服务颜色/透明度等状态反馈
组合整感三枚全 expressive+slow = 最具表达力的大面积转场,500–750ms三枚全 standard+fast = 最克制的快速反馈,150–350ms

选型口诀:空间属性走 spatial(可过冲),状态反馈走 effects(不过冲);面积大/频次低升 speed 档,小控件一律 fast;Web 交付直接抄官方换算表,不要手拟合曲线。

适用场景 4
  • 需要 M3 Expressive 风格的位移类转场:FAB 展开、卡片变换等空间属性动画(spatial)
  • 状态反馈类动画(选中、颜色淡入)用 effects 档:临界阻尼、150–300ms,快而不弹
  • 跨端统一手感:Web 用官方 cubic-bezier 换算,Android 用 Compose MotionScheme 同名 token
  • 从 Material 迁移到 Web 端组件库时,以本表的曲线+时长为交付参数
何时不要用 4
  • spatial 曲线(y>1 过冲)用在连续量(进度条、滚动同步)——过冲属装饰性位移
  • 把 expressive/standard 当作新旧体系之分——两者是并行 MotionScheme,旧 easing+duration 体系才是被替代项(调研 02§B1/B4)
  • 同屏高频操作全用 slow 档——slow 300–750ms 只适合大面积、少频次转场(M3 时长准则,调研 04§1.4)
  • 自行拼接贝塞尔冒充官方 token——数值必须逐枚取官方表(调研 02§B2),不得沿用社区流传的 M2 曲线
无障碍

spatial 档的过冲属位移类动效,须响应 prefers-reduced-motion 直出终态(demo 已内建);effects 档时长短且临界阻尼,风险较低但仍建议一并降级;动效不作关键信息唯一渠道(HIG/M3 一致原则)。

浏览器支持

Web 端消费的是官方给出的 cubic-bezier 换算——普通 CSS animation/transition,全浏览器可用,无新特性依赖;原生物理弹簧在 Compose(Android)侧实现。demo 用 CSS 曲线 + WAAPI 复现,极旧环境(无 Web Animations API)直出终态。

兼容回退

prefers-reduced-motion 时直出终态(demo 跳过 element.animate);不支持 Web Animations API 的环境同样直出终态——token 的信息(曲线/时长数值)始终以文本读数呈现,不依赖动画。

来源 3

起源M3 官方 motion physics 系统以 spring(stiffness/damping/mass)替代旧 easing+duration 体系,提供 expressive/standard 两套 MotionScheme 预设(调研 02§B1);12 枚 composite token 的 Web cubic-bezier 换算表取自 m3.material.io/styles/motion/overview/specs(调研 02§B2);Compose MotionScheme 的 damping/stiffness 实现数值取自 androidx 官方源码(调研 02§B3)。
