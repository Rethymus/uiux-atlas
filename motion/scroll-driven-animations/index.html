滚动驱动动画 Scroll-driven Animations

滚动驱动动画 · animation-timeline · scroll()/view()

animation-timeline: scroll()/view() 把动画进度交给滚动位置或元素可见进度:阅读进度条、reveal 揭示、视差图层都能离开主线程运行(Chrome 官方指南)。

Web 标准 ★★★
实例演示 官方默认
参数
动效▾
timelineview()

时间轴类型:scroll()=以滚动容器的滚动进度(0–100%)为时间轴,进度条/视差的教科书用例;view()=以元素自身在滚动容器内的可见进度为时间轴(类似 IntersectionObserver),reveal 卡片用它。注意:entry/exit/contain 等 named range 仅对 view progress timeline 有定义(MDN animation-range),demo 在 scroll() 模式下把 entry/exit 档按 cover 全程处理并注明。

rangeStartentry 25%

animation-range 起点:named range + 偏移百分比组合(官方取值档 cover/entry/exit/contain,Chrome 指南与 MDN,调研 04§4)。默认 entry 25% = Chrome 官方 Reveal 示例起点:元素进入视口 25% 处才开始动画。

rangeEndcover 50%

animation-range 终点。默认 cover 50% = 官方 Reveal 示例终点:滚至元素覆盖视口 50% 时动画完成。终点早于起点的组合行为依实现而定,应避免。range 名义档可视化见官方工具 goo.gle/view-timeline-range-tool(调研 04§4)。

代码拆解

结构与 DOM

演示是一个内部滚动容器,三件套:顶栏阅读进度条(sticky,固定消费 scroll())、中段 reveal 卡片(消费参数)、上下垫高的占位内容。DOM:

<div class="sd-scroller" tabindex="0">        <!-- overflow-y: auto,最近的滚动容器 -->
  <div class="sd-progress"><div class="sd-bar"></div></div>  <!-- sticky 顶栏 -->
  <p class="sd-spacer">…垫高内容…</p>
  <div class="sd-card">Reveal 卡片</div>       <!-- timeline/range 参数作用于此 -->
  <p class="sd-spacer">…垫高内容…</p>
</div>

关键点:

  • scroll() 取最近的滚动容器祖先(即 .sd-scroller),进度条 sticky 在其顶部,滚动整条可见;
  • view() 以卡片自身在滚动口内的可见进度为时间轴——同一容器内两颗时间轴并存,各管各的;
  • 卡片是普通文档流元素,不附加 JS 监听——这正是声明式滚动驱动动画的意义(替代 scroll 事件手写逻辑,可在主线程外运行,调研 04§4)。

样式与参数

三个参数全部经 --sd-* CSS 变量注入:

/* 进度条:固定 scroll(),官方示例做法(scaleX 而非 width,走合成器) */
.sd-bar {
  transform: scaleX(0);
  transform-origin: 0 50%;
  animation: sd-grow linear both;
  animation-timeline: scroll();   /* 最近的滚动容器 */
  animation-duration: auto;
}
/* reveal 卡片:timeline/range 两个参数在这里生效 */
@supports (animation-timeline: view()) {
  .sd-card {
    animation: sd-reveal linear both;
    animation-duration: auto;
    animation-timeline: var(--sd-timeline);   /* scroll() / view() */
    animation-range: var(--sd-range-start) var(--sd-range-end);
  }
}
@keyframes sd-reveal {
  from { opacity: 0; transform: translateY(28px); }
  to   { opacity: 1; transform: none; }
}

数值出处:默认 entry 25% cover 50% 逐字取 Chrome 官方 Reveal 示例(调研 04§4:『图片进入视口 25% 处开始、滚过视口 50% 时完成』);进度条 scaleX(0→1) 同样是官方示例配方;animation-timeline 必须写在 animation 简写之后(不在简写内,调研 04§4)。named range 档位(cover/entry/exit/contain + 偏移百分比)的语义见 MDN animation-range——entry/exit/contain 只对 view progress timeline 有定义,所以 demo 在 scroll() 模式下把 entry/exit 档显式替换为 cover 全程,并在界面注明这一替换。

动效与交互

  • 进度条:随容器滚动 0→100%,官方教科书用例;不支持的环境呈静态底条;
  • reveal 卡片:timeline 切 view()/scroll() 会立刻改变「进度」的含义——view() 看卡片自身可见度,scroll() 看整条容器滚动;range 起止档变化同样即时生效(滚动位置不变、动画映射变了);
  • scroll() 模式的替换:entry/exit 档被换成 cover 0%→100% 全程,读数条显示「实际生效值」与替换原因;contain 同样只适用 view 时间轴,一并替换;
  • 键盘与按钮:滚动容器可聚焦,方向键滚动;「滚到卡片 / 回顶部」按钮调 scrollTo(reduced-motion 时用 auto 行为直跳);
  • 双降级:@supports 不通过 → 卡片静态可见;prefers-reduced-motion: reduce → 取消 reveal(始终可见),进度条保留(滚动位置的信息映射,非装饰)。

参数敏感度

参数调大会…调小会…
timelinescroll():进度=整条容器滚动比例,卡片提前/延后与滚动总量挂钩,entry/exit 失效view():进度=卡片自身进出滚动口的过程,range 语义围绕元素几何;默认档即官方 reveal 场景
rangeStartentry 档百分比越大,动画开始越晚(元素要进入更深才开始);contain 档 = 元素完全含于视口才开始entry 0% = 刚冒头就开始;cover 0% = 时间轴全程起点(从容器顶就开始算)
rangeEndcover/exit 档百分比越大,完成得越晚(如 cover 100% 要滚过整个视口才收尾)cover 50% = 官方默认,半程即完成;终点早于起点时行为依实现而定,应避免
组合节奏起点晚 + 终点晚 = 「深滚出」的长程揭示;适合大图/长卡起点早 + 终点早 = 「刚冒头就到位」的短促揭示;适合小卡片

经验区间:reveal 常用 entry 10%–30% 起、cover 40%–60% 收(官方示例 25%/50% 居中);进度条固定 cover 全程(scroll() 的 cover 即整条时间轴)。内容优先:凡 reveal 会隐藏的东西,两套降级都必须先就位。

适用场景 4
  • 阅读进度条:顶栏 scaleX(scroll() 官方示例,调研 04§4)——transform 走合成器
  • 图片/卡片进入视口的 reveal 揭示(view() + animation-range,官方示例 entry 25% cover 50%)
  • 视差图层:前景/背景挂不同 timeline/range(官方列出的典型用例,调研 04§4)
  • 替代 scroll 事件 + IntersectionObserver 的手写进度逻辑——声明式、可在主线程外运行(调研 04§4)
何时不要用 4
  • 把 entry/exit 档配到 scroll() 时间轴——这些 named range 只对 view progress timeline 有定义(MDN)
  • 把会隐藏内容的 reveal 用在关键信息上——不支持动画的浏览器/reduced-motion 用户必须仍能读到内容
  • 在 animation 简写内内联 animation-timeline——该属性不在简写里,须在简写之后单独声明(调研 04§4)
  • 用 width 驱动进度条——用 transform: scaleX 才能留在合成器(官方示例做法,调研 04§4)
无障碍

滚动驱动动画锁在滚动位置上、不随时间自动播放,对前庭刺激低于时长型动画;但内容隐藏型 reveal 必须双降级:reduced-motion 时始终可见、不支持时始终可见(内容由 reveal 揭示 ≠ 内容依赖动画才存在);进度条保留——它是滚动位置的信息映射;键盘用户用 Tab 聚焦滚动区后可用方向键滚动(demo 已支持)。

浏览器支持

animation-timeline:Chrome/Edge 115+、Firefox 159+、Safari 26(mdn/browser-compat-data 2026-11 实测,调研 02§D6);Chrome 官方文章快照(调研 04§4)只确证了 Chrome/Edge 115+,Firefox/Safari 现状以调研 02 的 BCD 数据为准。animation-range 在 MDN 标注 Limited availability(非 Baseline)。demo 以 @supports 检测并静态兜底。 · Limited availability (Chrome 115+ / Firefox 159+ / Safari 26; not yet Baseline)

兼容回退

@supports (animation-timeline: view()) 不通过时,卡片直接可见、进度条呈静态——内容永远不被动画藏起来;reduced-motion 时取消卡片揭示动画(始终可见),保留进度条:它反映滚动位置,是信息而非装饰。scroll() 模式下 entry/exit 档被显式替换为 cover 全程(见 timeline 参数)。
