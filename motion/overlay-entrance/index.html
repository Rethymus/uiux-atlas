浮层入场 Overlay Entrance

弹层入场 · zoom-in-95 · popover animation · dialog entrance

浮层从触发钮弹入的事实标准:初态 scale 0.95 + opacity 0(+ 方向性位移 8px),200ms 到位,transform-origin 交给锚点方向;关闭永远比打开快。

组件库 ★★★
实例演示 官方默认
参数
几何▾
initialScale0.95

入场初态缩放。默认 0.95 = shadcn `zoom-in-95` 事实标准(调研 10§3.1)。调大趋近 1 则只剩淡入、空间感消失;调小(≤0.9)『从深处长出来』的戏剧感增强,但位移距离变大、更容易闪。超过 1(如 1.02)配合过冲曲线可做轻微 overshoot。

shiftY8px
px

方向性入场位移。默认 8px = shadcn Popover `slide-in-from-bottom-2`(Tailwind 2 格 = 8px)同构(调研 10§3.1)。0 = 纯 zoom+fade(radix Dialog 语义);调大则方向感更强,超过 12px 开始抢内容的注意力。

inDuration200ms
ms

入场时长。默认 200ms = shadcn Dialog `duration-200`;调到 500ms 即 Sheet 档(入 500ms,调研 10§3.1)。调大更隆重但等得久;调小到 100ms 以下接近瞬开,入场感消失。

outDuration150ms
ms

退场时长。默认 150ms = 调研 10§3.3 Motion 版出场(『出快入慢』);shadcn Sheet 官方不对称是入 500ms/出 300ms(调研 10§3.1)。退场必须短于入场——用户在等的是『离开』(调研 10 巧思 7)。

动效▾
curvestandard

入场缓动(CSS 变量 --overlay-ease)。standard=`cubic-bezier(0.4,0,0.2,1)`(调研 10§3.3 CSS 版);overshoot=`cubic-bezier(.21,1.02,.73,1)`,y₂>1 产生轻微过冲(react-hot-toast 同款);arco=`cubic-bezier(0.3,1.3,0.3,1)`(Arco 全局过冲 token)。过冲档与 initialScale>1 组合才明显。

代码拆解

结构与 DOM

浮层 = 触发钮 + 面板两层;面板常驻 DOM,用 data-open 驱动进/出场(shadcn/radix 语义是 data-[state=open] 状态类,同构):

<button class="ov-trigger" aria-expanded="false">打开浮层</button>
<div class="ov-panel" data-open="false" role="dialog" aria-hidden="true" tabindex="-1">
  <h4>浮层</h4>
  <button class="ov-item">条目一</button>
</div>

关键点:

  • 面板是触发钮的兄弟层(绝对定位),transform-origin 按锚点方向写(触发钮在下方 → origin: bottom)——Radix 官方做法是由库写 --radix-popover-content-transform-origin,标准替代就是按方向手写(调研 10§3.1/巧思 5);
  • 打开/关闭是两条不同时长的编排:入走 keyframes both,出走反向 keyframes,animationend 语义天然覆盖;
  • 无障碍三件套:aria-expanded(触发钮)、role="dialog"+aria-hidden(面板)、焦点打开入面板/关闭归还触发钮;Esc 与点击外部均为关闭路径(WAI-APG Dialog 模式)。

样式与参数

五个参数全部是 CSS 变量型,经 --overlay-* 注入后被 keyframes 直接消费:

.ov-panel {
  opacity: 0;
  transform: translateY(var(--overlay-shift)) scale(var(--overlay-scale));
  transform-origin: var(--tf-origin, bottom);
}
.ov-panel[data-open="true"]  { animation: ov-in var(--overlay-in-ms) var(--overlay-ease) both; }
.ov-panel[data-open="false"] { animation: ov-out var(--overlay-out-ms) cubic-bezier(0.4, 0, 1, 1) both; }

@keyframes ov-in  { from { opacity: 0; transform: translateY(var(--overlay-shift)) scale(var(--overlay-scale)); }
                    to   { opacity: 1; transform: translateY(0) scale(1); } }
@keyframes ov-out { from { opacity: 1; transform: scale(1); }
                    to   { opacity: 0; transform: scale(var(--overlay-scale)); } }

数值出处(调研 10§3.1/§3.2/§3.3,均为源码逐字核验):

  • scale(0.95) + opacity 0 + 200ms = shadcn Dialog zoom-in-95 + fade-in-0 … duration-200;
  • 方向性位移 8px = shadcn Popover slide-in-from-bottom-2(Tailwind 2 格 = 8px);
  • 进慢出快:shadcn Sheet 官方 data-[state=open]:duration-500(入)/data-[state=closed]:duration-300(出);demo 默认出 150ms 取调研 10§3.3 Motion 版;
  • 过冲曲线:cubic-bezier(.21,1.02,.73,1)(react-hot-toast 入场,y₂>1 轻微过冲)、Arco 过冲 token cubic-bezier(0.3, 1.3, 0.3, 1);standard 档 cubic-bezier(0.4, 0, 0.2, 1) 取调研 10§3.3 CSS 版;
  • M3 emphasized easing 的具体数值调研未证实(m2/m3.material.io 正文 JS 渲染未抓到),如需 M3 档用 standard 兜底(调研 10§3.2)。

动效与交互

  • 入场编排:fade + zoom-95 + 方向位移同帧起跑;origin 在锚点侧,缩放「从触发钮长出来」而不是从屏幕中心;
  • 出场永远更快:150ms 缓出(cubic-bezier(0.4, 0, 1, 1) 加速曲线)——「关闭永远比打开果断,用户在等的是离开」(调研 10 巧思 7;shadcn Sheet 500/300 与 M3 enter>exit 双源一致);
  • 点击外部关闭:document 级 pointerdown,目标不在面板/触发钮内即关;Esc 关闭同步监听;
  • 焦点管理:打开 → panel.focus()(tabIndex=-1),关闭 → 归还触发钮;
  • reduced-motion:取消位移/缩放,以 80ms 纯 fade 出现(位移类动画是前庭障碍触发源,调研 04§6.1);
  • 性能:入场只动 opacity/transform(合成器属性),web.dev 底线(调研 10§7.1)。

真实产品案例

  • shadcn/ui Dialog / Popover:zoom-95+fade 200ms、Popover 附 8px 方向位移与 Radix 变量 origin——Web 浮层入场的事实标准,源码逐字(调研 10§3.1);
  • GitHub 站内下拉菜单/Popover:打开快、关闭更快,菜单从触发点方向缩放展开(与 radix 同族交互语义;具体数值 GitHub 未公开,未证实);
  • Linear / Vercel 仪表盘的菜单气泡:轻浮层普遍带轻微过冲的入场(bezier y₂>1 一族),与 react-hot-toast 过冲曲线同构(曲线本身有源码出处,Linear/Vercel 的具体实现数值未证实)。

参数敏感度

参数调大会…调小会…
initialScale趋近 1 时只剩淡入,空间归属感消失;>1 配过冲曲线可做 overshoot 弹入戏剧感增强;≤0.85 位移过大易闪,模态场景明显
shiftY方向感更强,「从按钮长出来」更明确;>12px 开始抢注意力0 退化为纯 zoom+fade(radix Dialog 语义),方向信息丢失
inDuration更隆重;400ms+ 开始让人等待,适合 sheet 级大浮层瞬开感;≤100ms 入场退化为闪烁
outDuration关闭变拖沓,超过入场时长违反「进慢出快」更果断;趋近 0 时像「消失」,可接受但不留余韵
curveovershoot/arco 档带轻微过冲,轻浮层更「弹」;配 initialScale>1 更明显standard 档克制标准,模态/信息型浮层首选

经验区间:initialScale 0.95、shiftY 8px、入 200ms、出 150ms(shadcn 系);sheet 类入 500/出 300。所有浮层入场都应回答一个问题:它是从哪长出来的——origin 与位移方向就是答案。

适用场景 4
  • tooltip/popover/menu:zoom-95 + fade 200ms + 锚点侧 8px 位移 + 锚点方向 origin——radix 事实标准全套(调研 10§3.1/巧思 5)
  • 模态对话框:同款入场,配 overlay 遮罩 fade;关闭走更快的退场(150~300ms)
  • 需要『弹』的轻浮层(菜单气泡、toast 同族):入场换过冲 bezier(.21,1.02,.73,1) 或真弹簧(bounce 0.2)
  • sheet/抽屉:入 500ms、出 300ms 的官方不对称档(进慢出快,调研 10§3.1)
何时不要用 4
  • transform-origin 恒为屏幕中心——缩放会『从屏幕中心长大』,与触发钮脱钩;origin 必须交给锚点方向(调研 10 巧思 5)
  • 入场比退场还慢——关闭永远比打开果断,用户在等的是『离开』(shadcn Sheet 500/300 与 M3 enter>exit 双源一致)
  • 大位移入场(>16px)或 initialScale ≤0.85——位移过冲视觉噪声,模态场景尤其闪
  • 只做入场不做退场编排——AnimatePresence/animationend 未处理时关闭会闪跳或残留 DOM
无障碍

浮层打开时焦点移入内容、关闭后归还触发钮(Esc 与点击外部均为标准关闭路径,WAI-APG Dialog/Popover 语义);入场动画只是方向提示——位置与归属关系必须同时由位置本身表达;prefers-reduced-motion 时纯 fade 出现;动画期间内容立即可交互,不得被入场动画锁住(动效可中断,HIG Motion)。

浏览器支持

实现只用 transition/transform/opacity、`data-open` 属性切换与 `transform-origin`,均为 Baseline;Radix 的 `--radix-*-transform-origin` 变量是库行为,标准替代是按锚点方向手写 origin(demo 即如此)。focus trap 用原生 focus 事件实现。

兼容回退

prefers-reduced-motion 时取消位移/缩放,浮层直接以纯 fade(或瞬时)出现;浮层的可发现性不得依赖入场动画——Esc 关闭、点击外部关闭、焦点进入/归还是必须保留的交互路径(WAI-APG Dialog 模式);不支持 transform-origin 的旧环境退化为中心缩放。
