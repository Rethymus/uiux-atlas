卡槽弹簧(竹简槽) Slot Spring (Segmented)

分段滑块弹簧 · segmented control spring · layoutId pill · 竹简槽

分段控件里滑签沿固定槽位弹簧滑动:一只常驻气泡在 N 个卡位间物理位移(可中断、速度接力),把 iOS 分段控件指示器的滑动感搬进 Web。

Apple HIG ★★★
实例演示 官方默认
参数
几何▾
stiffness300

弹簧刚度 k(mass=1,ω₀=√k)。默认 300 取调研 10§2.3『中·微弹』档(分段控件默认推荐):ω₀≈17.3rad/s、t_peak≈262ms。Motion 源码默认 100(调研 10§6.3)。调大启动更猛、到达更快(过冲比例不变);调小更迟缓。

damping25

阻尼系数 c。默认 25 与刚度 300 配对得 ζ=0.722、过冲≈3.8%——『弹而不闹』区间(调研 10§2.3)。调大趋近临界(ζ→1 过冲消失);调小回弹增多,ζ<0.5 明显振荡。反例警示:`500/50` 这组社区流传参数其实过阻尼(ζ≈1.118)——抄参数前先算 ζ(调研 10§2.3)。

动效▾
segments4

JS 型参数(demo 订阅后重建槽位)。HIG 官方定性:分段控件段通常等宽,作为单一选择器使用,宽界面 ≤5–7 段、iPhone ≤5 段(调研 10§2.4);demo 封顶 5 段即按 iPhone 上限收敛。

代码拆解

结构与 DOM

「竹简槽」= 固定容器(rail)内 N 个等宽槽位 + 一只常驻滑签(pill)。事实范式是 Sam Selikoff 的 AnimatedTabs:只渲染一个气泡,槽位只是它的「家」,切换槽位 = 同一元素的物理位移(调研 10§2.1、签名巧思 2):

<div class="sl-rail" role="radiogroup" aria-label="分段控件">
  <div class="sl-pill"><!-- 常驻滑签,唯一动元素 --></div>
  <button role="radio" aria-checked="true">日</button>
  <button role="radio" aria-checked="false">周</button>
  <button role="radio" aria-checked="false">月</button>
  <button role="radio" aria-checked="false">年</button>
</div>

关键点:

  • 滑签绝对定位、只动 transform: translateX(demo 经 Motion 的 motion value 写入),槽位按钮是普通文档流;
  • 实现两条路:Motion layoutId(同一 layoutId 跨槽位,FLIP 布局动画自动接力,BuildUI 原版配方)或手写 transform 插槽弹簧(半隐式欧拉积分 a=(−k(x−to)−cv)/m、速度存 dataset 供中断接力,restDelta 与 Motion 源码对齐)(调研 10§2.1/§2.2);demo 取后者思路的 Motion 物理弹簧版;
  • ARIA 用 radiogroup/radio + aria-checked(单选器语义),方向键移动、点击选中。

样式与参数

三个参数全部为 JS 型,由 demo 组装 Motion 弹簧与槽位:

// 滑签弹簧:stiffness 300 / damping 25(mass 1)= 调研 10§2.3「中·微弹」档
animate(x, slotIndex * slotWidth, { type: "spring", stiffness: 300, damping: 25, mass: 1 });

// 阅读数值(本地实算,mass=1):ω₀=√k,ζ=c/(2√k)
const w0 = Math.sqrt(stiffness);            // 300 → 17.3 rad/s
const zeta = damping / (2 * w0);            // 25 → 0.722
const overshoot = zeta < 1
  ? Math.exp(-Math.PI * zeta / Math.sqrt(1 - zeta * zeta)) * 100  // 3.8%
  : 0;
const envelope5 = Math.log(20) / (zeta * w0) * 1000;             // 240ms

数值出处(调研 10§2.1/§2.3/§2.4):

  • BuildUI AnimatedTabs 官方配方:bounce 0.2 / duration 0.6(duration-based 弹簧),换算 ζ≈0.8、过冲≈1.5%——「弹得克制不闹腾」;
  • 推荐档位(本地 Python 实算,调研 10§2.3):快·稳 700/40(ζ0.756、过冲 2.7%、t_peak 181ms)、中·微弹 300/25(ζ0.722、3.8%、262ms)、慢·弹 200/15(ζ0.530、14.0%、262ms)、Motion 物理默认 100/10(ζ0.500、16.3%、362ms);
  • 反例:stiffness:500, damping:50 是过阻尼(ζ≈1.118)——零过冲,比微弹档更钝;抄参数前先算 ζ;
  • iOS 系统分段控件指示器滑动为弹簧动画,但 Apple 未公开其 stiffness/damping,未证实;工程上以「中·微弹」档作等感替代。

动效与交互

  • slot-to-slot 弹簧:点槽位 → 滑签以 type:"spring" 奔向该槽位中心;连续点击不同槽位,Motion 物理弹簧从当前位置+当前速度续接(文档原文语义),永不归零重启(调研 10§7.3);
  • 参数即改即看:拖动 stiffness/damping 滑杆立即以新参数重跑当前槽位;阅读条实时换算 ζ/过冲/包络→5%/t_peak,建立「数值↔手感」直觉;
  • 对照 iOS 分段控件:段等宽、单一选择器(不混动作触发)、iPhone ≤5 段——demo 封顶 5 段(HIG 官方定性,调研 10§2.4);
  • 键盘:radiogroup 上方向键/上下键移动选中段,aria-checked 同步;
  • reduced-motion:跳过弹簧,滑签直落目标槽位;选中态仍由 aria-checked + 文字对比承载;
  • 性能:只动 transform(滑签位移),合成器友好(调研 10§7.1)。

真实产品案例

  • BuildUI AnimatedTabs:上述范式的出处,layoutId + bounce 0.2/duration 0.6,圆角内联以获得 Motion 的 scale 校正(调研 10§2.1);
  • iOS 系统分段控件(日历/闹钟等):选中指示器弹簧滑动是公认系统行为,段等宽、iPhone ≤5 段符合 HIG;Apple 未公开动画参数,未证实(调研 10§2.4);
  • shadcn/ui Tabs:指示器思路同族——社区生态大量以「单滑块 + transform」实现激活指示器;shadcn 官方按钮/弹层源码中无按压缩放,浮层参数见 overlay-entrance 条目(调研 10§1.1/§3.1)。

参数敏感度

参数调大会…调小会…
stiffnessω₀↑:启动更猛、到达更快,同 ζ 下波次更密、过冲比例不变更迟缓黏滞;低于 100 时跨大槽位像「漂」过去
dampingζ↑ 趋近临界:过冲指数式消失,手感「稳」;≥ 过阻尼阈值(ζ≥1)后起步快收尾慢ζ↓ 回弹增多;≤0.5 明显振荡,0.3 以下像弹跳球
segments段多槽位窄,单格位移短、弹簧行程小,节奏更碎段少位移大,弹簧行程长、手感更「整」;5 段是 iPhone 上限(HIG)
阅读值(只读)过冲%/包络时间让你在拖滑杆时看到手感变化的数值对应同反向;对照表:ζ0.7→4.6%(弹而不闹)、ζ0.8→1.5%(克制)、ζ1→0(临界)

经验区间:分段控件默认推荐 300/25(ζ≈0.72,过冲<5%);要「快·稳」升到 700/40;要「竹简手感」降 200/15;任何组合先算 ζ,守住 0.7±0.1 是多数交互的甜点(调研 10§2.3/巧思 3)。

适用场景 4
  • 分段控件/标签页指示器:单气泡跨槽位滑动,300/25 起步,追求克制手感降到 700/40(快·稳档)
  • 强调『竹简手感』的场合:200/15(慢·弹档,过冲 14%),适合偶发操作的强调,不适合高频切换
  • 与 iOS 分段控件对照:等宽段 + 单一选择器语义 + 弹簧指示器;iPhone 上 ≤5 段(HIG)
  • 需要中断接力的滑动:点击新槽位时弹簧从当前位置+当前速度续接,不归零重启
何时不要用 4
  • iPhone 上超过 5 段或混入『动作触发』段——违反 HIG 分段控件规范(调研 10§2.4)
  • 照抄社区流传的 500/50 而不算 ζ——那是过阻尼假弹簧(ζ≈1.118),比微弹档更钝(调研 10§2.3)
  • 进度条/连续量用卡槽弹簧——指示器语义是离散槽位;连续量该走进度条(参考 motion-spring 条目同款告诫)
  • 每个槽位各自渲染选中背景再各自动画——应只养一个常驻气泡(单元素位移),否则槽位间会出现形变与跳变
无障碍

分段控件是单选器:demo 用 role=radiogroup + role=radio/aria-checked,方向键在段间移动、空格选中(WAI-APG Radio Group 语义);滑签动画只是选中态的视觉增强,选中信息同时由 aria-checked 与文字对比承载;prefers-reduced-motion 时直落目标槽位;动画不得作为传达选中变化的唯一手段(HIG Motion:动效可关闭)。

浏览器支持

demo 用 Motion(motion/react)驱动,依赖 JS 执行,禁用 JS 时滑签停在初始槽位;原生 layoutId 属 Motion 布局动画能力(Web 全支持,因实现是 JS 测量 + transform)。Spring 阅读数值(ζ/过冲/包络)由本地公式实算,与浏览器无关。

兼容回退

prefers-reduced-motion 时跳过弹簧,滑签直接落到目标槽位;分段选择本身绝不能只靠动画表达——选中态必须同时有可读的视觉状态(底色/文字色);reduced-motion 下读数条仍显示当前参数换算值。

来源 5

起源事实范式是 Sam Selikoff 的 AnimatedTabs:只渲染一个气泡、`layoutId` 相同,Motion 自动跨槽位做 FLIP 布局动画,官方配方 `bounce 0.2 / duration 0.6`(换算 ζ≈0.8、过冲≈1.5%)(调研 10§2.1);手写版与 Motion 源码同为半隐式欧拉积分 + restSpeed/restDelta 双阈值停机(调研 10§2.2/§6.3)。iOS 系统分段控件指示器滑动为弹簧动画,但 Apple 未公开其 stiffness/damping——未证实(调研 10§2.4)。
