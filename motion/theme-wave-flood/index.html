波浪涌入 Theme Wave Flood

wave surge · liquid theme flood · 波浪液面切换 · 液面上涨

新主题以双正弦叠加的起伏波浪液面整体涌入、覆盖旧主题:rAF 逐帧重写液面 path,波数 k=2π/λ 决定波峰密度,覆盖完成瞬间翻转 data-theme,500ms 整屏档完成。

几何▾
amplitude8px
px

主波振幅 A1。默认 8px 取调研 20§6.1 记录值(A1=8/A2=3);demo 以固定比例 A2=A1×3/8 叠加次波,合成波峰 = 两波同相叠加。调大波峰更高、「浪」感更强,超过 24px 后在小舞台/窄视口上显得夸张、逐帧 path 采样跨度也变大;调小趋近 0 时液面退化为直线边缘整体上移——失去液感,但仍是合法的降级形态。

wavelength240px
px

主波波长 λ,波数 k=2π/λ(rad/px),宽度 W 内可见完整波峰数 = W/λ。默认 240px 在实测 demo 舞台(约 840px 宽)上约为宽度的 1/3.5,略密于宽度/3 档;站点级 1440px 视口按调研 §6.1 取 720(屏宽/2)或 480(屏宽/3)。demo 以固定比例 λ2=λ1×2/3 叠加次波(§6.1 的 /2 与 /3 两档)。调大波峰稀疏、边缘趋近整体倾斜的「涌潮」,接近视口宽时只剩一个波峰;调小低于 120px 后毛刺感上升,采样点数需求随之增大。

duration500ms
ms

液面从起涨到完全覆盖的时长,即 demo 舞台 data-fx-duration 的实际值。默认 500ms = M3「按过渡面积定时长」的整屏/大容器档(调研 20§5);更长的总时长属多段编排范畴(M3 允许进入段更长以聚焦新内容,§6.6 四阶段即 700ms)。调大更从容但等待感上升,超过 800ms 与 HIG「高频交互不加动效」相抵触;调小低于 300ms 时波浪形几乎读不出,接近直切。

directionup

JS 型参数(demo 订阅后切换采样轴)。up/down 为纵向涌入——液缘是横向波,与「注水」心智一致,是默认方向;left/right 为横向涌入——液缘是纵向波,适合侧栏/抽屉式换肤。四个方向共用同一条 η(x,t) 采样公式,只换采样轴与均值边缘的推进方向,时长同取 500ms 档。

代码拆解

结构与 DOM

换肤逻辑与表演层完全解耦:主题状态只由 data-theme 承载,波浪是 aria-hidden 的常驻 overlay(fixed、pointer-events:none),覆盖在内容层之上(调研 20§6 共同骨架):

<div class="liquid-overlay" aria-hidden="true">
  <svg class="liquid"><path class="liquid-body" fill="var(--liquid-fill)"/></svg>
</div>

关键点:

  • --liquid-fill 取目标主题的 surface 色;液面之下是新主题(液体填充),之上是尚未覆盖的旧主题(动画中 data-fx-theme 在覆盖完成瞬间才翻转);
  • 站点主通路(spike 20a S3,关键路径):document.startViewTransition(翻主题) + ::view-transition-new(root){ clip-path: url(#liquid) } 引用文档内 SVG <clipPath>,vt.ready 后 rAF 每帧 clipP.setAttribute('d', waveD(y))——过渡进行中每帧只改一个 SVG 属性即可让裁剪逐帧跟随;
  • demo 通路(spike S4 已证普通元素同构成立):常驻 overlay 直接画液面 path,逐帧改 d,不依赖 startViewTransition,任何浏览器可跑;
  • url() 引用的 clip-path 不可 CSS 插值(MDN clip-path Formal definition,调研 20§1.2),所以液面只能逐帧 JS 重写,不能靠 CSS transition;
  • 与站内条目的关系:color/theme-transition 收录的是 Chrome 官方圆形扩散配方(调研 20§1.1 逐字复核),本条目是其液态族补强——共享同一 VT 骨架,只把 clip 形状从圆换成逐帧波浪 path;motion/view-transitions 立了发射前赋名/结束摘名等守则,S3 机制即「过渡伪元素引用文档内 SVG 资源」的实证版;motion/page-transitions 的页面级液态揭示与本配方同构(液面 path 换成页面遮罩)。

样式与参数

四个参数(振幅/波长/时长/方向)全部为 JS 型,由 demo 订阅 store 后驱动 rAF 循环:

const surf = (x, t) =>
  A1 * Math.sin(k1 * x - w1 * t) +            // 主波
  A2 * Math.sin(k2 * x - w2 * t + phi);       // 次波(频率比取 1:1.618,拍效应防机械感)
// 每帧:M 底角 → 沿 x 采样 η(x,t) 连折线 → 闭合到顶角;t += dt 液面整体上移(level 0→100%)

(配方逐字出自调研 20§6.1)

波数与边缘位置随时间的关系:

  • 波数 k = 2π/λ(rad/px):λ=240px 时 k≈0.0262 rad/px;宽度 W 内可见完整波峰数 N = W/λ——这是波长参数的直观读法;
  • 边缘位置 = 均值液位 + 波形:均值液位 meanY(t) 由缓动进度 p 决定,从 H + A(起涨前藏一个振幅防露边)推进到 −A(完全覆盖时再沉一个振幅防露底);瞬时边缘 y(x,t) = meanY(t) + A1·sin(k1·x − ω1·t) + A2·sin(k2·x − ω2·t + φ);
  • 波形随时间沿 x 以相速 c = ω/k 推进(demo 取主波周期 1s,即波峰每秒走一个 λ;绝对角速度是 demo 调参值,调研只核验了 1:1.618 的比值);
  • 主/次波比例全部取调研 20§6.1 记录值:A1=8px、A2=3px、λ≈屏宽/2 与 /3(比例 2:3)、角速比 1.618——双正弦叠加产生拍/波群,液面永不重复自己(Wikipedia Dispersion (water waves),§2.6);
  • 500ms = M3「按过渡面积定时长」整屏/大容器档(§5);缓动取调研 §6.3 记录的液块曲线 cubic-bezier(0.3, 0, 0.2, 1)。

动效与交互

  • 点击 → 涌入:rAF 每帧重写 path d,均值液位按缓动推进、波形按相位推进;data-fx-duration 与实际时长一致;覆盖完成瞬间翻转 data-theme——液面恰已盖满、换肤无可见缝(站点四阶段配方「过中点翻转」的做法见 §6.6,demo 化简为完成瞬间一次性提交,翻转时刻与 data-fx-duration 严格对齐);
  • 过渡中再次点击:旧过渡立即收尾(主题落定、液层隐藏),新过渡完整播放——永不卡死或停在半途(spike S8 实证:二次点击时旧过渡立即被跳过;站点实现再加约 200ms 防抖或「活跃则先 skip 再启动」守卫);
  • 三层降级(§6 共同骨架 + S8):无 startViewTransition → 直切;prefers-reduced-motion: reduce → 瞬时完成(时长视作 0);ready reject / 过渡中 resize → catch 落直切(S8:resize 会跳过过渡,等价直切);
  • 滚动不被阻塞:揭示边缘固定于视口、内容在液面下正常滚动、快照内容跟随滚动重新锚定(spike S8 逐帧验证);
  • 变体:排空式退场(液面从 100% 下沉)= 反向播放(§6.1)。

真实产品案例

  • Cuberto/liquid-swipe(iOS,Swift 4.2,MIT,2984★):以波浪形 path 作页面遮罩的液态滑动,「旧页被水卷走」——液态页面揭示最常被引用的开源先例(GitHub API/README 核实,调研 20§4);
  • iamSahdeep/liquid_swipe_flutter(Flutter,1266★):同族波浪掩模滑动,波峰跟随手势推进(§4);
  • Chrome for Developers 主题切换官方配方(圆形扩散,500ms ease-in):网页端唯一成文的「主题切换 + 快照揭示」官方配方,站内 color/theme-transition 已逐字收录;波浪涌入与其共享同一 VT 骨架,只是把揭示形状换成逐帧波浪(§1.1)。
  • 网页端大厂产品的「液体主题切换」公开实现未找到可打开且确定的先例(§4)——不虚构;此结论同时意味着:本条目是当前网页端该效果的成文配方来源。

参数敏感度

参数调大会…调小会…
amplitude波峰更高、「浪」感更强;超过 24px 在小舞台夸张,逐帧 path 采样跨度变大趋近 0 退化为直线边缘整体上移——液感消失,但仍是合法降级形态
wavelength波峰稀疏,边缘趋近整体倾斜的「涌潮」;接近视口宽时只剩一个波峰波峰密集;低于 120px 毛刺感上升、采样点数需求增大
duration更从容但等待感上升;超过 800ms 与 HIG「高频交互不加动效」相抵触低于 300ms 波形几乎读不出,接近直切
directionup/down 纵向涌入:液缘横波,「注水」心智,长页面换肤首选left/right 横向涌入:液缘纵波,适合侧栏/抽屉式换肤;边缘在宽屏上行程更长

经验区间:振幅 4–12px、波长取视口宽的 1/2–1/3、时长守住 500ms 整屏档;起止各预留一个振幅的行程防露边/露底(起涨前边缘藏底、收尾时边缘沉顶)。

适用场景 4
  • 深浅主题切换的整屏液态揭示(主题按钮、设置页的主题卡)——默认 up 方向即「注水」心智
  • 品牌性、低频的主题时刻:首次引导、节日主题、档位化主题的隆重切换
  • 内容可滚动的长页面换肤:揭示边缘固定于视口、内容在液面下正常滚动(spike S8 实证的理想行为)
  • 与 motion/theme-turbulence-edge 组合:平滑波缘烘进 path,湍流毛边走独立滤镜层
何时不要用 4
  • 高频切换入口连播整屏波浪——HIG「高频交互避免加动效」,500ms 每按必播会拖慢连按(调研 20§5)
  • prefers-reduced-motion 用户仍看波浪——WCAG 2.3.3 要求交互触发的运动动画可禁用(C39),reduce 档必须直切或 crossfade
  • 在 ::view-transition-* 伪元素上挂 SVG 滤镜求液缘——spike S5 反证滤镜被忽略;液缘要么烘进 path,要么走独立层
  • 把关键信息只交给波浪动画传达——HIG「动效不能是重要信息的唯一通道」,主题状态必须有颜色/文字承载
无障碍

WCAG 2.3.3「Animation from Interactions」:交互触发的运动动画必须可禁用,技术路径 C39(CSS prefers-reduced-motion 阻止运动)或 SCR40(JS 判定);reduce 档瞬时直切,不做半程液面。HIG Motion:「动效可取消」——过渡中再次点击应立即完成旧过渡并完整播放新过渡,不得卡在半途;反馈动效短促精准,整屏波浪守住 500ms 档。主题信息由颜色与 data-theme 属性承载,波浪只是增强;demo 用 data-fx-theme 局部作用于舞台,不污染站点主题。

浏览器支持

站点主通路依赖 document.startViewTransition(同文档):Chrome/Edge 111(2023-03)、Safari 18(2024-09-16)、Firefox 144(2025-10-14;MDN BCD JSON 实抓,数据版本 8.1.11,调研 20§1.4)。demo 通路(rAF + SVG path + 常驻 overlay)不依赖该 API,全浏览器可用。clip-path 本身 Baseline Widely available 自 2020-01(§1.4),但 url() 引用的 clip-path 不可 CSS 插值(§1.2)——液面必须逐帧 JS 重写 d,不能靠 CSS transition。

兼容回退

三层降级(调研 20§6 共同骨架 + 20a 推荐架构):① 无 document.startViewTransition(如旧 Firefox)→ 直切主题——表演层是常驻 overlay,本就不依赖 API;② prefers-reduced-motion: reduce → 波浪取消、瞬时直切或纯 crossfade(整屏液面属「缩放/平移大物体」的前庭触发源,必须降级,C39);③ transition.ready reject 或过渡中 resize → catch 落直切,界面停在换肤后的正确状态(spike S8:resize 会跳过过渡,等价直切)。demo 通路再兜一层:无 rAF/SVG 的环境直接落 commit。

来源 5

起源配方出自调研 20§6.1「波浪涌入」:双正弦叠加液面(主波 A1=8px、次波 A2=3px、角速比 1:1.618 的拍效应防机械循环感)、k=2π/λ(λ≈屏宽/2 与 /3)、500ms 取 M3「按过渡面积定时长」整屏档(§5);波数/波群/拍的波数学核验自 Wikipedia Dispersion (water waves)(§2.6)。机制经技术 spike 20a 实测成立:过渡伪元素引用文档内 SVG clipPath 并 rAF 逐帧改 d(S3,站点端关键路径)、CSS 变量 path() 逐帧驱动对普通元素同构成立(S4);同一 spike 反证 VT 伪元素上的 SVG 滤镜会被忽略(S5),故液缘毛边只能烘进 path 或走独立层(见 motion/theme-turbulence-edge)。
