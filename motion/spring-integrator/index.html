弹簧积分器 Spring Integrator

semi-implicit Euler · symplectic Euler · damped harmonic oscillator · spring simulation

UI 弹簧的物理内核:m·ẍ+c·ẋ+k·(x−target)=0 用半隐式欧拉离散——先更新速度、再用新速度推进位置;ζ=c/2√(km) 一行锁死手感,dt 决定能量守恒还是爆炸。

几何▾
stiffness100

弹簧刚度 k(N/m)。默认 100 = Motion 物理弹簧出厂值;决定固有角频率 ω₀=√(k/m)——k 越大节奏越急促,过冲比例(只由 ζ 决定)不变。

damping10

阻尼系数 c(N·s/m)。默认 10 与 k=100、m=1 组成 Motion 出厂手感:ζ=0.5、过冲 16.3%;调到 20 即临界阻尼(ζ=1,最快无过冲)。

mass1

质量 m(kg)。默认 1;放大 m 同时压低 ω₀ 并压低 ζ(临界阻尼 c_crit=2√(km) 抬高)——「重元素反应慢且更容易晃」的数学来源。

dt4ms
ms

  • 小球回放只是读数的可视化,aria-hidden,真实信息在文本读数里。

样式与参数

四个 JS 型参数(k/c/m/dt)由 demo 订阅 store,页面内零依赖积分。公式逐步(调研 14§3,迭代式逐字核对自 Wikipedia,工业默认值实读自 motion-dom@14.14.0 源码):

① 微分方程与半隐式(辛)欧拉离散——先速度、后位置:

m·ẍ + c·ẋ + k·(x − target) = 0

v_{n+1} = v_n + ( −k·(x_n − target) − c·v_n ) / m × dt
x_{n+1} = x_n + v_{n+1} × dt          ← 用 v_{n+1}(区别于显式欧拉的 v_n)

② 手感解析式(控制论标准结果,调研实跑对拍:解析 OS=0.163 vs 仿真峰值 115.89@dt=1/240,差 0.3%):

const springAnalytics = (k, c, m) => {
  const w0 = Math.sqrt(k / m), z = c / (2 * Math.sqrt(k * m)); // ω0、ζ
  return { w0, z, ccrit: 2 * Math.sqrt(k * m),
    OS: z < 1 ? Math.exp(-Math.PI * z / Math.sqrt(1 - z * z)) : 0, // 过冲比
    ts2: z > 0 ? -Math.log(0.02) / (z * w0) : Infinity };          // 2% 整定
};

③ 积分器本体(返回整条轨迹供绘图/采样):

function springSim(k, c, m, x0, target, dt = 1 / 240, T = 2) {
  let x = x0, v = 0, peak = 0, ts2 = 0;
  const band = 0.02 * Math.abs(target - x0);
  for (let i = 1; i <= Math.round(T / dt); i++) {
    const a = (-k * (x - target) - c * v) / m;
    v += a * dt;                            // 先速度
    x += v * dt;                            // 后位置(用新 v)
    if (x - target > peak) peak = x - target;
    if (Math.abs(x - target) > band) ts2 = (i + 1) * dt;
  }
  return { peak, ts2, final: x };
}

核验输出(实跑,k=100, c=10, m=1 即 Motion 默认):ω0=10、ζ=0.5、c_crit=20;解析过冲 OS=0.163 → 峰值应为 116.30,仿真实测 115.89 @t≈0.358s;解析 2% 整定 0.7824s vs 仿真 0.7917s ✓。经验参数带:UI 手感 ζ∈[0.6, 1](0.7≈4.6% 过冲,0.5≈16.3%),k∈[50,300],dt≤1/120 保证辛积分器能量不漂移。

动效与交互

  • 参数即改即算:拖 k/c/m,曲线重积、读数条同步——调 c 从 10 到 20(ζ 0.5→1)能看到过冲消失、整定反而略慢,「临界阻尼最快无过冲」在图上直接可读;
  • dt 对照实验:dt 从 4ms 拉到 30–40ms,半隐式曲线先「变硬」(能量缓慢漂移)后发散,显式曲线在更小的 dt 就振幅滚雪球——两条线的分岔就是辛积分器的价值;
  • 小球回放:点「回放」沿半隐式轨迹按真实时间跑 2s;prefers-reduced-motion 时跳过回放,曲线与读数照常呈现;
  • 发散保护:轨迹超出绘图域(±3)即截断并标注「发散」,不画无穷值。

真实产品案例

  • Motion(原 Framer Motion)默认弹簧:源码 stiffness:100, damping:10, mass:1 → ζ=0.5、过冲≈16.3%、整定≈0.78s——「UI 弹簧出厂手感」正是这条方程在 k/c/m(100,10,1) 下的解(源码实读 motion-dom@14.14.0);
  • Apple UISpringTimingParameters(dampingRatio:):iOS 把 ζ 做成一等 API 参数(『更阻尼更少震荡→1.0;多震荡→接近 0.15』),内部同样解这条二阶方程——平台级证据(调研 10§4.3,damping-craft 条目双源一致);
  • iOS 分段控件滑签(slot-spring 条目):卡槽间滑动的气泡就是中断续接的弹簧——积分器保存当前 x/v,新一帧从 (x_n, v_n) 继续迭代,这正是「可打断物理动画」的工程含义。

公式的量纲与边界

变量量纲取值边界退化情形
k(stiffness)N/m实务 50–300;>0k→0 无回复力,永远到不了目标;只影响 ω₀ 与 c_crit,不影响过冲比例
c(damping)N·s/m≥0;c=0 无阻尼永振c=c_crit=2√(km) 临界(最快无过冲);c>c_crit 过阻尼(爬行到位)
m(mass)kg>0;实务 0.2–4m→∞ 时 ω₀→0(冻结);m 同时进 ω₀ 与 ζ,放大 m 会「又慢又晃」
dts(物理)或 ms(UI)≤1/120 保能量;1/240 为调研核验精度dt 过大:半隐式先变硬后发散,显式更早爆炸;dt→0 两者都收敛到解析解
ζ无单位<1 欠阻尼、=1 临界、>1 过阻尼ζ≤0 无阻尼(OS 公式发散);ζ→1⁻ 时 OS→0、ωd→0,公式仍连续
ω₀=√(k/m)rad/s决定节奏;UI 常见 5–20ζ 与 ω₀ 正交:ζ 管形状(弹不弹),ω₀ 管时间尺度(多快)
OS无单位比例0(ζ≥1)到 <1OS=e^(−πζ/√(1−ζ²)) 只对欠阻尼成立;过阻尼时 OS≡0(无峰)
t_s(2%)s≈4/(ζω₀);ζ=0 时无穷近似式由包络 e^(−ζω₀t) 推出,过阻尼时偏保守,以带内最后出带时刻为准
目标 target与 x 同量纲(如 px)任意有限值带宽 band=2%×

经验口径:先算 ζ 定形状(0.5 弹、0.8 克制、1 临界),再用 k 或 ω₀ 定节奏;dt 只管保真度,永远 ≤1/120。姊妹条目:damping-craft(ζ 手感分档)、slot-spring(中断续接的工程化)、motion-spring / swiftui-spring / m3-spring-tokens(各平台把 ζ 做成 API 的方式)、linear-easing(积分轨迹→linear() 关键帧的编译出口)。

适用场景 4
  • 自研弹簧动画引擎:手写积分器而非依赖库,先算 ζ 再定参数
  • 弹簧→linear() 采样编译的采样端:物理步长积分后输出关键帧(linear-easing 条目的上游)
  • 设计系统动效 token 定标:给定目标过冲/整定时间反解 ζ 与 k
  • 评审弹簧手感:用 OS=e^(−πζ/√(1−ζ²)) 与 t_s≈4/(ζω₀) 把「感觉」换算成数字
何时不要用 4
  • 显式欧拉做生产积分——同一参数同一 dt 下比半隐式更早发散、能量持续注入
  • 把帧间隔原样当 dt 而不设上限——掉帧到 200ms 的一帧会把弹簧炸飞
  • 只调 k 不看 ζ——k 只改节奏不改过冲比例,「弹多少」永远由 ζ 说了算
  • 超大 m 配小 c 的「仪式感」参数——ω₀ 掉到个位数,整定时间以秒计,交互像陷进泥里
无障碍

弹簧参数最终都落回 CSS transform 动画,必须全局尊重 prefers-reduced-motion(跳过或直落终态);过冲不是装饰——对前庭障碍用户大幅度过冲是真实的生理不适,ζ≥0.8 是无障碍弹簧的稳妥档;数值曲线 demo 不承载唯一信息,读数以文本同步输出。

浏览器支持

纯 JS 数值计算,无平台差异;浏览器动画一般按 rAF 帧节拍取 dt(60Hz≈16.7ms),本条公式的 dt 指物理步长——帧率波动时按真实 Δt 逐步积分即可,必要时对单步 dt 设上限防大帧间隔爆炸。

兼容回退

数值发散(显式欧拉、dt 过大)时钳制单步 dt(如 ≤1/120s)并视作能量泄漏处理;不支持高精度定时器的环境按帧长积分即可——弹簧积分对精度不敏感,ζ 定形状、dt 只定保真度。

来源 3

起源阻尼谐振子是二阶系统控制论标准模型;半隐式欧拉(Euler–Cromer/辛欧拉)迭代式逐字核对自 Wikipedia《Semi-implicit Euler method》——『v_{n+1}=v_n+g(t_n,x_n)Δt; x_{n+1}=x_n+f(t_n,v_{n+1})Δt』;工业对照为 Motion(原 Framer Motion)物理弹簧:默认 k=100、c=10、m=1,bounce→ζ 映射源码注释『0 为临界阻尼』(自 npm motion-dom@14.14.0 包内 spring.mjs 实读,调研 14§3)。
