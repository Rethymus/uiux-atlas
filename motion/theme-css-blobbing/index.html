纯 CSS 形状融合 Theme CSS Blobbing

shape blobbing · blur+contrast · CSS goo · 纯 CSS 粘液 · contrast blobbing

stage 容器 filter:contrast(20) + 显式实底,子元素 blur(15px) 高对比色:靠近的模糊区互相抬升对比即粘连。无 SVG 的 goo 快速通路,限单色液体层。

参数
几何▾
contrast20

stage 容器的 contrast() 值,原方逐字默认 20。它把模糊产生的中间灰阶重新拉开:调大粘边更锐利、融合判据更「脆」,超过 30 后边缘开始硬得像剪纸;调小到 5 以下时中间灰阶拉不开,粘连消失只剩两团模糊晕。

blur15px
px

子元素的 blur() 半径,原方逐字默认 15px。决定模糊晕的范围与融合距离(经验:与 goo 滤镜同构,临界间隙 ≈ 1σ~1.3σ,spike 20a S6):调大粘连更早、单体轮廓更圆润;调小趋近 4 时要几乎重叠才粘连。

duration500ms
ms

切换钮驱动的「分散↔聚拢」过渡时长,即 demo 舞台 data-fx-duration 的实际值。默认 500ms 对齐 M3「按过渡面积定时长」的大容器档(调研 20§5)。调长融合过程清晰可读;调短低于 300ms 时粘连瞬间一闪而过。

blobs3

JS 型参数(demo 订阅后重建液滴)。同时是性能演示位:原作者告诫这类滤镜组合「资源消耗大」,成本随元素数近线性上涨——5 颗已能感到过渡期间的 repaint 压力;生产里液体层尽量 ≤3–4 颗。

代码拆解

结构与 DOM

这是无 SVG 的 goo 通路:stage 容器套 contrast()、子元素套 blur(),靠近的模糊区互相抬升对比即粘连(调研 20§2.7,Coyier 原方):

<div class="stage"><!-- 唯一被 contrast() 的层:显式实底 + 留出血 -->
  <span class="dot"/><!-- blur 的高对比圆点,只此一种内容 -->
  <span class="dot"/>
  <span class="dot"/>
</div>
<div class="page"><!-- 文字/控件放滤镜层之外 -->

关键点:

  • stage 必须有显式背景(原方:白底黑点)——contrast 作用于整个层的渲染结果,没有实底就没有可拉开的灰阶,效果静默失效;
  • 颜色要高对比(浅灰配白底不行):对比不足时粘连判据失效,只剩两团灰晕;
  • stage 留 padding 出血,圆点任何位姿距层边 ≥ blur 半径,否则边缘出 artifacts;
  • 粘连原理(原文):「元素靠近时,各自的模糊区在对方区域制造足够的颜色对比,形状就粘连起来」——单层对比判据,因此限单色液体层,多色会在阈值处互相污染;
  • 文字/图标/中间调内容绝不能放进滤镜层(contrast(20) 会把它们撕成硬边鬼影)——demo 把标题/读数/按钮全部放在 .cb-liquid 之外的兄弟层。

样式与参数

两颗 CSS 变量型参数(contrast/blur,经 DemoStage 注入)+ 两个 JS 型参数(时长/颗数,订阅 store):

.stage {
  background: var(--cb-bg);            /* 显式实底(要点①) */
  filter: contrast(var(--cb-contrast)); /* 原方 20 */
}
.dot {
  background: var(--cb-ink);            /* 高对比墨色(要点②) */
  filter: blur(var(--cb-blur));         /* 原方 15px */
  transition: transform 500ms cubic-bezier(0.3, 0, 0.2, 1);
}

数值出处:

  • contrast(20) + blur(15px) + 显式实底 + 高对比 + 出血 = Coyier《Shape Blobbing in CSS》原方逐字(2014-10-28);
  • 500ms = M3「按过渡面积定时长」大容器档(§5);曲线取调研 §6.3 液块曲线(同族条目一致);
  • 融合临界间隙与 goo 滤镜同构:≈ 1σ~1.3σ(spike 20a S6 实测的是同一 blur→阈值物理);
  • 性能:contrast 层 + N 个 blur 子元素在过渡期间逐帧重绘——原作者 CPU 告诫,成本随元素数近线性上涨;demo 的「颗数」参数即性能演示位。

动效与交互

  • 切换钮 → 分散↔聚拢:圆点在两组位姿间做 transform 过渡——聚拢位圆心距压到直径以内,模糊晕重叠、阈值处粘连成一滴;主题在过渡完成瞬间原子提交,data-fx-duration 与实际时长一致;
  • 进行中再次点击:取消提交计时器,圆点从当前位姿平滑重定向(transform 过渡天然可中断,不停在半途),新目标重新计时;
  • reduced-motion:prefers-reduced-motion: reduce 时位置过渡直落(时长视作 0),data-fx-duration 同步为 0;静态「聚拢成一体」构图仍在(非运动);
  • 降级:滤镜不可用时圆点退化为普通实色圆(位姿过渡仍在,只是无粘连)——布局与状态零损失;两大前提(显式实底/高对比)不可省,否则整个效果静默失效;
  • 性能纪律:液体层 ≤3–4 颗、面积可控;大面积(全屏、长列表)不用本通路——原作者 CPU 告诫(§2.7)。生产级多色/带内容液体改走 metaball 单 path(motion/theme-metaball-bridge)或 goo 滤镜分层(motion/theme-goo-filter)。

真实产品案例

  • Lucas Bebber 的 Gooey Pagination:Coyier 在原文中注明「最早所见 demo」即此——blur+contrast 技法的产品化源头(分页圆点粘连),与 goo 滤镜同源(调研 20§2.7);
  • Chris Gannon 的 Bubble Slider:blur+contrast 通路被 varun.ca/metaballs 点名的可运行示例(本会话重抓原文核实其作为「CSS+SVG 复刻 metaball」的例子);气泡滑杆的液态粘连即此配方;
  • 独立的「纯 CSS blobbing」大厂产品公开实现未找到可打开且确定的先例(§4 未证实清单)——本条目定位是快速原型通路,不虚构产品案例。

参数敏感度

参数调大会…调小会…
contrast粘边更锐利、融合判据更「脆」;超过 30 后边缘硬得像剪纸中间灰阶拉不开,粘连消失只剩模糊晕;≤5 基本失效
blur粘连更早、单体轮廓更圆润;光晕触边风险随之上升(出血要留够)临界间隙缩到 ~4–6px,要几乎重叠才粘连;≤4px 失去液感
duration聚拢—粘连—散开三拍可读;超过 800ms 等待感上升低于 300ms 粘连瞬间一闪而过
blobs演示成本随颗数近线性上涨(原作者 CPU 告诫),5 颗已能感到过渡期 repaint 压力≤3 颗性能最稳,但构图单薄;2 颗只表现「滴落合并」

经验区间:contrast 15–25、blur 10–20px、颗数 2–4、时长 400–600ms;显式实底 + 高对比两大前提永远排第一——它们不成立时,其余参数调什么都无效。

适用场景 4
  • 主题切换的「液体聚拢」时刻:圆点向中心聚成一滴,换肤完成后散开(单色液体层)
  • 加载/聚拢类小徽章:几个点互相粘连成有机形状(≤3–4 颗、小面积)
  • 快速原型的 goo 通路:不想写 SVG 滤镜时的单色粘液(原型先行,生产再换 metaball/goo-filter)
  • 装饰性背景液斑的聚散(面积可控、纯装饰、aria-hidden)
何时不要用 5
  • 大面积使用——contrast 层 + N 个 blur 子元素逐帧重绘,原作者 CPU 告诫,成本随元素数近线性上涨(§2.7)
  • 把文字/图标/中间调内容放进滤镜层——contrast(20) 会把它们撕成硬边鬼影;内容永远放层外
  • 浅灰配白底等低对比配色——原文要点②:颜色不高对比则粘连判据失效,只剩两团灰晕
  • 层底不显式声明(透明/渐变底)——原文要点①:contrast 作用于整个层渲染结果,没有实底就没有可拉开的灰阶
  • 多色液体——本通路只有一层对比判据,多色会在阈值处互相污染;多色液体走 metaball 单 path 或 goo-filter 分层
无障碍

液体层是 aria-hidden 的纯装饰;任何状态(主题、选中、进度)都由颜色/文字在滤镜层之外承载,不依赖粘连形态(HIG:动效不得是重要信息的唯一通道)。切换钮是真按钮;prefers-reduced-motion: reduce 时圆点直落目标位(时长视作 0)。装饰动效遵守 HIG『Make motion optional』:粘连消失后界面仍完整可读。大面积与多元素场景先看性能预算(原作者 CPU 告诫),低端设备上宁可减颗数。

浏览器支持

只依赖 CSS filter: contrast() 与 blur(),均为 Baseline Widely available 的基础滤镜函数,Chrome/Firefox/Safari 全支持(无需 SVG 滤镜引用,规避 Safari 对 DOM 套 SVG 滤镜的历史问题)。注意:contrast() 作用于整个液体层(含层底色),层内不能放任何中间调内容;文字/控件必须放在滤镜层之外(本 demo 即如此分层)。性能:contrast 层 + N 个 blur 子元素在过渡期间逐帧重绘,元素数与层面积直接决定成本(原作者 CPU 告诫,§2.7)。

兼容回退

滤镜不可用时,子元素退化为普通实色圆点(位置过渡仍在,只是无粘连)——布局与状态零损失。prefers-reduced-motion: reduce 时关闭位置过渡、圆点直落目标位(时长视作 0,data-fx-duration 同步为 0);静态「聚拢成一体」的构图仍在(非运动)。两大前提不可省:液体层必须有显式实底、墨色必须对底色高对比——否则 contrast 无从生效,整个效果静默失效(原文要点①②)。
