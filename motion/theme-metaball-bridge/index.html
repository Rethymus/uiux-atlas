液滴连接桥(metaball 单 path 融合) Theme Metaball Bridge

metaball bridge · 连接膜 · 液滴膜颈 · metaball membrane · 拖拽粘连

两颗液滴用一条贝塞尔「连接膜」焊成单 path:靠近时膜颈收缩融合、拉远超过 maxDist 即断裂。SATO Hiroyuki 公式纯 JS 采样,不依赖滤镜。

参数
几何▾
handleLenRate2.4

控制柄长度系数(公式默认 2.4,varun 移植版逐字)。柄长 = 圆半径 × d2,d2 随 v·handleLenRate 增大:调大膜缘更外凸、颈部曲线更『鼓』;调小柄更短,膜缘更直、连接更『紧』。超过 3 后小液滴上容易出现过冲鼓包。

v0.5

切点角插值系数(公式默认 0.5,逐字)。angle1a = angle1 + u1 + (angle2−u1)·v:v=0 时切点收在两圆交点角(u)——颈部最细、膜最『瘦』;v=1 时切点张到公切角(angle2 = acos((r1−r2)/d))——颈部最宽、膜面最饱满。demo 默认 0.5 即原方折中。

maxDistFactor2.5

断膜距离系数:maxDist = r1 + r2×该系数。原式固定 2.5(逐字),demo 参数化便于观察断裂点——默认 2.5 时两颗 demo 液滴(r1=64/r2=34)在圆心距 149px 处断膜。调大膜更『恋』,拉更远才断;调小更脆,轻拉即断(低于 1.7 时 demo 停靠位本身已断膜)。

duration700ms
ms

切换钮驱动的整段飞行周期(出航→悬停→归位),即 demo 舞台 data-fx-duration 的实际值。默认 700ms 取调研 20§6.6 四阶段配方的总时长档——超出 M3 500ms 整屏档的部分由多段编排承担(§5:M3 允许进入段更长以聚焦新内容)。调大更从容;低于 400ms 时断膜瞬间一闪而过、读不出『液滴脱离』叙事。

代码拆解

结构与 DOM

不对像素做模糊,而是用一条贝塞尔「连接膜」把两个圆焊成单条 path:液滴接近主液面时膜颈收缩,拉远超过 maxDist 即断开(脱离)——「液柱—液滴—飞溅」联合轮廓的标准描述法(调研 20§2.1):

<svg class="scene" aria-hidden="true">
  <path class="membrane" /><!-- 连接膜:逐帧重算 d,断裂时置空 -->
  <circle class="drop-parent" r="64" /><!-- 大圆(主液滴) -->
  <circle class="drop-child"  r="34" /><!-- 小圆(子液滴,可拖拽) -->
</svg>

关键点:

  • 三个元素同色填充(圆 + 膜):膜 path 末段是 C … p1b 且无 Z,填充时自动用弦闭合穿过大圆内部——三块叠成一体才读作一颗液体;
  • 大圆必须作为 radius1 传入:varun 移植版按 radius1 为大圆设计,原文不做半径交换;d ≤ |r1−r2|(小圆完全没入)时公式返回空串,本就无膜;
  • 纯 JS 采样、零滤镜依赖:每帧只重算一条 path 的 d,天然规避「VT 伪元素上引用 SVG 滤镜未证实」的问题(spike 20a S5 反证滤镜挂过渡伪元素被忽略——本条目根本不碰过渡伪元素,也不依赖 startViewTransition);
  • 膜是逐帧几何 path,不需要 CSS 插值能力,不受「url() 引用的 clip-path 不可插值」限制(调研 20§1.2)。

样式与参数

公式(SATO Hiroyuki 脚本,varun.ca/metaballs 移植版逐字;handleLenRate = 2.4、v = 0.5 为默认值):

function metaball(radius1, radius2, center1, center2, handleLenRate = 2.4, v = 0.5) {
  const d = dist(center1, center2);
  const maxDist = radius1 + radius2 * 2.5;          // 断膜距离(逐字);超过返回空 path
  if (radius1 === 0 || radius2 === 0) return "";
  if (d > maxDist || d <= Math.abs(radius1 - radius2)) return "";
  // 余弦定理求切点角(重叠时;分离时 u1 = u2 = 0)
  const u1 = Math.acos((r1² + d² - r2²) / (2·r1·d));
  const u2 = Math.acos((r2² + d² - r1²) / (2·r2·d));
  // 切点 p1a/p1b/p2a/p2b:由 v 在 [切点角, 公切角] 区间内插值
  // 控制柄长 d2 = min(v·handleLenRate, dist(p1a,p2a)/(r1+r2)) · min(1, d·2/(r1+r2))
  // path:M p1a C h1 h2 p2a A r2 r2 (escaped?1:0) 0 p2b C h3 h4 p1b  —— escaped = d > radius1
}

数值出处(调研 20§2.1,本会话重抓原文复核一致):

  • maxDist = r1 + r2×2.5:断膜阈值——r1=64/r2=34 时即 149px;这是「膜更恋还是更脆」的唯一旋钮;
  • 余弦定理切点角 u1 = acos((r1²+d²−r2²)/(2·r1·d))、u2 对称;v(0.5)决定切点在「两圆交点角 ↔ 公切角 acos((r1−r2)/d)」之间的位置——v=0 颈最细、v=1 颈最宽;
  • 控制柄长随重叠收缩:d2 = min(v·handleLenRate, dist(p1a,p2a)/(r1+r2)) · min(1, d·2/(r1+r2));
  • large-arc flag = escaped ? 1 : 0,escaped = d > radius1(原文逐字):圆心距越过半径 1 时,圆 2 上的弧恰好在长短弧临界处切换(切点角越过 π/2)——这是原公式自洽的关键,不要改成 d > r1 + r2;
  • demo 的 maxDistFactor 参数把原式固定的 2.5 参数化(默认仍 2.5),便于观察断裂点。

动效与交互

  • 切换钮 → 出航/悬停/归位:子液滴从停靠位飞向远处(膜拉细→越过得膜距离即断)→ 悬停(断膜状态可见)→ 归位重接;主题在周期完成瞬间原子提交,data-fx-duration 与实际周期一致;默认 700ms 取调研 §6.6 四阶段总时长档(M3 允许进入段更长,§5);
  • 拖拽吸附:Pointer Events 拖子液滴,膜逐帧跟随;松手时超出 maxDist → 回巢重接,未超出 → 停在原地膜保持连接——「拖起元素与原位拉出膜颈、断裂与重接」全在这条公式里(调研 20 巧思 5);
  • 动画进行中再次点击:旧过渡立即收尾(液滴落位、主题提交)、新过渡完整播放——不卡死不停半途(spike S8:二次点击旧过渡立即被跳过,站点实现再加约 200ms 防抖或「活跃则先 skip 再启动」守卫);
  • 断裂瞬间膜 path 直接置空,绝不做两段 path 之间的补间——spike 20a S7 实证:环数不同的 path() 之间不能连续插值,τ≈0.5 处会离散跳变;
  • 降级三层:无 SVG/rAF → 膜隐藏、两颗静态圆;prefers-reduced-motion: reduce → 点击瞬时落位(时长视作 0,data-fx-duration 同步为 0),拖拽松手瞬时跳回;拉远断膜本身是天然降级——功能零损失。

真实产品案例

  • KittenYang/KYGooeyMenu(iOS,Objective-C,1898★):以 UIBezierPath 画 metaball 膜的菜单家族代表,菜单项展开时膜颈相连(GitHub API 核实,调研 20§4);
  • KittenYang/KYCuteView(iOS,984★):拖拽粘连气泡——拖起元素与原位之间拉膜、超过距离断裂、松手回弹重接,即「拖拽吸附」的原生先例(§4);
  • varun.ca/metaballs 的 Amoeba demo(Web):本条目公式的可运行参考实现——大阿米巴与小细胞拖拽分离/融合,膜 path 逐帧重算(本会话重抓原文,内嵌代码即此实现)。

网页端大厂产品的公开实现未找到可打开且确定的先例(§4 未证实清单)——不虚构。

参数敏感度

参数调大会…调小会…
handleLenRate柄更长,膜缘更外凸、颈部曲线更「鼓」;超过 3 后小液滴上出现过冲鼓包柄更短,膜缘更直、连接更「紧」;0.5 时膜几乎变成两条直边
v切点向公切角张开,颈部更宽、膜面更饱满(更「液」)切点向两圆交点收拢,颈部更细、膜更「瘦」;0.05 时接近线连接
maxDistFactor膜更「恋」,拉更远才断;3 时断膜距离 166px膜更脆,轻拉即断;低于 1.7 时 demo 停靠位本身已断膜(初始即分离)
duration飞行更从容,断膜—悬停—重接三拍都读得清;超过 1200ms 等待感上升低于 400ms 断膜瞬间一闪而过,「液滴脱离」叙事读不出

经验区间:handleLenRate 2–3、v 0.35–0.7、断膜系数守原方 2.5、周期 600–800ms;膜色必须与圆同色且对舞台底色高对比,否则融合边界读不出。

适用场景 4
  • 导航/标签指示器的液态桥接:滑块在项间移动时与相邻项短暂融合(先例 iOS 系 GooeyTabbar/KYGooeyMenu 家族,调研 20§4)
  • 按钮组粘连:间距很近的关联动作(工具条、分屏把手)在 hover/激活时膜颈相连
  • 拖拽吸附:拖起元素与原位之间拉出膜颈,超过 maxDist 断裂、松手回巢重接(先例 KYCuteView 拖拽粘连气泡,984★,§4)
  • 主题/液态叙事里的『液滴溅起—落回』:一次采样同时描述流出与飞溅(调研 20 巧思 5,§6.6 四阶段骨架)
何时不要用 4
  • 小圆在前调用公式——varun 移植版按 radius1 为大圆设计(原文不做半径交换);传入前先保证 r1 ≥ r2
  • 对断裂瞬间做 path 补间——环数不同的 path() 不能连续插值,会离散跳变(spike 20a S7);断裂必须直接置空
  • 把膜颈当唯一的选中/连接指示——膜是装饰层(aria-hidden),状态必须另有颜色/文字承载(HIG:动效不得是重要信息的唯一通道)
  • 低对比液体色——膜与圆同色才能读作一体;深浅主题都要保证液体色对舞台底色高对比(对照 theme-css-blobbing 的高对比前提)
无障碍

整个液滴场景是 aria-hidden 的装饰层;主题状态由 data-fx-theme、文字读数(圆心距 d、连接状态)与颜色共同承载,不依赖动画。切换钮是真按钮(keyboard 可达);拖拽是增强交互——键盘/触屏用户用切换钮看同一叙事。prefers-reduced-motion: reduce 时点击瞬时落位(WCAG 2.3.3/C39:交互触发的运动动画可禁用);高频切换遵守 HIG『高频交互避免加动效』,连按时长按 700ms 档可中断不排队(动画进行中再次点击 = 旧过渡立即收尾、新过渡完整播放)。

浏览器支持

纯 JS 采样(rAF + SVG path d),无滤镜依赖——天然规避「VT 伪元素上引用 SVG 滤镜未证实」的问题(spike 20a S5 反证滤镜挂过渡伪元素被忽略;本条目根本不碰过渡伪元素)。rAF 与 SVG <path> 全浏览器可用;拖拽用 Pointer Events(Baseline)。膜是逐帧重算的几何 path,不需要 CSS 插值能力,也不受 clip-path url() 不可插值限制(调研 20§1.2)。

兼容回退

膜断裂本身就是天然降级:拉远即断、功能零损失(液滴仍是完整圆)。无 SVG/rAF 的环境隐藏连接膜,只画两颗静态圆;prefers-reduced-motion: reduce 时点击瞬时落位(时长视作 0,data-fx-duration 同步为 0),拖拽仍可用(直接操纵),松手回巢改为瞬时跳回。要点:断裂瞬间膜 path 直接置空,绝不做两段 path 之间的补间(spike 20a S7:环数不同的 path() 插值会离散跳变)。

来源 2

起源公式原始出处是 SATO Hiroyuki 的 Illustrator 脚本,Web 移植与通行代码出自 Varun Vachhar《Metaballs》(2017-10-16)。逐字核验值:metaball(radius1, radius2, center1, center2, handleLenRate = 2.4, v = 0.5)、maxDist = radius1 + radius2×2.5(超过即脱膜返回空 path)、余弦定理求切点角 u1 = acos((r1²+d²−r2²)/(2·r1·d))、切点由 v 在切点角区间内插值、控制柄长 d2 = min(v·handleLenRate, dist(p1a,p2a)/(r1+r2))·min(1, d·2/(r1+r2))、path 按 M p1a C h1 h2 p2a A r2 r2 (escaped?1:0) 0 p2b C h3 h4 p1b(escaped = d > radius1)(调研 20§2.1;2026-11-28 重抓原文复核一致)。
