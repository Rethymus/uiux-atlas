液体主题切换 Liquid Theme Reveal

liquid theme switch · liquid reveal · theme pour · 液体切换 · 倾倒主题 · 液态主题过渡 · theme liquid transition

新主题像液体一样从按钮下方流出:视图过渡真揭示 + 动态 SVG clipPath,液柱/液滴/飞溅/波浪的联合轮廓由单一 rAF 逐帧重算 path d(液缘烘进 d,不用滤镜);旧快照垫底、逐像素对齐,配合 Web Audio 本地合成的四阶段音效(默认关)。

代码拆解

结构与 DOM

点击切换按钮后,新主题像液体一样从按钮下方流出。揭示主体是视图过渡真揭示:document.startViewTransition(应用新主题) + 注入样式关闭默认动画,::view-transition-new(root) 挂 clip-path: url(#id) 引用文档内动态 SVG clipPath;vt.ready 后单一 rAF 循环每帧只改一个 <path d> 属性——d 是液柱 + 分离液滴 + 飞溅液滴 + 波浪液面的联合轮廓(20a spike S3 证立的关键通路):

<!-- 运行期临时层(模块注入;结束/中断/卸载时移除,uid 唯一不重复) -->
<style>
  ::view-transition-old(root), ::view-transition-new(root) { animation: none; mix-blend-mode: normal; }
  ::view-transition-new(root) { clip-path: url(#liquid-fx-clip-N); }
  ::view-transition-group(*), ::view-transition-image-pair(*) { pointer-events: none; }
</style>
<svg width="0" height="0" aria-hidden="true" focusable="false"><!-- 0×0 载体,不进焦点/阅读顺序 -->
  <defs><clipPath id="liquid-fx-clip-N" clipPathUnits="userSpaceOnUse">
    <path d="…液柱/液滴/飞溅/波面联合轮廓,逐帧重算…"/>
  </clipPath></defs>
</svg>

关键点:

  • 两层内容与布局完全对应,由浏览器保证:旧主题快照天然垫底、新主题快照作揭示层,尺寸/位置/滚动位置/sticky·fixed 元素逐像素对齐(S9 实测恒等回调两帧 diff=0);不是 DOM 克隆,业务事件零重复绑定,表单内容与筛选状态在真 DOM 上原样保留;
  • 液缘烘进逐帧 d,不用滤镜:S5 反证 SVG 滤镜挂过渡伪元素会被忽略;液柱摆动(沿柱相位滞后正弦)、粗细变化、波面双正弦叠加全部直接算进 path;
  • 联合轮廓 = 同向顺时针子路径并集(nonzero 填充),坐标定点数 toFixed(2)(S7 纪律);子路径数可随帧自由增减(不用 WAAPI 插值,无环数约束);
  • 过渡生命期用 opacity 1→1 的无视觉效果 WAAPI「守护动画」拉长(::view-transition-group(root)),揭示完成后取消守护 → 过渡拆除(S9 同款配方);
  • 揭示层是纯合成器覆盖(pointer-events: none),交互落在真实 DOM——动画中可以继续滚动(S8:液缘固定视口、内容在其下滚动)。

样式与参数

四个参数全部为 JS 型;主题令牌是舞台作用域变量(data-fx-theme 切换,值取站点 design-spec §2.1 深/浅两套原值,不动站点主题):

// 逐帧几何(20a spike 推荐架构;比例分配:pour 16% / splash 16.5% / rise→settle 78%)
const tipY = origin.y + (bottomY - origin.y) * (p / 0.16) ** 2;      // 液柱重力加速下落
const sway = u * amp * Math.sin(u * 2.1 + tau * 5.0 + 0.6);          // 液柱摆动
const surf = amp * (sin(k1x - ω1τ) + 0.45 * sin(k2x - ω2τ + 1.1));   // 波面:ω2/ω1 = 1.618 拍效应
// 撞击涟漪 = 高斯包(展宽 + 衰减);液滴 = 重力抛体,触液面即并入;坐标全部按舞台高度自适应缩放

数值出处:

  • 波面双正弦、角速比 1:1.618 = 调研 20§2.6 记录值(Wikipedia Dispersion (water waves) 拍效应,防机械循环);
  • 液块缓动 cubic-bezier(0.3, 0, 0.2, 1) = 调研 20§6.3 记录值(JS 二分反解);
  • 阶段比例(16%/16.5%/78%)、sway=10px、waveAmp=8px、液滴间隔 110ms、飞溅 7 颗 = demo 调参值(调研未核验绝对值;已核验的是「逐帧改 d 成立」「快照对齐成立」「滤镜不可挂」这些机制);
  • 振幅/重力按填充区域高度缩放(0.45–1.25 倍)——手机到桌面同一组参数观感一致,不用固定舞台尺寸硬套。

动效与交互

  • 四阶段:①细长液柱从按钮下探出(pour),带摆动/粗细变化/分离液滴;②落底触发飞溅小液滴与局部涟漪(splash);③底部积聚成持续起伏的波浪液面并上涨(rise);④覆盖全视口后波幅归零、平稳收尾(finish)。浅色切深色、深色切浅色都是完整动画(方向只影响音效明暗);液体经过处背景/卡片/文字/边框/图表即切新主题,未覆盖处保持旧主题——不是圆形扩散、不是渐变淡入、不是纯色遮罩、不是整页同切;
  • 音效(Web Audio 本地合成,零远程资源):流出=短促滴落、落底=轻微水花、上涨=低音量连续流水、完成=柔和短收尾;切深色偏低沉(×0.78)、切浅色偏清亮(×1.26)。默认关;开关与音量持久化 localStorage(atlas-sound);AudioContext 模块单例、点击手势内创建/恢复;阶段由动画实际进度触发(同一运行每阶段至多一次),不用固定延时堆叠;中断停流水不误播收尾;静音/音量 0/后台/卸载即停断连;减少动态效果跳过长流水只留简短反馈;音频不可用时切换照常完成;
  • 重复点击:防抖窗口(200ms)内忽略;窗口外即时收尾(显式 skip,主题已提交)——绝不卡死、不停半途(S8 纪律);
  • 窗口变化:运行中 resize → 浏览器自动跳过过渡(S8),模块主动 skip 保证状态一致;滚动不被阻塞;
  • 降级:无 startViewTransition(旧 Firefox)→ 直切(站点已有 @view-transition 渐进增强先例,global.css);prefers-reduced-motion: reduce → 直切(时长视作 0,data-fx-duration 同步为 0);进入后台 → 即时收尾 + 停声;
  • 清理:动画帧、临时节点(style + svg)、resize/visibilitychange/RM 监听器在结束、中断、卸载三条路径上全部移除。

真实产品案例

  • View Transitions API 同文档过渡(MDN/Chrome 111+ 文档):startViewTransition + 伪元素裁剪的官方机制出处——本条目把默认交叉淡入换成逐帧液体轮廓(S3/S4 实测通路);
  • 站点内先例:global.css 的 @view-transition MPA 规则(无过渡支持的浏览器退回普通导航的结构性降级同款思路);motion/theme-reveal-wipes 与 theme-wave-flood 是同族的固定形状/整屏波浪变体;
  • 「从按钮流出的液体主题切换」的公开产品级实现未检索到可引用案例(调研 20§4)——demo 参数(摆幅/波幅/阶段比例)是设计值,机制层(S3/S5/S8/S9/S10)全部有 spike 实测证据。

参数敏感度

参数调大会…调小会…
duration过程更从容、叙事更完整;超过 2000ms 等待感明显四阶段读不出过程;低于 800ms 接近「快速擦拭」
sway摆动更泼辣,像粗流倾倒;过大时液柱可能摆出按钮边缘趋近 2px 液柱笔直,失去「倒」的姿态
waveAmp液面汹涌,上涨段更有「液体感」;过大时波峰可能高出最终液位目测线趋近 2px 接近平静水面;失去起伏
droplets断续感更强,液流更「细碎」;0–8 之外无意义0 = 关闭分离液滴,只留液柱与飞溅

经验区间:duration 1200–2000ms、sway 6–14px、waveAmp 5–12px、droplets 2–6;阶段比例(16/16.5/78)不建议改——pour 段过短会看不到液柱,过长则飞溅迟到。

适用场景 4
  • 主题/外观切换的「品牌瞬间」:深浅两套完整主题像液体一样从触发按钮处铺开,与站点既有 data-theme 切换语义互补(调研 20§8 候扩)
  • 需要「过程可读」的主题迁移:液体经过处逐块切换,用户能看见新主题如何铺满界面,而非整页同切
  • 从明确交互点发起的局部→全屏揭示:起点来自实际按钮位置,填充范围来自实际舞台/视口尺寸,手机到桌面同一套几何自适应
  • 同族条目组合:与 theme-reveal-wipes(固定形状)/ theme-water-fill(液面档位)互补——需要「从按钮流出 + 联合轮廓」时用本条目
何时不要用 4
  • 高频切换入口(拖动滑杆连续改主题):整段 1.6s 动画 + 快照捕获成本不该挂在连续输入上;高频路径用直切(motion/theme-transition 同诫)
  • 首屏自动播放:液体切换必须由用户手势发起(AudioContext 手势约束 + 快照捕获 57–94ms 的主线程成本不该花在用户没要求的动画上)
  • 在动画期间叠加整页遮罩或复用旧遮罩层:揭示层由过渡伪元素承载,再叠遮罩会双份变色;临时层必须随结束/中断/卸载移除
  • 把静态快照说成「能自动重绘另一主题」:过渡快照是捕获瞬间的像素——Canvas/WebGL/视频在揭示层里是静态像,活重绘需双层渲染方案(docs/liquid-theme.md 如实标注)
无障碍

揭示层(过渡伪元素树)不进键盘焦点与无障碍阅读顺序;0×0 aria-hidden SVG 宿主只是 clipPath 载体,无重复 ID。主题状态由 data-fx-theme 属性承载(舞台作用域,不动站点主题)。prefers-reduced-motion: reduce → 直切(时长视作 0)。临时节点(style + svg)、动画帧、resize/visibilitychange/RM 监听在结束、中断、卸载三条路径上都清理;表单内容与业务状态在真 DOM 上,揭示不触碰输入焦点。音效默认关、可开关可调音量并记忆(localStorage atlas-sound);静音/音量 0/进入后台/卸载即停声断连;音频不可用或解锁失败时主题切换照常完成。

浏览器支持

主通路依赖 View Transitions L1(document.startViewTransition + ::view-transition-* 伪元素):Chromium 111+ / Safari 18+ 支持;Firefox 未实现 → 自动直切降级(与站点 global.css 的 @view-transition MPA 渐进增强同一先例)。rAF + SVG path d 逐帧重算、clipPath userSpaceOnUse 裁剪全浏览器可用。SVG 滤镜不做液缘(S5 实测滤镜挂过渡伪元素被忽略)。Web Audio 全浏览器可用;不可用时音效静默、切换照常。

兼容回退

三层直切降级(S8/S9 实测纪律):① 无 document.startViewTransition(如旧 Firefox)→ 直接 applyTheme(站点已有 @view-transition 渐进增强先例);② prefers-reduced-motion: reduce → 直切(时长视作 0,data-fx-duration 同步为 0);开启音效时只保留一段简短切换反馈、跳过长流水;③ 运行中窗口 resize → 浏览器自动跳过过渡(S8),模块再主动 skip 保证状态一致。重复点击:防抖窗口(200ms)内忽略;窗口外即时收尾(显式 skip,主题已提交),绝不卡在半途。进入后台 → 即时收尾 + 停声。

来源 3

起源技术核验来自本站 20a 无头 Edge 实测 spike(out/design-study/20a-theme-liquid-spike.md):S3 证立「过渡伪元素引用文档内动态 SVG clipPath + rAF 逐帧改 d」是液体切换的关键通路;S5 反证滤镜不能挂过渡伪元素 → 液缘必须烘进逐帧 d;S8 证立二次点击防抖/resize 自动跳过/滚动不被阻塞且快照随滚动重锚定;S9 证立 sticky 页头两帧快照逐像素对齐、root 捕获仅一次(57–94ms);S10 证立点击手势内 Web Audio 调度全链路。波面双正弦叠加(角速比 1:1.618 拍效应)同 motion/theme-water-fill 的物理出处(Wikipedia Dispersion (water waves))。与 theme-reveal-wipes(固定形状擦除)、theme-wave-flood(整屏波浪)同族:本条目的差异点是「液体从按钮处发起、液柱-液滴-飞溅-波面联合轮廓随实际布局计算」。
