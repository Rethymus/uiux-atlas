按压反馈对 Press Feedback Pair

按压态 · pressed state · highlighted · active 反馈

按压/释放是一对状态:按下瞬时生效(0ms)、松手才给短过渡——成熟组件库默认做色彩阶进而非 scale,scale(0.95~0.98) 是社区惯例。

几何▾

按压缩放量。默认 0.97:社区常见值,未证实——本次在 AntD/Arco/shadcn/Magic UI 默认按钮源码中均未发现任何按压 scale(调研 10§1.1/§9),常见经验区间 scale(0.95~0.98)。调大更接近 1 反馈越弱;调小按压感越重、文字形变越明显。

pressAlpha0.8

ms

松手回弹时长。默认 120ms,取调研 10§1.3 可复用代码(结构仿 Arco:按下瞬时、松手缓出);Arco 官方实际档位是 0.1s linear(`@transition-duration-1`)。调大更『黏』,超过 200ms 跟手感明显劣化;调小趋近 0 则与『按压瞬时』无异,反馈只剩状态切换。

代码拆解

结构与 DOM

按压反馈是一对状态:normal(释放)↔ highlighted(按压中)。Apple 侧的规范语义是 UIControl.isHighlighted——「控件自动随合适的 touch 事件设置与清除该状态」,即按下进入、移出/释放退出,天然成对(调研 09§4)。Web 对应物就是 :active,但要可靠覆盖键盘与触摸,用 data 属性驱动更稳:

<button class="pf-btn" data-pressed="false">主操作</button>
<span class="pf-badge" data-hot="false">normal(释放)</span>

关键点:

  • 按下进入、释放/移出/取消退出——pointerdown 设 data-pressed,pointerup/pointercancel 清除;配合 setPointerCapture,按住拖出按钮仍保持 highlighted(与 iOS 语义一致);
  • 键盘按住 Space/Enter 同样进入按压态(与指针等价),blur 时兜底复位;
  • 状态读数徽章实时显示当前是 normal 还是 highlighted,把「成对」变成可见事实。

样式与参数

五个参数对应一组 CSS 变量与两个 data 开关:

.pf-btn {
  /* 松手回弹:120ms + Arco decelerate 曲线(调研 10§1.3 可复用代码) */
  transition: all var(--press-release-ms) cubic-bezier(0.4, 0.8, 0.74, 1);
}
/* 按压瞬时:Arco Button 官方 :active { transition: none } 的等价实现 */
[data-response="instant"] .pf-btn[data-pressed="true"] { transition: none; }
/* scale+alpha 按压对 */
.pf-btn[data-pressed="true"] {
  transform: scale(var(--press-scale));   /* 0.97 */
  opacity: var(--press-alpha);            /* 0.8 */
}
/* 色彩阶进版:库默认语义,只换底色/明度 */
.pf-btn[data-pressed="true"] { filter: brightness(0.88); }

数值出处(全部为本次源码核验,调研 10§1.1):

  • Arco Button:transition: all 0.1s linear + :active { transition: none };primary hover=色阶-5(变亮一阶)、active=色阶-7(变深一阶);全局缓动 token 含 decelerate cubic-bezier(0.4, 0.8, 0.74, 1);
  • AntD Button:只过渡 color / background-color / border-color / box-shadow / opacity 五个颜色系属性,时长 motionDurationMid = 0.2s(motionUnit 0.1×2),缓动 motionEaseInOut = cubic-bezier(0.645, 0.045, 0.355, 1)——默认不缩放;
  • scale(0.950.98) 与 alpha≈0.70.8:社区常见值,未证实——四大库默认按钮源码中均未发现按压 scale;iOS 原生 highlighted 的 alpha/scale 变化量官方同样未公布(调研 09§4);
  • Apple 官网 :active 只换底色与字色、不加 outline——按压=色彩反馈的官方一手实现(调研 09§4)。

动效与交互

  • 按压瞬时、松手缓出(调研 10 签名巧思 1):状态切换本身 0ms,恢复才给 100~120ms 过渡——这是「跟手感」第一原则;WWDC18 803 同语义:所有交互对象「必须即时响应」(调研 09§4);
  • 两档语义对照:scale+alpha 档演示触屏物理感(数值标注未证实);色彩阶进档演示库默认工艺(不动 transform,零布局影响);
  • reduced-motion:prefers-reduced-motion: reduce 时去掉 transition 与 scale 形变,保留瞬时透明度/色彩状态切换——状态本身是信息,不应被删;
  • 性能:scale/opacity/filter 都不触发布局;高频按钮遵循 HIG「高频交互避免加动效」,只做瞬时色彩切换即可(调研 04§1.6)。

真实产品案例

  • Arco Design 按钮:primary 按钮 hover 变亮一阶(色阶-5)、按下变深一阶(色阶-7),且按下瞬时生效、松手 0.1s 恢复——「色彩阶进 + 瞬时按压」的源码级实现(调研 10§1.1);
  • Ant Design 按钮:默认按压不缩放,只对颜色系五属性做 0.2s easeInOut 过渡,另配可关闭的点击波纹(_util/wave)——「库默认=色彩反馈」的直接证据(调研 10§1.1);
  • apple.com 按钮:按压态 :active 只切换底色与字色变量(--sk-button-background-active),不加 outline——官网一手 CSS 实抓(调研 09§4)。

参数敏感度

参数调大会…调小会…
pressScale趋近 1 时按压感消失,只剩透明度反馈按压感更重;≤0.93 时文字形变明显,密集文本按钮可读性受损
pressAlpha更含蓄,对比度安全反馈更重;≤0.6 时文字对比骤降,浅色底上低于 4.5:1(WCAG 2.1 SC 1.4.3 风险)
releaseDuration松手更「黏」;超过 200ms 高频点击时上一次反馈还没结束,状态语义打架趋近 0 时与按压瞬时无异,回弹感消失;Arco 官方档位即 100ms
pressResponseeased 档按下也走过渡——按下感被延迟,是反面教学档instant(Arco 官方)按下 0ms 生效,跟手感最好
modecolor 档零布局影响、库默认语义,任何场景都安全scale 档物理感强但属社区惯例,密集列表/桌面高 DPS 场景慎用

经验区间:releaseDuration 100120ms、pressScale 0.950.98(社区惯例,未证实)、pressAlpha 0.7~0.8(同);桌面端成熟组件库的默认答案是色彩阶进,scale 是触屏/社区的流行补充。

适用场景 4
  • 所有可点按钮/卡片的基础反馈:默认做色彩阶进(Arco hover −5 / active −7 的语义)
  • 触屏优先的产品:scale+alpha 按压对提供物理『按下去』的错觉,释放用 100~120ms 缓出
  • 键盘可达性:`:active` 与 `:focus-visible` 成对设计,Space/Enter 触发时同样能看到按压态
  • 高频操作按钮:遵循 HIG『高频交互避免加动效』,只做瞬时色彩切换即可
何时不要用 4
  • 按下也加过渡——按压感被延迟,违反『即时响应』(WWDC18 803);Arco 官方即 `:active { transition: none }`
  • 把 scale 按压说成组件库默认——AntD/Arco/shadcn/Magic UI 默认按钮均无 scale,该说法无一手证据(调研 10§9)
  • 按压 alpha 压得太低(如 ≤0.6)——文字对比度骤降,浅色底上直接不可读
  • release 时长超过 200ms 还在回弹——高频点击时上一次反馈还没结束,状态语义开始打架
无障碍

按压态是视觉增强,不是可点击性的唯一信号(WCAG 2.1 SC 1.4.11 非文本对比:控件边界 ≥3:1);键盘用户经 `:focus-visible` 必须看到等价的焦点反馈(Apple 官网焦点环:2px accent outline + 1px offset,调研 09§3);`prefers-reduced-motion` 时保留状态切换、去掉回弹;按压导致的透明度变化不得把文字对比压到 4.5:1 以下(WCAG 2.1 SC 1.4.3)。

浏览器支持

实现只用 `:active`/`:focus-visible` + transition/transform/opacity,均为 Baseline 能力;`:active` 在触屏上跟随触摸按下生效。demo 另用 pointer 事件驱动高亮语义读数,事件均为 Baseline。

兼容回退

prefers-reduced-motion 时取消 scale 回弹与 release 过渡,保留瞬时色彩/透明度状态切换(状态本身是信息,不应被删);按压反馈不得作为传达『可点击』的唯一手段——仍需光标/形态等常规 affordance。

来源 5

起源两条一手源码证据链:Arco Button `transition: all 0.1s linear` + `:active { transition: none }`(按压瞬时,松手走 0.1s)与 primary hover=色阶-5/active=色阶-7;AntD Button 只过渡 color 等 5 个颜色系属性、时长 `motionDurationMid`=0.2s easeInOut,默认不缩放(调研 10§1.1)。Apple 侧对照:UIControl.isHighlighted『随合适的 touch 事件自动设置与清除』——按下进入、移出/释放退出,天然成对(调研 09§4)。
