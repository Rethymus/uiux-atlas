揭示转场族 Theme Reveal Wipes

百叶窗转场 · 棋盘格转场 · 对角擦除 · 多边形揭示 · reveal wipes · 几何揭示

百叶窗、棋盘格、对角擦除、多边形揭示四种 clip-path 关键帧几何揭示:单个常驻 overlay 拆成 N 块同构 basic-shape,逐块级联把旧主题擦掉露出新主题——与圆形扩散(color/theme-transition)互补:该条目讲官方圆形配方,本条目讲其余几何揭示。

patternblinds

JS 型参数(demo 订阅后重建液块)。blinds=横条逐条上下交替收条(调研 §6.3:8–12 条);checkerboard=格子向自身中心收点、按 (行+列) 对角波级联(调研 §6.3 先例 6×4,demo 列数=stripes、行数=⌈stripes/2⌉);diagonal=45° 斜带沿对角方向平移出框;polygon=自中心扇形展开的大三角互相咬合、收拢回圆心(调研 §6.3:大三角 2–4 块,『块形用 clip-path polygon() 而非背景块』正是同构 basic-shape 可插值)。四种模式各自 from/to 同构,不跨型混用。

duration500ms
ms

目标总时长。默认 500 = M3 整屏/大区域档(调研 §5『按过渡面积定时长:小区域 200ms、大区域 500ms』;§6.3 整族对齐 500)。派生:单块时长 = duration − 级联 × 最大延迟档数,级联默认 20ms(调研 §6.3 级联带 15–30ms 取中值);单块被压穿 150ms 下限时级联先压缩、仍不足则总时长向上修正——data-fx-duration 始终写实际总时长。缓动用无过冲减速曲线 cubic-bezier(0.3, 0, 0.2, 1)(调研 §6.3 原文;揭示类禁过冲,与 color/theme-transition 同结论)。

代码拆解

结构与 DOM

揭示转场族是「一张 overlay + N 块液块」的结构:换肤(data-fx-theme 翻转)发生在底层,表演层是一层常驻 overlay,内部 N 个绝对定位的液块把舞台铺满——动画开始时液块以旧主题底色整层覆盖(t=0 无闪变),随后逐块按 clip-path 关键帧擦除,露出底下已经切成新主题的界面。

<div class="stage" data-fx-theme="dark" data-fx-duration="500">
  <div class="content">…正常内容,颜色随 data-fx-theme 即时翻转…</div>
  <button data-fx-toggle>切换主题</button>
  <div class="overlay" data-from="light" aria-hidden="true">
    <span class="cell" style="--rw-in: inset(0 0 0 0); --rw-out: inset(0 0 100% 0)"></span>
    <!-- ×N:百叶窗横条 8–12 / 棋盘格 6×4 / 对角斜带 / 多边形 2–4 块大三角(调研 §6.3) -->
  </div>
</div>

关键点:

  • 换肤与表演完全解耦:点击即翻转主题变量,overlay 在 t=0 已整层盖住换肤瞬间,观众只见「旧主题被擦走」;
  • 四种模式的块形全部是同构 basic-shape(inset() 四分量一致 / polygon() 顶点数一致)——MDN clip-path 页 Formal definition 写明:只有 <basic-shape> 可动画插值,url() 引用不可(调研 20§1.2);同构插值已在本机无头 Edge 实证:两条同构 path() 在过渡伪元素上逐坐标线性插值、三帧 computed 值与理论值逐点吻合(调研 20a§S1),CSS 变量逐帧驱动 clip-path 在普通元素上同样成立(20a§S4);
  • 与 color/theme-transition 的圆形扩散互补:该条目讲官方圆形配方(::view-transition-new(root) 上的 circle() 扩散),本条目讲其余几何揭示;两者共用「换肤解耦 + 禁过冲 + reduced-motion 直切」的骨架;
  • overlay pointer-events: none 且 aria-hidden——擦除不挡点击、不承载信息,切换按钮始终可点。

样式与参数

全部液块共用同一条 CSS 动画,差异只在三个变量:入态 --rw-in、出态 --rw-out、逐块递增的 --rw-delay:

.cell {
  position: absolute;
  clip-path: var(--rw-in);
  animation: wipe var(--rw-cell-dur) cubic-bezier(0.3, 0, 0.2, 1) var(--rw-delay) forwards;
}
@keyframes wipe { to { clip-path: var(--rw-out); } }

/* 百叶窗:相邻条上下交替收条(inset 同构) · 棋盘:格子收向自身中心
   对角:斜带 polygon 整块平移出框 · 多边形:扇形三角收拢回圆心(polygon 同构) */
.overlay[data-from="light"] .cell { background: #f2efe8; } /* 旧主题底色 */
.overlay[data-from="dark"]  .cell { background: #14161b; }

时间结构(demo 逐次实算,data-fx-duration 始终写实际值):

单块时长 = duration − 级联 × 最大延迟档数
实际总时长 = 单块时长 + 级联 × 最大延迟档数
默认:duration 500、级联 20ms、百叶窗 8 条 → 单块 500 − 20×7 = 360ms(单块带 300–400ms ✓)

数值出处(调研 20):

  • 500ms 总时长:M3「按过渡面积定时长:小区域 200ms、大区域 500ms」整屏档(§5),§6.3 整族对齐 500;
  • cubic-bezier(0.3, 0, 0.2, 1):调研 §6.3 关键帧原文,无过冲减速曲线;揭示类禁过冲(回缩露馅),与 color/theme-transition 条目同结论;
  • 块量级:百叶窗横条 8–12、棋盘 6×4、多边形大三角 2–4;块数自适应 min(12, 屏宽/120)(§6.3);
  • clip-path Baseline Widely available(2020-01 起,MDN,§1.4)。

动效与交互

  • 一次点击三拍:①翻转舞台 data-fx-theme(界面即刻进入新主题变量);②挂载 overlay——N 块旧主题色液块整层覆盖;③逐块按级联延迟擦除,露出新主题;
  • 中断(动画进行中再次点击):清计时器、以新 key 重建 overlay 从头播——液块重新整层覆盖(此时盖的是当前主题色),不停在半途。语义对应视图过渡的「一次只能运行一个,新过渡开始时旧过渡跳到结尾」(Chrome 文档,调研 §1.1;二次点击/skip 行为已在无头 Edge 实证,调研 20a§S8);
  • reduced-motion:时长视作 0——点击直切、不挂 overlay(C39,调研 §5);matchMedia 变化动态生效;
  • 不依赖 View Transitions API:overlay 方案天然独立于 document.startViewTransition 播放(调研 §6.6「纯 overlay 方案天然不依赖 API」)——API 机制本身见站内 motion/view-transitions 条目;要搬进 VT 有两条已实证的路——::view-transition-new(root) 上 WAAPI 双同构 path 插值(20a§S1)或 CSS 变量逐帧驱动 clip-path(20a§S4);不要把 SVG 滤镜挂到过渡伪元素上加液缘,实测被忽略(20a§S5 反证);
  • 级联编排与站内 motion/stagger-orchestration 条目同构:第 i 块在 i × 级联后启动,铺开 = 级联 × 最大延迟档数。

真实产品案例

  • Chrome 官方开发者文档(View Transitions same-document 页):同族「root 快照 + clip-path 揭示」的官方配方出处——圆形扩散即该页「Animating with JavaScript」小节示例(circle() 从点击点扩散,500ms ease-in);本条目是同一骨架下的其余几何形状(调研 §1.1 逐字复核);
  • Cuberto/liquid-swipe(iOS,MIT,2984★)及同族开源:liquid_swipe_flutter(1266★)、Chrisvin/LiquidSwipe(Android,848★)——「波浪形 path 作页面遮罩、旧页被卷走」的液态揭示家族,GitHub API 逐仓核实(调研 §4);属页面级液态揭示而非主题切换,是揭示转场族的近亲先例。网页端大厂产品的「几何揭示换肤」公开实现,调研未找到可打开且确定的先例(§4),不作罗列。

参数敏感度

参数调大会…调小会…
pattern枚举无大小序;按档看:diagonal/polygon 方向感强、对宽高比不敏感,checkerboard 最「分区」,blinds 介于两者四档共用同一时间结构;inset 系(百叶窗/棋盘)块随屏幕比例伸缩,斜带/扇形的块形恒定
duration擦除更从容;>500ms 开始拖沓(M3 整屏档即 500,§5)趋近直切;200ms 档单块被压到 150ms 下限、级联自动压缩,实际总时长可能略超设定值(data-fx-duration 写实际值)
stripes块多节奏密、单块变短;12 块百叶窗单块 280ms(级联 20ms×11 档)块少揭示粗犷、方向感更强;≤3 块时接近「分块淡出」而非擦除
级联(派生)调研 §6.3 给 15–30ms 带:>30ms 块间脱节、逐块「点名」感明显<15ms 趋近整层一起动,级联叙事消失

经验区间:总时长 400–500ms、级联 15–30ms、单块 300–400ms、块数 8–12(全出自调研 §5/§6.3);窄屏减块。

适用场景 3
  • 低频换肤的仪式感场景:设置页、个人主页、活动/发布会皮肤——500ms 几何揭示让『换了主题』可感知(调研 §5 高频交互不加动效的反用:仅低频使用)
  • 与圆形扩散混用编排:全局默认圆形扩散(color/theme-transition),营销/节日皮肤切换到几何揭示族
  • 内容分区明显的界面用棋盘格(逐区换装可读),阅读型页面用百叶窗/对角(方向感最强)
何时不要用 4
  • 高频主题切换——每次点击都是一次全屏运动动画(Apple HIG:高频交互避免加动效,调研 §5)
  • 过冲曲线(ease-out-back 一类)——揭示类回缩露馅,禁用(调研 §6.3;与 color/theme-transition 条目同结论)
  • 块数多且单块被压到极短——节奏发碎;按 min(12, 屏宽/120) 自适应减块(调研 §6.3)
  • reduced-motion 用户只给『没有动画』不给『换肤完成』——直切后界面必须立即停在新主题的正确状态
无障碍

主题换色本身是瞬时变化,不属于 motion animation(WCAG 2.3.3 边界,调研 §5);但几何擦除是交互触发的运动动画,必须可禁用——demo 在 prefers-reduced-motion 下时长视作 0、点击直切(C39/SCR40 充分技术,调研 §5)。擦除层 aria-hidden 且 pointer-events:none,不承载信息不挡交互;『主题已切换』的结论由换肤后的颜色与文字对比承载,两套主题变量分别按 4.5:1 核对(WCAG 1.4.3);动效不是传达切换的唯一通道。

浏览器支持

clip-path Baseline Widely available(2020-01 起,MDN,调研 §1.4);同构 basic-shape 关键帧插值属 CSS clip-path 动画,各主流引擎均支持。demo 不依赖 document.startViewTransition——overlay 独立于 VT 播放(调研 §6.6『纯 overlay 方案天然不依赖 API』),无 VT 的引擎行为一致;注意不要把 SVG 滤镜挂在过渡伪元素上加液缘——实测被忽略(调研 20a§S5 反证),液缘要烘进 path 本身或走普通元素双层。

兼容回退

prefers-reduced-motion: reduce → 时长视作 0,点击直切、不挂擦除层(WCAG 2.3.3/C39,调研 §5);无 View Transitions API 的引擎 → 无需处理,overlay 方案天然不依赖 API;clip-path 不可用的遗留环境 → 整层 opacity 退场替代;动画进行中再次点击 → 清计时器、以新 key 重建 overlay 从头播,不停在半途。

来源 3

起源配方出自调研 20§6.3:单个 overlay + N 个液块子元素,全部块共用同一条 CSS 动画、仅 animation-delay 逐块递增(级联编排与站内 stagger-orchestration 条目同构);整族总时长对齐 M3 整屏 500ms 档、单块 300–400ms + 15–30ms 级联(调研 20§5/§6.3);块形用 clip-path basic-shape,因为同构 polygon()/inset() 才可逐坐标插值、url() 引用不可插值(MDN clip-path 页 Formal definition,调研 20§1.2);同构插值已在本机无头 Edge spike 实证——两条同构 path() 在 ::view-transition-new(root) 上逐坐标线性插值、三帧 computed 值与理论值逐点吻合(调研 20a§S1);CSS 变量逐帧驱动 clip-path 在普通元素上同样成立(调研 20a§S4)。

  1. 条目 编排交错

    搭配:液块级联就是 stagger 数学的纯 CSS 现场版:第一项 0 延迟立即入场、末项在 stagger×(n−1) 后启动,这里即第 i 块在 i×级联后擦除。

  2. 条目 主题切换过渡

    对比:同一换肤骨架的两个几何答案易混:那边是官方圆形扩散(快照层被圆形 clip-path 逐步揭开),这边是其余几何的纯 overlay 逐块擦除。

  3. 条目 元素级翻转换肤

    反向自「元素级翻转换肤」的精选:搭配关系,原句「换肤编排的姊妹篇:那边液块按级联逐块擦除(第 i 块在 i × 级联后启动),这边卡片逐张翻到 90° 侧棱换装——同构时间结构两种块形。」
