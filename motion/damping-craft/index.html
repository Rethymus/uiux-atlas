阻尼感设计 Damping Ratio Craft

阻尼比 · damping ratio · ζ 手感 · critical damping

ζ(阻尼比)是手感的第一变量:0.3~0.7 是『弹』区、0.5~0.8 是多数 UI 的目标区、ζ=1 临界最快无过冲、>1 过阻尼粘滞——同一目标位下四种手感,由一个比值决定。

参数
几何▾
zeta0.5

阻尼比 ζ=c/(2√(mk))(demo 的可调轨)。默认 0.5 = Motion 源码默认弹簧的阻尼比(100/10,mass 1),过冲≈16.3%(调研 10§6.3)。0.3~0.7 是『弹』区;0.7~0.85 适合高频交互;ζ=1 临界最快无过冲;>1 过阻尼粘滞(调研 10§6.2)。

stiffness200

刚度 k(mass=1,ω₀=√k),作用于全部五条轨。感知规律(推导+实算,调研 10§4.3):同一 ζ 下提高 ω₀ → 波次更密、单次过冲比例不变——『抖几下由 ζ 定,抖多快由 ω₀ 定』。调大整体更急促;调小整体更慢。

结构与 DOM

演示是同一目标位下的五条弹簧轨:顶部一条可调轨(ζ 连续可调)+ 四条固定参考轨(0.3 强弹 / 0.5 Motion 默认 / 0.8 微弹克制 / 1.1 过阻尼)。每条轨只有「目标位标记 + 一只球」:

<div class="dc-row">
  <div class="dc-meta"><b>强弹 ζ=0.30</b><span>过冲 37.2%</span><span>包络→5% 300ms</span></div>
  <div class="dc-lane" aria-hidden="true">
    <div class="dc-goal"></div>
    <motion.div class="dc-ball" style="x"></motion.div>
  </div>
</div>

关键点:

  • 五轨共享同一 stiffness、同一目标位——ζ 是唯一变量,差异全部来自阻尼比;
  • 每轨读数(过冲 %、包络→5% 时间)由公式本地实算,与动画并行显示,「手感」随时可被数值引用;
  • 轨道 aria-hidden,演示为纯视觉对照,不承载唯一信息。

样式与参数

两个 JS 型参数,由 demo 换算成每轨的 Motion 弹簧:

// 每轨 damping 由阻尼比反解(mass=1):c = 2·ζ·√(k·m) —— 维基临界阻尼定义 c_c=2√(mk)
const damping = 2 * zeta * Math.sqrt(stiffness);
animate(x, target, { type: "spring", stiffness, damping, mass: 1 });

// 读数(本地实算,调研 10§2.3):
const w0 = Math.sqrt(stiffness);                    // ω₀ = √(k/m)
const overshoot = Math.exp(-Math.PI * zeta / Math.sqrt(1 - zeta * zeta)) * 100; // ζ<1
const envelope5 = Math.log(20) / (zeta * w0) * 1000; // 包络衰减到 5% 的毫秒数

数值出处(调研 10§6.1/§6.2/§6.3/§4.3):

  • 物理定义(维基 Damping ratio):ζ=c/c_c、ω₀=√(k/m)、m·x''+c·x'+k·x=0;0<ζ<1 欠阻尼(过冲振荡指数衰减)、ζ=1 临界(最快无过冲)、ζ>1 过阻尼;
  • ζ→过冲表(本地 Python 实算):0.10→72.9%、0.15→62.1%、0.25→44.4%、0.50→16.3%(Motion 源码默认弹簧 100/10)、0.70→4.6%、0.80→1.5%(BuildUI bounce 0.2)、1.00→0;
  • 感知区间:0.3–0.7 =「弹」区;0.5–0.8 = 多数 UI 目标区;0.7–0.85 适合高频交互;ζ=1 = Apple 官方『更阻尼更少震荡』档;ζ>1 过阻尼粘滞(Motion 的负 bounce 支持同一语义);
  • bounce↔ζ 换算(Motion 源码 bounceToDampingRatio):bounce 0.2→ζ0.8、0.3→ζ0.7、0.7→ζ0.3;SwiftUI dampingFraction 即 ζ,官方默认 0.825(过冲≈1.3%,swiftui-spring 条目双源一致)。

动效与交互

  • 同跑对照:点「发射」五球同目标同起点同时出发——0.3 档大幅过冲、0.5 档一晃、0.8 档微颤、1.1 档爬行,四种手感一屏可辨;
  • 参数即改即看:拖 ζ 滑杆只改可调轨的阻尼比;拖 stiffness 改变全部轨的节奏(波次密度)——验证「ζ 定抖几下、ω₀ 定抖多快」;
  • 中断接力:连点发射,物理弹簧从当前位置+速度续接;
  • reduced-motion:跳过动画,五球直落目标位,读数保留;
  • 性能:只动 transform(球位移),合成器友好。

真实产品案例

  • Motion(framer-motion 后继)默认弹簧:源码 stiffness:100, damping:10, mass:1 → ζ=0.5、过冲≈16.3%——「UI 弹簧的出厂手感」落在弹区中段(调研 10§6.3);
  • Apple UISpringTimingParameters.init(dampingRatio:):ζ 是 iOS 弹簧的一等参数,官方表述『更阻尼更少震荡 → 1.0;更多震荡 → 接近 0.15』——平台级证据(调研 10§4.3);
  • BuildUI 卡槽气泡:bounce 0.2 / duration 0.6 → ζ≈0.8、过冲≈1.5%——「微弹克制」档的生产实例(调研 10§2.1)。

参数敏感度

参数调大会…调小会…
zeta过冲指数式下降:0.7→4.6%、0.8→1.5%、1→0(临界最快无过冲);>1 过阻尼,起步快收尾慢(粘滞)过冲指数式上升:0.3→37%、0.25→44%、0.15→62%(Apple『多震荡』下限)、0.1→73%(弹跳球)
stiffnessω₀↑:全轨更急促,波次更密、包络时间缩短,过冲比例不变全轨更慢更黏;同一 ζ 下只是把节奏放慢,手感类别不变
参考档对照0.8 档是「克制」的天花板:能感到颤但不闹;1.1 档展示过阻尼的代价(到位慢)0.3 档展示「玩具感」的下限;0.5 档是 Motion 出厂值,两极之间的锚
读数(只读)过冲 % 让「弹多少」可评审;包络→5% 让「多久安定」可排期—

经验区间:多数 UI 用 ζ 0.50.8(过冲 16%→1.5%);高频交互 0.70.85;强调手势收尾 0.3~0.5;任何参数组合先算 ζ 再上(巧思 3),守住 0.7±0.1 是通用甜点。

适用场景 4
  • 为控件选『手感档』:先定 ζ 区间(弹 0.3~0.7 / 稳 0.7~1 / 粘滞 >1),再用 ω₀ 调节奏
  • 校准弹簧预设:Motion bounce 与 ζ 的换算(bounce 0.2→ζ0.8、0.3→ζ0.7)用本条目读数核对
  • 大元素调 mass 前的基准实验:先在同 mass=1 下锁 ζ,再单独评估 mass 的『大物沉』效应(Motion mass:'auto' 同理,调研 10§6.3)
  • 评审/教学:同一目标位下四档 ζ 并排跑,过冲与包络时间读数让『手感』变成可讨论的数值
何时不要用 4
  • ζ<0.3 的弹跳球手感放进表单/列表等高频交互——过冲 >37% 是玩具感,不是活力(调研 10§6.2)
  • 把 stiffness/damping 当独立手感旋钮乱调而从不计算 ζ——`500/50` 这类组合是过阻尼假弹簧(ζ≈1.118)(调研 10§2.3/巧思 3)
  • 进度条/连续量用欠阻尼弹簧——连续量不该有过冲(参考 motion-spring 条目告诫)
  • ζ>1.2 的重度过阻尼放在需要『到位感』的反馈上——粘滞感会被读成卡顿/失灵
无障碍

演示为纯视觉对照,不承载唯一信息(每轨有文字标签与读数);prefers-reduced-motion 时直落终态;大幅振荡动画是前庭障碍触发源(MDN),所以本演示默认过冲有上限、且提供 reduced-motion 直落;真实的 UI 弹簧同样要给用户『可关闭/可中断』的动效(HIG Motion)。

浏览器支持

demo 用 Motion 物理弹簧驱动,依赖 JS,禁用 JS 时球停在初始位;ζ/过冲/包络读数为本地公式实算(与浏览器无关)。物理弹簧语义(set() 续接速度)由 Motion 实现。

兼容回退

prefers-reduced-motion 时跳过动画,五球直落目标位,读数条仍显示各轨 ζ/过冲换算;阻尼手感不得作为传达状态的唯一手段——落点状态同时由颜色/位置承载。

来源 5

起源物理定义出自维基 Damping ratio:ζ=c/c_c=c/(2√(mk))、ω₀=√(k/m)、临界阻尼 c_c=2√(mk)、过冲=e^(−πζ/√(1−ζ²))、包络→5% = ln20/(ζω₀)(调研 10§6.1/§2.3);感知区间结合 Motion 源码默认(stiffness 100/damping 10 → ζ=0.5,过冲 16.3%)与 Apple `UISpringTimingParameters.init(dampingRatio:)` 官方表述——『更阻尼更少震荡取 1.0;要更多震荡取接近 0.15』(调研 10§6.2/§4.3)。Motion 源码 bounceToDampingRatio:bounce 0.2→ζ0.8、0.3→ζ0.7、0.7→ζ0.3(调研 10§6.3)。
