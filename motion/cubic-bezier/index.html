贝塞尔缓动 Cubic Bézier Easing

贝塞尔缓动 · cubic-bezier() · 自定义缓动曲线

cubic-bezier(x1,y1,x2,y2) 用两个控制点定义进度-时间映射:x 必须落在 [0,1],y 可以越界制造过冲回弹——CSS 缓动的通用底层表达。

Web 标准 ★★★
实例演示 官方默认
参数
动效▾
curvecubic-bezier(0.25, 0.1, 0.25, 1)

缓动曲线本体,写入 animation-timing-function / transition-timing-function。默认 (0.25, 0.1, 0.25, 1) 即关键字 ease 的官方数值(MDN);x∈[0,1],y 可越界(面板限 -0.5–1.5)产生 overshoot 回弹(MDN 示例 cubic-bezier(0, 1.1, 0.8, 4))。四个关键字预设官方数值:ease (0.25,0.1,0.25,1)、ease-in (0.42,0,1,1)、ease-out (0,0,0.58,1)、ease-in-out (0.42,0,0.58,1)。

代码拆解

结构与 DOM

演示分两块并排:左边是运动区(一条轨道 + 一颗球),右边是曲线预览(SVG 坐标系)。DOM 只有三个必需件:

<div class="cb-track">
  <div class="cb-ball"></div>  <!-- animation-timing-function: var(--cb-curve) -->
</div>
<svg viewBox="0 -40 100 180">  <!-- 预留 y>1 / y<0 的越界带 -->
  <path class="cb-curve" d="M 0 100 C …" />
  <g class="cb-dot-x"><circle class="cb-dot-y" cx="0" cy="100" r="4.5" /></g>
</svg>

关键点:

  • 球的往返、预览里示踪点的水平/垂直分量,消费的是同一个 cubic-bezier() 值——预览与运动天然同步;
  • 示踪点拆成两层嵌套:外层 g 做线性水平移动,内层 circle 做贝塞尔垂直移动。CSS 多动画写同一属性会互相覆盖,嵌套是合成两个时间函数的唯一干净办法;
  • 预览把 SVG 的 y 轴映射为「进度」:y = (1 - 进度) × 100,顶部越界带(y>1)与底部越界带(y<0)画出过冲区间。

样式与参数

单一参数 curve(cubicBezier 型,经 --cb-curve 注入),即曲线本身:

.cb-ball {
  animation: cb-run 1.6s var(--cb-curve) infinite alternate;
}
@keyframes cb-run {
  from { transform: translateX(0); }
  to   { transform: translateX(var(--cb-dist)); } /* 轨道宽 - 球径,JS 测量注入 */
}
.cb-dot-x  { animation: cb-dot-x 1.6s linear infinite alternate; }                       /* 水平:匀速 = 时间轴 */
.cb-dot-y  { animation: cb-dot-y 1.6s var(--cb-curve) infinite alternate; }              /* 垂直:贝塞尔 = 进度 */

数值出处(MDN <easing-function> 原文,调研 04§1.1):

  • 默认 ease = cubic-bezier(0.25, 0.1, 0.25, 1);
  • 四个关键字预设官方数值:ease-in = cubic-bezier(0.42, 0, 1, 1)、ease-out = cubic-bezier(0, 0, 0.58, 1)、ease-in-out = cubic-bezier(0.42, 0, 0.58, 1)(另 linear = cubic-bezier(0, 0, 1, 1));
  • x1、x2 必须在 0,1;y 可以越界——MDN 示例 cubic-bezier(0, 1.1, 0.8, 4) 即靠 y>1 实现过冲。

只动画 transform(球位移、示踪点),符合 web.dev「只动 transform/opacity」的性能底线(调研 04§1.5);球位移距离用 JS ResizeObserver 测量后写入 --cb-dist,避免动画 left。

动效与交互

  • 实时联动:拖动参数面板的两个控制点(或点 ease/ease-in/ease-out/ease-in-out 预设),--cb-curve 即时更新——运行中的 CSS 动画会按新曲线重新插值,球与示踪点同步变形,无需重启;
  • 重播:点「重播」通过 React key 重挂载动画元素,从头播放一遍当前曲线(便于观察起步/收尾段);
  • 越界可视化:曲线越过顶部线(y=1)即为过冲段,示踪点会短暂冲出进度 100% 的位置再回落;
  • reduced-motion:prefers-reduced-motion: reduce 时停用全部循环动画,球静置在终点、示踪点钉在曲线末端,预览仍完整展示曲线形状——信息不丢。

参数敏感度

单一参数 curve,但四个控制点各有分工,逐一说明:

控制点调大会…调小会…
curve 整体前后两段都变陡,动画「先抢跑后刹车」的对比更强趋近直线,读作 linear 匀速
x1(P1 时间)起步延迟更久,前段显得「迟钝」起步更早更急;为 0 时起步即最大斜率
y1(P1 进度)>1 直接过冲(先冲过头再回头);前段冲刺感强<0 先反向「蓄力」再前进;前段更拖
x2(P2 时间)收尾加速段开始得更晚,中段平台期更长更早进入收尾;为 1 时收尾段被压缩到极短
y2(P2 进度)>1 末段过冲回弹;<1 减速收尾(ease-out 手感)越低末段越「悬停」;为 0 时刻意停顿后才到位

经验区间:通用过渡 ease 系四预设覆盖九成场景;轻回弹取 y∈(1, 1.5);y>2 的强过冲只适合极短行程,否则读作失控。注意单段贝塞尔表达不了真弹簧——可打断、速度继承只能靠 JS 物理弹簧或 linear() 采样近似(调研 04§1.2/1.3)。

适用场景 4
  • 通用 UI 过渡的默认手感(ease);小控件配 150–200ms 时长(调研 04§2.1)
  • 进入屏幕用 ease-out 系减速收尾、永久退出用 ease-in 系加速离场(M3 缓动选型同构,调研 04§1.4)
  • 强调性到位与轻回弹:y1 或 y2 > 1(如 (0.34, 1.56, 0.64, 1)),宜短行程小幅度
  • 对齐官方体系曲线,如 M3 Standard = cubic-bezier(0.2, 0, 0, 1)(调研 04§1.4)
何时不要用 4
  • 进度条、滚动同步等连续量——用 linear,不该有加减速(调研 04 清单#1)
  • 需要可打断、速度继承的真弹簧——单段贝塞尔表达不了,只能 linear() 采样近似(调研 04§1.2/1.3)
  • 长行程大幅度的 y 越界回弹——位移类动效是前庭触发源,必须提供 reduced-motion 降级(调研 04§6)
  • 逐帧/步骤化状态切换——用 steps() 而非贝塞尔(调研 04§1.1)
无障碍

缓动曲线本身不承载信息,但过冲与大幅位移是前庭障碍的常见触发源:装饰性动画必须响应 prefers-reduced-motion 降级(demo 已内建);y 越界回弹避免用于持续循环;信息不得依赖动画完成才可读(HIG:动效可取消、不作关键信息唯一渠道,调研 04§1.6/§6)。

浏览器支持

cubic-bezier() 属 CSS Transitions/Easing 基础能力,全主线浏览器自 CSS3 时代起可用,无版本风险,y 越界回弹同样全支持。要把弹簧类曲线导出为纯 CSS 时,改用 linear() 分段采样(Baseline 2023-12 起全浏览器可用,调研 04§1.2)。 · Widely available (long-standing CSS Transitions/Easing feature; no modern support risk)

兼容回退

无需降级:cubic-bezier() 不支持的场景仅存在于禁用 CSS 的极端环境,元素直接呈起止态,信息不丢失——缓动只改变过程观感,不改变起止值。装饰性动画本身仍须响应 prefers-reduced-motion(demo 内建)。
