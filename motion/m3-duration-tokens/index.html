M3 时长令牌 M3 Duration Tokens

时长分档 · duration tokens · md.sys.motion.duration

Material 3 官方时长四档 16 令牌:short 50–200ms(小工具类)、medium 250–400ms、long 450–600ms、extra-long 700–1000ms;按转场覆盖面积选档,>600ms 仅限无用户输入的环境类转场。

结构与 DOM

时长令牌不是 DOM 结构,而是一张选档表:先给转场分类(它覆盖多大面积、进还是出、有没有用户输入),再从官方四档里取一个令牌名。落地时 DOM 只需要一个承载过渡的元素:

<!-- 选择控件类过渡:short4 = 200ms -->
<button class="chip" style="--md-duration: 200ms">…</button>

<!-- 容器转场:FAB→Sheet = medium4 400ms;Card→全屏 = long2 500ms -->
<div class="sheet" style="--md-duration: 400ms">…</div>

关键点:

  • 官方令牌名为 md.sys.motion.duration.{tier}{n},四档各 4 个序号:short1–4、medium1–4、long1–4、extra-long1–4;
  • 档位是语义而非连续刻度:选择控件归 short(官方示例 200ms + Standard),FAB→Sheet 归 medium(400ms),Card→全屏归 long(500ms + Emphasized);
  • demo 用一个采样卡片按所选令牌重播入场,参数面板切档即可对比手感。

样式与参数

两个枚举参数(tier / step)都是 JS 型,demo 订阅后换算成 ms 注入动画时长;曲线固定 Standard cubic-bezier(0.2, 0, 0, 1):

.sample {
  animation: enter var(--md-duration, 200ms) cubic-bezier(0.2, 0, 0, 1) both;
}
@keyframes enter {
  from { opacity: 0.25; transform: translateY(14px) scale(0.97); }
  to   { opacity: 1; transform: none; }
}

配套官方准则:时长按转场覆盖面积缩放(小面积 200ms、大面积 500ms);进入比退出更长(示例进入 500ms / 退出 200ms);>600ms 仅用于无输入的环境转场。

动效与交互

  • 换档即重播:tier/step 任一变化,demo 重挂载采样卡片,动画按新时长从头播——同一曲线下只变时长,手感差异(从容 vs 拖沓)直接可比;
  • >600ms 警示:选中 extra-long 档时 demo 标出官方口径「仅限无用户输入的环境类转场」;
  • 进入/退出不对称:退出类转场应取同档或更低时长(官方示例退出 200ms),把注意力留给下一任务;
  • 性能:动画只落 opacity/transform(web.dev 底线,调研 04§1.5);
  • reduced-motion:reduce 时直出终态,不按时长播放位移类转场;时长档位仍可留给纯 opacity 微动效。

与缓动选择的关系见 easing-pairs 条目(官方配对表把档位与曲线绑成六组);小控件按压反馈的选档实例见 press-feedback 条目。

真实产品案例

  • 选择控件(M3 官方示例):开关/复选/单选类小控件统一取 short4 200ms + Standard easing——这是 tokens 页的官方示例注,也是小面积状态变化的事实基准档;
  • FAB→Sheet(M3 官方示例):悬浮按钮展开为 Sheet 的容器转场取 medium4 400ms;Card→全屏取 long2 500ms + Emphasized——官方用这两例示范「按面积选档」;
  • 进入/退出不对称(官方准则):进入 500ms / 退出 200ms 的示例配比出自 M3 官方准则,Android/iOS 系统转场普遍退得比进得快(见 page-transitions 条目)。

参数敏感度

参数调大会…调小会…
tier面积更大的转场获得更从容的铺开;extra-long 档(700–1000ms)只能服务无输入的环境转场,用户输入触发时会读作迟滞转场更利落;short 档(50–200ms)适合小控件,大面积转场会显得仓促突兀
step档内更慢,与相邻档的边界更模糊(如 short4 200ms ≈ medium 档下限 250ms 的观感)档内更快,趋近上一档上限;50ms 级的差异在小控件上几乎不可辨

选型口诀:先问「转场覆盖多大面积、谁触发的」,面积定档、输入定上限(>600ms 禁用于输入触发),档内序号做微调;进入恒长于退出。

适用场景 4
  • 选择控件(开关/复选/单选)的状态过渡——官方示例 short4 200ms + Standard
  • 容器转场选档:FAB→Sheet 用 medium4 400ms,Card→全屏用 long2 500ms + Emphasized(官方示例)
  • 按转场覆盖面积缩放时长:小面积 200ms、大面积 500ms(M3 官方准则)
  • 无用户输入的环境类转场(加载氛围、环境反馈)可用 extra-long 档 700–1000ms
何时不要用 3
  • >600ms 的时长用在用户输入触发的转场上——官方明确超出即属环境类,用户会觉得迟滞
  • 为「显得精致」整体上调档位——退出类转场应比进入更快(官方示例进入 500ms / 退出 200ms)
  • 把 extra-long 档当作「重要 = 更久」的强调手段——时长应跟随面积与注意力,不是权重
无障碍

时长档位不豁免 prefers-reduced-motion:reduce 时位移类转场直出终态(前庭安全,MDN);动效不得是传达关键信息的唯一渠道(HIG:需可辅以 haptics/音频);进入比退出更长的官方原则把注意力还给下一任务,对认知负荷友好。

浏览器支持

时长令牌是设计规范值而非 Web API,demo 以 CSS animation 承载(各浏览器对 CSS animation 的支持本次调研未逐项核验);同页官方配对表中的 Emphasized 曲线在 CSS 无等价贝塞尔(官方标注 N/A,以 Standard 兜底,调研 04§1.4)。

兼容回退

prefers-reduced-motion 时不要按令牌时长播放位移类转场——直接呈现终态(等价 0ms 直切);降级语义与官方「动效可取消」原则一致(HIG,调研 04§1.6)。时长档位仍可保留给 opacity 类微动效。
