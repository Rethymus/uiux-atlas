Chart Accessibility Two-tier alternative text for complex images: a short alt/svg aria-label naming type + summary, an in-page long description carrying trends/scale/color order; the carrier of choice is figure role=group + figcaption (visible to everyone), while aria-describedby takes plain text only — plus two non-color channels: direct labels and decal patterns. Web Standard ★★ Chart Animation Three entrances — grow (rise from the zero baseline) / fade / sweep (left-to-right clip-path reveal): 1000ms, easeOutQuart (Chart.js official defaults), animation on the data layer only while axes and grids stay still; under prefers-reduced-motion the final state renders directly. Component Lib ★★ Categorical Palette A qualitative scheme whose colors are distinctly different yet mutually equivalent: take colors in the official order, cap at 8 classes, and let lightness differences secure adjacent contrast. Community ★★★ Chart Axes & Grid The chart's 'table lines' discipline: grids stay faint (Grafana inverts the theme text color at 9% alpha), axis lines are optional (ECharts vs ggplot2 take opposite defaults), tick counts stay restrained (ECharts splitNumber defaults to 5) — three params decide a line chart's professionalism. Component Lib ★★ Chart Selection Identify the data relationship first, then pick the chart: compare → bars, trend → lines, distribution → histogram, composition → stacked bars; columns/areas must start at zero, line charts may not. Community ★★ Colorblind-Safe Palette Audit charts with color-vision-deficiency simulation before shipping: flip the same charts between normal / deuteranopia / protanopia / tritanopia views, and add shape/line-style/texture redundancy — simulation is an approximation; redundancy is the insurance. Community ★★★ Data Color Ordering Series colors are an ordered queue, not a free palette: the official order maximizes adjacent contrast; to emphasize, mute the context series to gray and let only the focal series keep saturation. Community ★★ Dashboard Density The density base of BI grids: Grafana's 24 columns × 30px row height × 8px panel gap (source constants) driving Power BI's official example font ladder 45/12/12/10 — a comfortable/compact switch that retunes the whole board's breathing room. Component Lib ★★ Ordinal Scale A scale mapping ordered values to ordered colors: monochrome linear (light → dark) or multi-hue progression, taken as official ColorBrewer classes with the midpoint anchored to the data zero — the default for heatmaps and choropleths. Community ★★★ Scale Functions The mother formula of all mapping: a linear scale is normalize ∘ interpolate, y = r0 + (x−d0)/(d1−d0) × (r1−r0); the log scale runs the same pipeline in log space — domain→[0,1]→range, with adjustable domain/range computed live. Community ★★★ Tooltip & Legend The chart's two reading channels: the legend handles series lookup (right by default — ggplot2's source default), the tooltip handles precise values (ECharts defaults: mousemove trigger / 100ms hide delay), and WCAG 1.4.13 demands Esc-dismissibility, hoverability and persistence. Component Lib ★★ Small Multiples A row of similar small charts at one shared scale and axes: each panel tells a single series, and cross-panel comparison works only because every panel shares the same ruler — Tufte's defining requirement; the dual-axis mashup is its exact opposite.
