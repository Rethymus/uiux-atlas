Structure & DOM

Choosing a set is not renaming files — it is swapping a delivery form and style contract. The six sets’ real integration shapes:

<!-- SVG file/inline route (Lucide / Feather / Heroicons / Phosphor core) -->
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <path d="…" />
</svg>

<!-- Framework package route: lucide-react, @heroicons/react (tree-shaken by path) -->
<House size={24} strokeWidth={2} aria-hidden="true" />

<!-- Variable-font route (Material Symbols only): ligatures use words, not codepoints -->
<span class="material-symbols-outlined" aria-hidden="true">home</span>

Styling & Parameters

Two JS-type parameters drive the comparison view; the demo glyphs are self-drawn illustrations (no verbatim copies of official files), with style differences landing on four checkable numbers:

// Line sets: stroke-width is each set's identity
Lucide/Feather → strokeWidth 2 (Lucide defaultAttributes source value)
Heroicons      → strokeWidth 1.5 (measured from the real repo file; README sample still says 2 — stale copy)
Material Symbols → wght axis 100–700 (default 400), never by editing SVG widths

// Solid sets: stroke baked into filled outlines
Phosphor  → viewBox="0 0 256 256", fill="currentColor" (measured across six weights)
Classic Material Icons → 24-grid filled paths, five styles frozen

The selection triad (07 §0’s core narrative):

  1. Grid: 24 is the common ancestor (Lucide/Feather/Heroicons/Material); Phosphor’s 256 grid is the other pole;
  2. Stroke philosophy: the 2px anchor (Lucide/Feather) vs the 1.5px exception (Heroicons) vs the variable axis (Material wght) — “never rescale an SVG to fake a stroke change”;
  3. License: ISC (free for commercial and personal use, Lucide README), MIT ×3, Apache-2.0 ×2 — all commercial-friendly; one discrepancy recorded as-is: Lucide’s site says “1600+” while the repo blurb says “2000+”.

Motion & Interaction

Set comparison is a static view; demo interaction lives in the switches:

  • set switch: the main preview and the six mini cards move together; mini cards are clickable (two-way sync with the parameter panel through the store);
  • glyph switch: one semantic redrawn across six sets makes the stroke/fill differences obvious;
  • No motion effects, so prefers-reduced-motion needs no fallback;
  • A maintenance note: Feather is long unreleased and classic Material Icons is frozen — “activeness” is itself a selection dynamic; the checklist sits in avoid.

Real-world examples

  • The Lucide family: lucide plus nine framework packages (lucide-react/vue/svelte/solid/preact/react-native/angular/astro/static per the README packages table); animation is left to the host, never embedded SMIL (07 §1.1/§6.3);
  • @heroicons/react tree-shaking: import by path like @heroicons/react/24/outline; the project officially declines new icon PRs — pick another set if you need growth (07 §1.3);
  • Material Symbols subsetting: the Google Fonts service serves ~1.7KB fonts per icon_names subset (e.g. home,palette,settings), ~2.6KB with axis combos, and mandates &display=block against FOUC — the only sane route for putting a huge set on first screen (07 §1.5).

Parameter Sensitivity

ParameterTurning it up…Turning it down…
setmoving to Phosphor/Symbols buys weight flexibility (Fill/Duotone/wght) at the cost of delivery-form changes (filled paths / a variable font) and subsetting overheadstaying on Lucide/Feather’s fixed 2px stroke — the narrowest capability but lowest cost and the fullest package ecosystem
glyphswapping glyphs changes no style parameters — that is a “set’s” value: one style contract over the whole libraryhand-fitting a single glyph across sets (editing strokes/fills) breaks all three philosophies at once; migrate the set instead

Anchors: fix the grid first (24 or 256), then the stroke philosophy (fixed/exception/axis), then check license and maintenance; README sample values always get re-measured against repo files.

When to use 3
  • New-project selection: the triple default of a 24 grid + 2px stroke + currentColor (Lucide/Feather) is the cheapest starting line (07 §1.1/§1.2)
  • For filled/layered weights choose Phosphor (Fill/Duotone, one of two players) or Material Symbols' FILL axis (07 §1.4/§1.5)
  • In the Tailwind ecosystem or React/Vue-first codebases, choose Heroicons (tree-shakable path imports, 07 §1.3)
When not to use 3
  • Mixing sets on one page — grids align but stroke philosophies differ (2px vs 1.5px vs baked fills), visibly unbalanced weight (07 §0)
  • Adopting frozen sets for new work (classic Material Icons stopped in 2022; Feather long unreleased) without a migration assessment (07 §1.2/§1.5)
  • Trusting README sample values (Heroicons' sample says stroke-width=2, stale; measured 1.5) — repo files win (07 §1.3)
Accessibility

Set choice changes no accessibility obligations: stroke width stays bound by the WCAG 1.4.11 note (thin lines render fainter, 07 §3.3); Lucide's site keeps an Accessibility guide section; Material hands icon states to the FILL axis and its color system (07 §4.3). Every set's decorative instances deserve aria-hidden and semantic instances accessible names (see icon-aria-accessible).

Browser support

SVG delivery forms (inline/component/sprite) work in all mainstream browsers; Material Symbols rides a variable font, needing font-variation-settings support (fine in modern browsers), with the official &display=block anti-FOUC requirement and subsetting (icon_names ≈1.7KB) for weight control (07 §1.5). npm ecosystem: Lucide's nine framework packages, @heroicons/react|vue, Phosphor across platforms (07 §1). · widely available

Fallback

Fallback layers by delivery form: SVG component packages need none; the variable-font route (Material Symbols only) falls back to a static wght 400 instance on load failure; rejected cross-origin sprites go inline. At selection level, sets with stalled maintenance (classic Material Icons frozen since 2022; Feather long unreleased) warrant migration analysis rather than new adoption (07 §1.2/§1.5).

Sources 6

OriginAll six sets were verified against official repo READMEs and real SVG source files (out/design-study/07-icons.md §1): Lucide (ISC; defaultAttributes source-defines 24/2px/round/currentColor), Feather (MIT; 24×24 grid at 2px, of the same lineage), Heroicons (MIT; 24/20/16 tiers, 24/outline measuring stroke-width=1.5), Phosphor (MIT; six weights on a measured 256×256 viewBox delivered as filled paths), Material Symbols (Apache-2.0; opsz default 24, wght 100–700 variable axis), and classic Material Icons (same repo, Apache-2.0; five styles frozen since 2022). Heroicons' README quick-start still says stroke-width=2 — stale v1 copy; the file wins (07 §1.3); Phosphor's per-weight stroke pixel values are unpublished (unverified, 07 §7).
