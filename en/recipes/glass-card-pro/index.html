Glass Card Pro

4 entries

Glassmorphism material + M3 content-color state layers + Fluent theme shadow + press-feedback pair: a production-grade glass card in four cooperating layers.

Combines

Glassmorphism Frosted-glass panels: backdrop blur + translucent fill + a 1px hairline light border — only reads as glass over a rich, colorful backdrop. Community ★★★ State Layers (M3) Material 3 state layers: a low-opacity overlay of the content color on top of a control, with fixed percentages distinguishing hover/focus/press/drag instead of ad-hoc colors. Material 3 ★★★ ThemeShadow (Fluent) Fluent ThemeShadow: a preset shadow driven by the element's z coordinate (elevation), auto-adapting to light, theme and surroundings; non-Popup usage must declare Receivers, and only rectangular shadows are supported. Fluent ★★ Press Feedback Pair Press and release form a state pair: the press lands instantly (0ms) and only the release gets a short transition — mature libraries default to color-stepping, not scale; scale(0.95–0.98) is a community convention. Component Lib ★★★

Why these combine

Research 16 §7 recipe-a: Apple Liquid Glass is the only complete official glass system — glass belongs to controls/nav layers only (Don't use Liquid Glass in the content layer), use it sparingly; pick variants by semantics: regular (blur + brightness tuning for text-heavy overlays like alerts/sidebars/popovers) and clear (highly translucent, only over media; add a 35%-opacity dark dimming layer when the underlying content is bright), thickness ultraThin/thin/regular/thick by semantics — thicker = better contrast; text on materials must use vibrant colors (https://developer.apple.com/design/human-interface-guidelines/materials ). Press feedback is NOT expressed with glass but with M3 content-color state layers: color from the content color (on color), one layer at a time, fixed tiers hover +8% / focus +10% / press +10% / drag +16% (https://m3.material.io/foundations/interaction/states/state-layers ); elevation semantics live in shadows — M3 allows 0~+3 at rest with hover lifting one level, and "small and sharp = near, large and soft = far" (https://m3.material.io/styles/elevation/applying-elevation ); card hover takes Ant's level-1 shadow @shadow-1 (0 1px 2px -2px rgba(0,0,0,.16)…, exact §2.3 values) with a motionDurationFast 0.1s transition (https://ant.design/docs/spec/shadow-cn/ ), switching levels only when hierarchy truly changes. Custom buttons always carry a press state — Apple's "Always include a press state for a custom button" (https://developer.apple.com/design/human-interface-guidelines/buttons ), here as the paired scale-0.96 + alpha state layer. TDesign/Arco/Semi have no official glassmorphism card recipe → unverified (§9 list; container/spacing may lean on TDesign layout numbers, https://tdesign.tencent.com/design/layout ). Division of labor (§8 craft 1–3): material owns ambience, state layer owns feedback, shadow owns elevation, press pair owns touch (composition glue: glass owns ambience, never stack decoration on it; press states go to state layers / press morphing, and Liquid Glass intensifies feedback for direct touch).
