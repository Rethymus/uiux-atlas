Analytics Table

4 entries

Data table + chart axes + tooltip/legend (small multiples as accent): the analytics board composition.

Combines

Table A row-column matrix for structured data: headers carry column semantics, rows carry records. Sorting, striping and row hover are scanning aids, not decoration. Component Lib ★★★ Chart Axes & Grid The chart's 'table lines' discipline: grids stay faint (Grafana inverts the theme text color at 9% alpha), axis lines are optional (ECharts vs ggplot2 take opposite defaults), tick counts stay restrained (ECharts splitNumber defaults to 5) — three params decide a line chart's professionalism. Component Lib ★★ Tooltip & Legend The chart's two reading channels: the legend handles series lookup (right by default — ggplot2's source default), the tooltip handles precise values (ECharts defaults: mousemove trigger / 100ms hide delay), and WCAG 1.4.13 demands Esc-dismissibility, hoverability and persistence. Component Lib ★★ Small Multiples A row of similar small charts at one shared scale and axes: each panel tells a single series, and cross-panel comparison works only because every panel shares the same ruler — Tufte's defining requirement; the dual-axis mashup is its exact opposite. Community ★★

Why these combine

Research 16 §7 recipe-h: the data table = Ant Table — three density tiers size large/medium/small (cellPaddingBlock/Inline 16/12/8 while cellFontSize stays 14 across all tiers: density changes spacing only, never type size), fixed columns require width + scroll.x, fixed headers likewise, sticky header (4.6+), virtual scrolling (5.9+, scroll.x/y must be numbers), rowHoverBg #fafafa (https://ant.design/components/table-cn/ ); ProTable is request/schema-driven with the options toolbar {reload,density,setting} making density switching a first-class capability (https://procomponents.ant.design/components/table/ ); TDesign Starter's "statistics report" template (https://tdesign.tencent.com/ ). Chart axes = AntV's five-part axis anatomy (title/labels/line/ticks/grid) — the axis title is on by default, units (like "亿元") live in the title while labels omit them, and the title can be dropped when other elements already say it (https://antv.antgroup.com/zh/specification/module/axis/ ); the demo takes dataviz-chart-axes entry defaults gridOpacity 0.09 (Grafana's getGridColor 9%-opacity formula) / axisLine on (#6E7079 at width 1 = the ECharts axisDefault) / tickCount 5 (ECharts splitNumber default, nice-ticks rounding). Tooltip & legend = AntV's unified "info components" frame (Label/Legend/Tooltip/Index Card) — PC hover→Tooltip, mobile→tiled index cards, "morphing without losing information"; legend position follows the reading flow; advanced legends carry values and actions (https://antv.antgroup.com/zh/specification/module/info/ ); the demo takes dataviz-tooltip-legend entry defaults legendPos right (the ggplot2 source default) / tooltipFollow on (ECharts mousemove trigger, showDelay 0 / hideDelay 100ms hover grace, WCAG 1.4.13 dismissible/hoverable/persistent); the small-multiples accent = small-multiples entry defaults layout multiples / scaleMode shared (every panel shares one 0–100 scale, Tufte's defining requirement) / panelGap 8px (Grafana GRID_CELL_VMARGIN source value). Table numerals = AntV's three conditions for number fonts → font-variant-numeric: tabular-nums with financial figures right-aligned (https://antv.antgroup.com/zh/specification/language/basic/ ); in-chart hierarchy = "component elevation" four-band opacity (secondary/support/body/emphasis). Board-level specs = AntV graph/pubDashboard (general) / graph/conDashboard (monitoring) (indexed at https://antv.antgroup.com/llms.txt ) + Ant's visualization-page-cn/detail-page-cn template docs. M3 ships no chart components or chart guidance → unverified (components is a generic set, sitemap checked). The value layer: AntV's trust/ease/significance — reference lines, event marks and smart insights are the official requirements for a board's "sense of significance" (https://antv.antgroup.com/zh/specification/principles/basic/ ).
