Media Hero

3 entries

Parallax scrolling + kinetic typography + aurora gradient: the media hero composition.

Combines

Parallax Depth from per-layer scroll-rate differences: background layers follow scrolling slower than the foreground (follow ratio p, 0 = pinned to viewport, 1 = synced with content), implemented per layer with scroll() timelines of scroll-driven animations that can run off the main thread; reduced-motion renders the static layers. Web Standard ★★★ Kinetic Typography Two routes: registered variable-font axes (wght et al.) animate weight/width — one variable, zero reflow; or split text into characters/words for staggered reveal. The demo headline both rises letter by letter and thickens continuously on the axis. Web Standard ★★★ Aurora Gradient Aurora gradient: stacked low-luminance oklch radial-gradient blobs over a conic base, blurred and saturated as one layer, then drifted slowly — an ambient glow at near-zero cost. Community ★★★

Why these combine

Research 16 §7 recipe-e: parallax is officially endorsed — M3's transition doc states iOS forward/backward transitions use parallax ("background slides slower than the foreground") to reduce motion, a reduction tool not a flourish (https://m3.material.io/styles/motion/transitions/transition-patterns ) (§8 craft 9); Apple adds the background extension effect + scroll edge effect (https://developer.apple.com/design/human-interface-guidelines/layout ). Demo values take entry-schema defaults: rate 0.3 (no official recommendation exists; 0.2–0.6 is the common community band, unverified) and mode css = declarative animation-timeline: scroll() (can run off the main thread), auto-falling back to JS (rAF + scroll events) when unsupported. Kinetic typography = Apple Dynamic Type hierarchy (Large default: Body 17pt / Large Title 34pt; visionOS Extra Large Title for editorial layouts, https://developer.apple.com/design/human-interface-guidelines/typography ) + M3 type-scale-tokens (https://m3.material.io/styles/typography/type-scale-tokens ); demo takes entry-schema defaults: stagger 40ms / rise 600ms cubic-bezier(.2,.7,.3,1) / wght 400 (Inter Variable axis range 100–900) / reveal chars, with per-char aria-hidden + a whole-sentence aria-label preserving screen-reader semantics. The aurora-gradient backdrop has no official spec in any of the four systems → unverified (§9 list); it degrades per Apple's "Don't use Liquid Glass in the content layer" — entry-schema defaults: spots 4 / blur 42px / saturate 115% / drift 18s (demo tier; production ambience should be ~60s) / spotA 20% / spotB 70%, with the text card outside the filter layer holding 4.5:1. Motion red line: visionOS forbids ~0.2Hz sustained oscillation and feedback stays short and precise (https://developer.apple.com/design/human-interface-guidelines/motion ); under reduced-motion, parallax and drift stop entirely and characters render directly.

The story unfolds as you scroll

The background trails at rate 0.3 — 70% slower than the foreground, so scrolling reads as reduced motion, not spectacle; text always scrolls 1:1, readability first.

Parallax is a motion-reduction tool (M3's own words)

M3's transition doc: iOS transitions use parallax, the background sliding slower than the foreground to reduce motion; aurora gradient has no official spec (unverified) — degraded to a plain gradient layer + dimming scrim per the no-Liquid-Glass-in-content rule, with the text card outside the filter layer holding 4.5:1.

reduced-motion: all three layers stop

Parallax stops (static layers), aurora drift stops, per-char rise stops (direct render); text semantics never depend on animation. visionOS red line: avoid ~0.2Hz sustained oscillation.
