Dashboard Tile

4 entries

Bento grid + density rules + skeleton loading + a magnetic accent: the dashboard data tile composition.

Combines

Bento Grid An array of unequal rounded slots on one CSS Grid, encoding information priority through cell size — the default shape of SaaS feature sections after Apple's 2022-09 keynote; it is a layout, not a color scheme. Community ★★★ Dashboard Density The density base of BI grids: Grafana's 24 columns × 30px row height × 8px panel gap (source constants) driving Power BI's official example font ladder 45/12/12/10 — a comfortable/compact switch that retunes the whole board's breathing room. Component Lib ★★ Skeleton Loading Geometric placeholder blocks replicate the upcoming content layout, topped by a sweeping shimmer pulse meaning "loading"; content fades in fast once ready, with zero layout shift. Community ★★ Magnetic Hover Inside the attraction radius the button is pulled toward the pointer proportionally and snaps back on exit; each frame lerps toward the target, while touch and prefers-reduced-motion get the plain hover. Community ★★★

Why these combine

Research 16 §7 recipe-b: "bento grid" is not an official term anywhere (§9 unverified list) — the working basis is each system's grid numbers. The container bento takes the researched recipe repeat(4, minmax(0,1fr))/180px rows/16px gap/24px radius (entry-schema defaults from superdesign.dev); the panel density layer uses Grafana panel numbers — gap 8px (GRID_CELL_VMARGIN), row height 30px (GRID_CELL_HEIGHT), KPI panel = 3 rows = 90px, Power BI type ladder 45/12/12/10. Macro-grid grounding: Ant 24-col/base-8 (https://ant.design/docs/spec/layout-cn/ ) + TDesign base 8px/gutter 16px (https://tdesign.tencent.com/design/layout ) + M3 linear spacing scale (https://m3.material.io/styles/spacing/applying-spacing ). Density switches spacing only, never font size (Ant Table three cellPadding tiers 16/12/8 with cellFontSize fixed at 14, https://ant.design/components/table-cn/ ; ProTable ships density switching as a first-class toolbar action). Skeleton sizes equal real card sizes so loading lands with zero shift — Ant "use skeletons only on the first data load" (https://ant.design/components/skeleton-cn/ ) + Apple Loading "show something as soon as possible", replace on arrival (https://developer.apple.com/design/human-interface-guidelines/loading ) + M3 officially lists skeleton loaders among its six transition patterns (https://m3.material.io/styles/motion/transitions/transition-patterns ) + TDesign forbids first-screen sequential animation (https://tdesign.tencent.com/design/motion ) (§8 craft 5: "the skeleton is the layout's trailer"). The magnetic button is an accent layer (radius 0.45 / lerp 0.15, entry-schema defaults) — touch and reduced-motion users get plain press states with magnetics off.
