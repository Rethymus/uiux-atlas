Onboarding Journey

3 entries

Choreographed motion + goal-gradient + empty-state handoff: the onboarding composition.

Combines

Motion Choreography Choreography in pure CSS: animation-delay grows with --i to stagger start points, and a shared direction (up/down/left/right/none) gives the whole group one spatial meaning; duration and curve come from M3's official pairs (enter std-decel 250ms, exit std-accel 200ms — enters outlast exits). Material 3 ★★★ Empty A friendly placeholder for no data: artwork + short title + next-step copy + an optional action button — turning a dead end into guidance. Component Lib ★★ Goal-Gradient Effect Effort toward a goal intensifies as the goal gets closer. Give clear progress indicators, pre-seed 'artificial progress' at the start, and invest in the final stretch — the nearer the goal, the stronger each step's pull. Community ★★★

Why these combine

Research 16 §7 recipe-g: Apple Onboarding leads — onboarding runs after launching, never inside it; teach interactively (better than manuals); show contextual tips near their target (TipKit); keep pre-flows short; tutorials are skippable and never re-shown; defer non-essential setup with defaults; rating/paywall requests come after the experience (https://developer.apple.com/design/human-interface-guidelines/onboarding ). Choreography discipline = TDesign's "never express content order with sequential animation on first load — present directly or cross-fade" (https://tdesign.tencent.com/design/motion ) — the demo's first paint renders directly (pure fade), and stagger is reserved for user-triggered step transitions: choreography entry defaults stagger 40ms (a common community value, unverified; no official inter-item interval exists) / direction up, in 250ms std-decel cubic-bezier(0,0,0,1) / out 200ms std-accel cubic-bezier(0.3,0,1,1) = M3's official pairing + Ant "exits vanish as whole blocks, never queued" (https://ant.design/docs/spec/motion-cn/ ) + M3 container transform for card→workspace continuity (https://m3.material.io/styles/motion/transitions/transition-patterns ). "Goal gradient" is not codified under that name in any of the four systems → unverified (§9 list); proxy numbers = visionOS ≥60pt button-center spacing and M3 40dp state layer / 48dp target (https://developer.apple.com/design/human-interface-guidelines/layout ; https://m3.material.io/foundations/interaction/states/state-layers ); the demo takes goal-gradient entry defaults steps=10 / headStart=1 (one artificial progress stamp pre-stamped at the start, the "pre-stamp one tick" craft note). Empty→content handoff = Ant Empty — explicit no-data hint plus initialization guidance, children as CTA (<Empty><Button>create</Button></Empty>), Empty built into Select/Table etc. for global consistency (https://ant.design/components/empty-cn/ ; the empty-state template page https://ant.design/docs/spec/research-empty-cn/ ) + Apple Loading "show something as soon as possible", replacing placeholders on arrival (https://developer.apple.com/design/human-interface-guidelines/loading ) + M3's official skeleton-loaders transition pattern; the demo swaps with zero shift (empty placeholder sized = content size, content fading in fast).
