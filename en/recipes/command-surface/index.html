Command Surface

3 entries

Command palette + overlay entrance + keyboard navigation: the keyboard-first command surface.

Combines

Command Palette A global command overlay summoned with Ctrl+K / Cmd+K (or the header search button): subsequence fuzzy search across all entries, ↑↓ to select, Enter to jump, Esc to close — a complete zero-dependency implementation of APG combobox/listbox semantics with focus trap and body scroll lock. Web Standard ★★★ Overlay Entrance The de-facto overlay entrance: initial scale 0.95 + opacity 0 (+ an 8px directional shift), settling in 200ms with transform-origin from the anchor side; closing is always quicker than opening. Component Lib ★★★ Keyboard Navigation Tab/Shift+Tab moves between components, arrow keys move inside composites (roving focus); focus indicators stay visible, focus is never lost, and modal traps must release via Esc and return focus. Web Standard ★★★

Why these combine

Research 16 §7 recipe-d: no vendor ships an official command-palette component (unverified, §9 list) — but the official parts are all there: Apple Searching (one discoverable search entry per app, recents and predicted suggestions, https://developer.apple.com/design/human-interface-guidelines/searching ) + M3 Search (suggestions as you type, app-bar global entry, https://m3.material.io/components/search/overview ) (§8 craft 8: "command palette = search pattern × overlay × focus trap"). Demo matching and caps take entry-schema defaults: subsequence matching ("gsm" finds Glassmorphism, the VS Code/Linear convention), maxResults 8, Ctrl K badge (actual listening accepts both Ctrl+K and Cmd+K). Overlay entrance takes entry-schema defaults: initialScale 0.95 / shiftY 8px / in 200ms / out 150ms / standard curve — official duration bands: Ant motionDurationMid 0.2s (https://ant.design/components/message-cn/ token table), TDesign drawer/notification/message 280ms band with dialogs classified as Z-axis motion (https://tdesign.tencent.com/design/motion ), M3 Enter and exit + medium 400ms + Emphasized (https://m3.material.io/styles/motion/transitions/transition-patterns ; https://m3.material.io/styles/motion/easing-and-duration/tokens-specs ); exit is faster and never queued (Ant "exits vanish as whole blocks", TDesign ease-in out-curve) — exit must be shorter than entrance. Keyboard navigation = Ant Modal keyboard-Esc default true + focusable{trap} (https://ant.design/components/modal-cn/ ) + M3 focus state layer +10% (https://m3.material.io/foundations/interaction/states/state-layers ) + the law citation WAI-ARIA APG Dialog (https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ ); composition glue: input stays focused, Esc unwinds the stack, focus returns to the trigger on close, and Esc/outside-click dismissal never depends on the entrance animation.
