Law of Similarity & Closure

相似原则 · 闭合原则 · Similarity · Closure

Visually similar elements (color/shape/size/orientation) group together; incomplete outlines are completed into whole figures. Similar look implies similar function; closure keeps broken shapes readable.

Code breakdown

Structure & DOM

The demo stacks two panes: Similarity (a 6-row list whose first n rows are marked as one class) and Closure (four inward-mouthed discs squaring off an invisible square):

<!-- Similarity: dual-channel marking -->
<button class="gc-row" data-marked="true" data-cue="color">
  <span class="gc-ico"></span> Item 1
</button>

<!-- Closure: a mouth cut by conic-gradient -->
<span class="gc-pac" data-pos="tl" style="--gc-mouth: 24deg"></span>

Key points:

  • Similarity cues are dual-channel by construction: in color mode marked rows change both text and icon color; in shape mode icons morph from rounded squares to circles — the direct application of 07 §33 “mark same-function elements with color and shape”;
  • The closure pane’s key number is --gc-mouth (mouth angle): at 24° the four discs suffice for the brain to complete the central square (a Kanizsa-style illusory contour); past 60° completion collapses;
  • Marked rows are real <button>s (Tab-focusable); unmarked rows carry tabIndex=-1 + aria-disabled — semantically “not clickable” aligned with visually “not one of us”.

Styling & Parameters

.demo-stage { --gc-mouth: 24deg; }
.gc-pac {
  background: conic-gradient(from var(--gc-rot), transparent var(--gc-mouth), oklch(0.45 0.05 260) var(--gc-mouth));
}
.gc-pac[data-pos="tl"] { --gc-rot: 135deg; } /* all four mouths face the center */
  • mouth defaults to 24°: the minimal teachable gap; range 0–90°, with 60° as the demo-defined collapse threshold;
  • cue (color/shape) and marked (1–6 rows) are JS-type params driving the list via the store;
  • The mouth uses conic-gradient rather than SVG: pure CSS, no child elements, sector angle as a plain variable; without support it degrades to full circles (the closure demo loses its mouths but stays readable).

Motion & Interaction

  • No looping animation; switching cue / marked re-renders the list instantly (no transition — grouping perception is an instantaneous perceptual event, and animation would mask it);
  • Hovering a marked row shows a faint background — the third confirmation of “clickable” (color + shape + hover);
  • The closure pane is static: the illusory contour is a perceptual phenomenon, not an animation; no prefers-reduced-motion handling needed.

Real-world examples

  • The link underline convention: the web’s default link = blue + underline, dual-channel against body text — the oldest implementation of 07 §33 “keep links and navigation distinguishable from plain text”; minimalism that only tints blue clashes with SC 1.4.1 (editorial generalization);
  • Loading spinners: a broken ring in rotation reads as “one spinning circle” via closure — the universal loading semantics (application of 07 §31 closure; same family as the loading-feedback section in research 04 §2.2);
  • Icon-family shape languages: Material icons share one grid and stroke weight, antd icons one line style — same function shares shape, and a new icon “joins the family” and inherits the functional hint automatically (systematic application of 07 §33 “similar visuals for same function”, editorial generalization).

Parameter Sensitivity

ParameterTurning it up…Turning it down…
markedmore marked rows: a bigger “same class” but less individual identity inside itone marked row degenerates similarity into “oddball emphasis” (von Restorff’s territory)
mouth≥60° closure collapses: four separate pac-men, the square goneat 0° the discs become full circles — no gap, no completion either (brokenness is required for completeness)
cuecolor is the faster perceptual channel but depends on color visionshape survives color blindness — the demo’s dual-channel insurance

The lesson: similarity answers “who is together”, closure answers “broken still reads”. Both carry one a11y red line — essential semantics must not live only in the visual channel: group semantically, and pair illusory contours with text.

When to use 3
  • Links/buttons/body text distinguished by color AND shape so function reads at a glance (07 §33)
  • Same-function icon families share one shape language (all rounded squares, all outline style)
  • Loading spinners and ring progress: broken rings read as wholes via closure
When not to use 2
  • Links distinguished by color alone, no underline or shape difference (clashes with SC 1.4.1)
  • Multiple oddballs competing for attention — similarity abused into noise (cf. 07 §30 'use restraint')
Accessibility

Two red lines: ① similarity cues must not be color-only (color-blind users lose the grouping — cf. 07 §30 / SC 1.4.1); the demo's shape cue demonstrates the dual channel. ② closure-completed figures don't exist for screen readers — the illusory square carries no semantics; essential UI information must never exist only as a closed figure (pair with text or ARIA).

Browser support

Pac-man discs use conic-gradient (the mouth is a transparent sector) — fully supported in modern browsers; without it the discs degrade to full circles: the closure demo loses its mouths but stays readable.

Fallback

Closure's engineering exits: the loading spinner IS closure applied — a broken ring reads as a spinning whole; skeleton blocks work the same way. Degradation path: replace conic-gradient mouths with SVG paths, or fall back to full circles. Similarity's floor matches proximity: semantic grouping (fieldsets/lists) must run parallel to visual similarity.

Sources 2

OriginTwo branches of Gestalt grouping: Similarity — visually similar elements are perceived as one group; guidance: mark same-function elements with color and shape, keep links and navigation distinguishable from plain text (research 07 §33); Closure — the tendency to complete shared outlines, one of the five Gestalt grouping laws (Proximity/Similarity/Continuity/Closure/Connectedness) (07 §31).
