CSS Anchor Positioning Tether a floating layer to an anchor element: anchor-name names the anchor, position-area pins the pop to a grid position in one declaration, and @position-try flips it on overflow — Tooltip/Popover with zero JS. Web Standard ★★★ auto-fit / auto-fill + minmax One declaration replaces every breakpoint: repeat(auto-fit, minmax(250px, 1fr)) grows and shrinks the column count with the container; auto-fill keeps empty tracks, auto-fit collapses them and stretches the rest. Web Standard ★★★ Custom Scrollbar Two implementations, one interoperability truth: the standard scrollbar-color/width properties are the Firefox route (Chrome 121+, Safari 26.2 caught up), the ::-webkit-scrollbar pseudo-elements are the WebKit legacy — and once scrollbar-width ≠ auto, the whole webkit family is ignored; scrollbar-gutter reserves the slot so layouts stop jumping. Web Standard ★★★ CSS Grid Lanes CSS Grid Level 3's lanes: display: grid-lanes drops items into column tracks one by one, stacking along the other axis and always entering the column with the most remaining space — a native Pinterest-style masonry. Web Standard ★★★ Container Queries Components respond to their container's width, not the viewport: @container breakpoints re-flow cards, and container units (cqw/cqi) let inner sizes track the host. Web Standard ★★★ Aspect Ratio One declaration locks a box's width-to-height ratio: change the width and the height follows; pair it with object-fit to decide whether images crop, letterbox or stretch inside — the foundation of video slots, avatars and CLS-proof cards. Web Standard ★★ Holy Grail Layout The classic three-column page (header/sidebar/main/footer) done the modern Grid way: grid-template-areas composes the whole skeleton in one declaration, and re-ordering — sidebar to the other side, stacked mobile — is just swapping strings. Web Standard ★★★ Grid Math Grid algebra: column width = (100% − (n−1)×gap)/n, auto-fit count = ⌊(C+gap)/(minCol+gap)⌋, and subgrid hands the parent's track sizes straight to children — adjust columns and gap, the true-scale model recomputes widths live. Web Standard ★★★ Logical Properties Block/inline flow axes replace physical top/right/bottom/left: one set of padding-inline, margin-block and border-start-start-radius declarations, and Arabic RTL or vertical CJK flips wholesale with a single dir attribute — the foundation of multilingual sites. Web Standard ★★ CSS Multi-column Masonry columns: 4 220px splits content into columns in one declaration; content flows down the columns into a masonry — zero JS, works everywhere, the mature fallback for grid-lanes; the trade-off is column-wise ordering. Web Standard ★★ position: sticky The element scrolls with its container, then sticks once it reaches the offset threshold of the nearest scrolling ancestor — position: sticky; top: 20px; never leaves document flow, and one line buys sticky table headers and sidebars. Web Standard ★★ Responsive Images srcset/sizes let the browser pick a resolution candidate by 'slot width × DPR'; <picture> handles art direction and format switching; fetchpriority hints the priority of above-the-fold heroes — three tools, one job: half the bytes for the same image. Web Standard ★★★ Safe Area Insets Notched-screen adaptation: after viewport-fit=cover fills the screen, env(safe-area-inset-top/right/bottom/left) reserves the four edges so content clears the notch and Home indicator. Web Standard ★★★ Subgrid Nested components inherit the parent grid's tracks: grid-template-rows/columns: subgrid makes a card's internal rows/columns BE the parent's tracks, so titles and footers align across cards without magic numbers. Web Standard ★★ Writing Modes writing-mode redefines the flow of a whole box: one vertical-rl line returns Chinese to traditional vertical setting (lines running right-to-left); text-orientation governs each glyph's direction inside; text-combine-upright stacks year digits into one cell — the base of spines, poem cards and vertical forms. Web Standard ★★ Split View A draggable divider splits the UI into two resizable panes: drag and arrow keys drive one shared value, while container queries re-flow pane content — the backbone of IDEs, mail clients and docs sites.
