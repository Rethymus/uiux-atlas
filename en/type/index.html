Baseline Grid Snap vertical space to a fixed step (8px, with 4px half-steps allowed) and overlay a baseline/grid visualization toggle — off-grid spacing has nowhere to hide. Community ★★ CJK Typography Four pillars of Chinese typesetting: 2-em paragraph indent, justified alignment, auto CJK-Latin spacing (≤¼ em), punctuation squeeze — rules from W3C clreq, landed via text-indent / text-align / text-autospace / text-spacing-trim. Web Standard ★★★ Display Typography The display-size trio: the larger the size, the tighter the tracking (the official SF Pro curve), the lower the line-height ratio (apple.com-measured 56px→1.07), and variable weights instead of synthesized bold — the same techniques this site's hero uses. Community ★★★ Drop Cap / initial-letter initial-letter makes a paragraph's first glyph span multiple lines with text wrapping around it (Chrome 110+/Safari prefixed/Firefox unsupported); the classic ::first-letter + float is the fallback. Web Standard ★★ Fluid Spacing Spacing tokens ride clamp too: --space-3xs…3xl stretch linearly with the viewport — fixed at both ends, interpolated between — so whitespace breathes instead of jumping at breakpoints. Web Standard ★★ Fluid Type Scale Font sizes interpolate linearly with the viewport: clamp(floor, rem+vw, ceiling) builds a --step-0..5 ladder — never below the floor, never above the ceiling, smooth in between. Web Standard ★★★ Font Loading Strategy @font-face's font-display decides how text renders while fonts load: five values map to block/swap period lengths — the web.dev table: fallback 100ms/3s, optional 100ms/no swap. Web Standard ★★ Measure & Line Length Cap body copy with the ch unit: keep average line length at 45–90 characters (incl. spaces) — too long strains vertical tracking, too short chops the rhythm. Web Standard ★★ Font Pairing Serif × sans contrast pairing, or the single-family multi-weight strategy: contrast, separated duties and restraint — two typefaces at most, and question the third. Community ★★ Modular Scale Math The math under type scales: size(n)=base×ratioⁿ builds hierarchy, calc() chains keep spacing co-axial, and Utopia's fluid clamp — slope in vw, intercept hidden in rem, both ends clamped — is a linear regression in one line of CSS. Community ★★★ Small Caps & OpenType Features The font-variant-* high-level properties address OpenType features (smcp/c2sc/liga/zero…); font-feature-settings is the low-level fallback — the official guidance: prefer the high level, 'do not use it to enable small caps'. Web Standard ★★★ Line-height Rhythm Line-height × font-size = baseline multiples: compute density first (lh = fs×m), then snap to the grid half-step (lh = round(fs×m/unit)×unit) — multiplication sets tension, addition sets order, with hard constraints for CJK. Web Standard ★★ Variable Fonts One font file carrying continuous axes: font-variation-settings turns wght/opsz dials — weight and optical size become continuous sliders instead of discrete cuts. Web Standard ★★★ Vertical Rhythm Take the body line-height as the base unit: derive heading line-heights backwards (unit ÷ size), snap gaps to integer multiples, stack line boxes row by row — rhythm visualization turns text blocks into readable sheet music. Community ★★★ text-wrap balance & pretty Two style values of the text-wrap shorthand: balance evens out line lengths (short text only — ≤6 lines in Chromium, ≤10 in Firefox), while pretty runs a slower, better algorithm to prevent orphans in long body copy. Web Standard ★★ Tabular Numbers font-variant-numeric: tabular-nums gives every digit the same width so columns align and counting animations stop jittering — the credibility floor of dashboards and data tables. Web Standard ★★ WCAG Text Spacing WCAG SC 1.4.12: when users override line height to 1.5×, paragraph spacing 2×, letter spacing 0.12× and word spacing 0.16× of the font size, content must not break — don't hard-lock these four ratios.
