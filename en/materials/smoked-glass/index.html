Smoked Glass

烟熏玻璃 · 熏黑玻璃 · 黑色玻璃 · 暗色磨砂 · Smoked Glass · Dark Glass

The "black glass": a dark substrate, a brushed top highlight, and a barely-transmissive base — the frost-density axis (§3.3) pushed to its dark end, leaving only color temperature from the backdrop, with naturally stable text contrast. Research 17 §12.3 states honestly: its parameter domain is the dark branch of §3 mist, engineering extrapolation.

highlight45%
%

Brushed top-highlight strength (the alpha of the 1px lit top edge + top gradient sheen). Default 45% takes §1.3's layer ① top specular highlight white/.45; the brushed texture (a repeating-linear-gradient of 1px lines near the top) is this entry's engineering extrapolation [R] (§12.3 defines "brushed top highlight" but records no values). 0 = highlight off, pure matte black glass.

Color▾
tint#0B0F14

Use a low-chroma cool gray-black, not pure black, to avoid dead black in the fog (the dark version of §3.3's "don't use white as the base" — engineering extrapolation).

Code breakdown

Structure & DOM

Smoked glass is the dark end of the frost-density axis (research 17 §12.3): a dark substrate, a brushed top highlight, and a barely-transmissive base. Structurally it sits in the mist-glass family — a glass panel floating over a rich backdrop, just with a dark fill and a high blur stop:

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="smoked-card">
    <h3>Title</h3>
    <p>Body</p>
  </div>
</div>

Key points:

  • The glass panel is a sibling layer of the backdrop; backdrop-filter samples everything behind it, and the dark fill strips nearly all information, leaving only color temperature;
  • The fill is a two-layer structure: a transparent body with ::before laying a solid tint whose opacity carries the density formula — no color-mix dependency, baseline capability;
  • The brushed top highlight sits above the fill (::after): a 1px lit top edge + a top gradient sheen + a 1px line texture, imitating a single directional lamp grazing the smoked surface;
  • The dark substrate makes text contrast naturally stable — clear-frost over a bright backdrop must add a 35% dark dimming layer (HIG, §2.3 [S]); smoked glass grows that layer into the material itself.

Styling & Parameters

Three parameters map onto §3.3’s density-axis formulas applied to the dark branch ([R]; the formulas themselves are §3.3 documented values):

.smoked-card {
  position: relative;
  border-radius: 20px;
  background: transparent;
  -webkit-backdrop-filter:
    blur(calc(2px + 38px * var(--sm-density)))          /* blur = 2+38d */
    saturate(calc(1.9 - var(--sm-density)))             /* sat  = 1.9−d */
    contrast(calc(1 - 0.15 * var(--sm-density)));       /* ct   = 1−0.15d */
  backdrop-filter:
    blur(calc(2px + 38px * var(--sm-density)))
    saturate(calc(1.9 - var(--sm-density)))
    contrast(calc(1 - 0.15 * var(--sm-density)));
  box-shadow:
    inset 0 1px 0 rgb(255 255 255 / calc(var(--sm-highlight) / 100)),  /* lit edge §1.3 ① */
    0 12px 40px rgb(0 0 0 / 0.25);                                      /* drop shadow §1.3 ⑤ */
}
/* Dark fill layer: solid tint + density-formula alpha (fill = .05+.35d) */
.smoked-card::before {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  background: var(--sm-tint);
  opacity: calc(0.05 + 0.35 * var(--sm-density));
  pointer-events: none;
}
/* Brushed top highlight: gradient sheen + 1px line texture (engineering extrapolation [R]) */
.smoked-card::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  pointer-events: none;
  background:
    repeating-linear-gradient(100deg,
      rgb(255 255 255 / 0.05) 0 1px, transparent 1px 4px),
    linear-gradient(180deg,
      rgb(255 255 255 / calc(var(--sm-highlight) / 100)), transparent 48%);
}
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .smoked-card::before { opacity: 0.96; }   /* §3.4's mist fallback idea */
}

Where the numbers come from:

  • The four density-axis formulas blur=2+38d / fill=.05+.35d / sat=1.9−1.0d / ct=1−0.15d: §3.3 documented values (light branch); applying them to a dark substrate is this entry’s [R] extrapolation (§12.3’s own words: “the parameter domain is the dark branch of §3 mist”);
  • Default d=0.9: the “barely transmissive” stop (§12.3’s definition); d=0.8 is exactly §3.3’s mist stop, for comparison;
  • The lit edge white/.45: §1.3’s layer ① documented value; the drop shadow 0 12px 40px black/.25: §1.3’s layer ⑤ documented value;
  • tint default #0B0F14: §9’s dark-field keynote “#0B0F14-class” [R]; preset #111928 = the hex of research 03§1’s production-measured dark glass rgb(17,25,40) (reused by this site’s glassmorphism dark variant);
  • Fallback .96: §3.4’s mist fallback value; the brushed texture’s 1px/4px period and the 48% sheen falloff are engineering extrapolation [R] (the research records no values).

Motion & Interaction

Smoked glass is a static material — keep motion restrained:

  • Entrance fade + 8px rise; removed under prefers-reduced-motion (the material has no autonomous animation, this is the only case);
  • density/tint/highlight all take effect live via CSS variables; no transition on parameter changes (they are recipe axes, not states);
  • For floating nav bars, smoked glass may deepen on scroll (like iOS’s scrollbar mode), implemented as an opacity transition rather than per-frame re-sampling — large-radius blur re-samples are expensive (§1.4);
  • Highlight states raise the lit edge alpha; never animate the blur.

Real-world examples

  • Handled honestly per §12.3: “smoked glass” is an engineering-extrapolation concept and the research verified no per-site examples — this entry cites no unverified sites;
  • Official counterpart [S]: SwiftUI’s Material.ultraThick / thick heaviest stops (§3.2 enum verified, lowest background transmission) in a dark environment are smoked glass’s official stop anchors (visionOS 1.0+ platform table verified);
  • Verified sibling recipes: §3’s mist recipe (the source of this entry’s formulas), §2 clear-frost’s 35% dimming rule (§2.3 HIG [S]), §9’s dark-field keynote value.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
densityblur→40px, fill→40%: information fully zeroed, only color temperature remains; sampling cost climbs with the high blur stoptoward an ordinary dark glass; under 0.4 the transmitted information returns and “smoked” no longer holds; 0.8 = §3.3’s mist stop
tintblacker reads more “sunglasses”, but pure black kills the transmitted color temperature (keep a low-chroma cool gray-black)grayer/bluer turns the fog into “morning mist”; preset #111928 (research 03’s production measurement) is a touch more transmissive than the default
highlightpast 60% the top edge starts “silvering” — metal, not smoked glassapproaches matte; 0 = highlight fully off, only the dark substrate and shadow remain (pure matte black glass)

Working ranges: density 0.75–0.95, tint a low-chroma cool gray-black (L≤12%), highlight 35–55%; over bright backdrops text contrast drifts far less than clear-frost (the substrate carries its own dimming). Related entries: mist-glass holds the same axis’s light end and the formulas’ source; clear-frost, the opposite end of the spectrum plus the 35% dimming rule (HIG [S]); dimming-layer, the “dimming grown into the material” form; specular-highlight, the optical semantics of the lit edge.

When to use 3
  • Overlays over bright backdrops (photos/video) that need stable text contrast — where clear-frost would need a 35% dark dimming layer (§2.3 [S]), smoked glass carries its own dark substrate
  • Dark dashboards, players, and cinema-mode panels (the dark branch of §3.6's car/TV screens)
  • Floating nav bars and toolbars — the dark realization of glass's navigation-layer privilege (§11.10)
When not to use 3
  • Large surfaces in light themes: dark panels and light themes fight over the layering language
  • Dense data tables: barely-transmissive is near-solid — not worth backdrop-filter's high-stop blur sampling cost (§3.3 point ①)
  • Body text directly on the glass: text belongs on the content layer's solid ground; glass is for the navigation layer only (§11.10)
Accessibility

The dark substrate makes text contrast naturally stable, but still check 4.5:1 against the brightest transmitted backdrop (WCAG 2.1 SC 1.4.3) — smoked glass's near-zero transmission drifts far less than clear-frost; the brushed highlight and border are pure decoration carrying no information; the material has no autonomous animation — prefers-reduced-motion only cancels the entrance.

Browser support

backdrop-filter is Baseline 2024 Newly available, cross-browser since 2024-09 (§1.4, MDN verified [S]); Safari 9–17 needs the -webkit- prefix; calc() inside custom properties is baseline (§3.4); saturate/contrast/brightness are all legal filter functions (§3.2, MDN backdrop-filter formal syntax verified [S]); color-mix is not needed — the fill is a two-layer "solid + opacity" structure, baseline capability.

Fallback

Without backdrop-filter: per §3.4's mist fallback idea (.96 opacity), raise the dark fill layer's opacity to .96 and the glass degrades to a near-solid dark panel — smoked glass is dark to begin with, so the fallback is nearly lossless (dark substrate, top highlight and border all survive; only the transmitted color temperature is lost).
