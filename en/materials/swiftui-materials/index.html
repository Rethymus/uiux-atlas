SwiftUI Materials

SwiftUI 材质 · 系统材质 · UIBlurEffect · vibrancy

SwiftUI's six background materials (ultraThin…ultraThick, bar): translucent layers between foreground and background that grant the foreground vibrancy; on the web they can only be approximated with CSS variables.

Foreground on a material gets vibrancy automatically; a custom foregroundStyle turns it off (A8). The demo highlights the chosen tier and shows the official warning for the disallowed combination.

Code breakdown

Structure & DOM

In official SwiftUI terms a material is not a view — it is a translucent layer between foreground and background, “like heavily frosted glass”, and the foreground above it automatically receives vibrancy (A8). The web approximation stacks “backdrop → veil (pseudo-material) → vibrancy text tiers”:

// Official API (iOS 15+, research 02 §1 A8)
ScrollView { … }
  .background(.ultraThinMaterial)   // one of six: ultraThin/thin/regular/thick/ultraThick/bar
  .foregroundStyle(.secondary)      // or rely on the material's automatic vibrancy
<div class="scene">
  <img class="bg" src="photo.jpg" alt="" />
  <section class="mat"> <!-- veil: pseudo-material -->
    <p class="v-default">default tier</p>
    <p class="v-secondary">secondary tier</p>
    <hr class="v-sep" />
  </section>
</div>

Key points: material thickness encodes a hierarchy promise — thicker approaches solid and steadier text; vibrancy is a contrast strategy granted by the material, not arbitrary opacity tuning.

Styling & Parameters

The web side approximates the six tiers with CSS variables for alpha and blur (community approximations — Apple publishes no numbers):

.mat {
  border-radius: 16px;
  -webkit-backdrop-filter: blur(var(--sm-blur));
  backdrop-filter: blur(var(--sm-blur));
  background: rgb(255 255 255 / var(--sm-alpha));
}
/* Community approximation table (unverified): ultraThin .08/12px · thin .18/16px · regular .30/20px
   thick .44/24px · ultraThick .60/28px · bar .36/16px */
.mat[data-material="thick"]     { --sm-alpha: 0.44; --sm-blur: 24px; }
.mat[data-material="ultraThick"]{ --sm-alpha: 0.60; --sm-blur: 28px; }

/* Vibrancy tiers: decreasing contrast (A10), approximated as foreground alpha */
.v-default    { color: rgb(0 0 0 / 1); }
.v-secondary  { color: rgb(0 0 0 / 0.65); }
.v-tertiary   { color: rgb(0 0 0 / 0.45); }
.v-quaternary { color: rgb(0 0 0 / 0.30); } /* officially disallowed on ultraThin/thin */

Where the numbers come from:

  • The six tier names and semantics: the SwiftUI Material docs (A8, research 02 §1); bar is the toolbar-specific tier;
  • The vibrancy hierarchy default→quaternary, a single separator tier, and quaternary disallowed on ultraThin/thin: HIG Materials (A10);
  • Alpha/blur numbers: not published by Apple — the table above is a community approximation showing the trend (thicker = darker = steadier contrast); on real devices the system render is authoritative.

Motion & Interaction

  • Material switch: the veil’s alpha/blur transition over 0.25s, giving a continuous “thickening” feel; removed under prefers-reduced-motion;
  • Tier switch: the four vibrancy rows fade in over 0.25s with a leading indicator bar on the selected row;
  • When the disallowed combination (quaternary + ultraThin/thin) appears, the warning fades in and other motion stops — it is a state the user must read, not one to be animated away;
  • The demo backdrop stays static: tier comparison does not need motion, and static is the friendliest state for contrast checks.

Parameter Sensitivity

ParameterTurning up (a thicker tier)…Turning down (a thinner tier)…
materialthicker is more opaque: steadier text contrast but a weaker “material” feel — ultraThick is nearly a solid cardthinner is more transparent: more transmitted color and more “liquid”, but text leans entirely on vibrancy/bold — ultraThin even loses quaternary by official rule
vibrancylower tiers (→quaternary) weaken contrast: right for timestamps and placeholders, safe only on thick materialshigher tiers (→default) strengthen contrast: body copy and key information belong at default/secondary
Combination (material × tier)thick material × low tier: readable but noisy — keep decorative tiers out of body copythin material × low tier: the officially disallowed pairing — the demo warns, production should simply avoid it

Rule of thumb: align the hierarchy promise with content importance — bar for toolbars, regular or thicker for body-bearing surfaces, ultraThin only for decorative floats; every vibrancy step down needs a fresh 4.5:1 check on real devices across both backdrop extremes (WCAG 2.1 SC 1.4.3).

When to use 3
  • Toolbars and tab bars (the official bar-material scene), list rows and card substrates
  • Transient surfaces: sheets, popovers, menus — tier thickness expresses hierarchy
  • Label/icon layers that need foreground vibrancy (foreground over a material gets it automatically, A8)
When not to use 3
  • quaternary-tier content on ultraThin/thin — officially disallowed for insufficient contrast (A10)
  • expecting system contrast after overriding the foreground — a custom foregroundStyle disables vibrancy (A8)
  • treating web approximation numbers as official — Apple publishes no alpha/blur figures for materials
Accessibility

Check text on materials against the brightest/darkest transmitted backdrop for 4.5:1 (WCAG 2.1 SC 1.4.3, research 06 §V §17); avoid low-contrast tiers on thin materials (quaternary is officially disallowed); when vibrancy is unavailable, fall back to explicit secondary text colors.

Browser support

The official materials are Apple-only: SwiftUI Material and UIBlurEffect on iOS 15+/macOS (research 02 §1 A7/A8). The web approximation relies on backdrop-filter: Chrome 76 / Firefox 103 / Safari 9 (-webkit- prefix, unprefixed since Safari 18) (research 02 §4 D2 / 03 §1).

Fallback

The web alpha/blur numbers are community mappings — without backdrop-filter support, raise the fill opacity by material tier (thicker = closer to solid) to keep text readable; vibrancy cannot be recreated on the web, so text contrast must be hand-checked against the brightest/darkest transmitted backdrop.
