Iridescent Glass

极光玻璃 · 虹彩玻璃 · 薄膜干涉玻璃 · 油膜玻璃 · Iridescent Glass · Oil-slick Glass

Glass with a thin-film interference feel whose hue drifts with phase: twin instances of one conic gradient (a sharp layer draws the ring, a blurred one draws the glow) plus inner light bleed — the hue slowly rotates around the ring like structural color on a soap film. Unlike the existing aurora-gradient (a background gradient), this is a panel material.

Parameters
Geometry▾
drift6s
s

Hue-ring rotation period (time for --ig-spin to travel 0deg → 360deg). Default 6s is §5.3's documented halo recipe value ("animation: spin 6s linear infinite"); 0 = drift stopped, frozen at the 90deg phase (same as the reduce branch). Other period values are demo range only — not recorded in the research, treated as engineering values.

hue32

Base hue of the film; the ring's three color stops derive from it (base / +90° / +200°, closed end-to-end — the derivation rule is this site's engineering inference [R]). Default 32° honors two verified anchors: §1.3's --glow-hue initial value of 32, and the measured hue of §5.3's first stop rgb(255 176 32) ≈34° (engineering conversion). Halo's fixed three stops (32 / rgb(255 86 168) / rgb(86 128 255)) are essentially this parameter's default state.

bleed30%
%

Inner light-bleed strength (inset glow layer alpha, §1.3 layer ② "inset 0 0 18px 2px, glow at 30%"). Default 30% is the documented recipe value; §1.3's working range is .22–.32, and past the 40% cap you enter wash-out territory (bloom alpha past .45 washes the panel out, §1.3's warning — treat bleed conservatively the same way). 0 = bleed off, leaving only the iridescent ring.

Code breakdown

Structure & DOM

Iridescent glass is thin-film interference whose hue drifts with phase (research 17 §12.2): the recipe is a generalized combination of §5’s conic ring + §1’s light bleed [R]. It shares halo-glow-border’s twin-instance structure, plus one bleed layer:

<div class="scene">
  <div class="iridescent">       <!-- glass body: backdrop-filter + bleed box-shadow -->
    <h3>Title</h3>
    <p>Body</p>
  </div>
</div>

Key points:

  • Ring = sharp layer: ::before knocks a 1.5px hairline out with the double mask (-webkit-mask-composite: xor / mask-composite: exclude dual declarations); stops derive from --ig-hue and close end-to-end;
  • Glow = blurred twin: ::after is a blurred copy of the same gradient (outset 3px, blur(10px), reduced opacity) spilling out behind the card — §5.3’s “sharp layer draws the line, blurred layer draws the glow” carried over verbatim;
  • Bleed lives in box-shadow: §1.3’s layer ② inset 0 0 18px 2px at 30% glow lets the ring color decay into the panel;
  • Registration is the prerequisite: @property --ig-spin { syntax: "<angle>" } — unregistered custom properties cannot interpolate; this is the 2024-07 (Baseline) watershed for whether it spins at all (§11.8);
  • Difference from the existing aurora-gradient entry: that one is an aurora gradient in the background layer; this entry is a panel material — structural color lives on the glass rim and lining.

Styling & Parameters

Three parameters injected via --ig-* variables:

@property --ig-spin { syntax: "<angle>"; inherits: false; initial-value: 0deg; }

.iridescent {
  position: relative;
  border-radius: 20px;
  background: rgb(255 255 255 / 0.08);                 /* §5.3 low-fill body */
  -webkit-backdrop-filter: blur(12px) saturate(1.4);   /* §5.3 */
  backdrop-filter: blur(12px) saturate(1.4);
  /* bleed (§1.3 ②) + drop shadow (§1.3 ⑤), alpha driven by --ig-bleed */
  box-shadow:
    inset 0 0 18px 2px hsl(var(--ig-hue) 90% 78% / calc(var(--ig-bleed) / 100)),
    0 12px 40px rgb(0 0 0 / 0.25);
}
.iridescent::before, .iridescent::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  pointer-events: none;
  background: conic-gradient(from calc(90deg + var(--ig-spin)),
    hsl(var(--ig-hue) 90% 62%),
    hsl(calc(var(--ig-hue) + 90) 85% 62%),
    hsl(calc(var(--ig-hue) + 200) 85% 62%),
    hsl(var(--ig-hue) 90% 62%));                        /* closed end-to-end */
  padding: 1.5px;
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
  animation: ig-spin var(--ig-period) linear infinite;
}
.iridescent::before { filter: drop-shadow(0 0 6px hsl(var(--ig-hue) 90% 70% / 0.45)); z-index: 1; }
.iridescent::after  { inset: -3px; padding: 3.5px; filter: blur(10px); opacity: 0.55; z-index: -1; }

@keyframes ig-spin { to { --ig-spin: 360deg; } }
@media (prefers-reduced-motion: reduce) {
  .iridescent::before, .iridescent::after { animation: none; --ig-spin: 90deg; }
}

Where the numbers come from:

  • --ig-spin registration, three conic stops closed end-to-end, double-mask knock-out, blur(10px), opacity .55, 6s rotation, reduce static at 90deg: all documented values of §5.3’s halo recipe;
  • Bleed inset 0 0 18px 2px, glow color hsl(hue 90% 78%), alpha 30%: §1.3 layer ② documented values (the --glow definition hsl(var(—glow-hue) 90% 78%));
  • hue default 32°: §1.3’s --glow-hue initial value; the ±90°/±200° stop derivation and the static from 90deg + spin phase are engineering inference [R];
  • Other drift values are demo range only (the research records just 6s), honestly labeled in the param effect.

Motion & Interaction

Iridescence is a slow ambient animation, restrained to “angles only”:

  • The only animation is --ig-spin angle interpolation (§5.3’s spin verbatim) — no element translation or scaling, which are vestibular motion triggers (§8.2, MDN verified);
  • prefers-reduced-motion: reduce: frozen at the 90deg phase, static structural color retained (§5.3’s reduce branch carried over verbatim — replace with a non-animated state, do not black it out);
  • drift = 0 means drift stopped, also frozen at 90deg; the demo produces no flicker at zero period (the animation is removed outright);
  • Keep the glass body in the navigation layer, sparingly (≤3 layers, §11.10); the content layer falls back to the standard five frost thicknesses.

Real-world examples

  • Handled honestly per §12.2: the iridescent-glass recipe is engineering extrapolation with no authoritative review verified — this entry cites no unverified sites;
  • Verified technical-lineage anchors: the MDN conic-gradient and @property pages (§5.2 verified in full), halo-glow-border’s §5.3 recipe (same twin-instance family), soft-glow-glass’s §1.3 bleed recipe;
  • Adjacent community practice: hyalite’s rim-light treatment (Fresnel sheen + specular line + per-pixel inset-shadow rim, README verified in full [S]) proves “edge optical events can be built from box-shadow/gradients.”

Parameter Sensitivity

Working ranges: drift 4–8s, hue within ±30° of the content hue, bleed 22–32% (§1.3’s range); without @property the ring degrades to static automatically, zero fallback cost. Related entries: halo-glow-border holds the twin-instance parent recipe; soft-glow-glass holds the bleed trio (bleed/bloom/lit edge); chromatic-edge, the “independently zeroable parameter” convention; aurora-gradient, the background-gradient vs panel-material divide.

When to use 3
  • Dark-field brand heroes and music/event accent cards (structural color is a dark-field language)
  • The high end of the soft-glass spectrum: more colorful than soft-glow, softer than halo — a panel accent
  • Small-badge "medal" moments: status badges, achievement cards
When not to use 3
  • Large content-layer surfaces — glass is a navigation-layer privilege; past three layers hierarchy dies (§11.10)
  • Surfaces carrying body text: the drifting hue keeps shifting the local backdrop, so text contrast is uncontrolled
  • Large use in light themes: structural color needs a dark field — on pale grounds it reads as noise
Accessibility

Iridescence and bleed are pure decoration: they carry no information; ring/glow layers get pointer-events: none and stay out of the accessibility tree; hue drift animates only the gradient angle (--ig-spin) — no element translation or scaling (vestibular safety, §8.2 MDN verified); under prefers-reduced-motion: reduce the phase freezes at 90deg and static structural color remains (§5.3); check body text at 4.5:1 against the brightest/darkest transmitted backdrop.

Browser support

conic-gradient is baseline everywhere (§5.4); @property angle registration is Baseline 2024-07 (since 2024-07) — older browsers show a static but correct ring (initial-value fallback, §5.4 [S]); mask-composite: exclude + -webkit-mask-composite: xor dual declarations cover Chromium/Safari/Firefox (§5.4); backdrop-filter is Baseline 2024-09 (§1.4); deriving stops via hsl(calc(…)) is baseline capability.

Fallback

Without @property the rotation stops and the static iridescent ring renders correctly (initial-value fallback, §5.4); without backdrop-filter, raise the fill opacity to .7+ to preserve readability (§1.4); under prefers-reduced-motion: reduce, --ig-spin freezes at 90deg (§5.3's reduce branch carried over verbatim) and the static structural color stays; drift = 0 also freezes at 90deg.
