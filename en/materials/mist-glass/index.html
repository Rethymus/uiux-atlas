Mist Glass

雾面玻璃 · 雾玻璃 · Mist Glass · Heavy Frost

High haze, low contrast: the backdrop is heavily homogenized (large-radius blur) while saturation and contrast drop, so what shows through carries color temperature, not information. The logarithmic opposite end of the same axis as clear frost.

Community ★★
Live demo official default
Parameters
Geometry▾
density0.8

Haze axis d∈[0,1] (research 17 §3.3 unified frost-density parameterization): blur = calc(2px + 38px×d), fill = calc(.05 + .35×d) and saturate = calc(1.9 − 1.0×d) all move together. Default 0.8 (mist grade); d≈0 is clear frost, d≈0.4 regular frost, d→1 approaches opaque. Recommended as a site-level token.

contrast0.88

Contrast attenuation (contrast filter). Default 0.88 = the recipe formula 1 − 0.15×d evaluated at d=0.8 (research 17 §3.3) — the key to mist is "blurred but grayer and softer": contrast must decay in step with blur.

Color▾
base#F5F7FA

Base color (hex form of the recipe's 245 247 250 triplet). Third of research 17 §3.3's three mist rules: use a low-saturation cool gray-white, not pure white, so the mist doesn't tint blue. Presets are adjacent grades of the same low-saturation family, engineering-derived demo values.

Code breakdown

Structure & DOM

Mist glass and clear frost are the logarithmic two ends of one clarity axis: the ultra-thin tier wants “blurred but vivid”, mist wants “blurred but grayer and softer” — what shows through carries color temperature, not information (research 17 §3.1).

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="mist">          <!-- high haze: large blur + low saturation + lowered contrast -->
    <h3>Notification</h3>
  </div>
</div>

Key points:

  • Same DOM as the glassmorphism/clear-frost entries: backdrop → mist panel → content; only the parameter range differs;
  • “Mist glass” has no official standalone definition (research 17 §3.2, stated honestly) — its parameter range is reverse-derived from Apple Material’s ultraThick/thick, the densest grades;
  • Mist panels usually carry long copy (notifications, panel titles) — that is the division of labor against the ultra-thin tier.

Styling & Parameters

The core is one fog-density axis coupling three filter functions (research 17 §3.3, [R] this site’s engineering recipe):

/* d ∈ [0,1]: 0 = clear frost, 0.4 = regular frost, 0.8 = mist, 1 = opaque */
.mist {
  --mg-blur: calc(2px + 38px * var(--mg-d));    /* 2 → 40px */
  --mg-fill: calc(0.05 + 0.35 * var(--mg-d));   /* .05 → .40 */
  --mg-sat:  calc(1.9 - 1.0 * var(--mg-d));     /* 1.9 → 0.9 (mist desaturates) */
  background: color-mix(in srgb, var(--mg-base) calc(var(--mg-fill) * 100%), transparent);
  -webkit-backdrop-filter: blur(var(--mg-blur)) saturate(var(--mg-sat)) contrast(var(--mg-ct));
  backdrop-filter: blur(var(--mg-blur)) saturate(var(--mg-sat)) contrast(var(--mg-ct));
  border-radius: 24px;
  box-shadow: inset 0 1px 0 rgb(255 255 255 / .3), 0 10px 32px rgb(15 23 42 / .18);
}

Where the numbers come from:

  • The three formulas, the default --d: 0.8, contrast = 1 − 0.15×d (default 0.88), and the base rgb(245 247 250) are all recorded in the research 17 §3.3 recipe;
  • Three rules of mist (research 17 §3.3): ① only blur ≥ 24px starts to erase information; ② saturate < 1 is the watershed between mist and frost; ③ the base is a low-saturation cool gray-white (245 247 250), not white, so the mist doesn’t tint blue;
  • blur/saturate/contrast are all legal backdrop-filter functions (MDN formal syntax verified); Apple’s Material.ultraThick doc line “resembles heavily frosted glass” is the official description of the densest grade (SwiftUI Material page verified).

Motion & Interaction

Mist’s value is static stability — even less motion than the clear tier:

  • Entrance: fade + 8px rise; removed under prefers-reduced-motion;
  • Never add breathing/flowing effects to mist — mist’s semantics are “the backdrop is erased”; any undulation in the mist layer reintroduces visual noise;
  • On big backdrop changes (scene switches), don’t animate the mist parameters: large-radius blur re-sampling is expensive, a direct swap is steadier (same performance rules as the backdrop-filter entry);
  • Nesting warning: a backdrop-filter element inside a mist panel samples only up to the parent mist layer (the MDN backdrop-root trap, research 17 §11.4) — the four grade chips inside the demo card show this live.

Real-world examples

  • iOS Notification Center / lock-screen frost: the thick-frost family’s system home turf, notification copy sitting directly on a heavily homogenized mist layer (SwiftUI Material enum counterparts, research 17 §3.6);
  • Automotive / living-room large-screen panels: keep color temperature, drop information when the backdrop is busy — the HIG standard materials’ target scenario (HIG Materials page, verified).

Parameter Sensitivity

ParameterTurning it up…Turning it down…
densityblur/fill rise and saturate falls together: denser fog, less legible information; d→1 approaches an opaque panelpast d≈0.4 you enter regular-frost territory; d≈0 is clear frost — the “mist” selling point is gone; the in-between (high saturation, low haze) is the dirtiest-looking range
contrastmore contrast retained, the light/dark structure inside the fog stays readable; above 1 it reads “frost”, not “mist”grayer, softer fog, color temperature only; below 0.8 the whole panel turns muddy and micro-contrast with the mist is lost too
basecooler gray-white reads “steel”; too blue a base tints the mist blue (violation of rule ③)warm yellowish bases make the mist look like an old lampshade; straying from the low-saturation family turns mist into a dirty block

Working ranges: start d at 0.8 (mist grade), notifications up to 0.9; contrast follows the formula 1−0.15×d; keep base in the 245 247 250 family. Related entries: clear-frost is the other end of this axis; swiftui-materials holds the official five-thickness semantics; backdrop-filter covers backdrop roots and filter-chain syntax.

When to use 3
  • iOS Notification Center / lock-screen style frost: system-grade thick-frost scenarios (Material enum counterparts, research 17 §3.6)
  • Automotive / living-room large-screen panels: keep color temperature, drop information when the backdrop is busy (HIG standard materials' target scenario, research 17 §3.6)
  • Overlays carrying long copy: once misted, text contrast stops jumping with backdrop content
When not to use 3
  • Scenes where backdrop color/content should stay legible — that is clear frost's job
  • The in-between state (saturate < 1 with blur < 24px): neither mist nor clear — the dirtiest-looking parameter range
  • Pure-white base: the mist tints blue (research 17 §3.3, rule ③)
Accessibility

Mist's advantage is stable contrast: with the backdrop homogenized, text contrast stops tracking scrolling content — still verify 4.5:1 against the actual misted image (WCAG 2.1 SC 1.4.3); never let the mist layer be the sole carrier of key information.

Browser support

backdrop-filter: Baseline 2024 Newly available (since 2024-09, MDN); Safari 9–17 needs the -webkit- prefix; calc() in custom properties is baseline (research 17 §3.4).

Fallback

Without backdrop-filter, fall back to opaque rgb(241 244 248 / .96) (research 17 §3.4) — mist already lives near the opaque end, so the fallback is nearly lossless; keep the stroke and radius.
