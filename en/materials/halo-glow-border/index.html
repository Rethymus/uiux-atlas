Halo Glow Border

光晕描边 · 光环描边 · Halo Border · Lit Border

Code breakdown

Structure & DOM

The essence of a halo border is two instances of one gradient (research 17 §5.1): the sharp layer is the line, the blurred layer is the light. Draw a 1–2px ring with a conic/linear gradient, then stack a blurred twin of the same gradient to spill as the halo.

<div class="halo">          <!-- glass base (optional) + two pseudo layers -->
  <h3>Title</h3>
</div>

Key points:

  • Ring and halo are both pseudo-layers (::before/::after); the host only needs position: relative — no extra DOM;
  • The ring is a double-mask knock-out: linear-gradient(#000 0 0) content-box + mask-composite: exclude (Webkit dual-written as -webkit-mask-composite: xor); the padding is the ring width;
  • The blurred twin sits behind the card (z-index: -1) and extends a few pixels beyond the edges — that is what makes the light “spill”; both layers set pointer-events: none.

Styling & Parameters

Four parameters drive the recipe (research 17 §5.3, [R]; the ring-drawing lineage comes from CSS-Tricks “Gradient Borders in CSS”, verified in full):

@property --hg-spin { syntax: "<angle>"; inherits: false; initial-value: 0deg; }
.halo {
  position: relative; border-radius: 18px;
  background: rgb(255 255 255 / .06);
  -webkit-backdrop-filter: blur(12px) saturate(1.4);
  backdrop-filter: blur(12px) saturate(1.4);
}
.halo::before, .halo::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background: conic-gradient(from calc(var(--hg-angle) + var(--hg-spin)),
    rgb(255 176 32 / .9), rgb(255 86 168 / .9), rgb(86 128 255 / .9), rgb(255 176 32 / .9));
  padding: var(--hg-ring);                                   /* knock out a 1–2px ring */
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
}
.halo::before { filter: drop-shadow(0 0 6px rgb(255 150 80 / .45)); animation: spin 6s linear infinite; }
.halo::after  { inset: -3px; filter: blur(var(--hg-blur)); opacity: calc(var(--hg-op) / 100%); z-index: -1; animation: spin 6s linear infinite; }
@keyframes spin { to { --hg-spin: 360deg; } }
@media (prefers-reduced-motion: reduce) { .halo::before, .halo::after { animation: none; --hg-spin: 90deg; } }

Where the numbers come from:

  • Ring width 1.5px, halo blur(10px), opacity .55, the 6s rotation, the three color stops (amber/magenta/blue) with same-color closure, and resting at 90° under reduce: all recorded in the research 17 §5.3 recipe; suggested ranges: ring 1–2px, halo-blur 6–14px, halo-opacity 40–70% (§5.5);
  • The conic border only rotates because the angle is @property-registered: unregistered custom properties cannot interpolate — the watershed of whether halos move at all, around Baseline 2024-07 (research 17 §11.8; MDN @property page verified);
  • conic-gradient’s from/at syntax and angle color stops: MDN verified in full; the static (no-animation) version can directly use the CSS-Tricks dual-background method: background: linear-gradient(#111,#111) padding-box, linear-gradient(120deg, gold, magenta) border-box; border: 1px solid transparent (the article’s verified original);
  • Rim-light feasibility is additionally backed by hyalite’s Fresnel sheen + specular line + inset-shadow rim approach (README verified in full).

Motion & Interaction

  • Rotation: both layers spin together (same keyframes), linear at 6s per turn; it depends on @property angle interpolation — in older browsers the ring rests but renders fine (initial-value fallback, research 17 §5.4 [S]);
  • prefers-reduced-motion: reduce: the animation is canceled and the phase rests at 90° — keep the static halo instead of going dark (MDN’s official approach of substituting a non-vestibular state; same principle as research 17 §8.2);
  • Selected/focus states: the halo appearing is the state — fade it in/out over 0.25s, never fly the whole ring in;
  • The halo layer sets pointer-events: none: light never intercepts the pointer, card interaction is unaffected.

Real-world examples

  • hyalite demo’s rim light: edge-light treatment via Fresnel sheen + specular line + inset-shadow rim, GitHub README verified in full (demo: https://vii-cae.github.io/hyalite—liquid-glass/demo/index.html, repo metadata verified);
  • CSS-Tricks “Gradient Borders in CSS” (Chris Coyier, 2018): the lineage source of six gradient-border methods — dual background padding-box/border-box, negative z-index pseudo-elements, clip-path and more (verified in full);
  • Highlighted cards / CTA active halos in dark SaaS consoles are common community practice; per-site exemplars could not be verified (research 17 §5.6 states so honestly) — no specific sites listed.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
ringpast 2px the line reads as a colored trim; wide rings show the gradient stops more stronglybelow 1px moiré/breaks can appear on high-DPI screens; at 0.5px the ring flickers in and out
glowBlura wider, more diffuse, more neon atmosphere; past 14px the halo blends into the drop shadowthe light hugs the edge and becomes a second line; at 4px there is barely a “halo”
intensitypast 70% the halo drowns the card’s hierarchy on dark backdropsthe light fades; at 20% only the sharp ring remains — an ordinary gradient border
anglethe phase decides which color stop catches the top light; clashing with the UI’s key color causes color collisionsonly shifts the static start phase; under rotation angle is the initial value, not the destination

Working ranges: ring 1–2px, glowBlur 6–14px, intensity 40–70%, stops as a 3-color group with same-color closure. Related entries: glassmorphism for the glass-base parameter range; backdrop-filter for filter chains and sampling domains; soft-glow-glass — halo is “light at the edge”, soft-glow is “light in the body”.

When to use 3
  • Dark SaaS dashboards' highlighted cards and CTA active-state halos (community practice; hyalite's rim light + the CSS-Tricks lineage as technical anchors, research 17 §5.6)
  • Selected/focused state as 'being lit': a halo expresses state more softly than a bold stroke
  • Brand atmosphere accents: color stops in brand triads (3 colors + same-color closure recommended, research 17 §5.5)
When not to use 3
  • Pale, bright backdrops: the halo disappears, leaving only a colored line
  • Applying it to every card: if everything glows, nothing does — hierarchy dies first
  • Reading containers: a rotating ring keeps pulling attention that reading cannot afford
Accessibility

The halo must not be the sole indicator of selection/error (states need textual/graphic redundancy, WCAG 1.4.1); rotation respects prefers-reduced-motion — under reduce it rests at the 90° phase rather than going dark (the static light is kept); the halo layer sets pointer-events: none and never blocks interaction.

Browser support

conic-gradient is fully baseline; @property angle animation is Baseline 2024 (since 2024-07) — in older browsers the ring rests but renders fine (initial-value fallback, research 17 §5.4 [S]); mask-composite: exclude + -webkit-mask-composite: xor dual-written to cover Chromium/Safari/Firefox; the extreme fallback without conic is the linear-gradient dual-background method (fully supported since 2018).

Fallback

Browsers without @property interpolation: rotation stalls and the ring shows statically via initial-value; without mask-composite, switch to CSS-Tricks' static dual-background method: background: linear-gradient(#111,#111) padding-box, linear-gradient(120deg, …) border-box; border: 1px solid transparent (the article's verified original).
