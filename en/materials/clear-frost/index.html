Clear Frost

清透磨砂 · 超薄磨砂 · Ultra-Thin Frost · Clear Frost Glass

Ultra-thin frost: minimal blur radius + minimal white fill + high backdrop saturation so background color passes through almost intact. Official counterparts: SwiftUI ultraThinMaterial and Liquid Glass' clear variant.

Community ★★★
Live demo official default
Parameters
Geometry▾
frost0.25

Frost thickness axis t∈[0,1] mapped to Apple Material's five-thickness semantics (research 17 §2.5): blur = calc(2px + 8px×t); t=0 is ultraThin-grade (2px), t=1 near thin's ceiling (10px). Default 0.25 → blur 4px, the §2.3 ultra-thin recipe value. Drives blur only; saturation and fill are independent.

saturate1.8×
×

Backdrop saturation refill. Default 1.8 from research 17 §2.3 saturate(1.8) — the ultra-thin tier compensates color lost to minimal blur with high saturation; regular frost only uses 1.1–1.3.

fill8%
%

White fill alpha. Default 8%, the midpoint of research 17 §2.3's .06–.10 range — blur detail, not color; regular frost sits at .22–.30. Pairing rule: the ultra-thin tier must use heavier font weights / pure white text.

dimming35%
%

Opacity of the dark dimming layer stacked over bright backdrops. Default 35% is Apple's one hard official number (HIG: for the clear variant over bright content, "consider adding a dark dimming layer of 35% opacity", research 17 §0/§2.2 [S]). Drop to 0 on dark scenes.

Code breakdown

Structure & DOM

Clear frost is the “ultra-thin tier” of the glass family, sitting at one end of the same clarity axis as mist-glass. Official counterparts: SwiftUI Material.ultraThin (visionOS 1.0+) and Liquid Glass’ clear variant — HIG, verbatim: “highly translucent… ideal for prioritizing the visibility of the underlying content” (research 17 §2.1/§2.2, verified).

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="clear-frost">          <!-- ultra-thin glass: blurs detail, not color -->
    <strong>Now playing</strong>
  </div>
</div>

Key points:

  • Structurally identical to the glassmorphism entry: backdrop → glass panel → content; only the parameter ranges differ, not the DOM;
  • The ultra-thin tier must pair with heavier font weights / pure white text (research 17 §2.3 pairing rule) — with such a thin fill, weight is the last contrast tool;
  • Bright-backdrop scenes add one ::before dark dimming veil — the only place Apple publishes a hard number (35%).

Styling & Parameters

Four parameters; frost maps blur along the officially anchored five-thickness semantics (research 17 §2.5):

.clear-frost {
  background: rgb(255 255 255 / var(--cf-fill));   /* default 8% (recipe range .06–.10) */
  -webkit-backdrop-filter: blur(calc(2px + 8px * var(--cf-t))) saturate(var(--cf-sat));
  backdrop-filter: blur(calc(2px + 8px * var(--cf-t))) saturate(var(--cf-sat));
  border-radius: 20px;
  box-shadow: inset 0 0 0 1px rgb(255 255 255 / 0.10);  /* ultra-thin inner stroke (regular tier: .16 + top light) */
}
/* Apple's official rule [S]: over bright content (photos/video), stack a 35% dark dimming layer */
.clear-frost.on-bright::before {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  background: rgb(0 0 0 / var(--cf-dim));
}

Where the numbers come from:

  • blur 4px, saturate 1.8, fill .08, inner stroke white/.10: the research 17 §2.3 ultra-thin recipe; the comparison column (regular frost blur 18–24px / sat 1.1–1.3 / fill .22–.30) comes from the same table — two grades of one axis;
  • The frost axis formula blur = 2px + 8px×t: research 17 §2.5, anchored on Apple Material’s five-thickness enum (ultraThin→ultraThick); default t=0.25 → 4px;
  • dimming default 35%: the official HIG number (research 17 §0 [S]); the dimming-layer entry covers that veil in depth;
  • Community quantification: rdev/liquid-glass-react’s blurAmount: 0.0625 + saturation: 140 is the community’s ultra-thin baseline (README verified) [S];
  • WWDC 219 additionally requires: clear and regular must not be mixed on the same class of controls (research 17 §2.3, verified).

Motion & Interaction

The ultra-thin tier needs even more restrained motion than regular glass — the backdrop shows through every frame:

  • Scene switch: the demo enables the dimming veil automatically over the bright Alps backdrop, cross-fading over 0.25s; under prefers-reduced-motion the transition is removed and the final state renders directly;
  • Entrance: fade + 8px rise on opacity/translate only;
  • High backdrop saturation channels every background motion (video, scrolling) straight through the panel — audit per-frame re-sampling cost for large glass over video (same performance rules as the backdrop-filter entry);
  • Press feedback via opacity/stroke tweaks; no translate-style decorative motion.

Real-world examples

  • visionOS windows and controls: system glass defaults to the ultraThin grade to preserve spatial transparency (SwiftUI Material API platform table verifies visionOS 1.0+, research 17 §2.6);
  • iOS 26 Control Center / media transport: the clear variant’s official target scenario, “float above media backgrounds” (HIG, verified);
  • rdev/liquid-glass-react: the community component implements the ultra-thin tier with blurAmount 0.0625 + saturation 140 (GitHub README verified, 6798★).

Parameter Sensitivity

ParameterTurning it up…Turning it down…
frostdrifts toward the thin/regular grades, detail smears into “frost”; at t=1 it is no longer clear frostapproaches bare backdrop at t=0 (2px, ultraThin grade); too low and only a tinted block remains
saturatericher backdrop color, more “alive” over media; past 2.2 it distorts and turns cloyingthe color refill disappears and ultra-thin blur reads gray and dull; below 1 you enter mist-glass territory
fillwhiter and more solid — readability up but the “clear” selling point gone; past 20% you are in regular-frost rangenearly bare backdrop; at 0 text has no substrate at all and contrast is uncontrolled
dimmingsteadier text contrast over bright backdrops; past 50% the glass turns murky and clarity diestext punches through 4.5:1 on bright backdrops; 0 = bare clear — the official 35% exists exactly for that rescue

Working ranges: blur 2–6px, saturate 1.6–1.9, fill 6–10%, dimming starting at the official 35% over bright backdrops. Related entries: swiftui-materials holds the official five-thickness semantics; liquid-glass documents the clear variant and its dimming rule; backdrop-filter covers the filter-chain syntax and backdrop-root pitfalls.

When to use 3
  • Floating controls over rich media backdrops: control centers, media transport, quick toggles — the clear variant's official target scenario (research 17 §2.6)
  • visionOS windows and controls: system glass keeps spatial context at the ultraThin grade (Material API platform table verifies visionOS 1.0+)
  • Caption bars and badges that let photo/video color pass through intact
When not to use 3
  • Text over bright backdrops with no dimming layer — the official 35% number exists exactly for this
  • Regular body text and dense data: the thin fill makes contrast uncontrolled (same avoid-list as the glassmorphism entry)
  • Mixing clear and regular grades on the same class of controls — WWDC 219 says the two variants should not be mixed (research 17 §2.3)
Accessibility

Text contrast is the most fragile in the whole glass family at this tier: heavier weights + pure white text are the pairing rule; over bright backdrops stack the 35% dark dimming layer before checking 4.5:1 (WCAG 2.1 SC 1.4.3); never mix clear and regular grades on the same control class, so readability expectations stay consistent.

Browser support

backdrop-filter: Baseline 2024 Newly available (cross-browser since 2024-09, MDN); Safari 9–17 needs the -webkit- prefix; calc() in custom properties is baseline (research 17 §2.4). No color-mix needed.

Fallback

Without backdrop-filter, set an opaque fill around .72 to keep text readable and keep the 1px inner stroke and radius; the 35% dimming layer is a plain rgba layer available everywhere (research 17 §2.4).
