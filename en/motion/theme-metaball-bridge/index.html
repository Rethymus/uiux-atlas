Theme Metaball Bridge

metaball bridge · 连接膜 · 液滴膜颈 · metaball membrane · 拖拽粘连

Two droplets welded into a single SVG path by one Bézier 'membrane': the neck fuses as they approach and snaps once they pass maxDist. SATO Hiroyuki's formula, sampled purely in JS — no filters involved.

Community ★★★
Live demo official default
Parameters
Geometry▾
handleLenRate2.4

Handle-length rate (formula default 2.4, verbatim in varun's port). Handle length = circle radius × d2, which grows with v·handleLenRate: higher bulges the membrane outward; lower shortens the handles and keeps the bridge tight. Past 3, small droplets can show overshoot bulges.

v0.5

Tangent-angle interpolation factor (formula default 0.5, verbatim). angle1a = angle1 + u1 + (angle2−u1)·v: at v=0 the tangent points collapse toward the circle-intersection angle (u) — the thinnest neck; at v=1 they spread to the common-tangent angle (angle2 = acos((r1−r2)/d)) — the fullest membrane. The demo default 0.5 is the original's midpoint.

maxDistFactor2.5

Break-distance factor: maxDist = r1 + r2×factor. The original hardcodes 2.5 (verbatim); the demo parameterizes it so the break point is observable — at 2.5 the demo droplets (r1=64/r2=34) snap at a center distance of 149px. Higher = clingier membrane; lower = snappier (below 1.7 the demo's resting dock is already disconnected).

duration700ms
ms

The full flight cycle driven by the toggle (launch → hover → return) — the demo stage's actual data-fx-duration. Default 700ms matches the four-phase recipe's total in research 20 §6.6 — the part beyond M3's 500ms full-screen tier is multi-phase orchestration (§5: M3 allows a longer entry to focus the new content). Higher reads calmer; below 400ms the break flashes by and the 'droplet detaches' story is unreadable.

Code breakdown

Structure & DOM

No pixel blurring — two circles are welded into a single path by one Bézier “membrane”: the neck contracts as the droplet approaches the main body and snaps once they pass maxDist — the canonical way to describe a joint “column–droplet–splash” outline (research 20 §2.1):

<svg class="scene" aria-hidden="true">
  <path class="membrane" /><!-- the membrane: d recomputed per frame, emptied on break -->
  <circle class="drop-parent" r="64" /><!-- large circle (parent droplet) -->
  <circle class="drop-child"  r="34" /><!-- small circle (child droplet, draggable) -->
</svg>

Key points:

  • All three elements share one fill (circles + membrane): the path ends at C … p1b with no Z, so filling closes the chord straight through the parent circle — only the union reads as one liquid body;
  • The larger circle must be passed as radius1: varun’s port is designed with radius1 as the bigger circle and never swaps; at d ≤ |r1−r2| (child fully inside) the formula already returns an empty string — no membrane there either;
  • Pure JS sampling, zero filter dependency: each frame recomputes one path’s d, sidestepping the unverified “SVG filter referenced from VT pseudo-elements” question entirely (spike 20a S5 disproved filters on transition pseudo-elements — this effect never touches them, and needs no startViewTransition);
  • The membrane is a per-frame geometric path: it needs no CSS interpolation and is unaffected by the “url() clip-path references cannot interpolate” limit (research 20 §1.2).

Styling & Parameters

The formula (SATO Hiroyuki’s script, verbatim from varun.ca/metaballs; handleLenRate = 2.4 and v = 0.5 are its defaults):

function metaball(radius1, radius2, center1, center2, handleLenRate = 2.4, v = 0.5) {
  const d = dist(center1, center2);
  const maxDist = radius1 + radius2 * 2.5;          // break distance (verbatim); past it, empty path
  if (radius1 === 0 || radius2 === 0) return "";
  if (d > maxDist || d <= Math.abs(radius1 - radius2)) return "";
  // Cosine rule for the tangent angles (while overlapping; u1 = u2 = 0 when separate)
  const u1 = Math.acos((r1² + d² - r2²) / (2·r1·d));
  const u2 = Math.acos((r2² + d² - r1²) / (2·r2·d));
  // Tangent points p1a/p1b/p2a/p2b: interpolated by v within [tangent angle, common-tangent angle]
  // Handle length d2 = min(v·handleLenRate, dist(p1a,p2a)/(r1+r2)) · min(1, d·2/(r1+r2))
  // Path: M p1a C h1 h2 p2a A r2 r2 (escaped?1:0) 0 p2b C h3 h4 p1b  — escaped = d > radius1
}

Where the numbers come from (research 20 §2.1; re-fetched the original article this session and it matches):

  • maxDist = r1 + r2×2.5 is the break threshold — 149px for r1=64/r2=34; the only dial between “clingy” and “snappy”;
  • Cosine-rule tangent angles u1 = acos((r1²+d²−r2²)/(2·r1·d)), u2 symmetric; v (0.5) places the tangent points between the circle-intersection angle and the common-tangent angle acos((r1−r2)/d) — v=0 is the thinnest neck, v=1 the widest;
  • Handles shrink while overlapping: d2 = min(v·handleLenRate, dist(p1a,p2a)/(r1+r2)) · min(1, d·2/(r1+r2));
  • The large-arc flag is escaped ? 1 : 0 with escaped = d > radius1 (verbatim): past radius1 the arc on circle 2 crosses its long/short-arc threshold exactly (the leave-angle passes π/2) — a self-consistency detail of the original formula; do not “fix” it to d > r1 + r2;
  • The demo’s maxDistFactor parameterizes the original’s hardcoded 2.5 (default unchanged) so the break point is observable.

Motion & Interaction

  • Toggle → launch / hover / return: the child droplet flies from its dock toward a far point (the membrane thins and snaps past the break distance) → hovers (the broken state is visible) → returns and re-fuses; the theme commits atomically the instant the cycle completes, and data-fx-duration matches the real cycle; the default 700ms follows the four-phase total of research §6.6 (M3 allows a longer entry, §5);
  • Drag-to-detach: Pointer Events drag the child droplet with the membrane following per frame; on release past maxDist it flies home and re-fuses, otherwise it stays put with the membrane intact — “stretch a neck between the dragged element and its home, snap, re-fuse” all live in this one formula (research 20 craft #5);
  • Re-click mid-animation: the old run finishes immediately (droplet docked, theme committed) and the new one plays in full — never frozen or half-way (spike S8: a re-click skips the old transition instantly; site builds add a ~200ms debounce or an “active → skip first” guard);
  • At the break the membrane path is emptied immediately — never tweened: spike 20a S7 proved paths with different ring counts cannot interpolate continuously and jump discretely around τ≈0.5;
  • Three degradation tiers: no SVG/rAF → hide the membrane, keep two static circles; prefers-reduced-motion: reduce → a click lands instantly (duration treated as 0, data-fx-duration synced to 0) and drag release snaps home without animation; the break itself is the natural degradation — zero functional loss.

Real-world examples

  • KittenYang/KYGooeyMenu (iOS, Objective-C, 1898★): the representative of the UIBezierPath membrane-menu family — menu items grow necks as they expand (verified via GitHub API, research 20 §4);
  • KittenYang/KYCuteView (iOS, 984★): sticky drag bubbles — a neck stretches between the dragged element and its home, snaps past a distance and re-fuses on release: the native precedent for drag-to-detach (§4);
  • The Amoeba demo on varun.ca/metaballs (web): the runnable reference implementation of this very formula — a large amoeba and a small cell separating/re-fusing under drag with the membrane path recomputed per frame (the embedded code on the page re-fetched this session is this implementation).

A public web implementation by a major product was not found (research 20 §4 unverified list) — none is invented here.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
handleLenRatelonger handles, fuller outward-bulging membrane; past 3, small droplets show overshoot bulgesshorter handles, straighter tighter bridges; at 0.5 the membrane degenerates toward two straight edges
vtangent points spread toward the common-tangent angle — wider neck, fuller “wetter” membranetangent points collapse toward the circle-intersection angle — thinner, leaner neck; 0.05 approaches a line bridge

Working ranges: handleLenRate 2–3, v 0.35–0.7, keep the break factor at the original 2.5, cycle 600–800ms; the membrane must share the circles’ color and stay high-contrast against the stage, or the fused boundary is unreadable.

When to use 4
  • Liquid bridging for nav/tab indicators: the slider briefly fuses with neighboring items as it travels (iOS-family precedents GooeyTabbar/KYGooeyMenu, research 20 §4)
  • Clinging button groups: tightly spaced related actions (toolbars, split handles) grow a neck on hover/activation
  • Drag-to-detach: a neck stretches between the dragged element and its home, snaps past maxDist, re-fuses on release (precedent KYCuteView's sticky drag bubbles, 984★, §4)
  • The 'splash up — fall back' beat of liquid theme stories: one sampling describes both departure and reunion (research 20 craft #5, §6.6 skeleton)
When not to use 4
  • Calling the formula with the smaller circle first — varun's port assumes radius1 is the larger (the original never swaps); sort before calling
  • Tweening across the break — paths with different ring counts cannot interpolate continuously and jump discretely (spike 20a S7); clear the path at the break instead
  • Letting the neck be the only selected/connected indicator — the membrane is decorative (aria-hidden); state needs its own color/text carrier (HIG: motion never the sole channel)
  • Low-contrast liquid color — the membrane only reads as one body when it shares the circles' color; keep the liquid high-contrast against the stage in both themes (cf. theme-css-blobbing's high-contrast premise)
Accessibility

The whole droplet scene is an aria-hidden decorative layer; theme state rides data-fx-theme, text readouts (center distance d, bridge state) and color — never motion alone. The toggle is a real button (keyboard reachable); dragging is an enhancement — keyboard/touch users get the same story from the toggle. Under prefers-reduced-motion: reduce a click lands instantly (WCAG 2.3.3/C39: interaction-triggered motion must be disableable); for rapid toggling honor HIG's 'avoid motion on frequent interactions' — re-click mid-run finishes the old run immediately and plays the new one, never queueing.

Browser support

Pure JS sampling (rAF + SVG path d) with zero filter dependency — sidesteps the unverified 'SVG filter referenced from VT pseudo-elements' question entirely (spike 20a S5 disproved filters on transition pseudo-elements; this effect never touches them). rAF and SVG <path> work in every browser; dragging uses Pointer Events (Baseline). The membrane is a per-frame geometric path — it needs no CSS interpolation and is unaffected by the url() clip-path non-interpolability limit (research 20 §1.2).

Fallback

Membrane breakage is the natural degradation: pull apart and it snaps with zero functional loss (the droplet stays a full circle). Environments without SVG/rAF hide the membrane and keep two static circles; under prefers-reduced-motion: reduce a click lands instantly (duration treated as 0, data-fx-duration synced to 0), dragging still works (direct manipulation) and release snaps home without animation. Key rule: on break the membrane path is emptied immediately — never tween between the two path topologies (spike 20a S7: interpolating paths with different ring counts jumps discretely).
