Classic Brutalism

经典粗野主义 · Web Brutalism · Classic Brutalism

Default, unstyled HTML as a style: system fonts, hard black/white contrast, 1–2px black borders, the browser default link blue, zero shadows and zero radius — a mindset of 'honest materials', not a visual recipe.

Community ★★
Live demo official default
Parameters
Geometry▾
borderWidth2px
px

Solid black border width, driving all containers via --cb-border. Research 03 §5 records a 1–2px range, default at the 2px top; compare neo-brutalism's 2–4px outlines (see our neo-brutalism entry) — the thinner border is the first visible split between classic and neo.

Color▾
linkColor#0000EE

Link color, defaulting to the browser default link blue #0000EE (verbatim from research 03 §5). 'Links look like links': underlines stay and the color stays the browser's own — undecorated, unbranded, the manifesto's 'honest materials' executed literally.

Motion▾
typefacesystem

JS-type param (demo subscribes and toggles data-typeface). system = the system default serif (Times New Roman lineage; study 11 §6 criterion 'system default fonts'); mono = the monospace stack ui-monospace/"JetBrains Mono"/Courier New (research 03 §5). Both are legitimate classic-brutalist faces — the common point is loading no font files at all.

hoverInverton

JS-type param (demo subscribes and toggles data-hover-invert). on = hard hover inversion (black↔white) with zero transition (research 03 §5); off = hover adds only an underline, showing inversion is not the only legitimate feedback. Either way transitions stay at 0 — classic brutalism uses no easing.

Code breakdown

Structure & DOM

Classic brutalism’s DOM is “the plainest structure a browser will render”: h1 / p / a / ul / table carry the content directly, no decoration layers, no card wrappers, no backdrop layers — structure is the visual. Per 99designs: “brutalism describes a mindset more than a set of visual features”; on the Web that means “default, unstyled HTML”.

<main class="page">
  <h1>THE BRUTALIST WEB</h1>
  <hr />
  <div class="box">
    <h2>Manifesto</h2>
    <ul><li>Content first</li><li>Links look like links</li><li>Performance is design</li></ul>
  </div>
  <table>…</table>
  <a href="#">Default link</a>
  <button class="btn">Submit Query</button>
</main>

Key points:

  • Semantic tags are used bare; delete all the CSS and the page remains fully readable and navigable — that is the style’s design promise, not a flaw;
  • The trio border-radius: 0, box-shadow: none, transition: none holds globally: zero radius, zero shadow, zero transition;
  • Uppercase headings (text-transform: uppercase with letter-spacing: -0.02em) and oversized type are the only two permitted “gestures”.

Styling & Parameters

Four parameters: two CSS declarations, a typeface switch and a hover-feedback switch:

.page {
  --cb-border: 2px;    /* solid black border (param; research range 1–2px) */
  --cb-link: #0000EE;  /* browser default link blue (param; default IS the default) */
  font-family: "Times New Roman", Times, Georgia, serif; /* system default */
  background: #fff;
  color: #000;
}
.page * { border-radius: 0; box-shadow: none; transition: none; }
.box, .btn, th, td { border: var(--cb-border) solid #000; }
a { color: var(--cb-link); text-decoration: underline; }   /* underline never stripped */
.btn:hover { background: #000; color: #fff; }              /* hard invert, zero transition */

Where the numbers come from:

  • Border 1–2px solid black, link blue #0000EE, hover hard invert without transition, the mono stack ui-monospace/"JetBrains Mono"/Courier New, body ≥16px: all verbatim from research 03 §5;
  • System default fonts (Times New Roman lineage), black/white/gray monochrome, square rectangles, bare functionality, modular repetition: study 11 §6 (99designs + the brutalistwebsites.com manifesto);
  • Criterion split from neo-brutalism (study 11 §6 quick table; the four rows that define this entry): shadows — classic none (or bare borders) vs neo’s zero-blur hard offset shadows; color — black/white/gray vs loud saturated blocks; type — system defaults vs experimental display faces; core — honest, unstyled HTML vs designed “roughness”. The only shared traits are “square corners” and “black borders” — distant relatives.

Motion & Interaction

Classic brutalism’s motion spec is “no motion”:

  • Hard hover invert: black↔white switches instantly, transition: 0 — inversion is a state receipt, not an animation;
  • Focus ring: the browser’s default outline stays, unremoved and unredrawn — the bare focus ring is part of the style;
  • No entrance animation, no scroll parallax, no easing curves; prefers-reduced-motion is trivially satisfied — there is no motion to exempt;
  • The red line: any urge to “add a little transition for polish” betrays the style — “abandon decoration” includes motion decoration.

Real-world examples

  • Craigslist — a classifieds directory kept near browser-default rendering for decades; the emblem of evergreen “functional brutalism” (research 03 §5).
  • Hacker News — system fonts, default-blue links and a lone orange badge; its traffic and age both prove “performance is design” can hold (research 03 §5).
  • Gucci PF18 and A$AP Rocky’s AWGE — “style-driven brutalism” appearing in the brutalistwebsites.com gallery: luxury and hip-hop labels borrowing the bare page for contrast — a one-off gallery usage, not a long-term skin (research 03 §5; the same research notes style-driven work dates fast: demand peaked at 3.6% in March 2026, then fell).

Working ranges: border 1–2px, body ≥16px, black/white with gray allowed for secondary text. Keep one boundary rule in mind: the moment a hard offset shadow (4px 4px 0 #000) or a saturated color block appears, you are writing neo-brutalism, not this — the tell comes from research 03 §5 (“a 4px 4px 0 #000 hard shadow is the tell of neo-brutalism”).

When to use 4
  • Functional content sites: docs, forums, directories, aggregators — the evergreen Craigslist/Hacker News lineage (research: functional brutalism endures)
  • Manifesto portfolios and magazine features — anti-decoration as the message, the style-driven 2014 gallery lineage
  • Prototypes and MVPs — ship first on the browser's default rendering with a zero style budget
  • Performance-critical contexts: slow networks, low-power devices — no fonts and no decorative images is the fastest first paint there is
When not to use 4
  • Consumer brand sites — 'unpolished' clashes directly with brand trust
  • Data visualization and rich apps — a black/white/gray palette cannot carry multi-dimensional encoding
  • Treating style-driven brutalism as a long-term skin: research shows it dates fast (demand peaked at 3.6% in March 2026, then fell)
  • Dense forms and checkout flows — default-styled controls leak brand consistency
Accessibility

Hard black/white contrast clears thresholds by construction: black on white is WCAG's 21:1 ceiling, so SC 1.4.3 passes without tuning. Links always keep their underline ('links look like links' = the affordance is never stripped); the focus ring is the browser's default outline, unremoved — the bare focus ring is part of the style. Hover inversion carries no information, it is pure decoration, and no keyboard path depends on it.

Browser support

No modern-feature dependency: system fonts, link underlines, borders, ul/table are all Web-antique features rendered identically everywhere; there is no @supports branch to write.

Fallback

This style's fallback is itself: delete all the CSS and the page remains fully readable, navigable and operable — 'default, unstyled HTML' means the browser's default rendering IS the fallback. That is where its 'performance is design' manifesto comes from: no font downloads, no decorative images, no JS dependency.

Sources 4

OriginBorn from postwar béton brut architecture — Corbusier's Unité d'habitation (1952) as the architectural start; brutalistwebsites.com (Pascal Deville, 2014) codified it as a standalone digital style — 'a younger generation's rebellion against the light, optimistic, pleasing modern web'; David Bryant Copeland's manifesto: 'honest materials: content first, links look like links, performance is design' (research 03 §5; study 11 §6).
