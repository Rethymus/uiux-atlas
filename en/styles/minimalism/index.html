Minimalism

极简主义 · Minimal Web Design · 极简网页

Do more with less: two typefaces, a restrained palette (neutrals + one accent), a uniform spacing scale, whitespace instead of borders and cards — not a trend but the baseline.

Parameters
Geometry▾
ratio1.25

Type-scale ratio (modular scale). Default 1.25 = Major Third, per the superdesign.dev minimalist-web-design page; a JS-type param (the demo subscribes and derives the scale specimen). The ratio is minimalism's hierarchy tool in place of borders: levels come from size differences, not decoration.

space8px
px

Spacing scale base value; every gap is an integer multiple. Default 8px = the 8pt scale (8/16/24/32/48/64/96px), per superdesign.dev. 'Whitespace is the design system' — once the scale slips, minimalism's sense of order collapses.

Color▾
accent#2563eb

The single accent, reserved for CTAs, links and key figures. Default #2563eb comes from the five documented palette tokens (--accent); the minimalist color budget is '2 neutrals + 1 ink + 1 muted ink + 1 accent' — one more accent is overspending.

Code breakdown

Structure & DOM

A minimalist DOM is startlingly thin: one column, one headline, one paragraph, one button — hierarchy comes entirely from size, weight and whitespace, never borders or cards.

<main class="min-page">
  <p class="min-eyebrow">Product</p>
  <h1 class="min-h1">One idea, one screen</h1>
  <p class="min-body">Whitespace is the design system.</p>
  <a class="min-cta" href="#">Get started</a>
</main>

Key points:

  • main is capped at 65ch (the documented readable measure) — the page has a single column;
  • The hierarchy kit: type scale (stepped by the ratio), weight (400/600), whitespace (integer multiples of the spacing base);
  • The accent appears only on CTAs/links/key figures — “one idea per screen” pairs with “one hue per page”.

Styling & Parameters

Three parameters map to the type ratio, spacing base and accent; the five palette tokens come from the research (superdesign.dev minimalist-web-design page):

:root {
  /* Five palette tokens (documented values): budget = 2 neutrals + 1 ink + 1 muted ink + 1 accent */
  --bg: #fafaf9;        /* page base */
  --surface: #f0efec;   /* surface, only where something must lift */
  --ink: #1c1917;       /* primary ink */
  --ink-muted: #57534e; /* muted ink: secondary text */
  --accent: #2563eb;    /* the only accent (parameter) */
  --min-space: 8px;     /* spacing base (parameter): 8/16/24/32/48/64/96 */
}

.min-page {
  max-width: 65ch;
  margin: 0 auto;
  background: var(--bg);
  color: var(--ink);
  font-size: 16px;             /* base size */
  line-height: 1.6;
}
.min-h1  { font-size: calc(16px * RATIO * RATIO * RATIO); }  /* ratio^3, computed in JS */
.min-body { color: var(--ink-muted); margin: calc(var(--min-space) * 4) 0; }
.min-cta {
  color: #ffffff;
  background: var(--min-accent);
  padding: calc(var(--min-space) * 1.5) calc(var(--min-space) * 3);
  border-radius: calc(var(--min-space));
}

Where the numbers come from:

  • The five tokens #fafaf9 / #f0efec / #1c1917 / #57534e / #2563eb: recorded verbatim in the research;
  • Ratio default 1.25 (Major Third), the 8px spacing base, --measure: 65ch: same page;
  • Body contrast ≥4.5:1, with the research sample hitting 7.4:1 (AAA).

Motion & Interaction

The minimalist motion principle: almost invisible, never abrupt.

  • CTA hover: a slight brightness shift (filter: brightness(0.96)) or an underline appearing, 120ms; no translation, no scaling;
  • Page transitions fade (120ms); under prefers-reduced-motion all of it is dropped, rendering final states directly;
  • Interaction affordances stay statically visible: permanent link underlines, a 2px solid focus ring — “stripped accessibility cues” is a top trap named in the research;
  • Parallax and stacked fade-ins smuggled in to look premium are maximalism sneaking back in.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
ratioa louder scale (1.5+ approaches Swiss posters) — vivid hierarchy, but long titles overflowflatter hierarchy; at 1.1 it nears a uniform wall of text and weight must carry the levels
spacemore generous whitespace, stronger “editorial confidence”; a 16px base wastes heavily on small screenstighter pages; a 4px scale feels cramped in long-form and blurs paragraph relationships
accentbrighter accents need dark text checked at 4.5:1; deeper ones can carry whitemore accent usage is “overspending”; the budget line: one hue per page

Working ranges: ratio 1.2–1.333, space 8px (4 for 4pt-grid contexts), accent coverage under 5% of the canvas. Check gray-on-white stepwise: the muted ink #57534e on #fafaf9 sits near 7:1 — one step deeper gray skirts the line.

When to use 3
  • Content-first landing pages, docs and editorial sites — one idea per screen
  • Single-CTA conversion pages: whitespace pushes the eye to the one action
  • Interfaces with type-driven hierarchy — levels from size differences, not decoration
When not to use 3
  • Dashboards and data-dense scenes — the research explicitly rules minimalism out for dense data
  • Multi-task tool UIs — weak hierarchy raises scanning cost
  • Dense forms relying on borders/cards to zone content — whitespace cannot carry the complexity
Accessibility

Body contrast ≥4.5:1 (the research sample hits 7.4:1, AAA); gray-on-white is the top trap — the muted ink #57534e on #fafaf9 sits near 7:1, and any deeper gray instantly drops below 4.5:1. Accessibility affordances must not be stripped as 'decoration': keep link underlines and visible focus rings; thin weights at small sizes are the second trap — body text no lighter than 400.

Browser support

Pure typography and spacing — no new API dependencies; the 65ch measure works everywhere.

Fallback

No technical fallback exists — the risk is entirely readability: if contrast fails, darken the muted ink #57534e until body text passes 4.5:1; if hierarchy is unclear, scale type up step by step instead of adding borders.
