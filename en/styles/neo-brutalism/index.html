Neo-Brutalism

新粗野主义 · Neubrutalism · Neo Memphis

Black outlines + zero-blur hard offset shadows + candy-colored geometric blocks: the commercialized branch of brutalism, wrapping conventional UX in loud shapes.

Community ★★★
Live demo official default
Parameters
Geometry▾
shadowOffset4px
px

The x/y offset of the hard shadow (zero blur, black). Default 4px comes from the signature recipe box-shadow: 4px 4px 0 #000 — 'a 4px 4px 0 #000 hard shadow is the tell of neo-brutalism' (superdesign.dev). The style's strongest identity marker.

borderWidth3px
px

Solid black outline width. Research range 2–4px (daisyUI entry 059 and superdesign.dev); default 3px is this entry's baseline (mid-range). Outline and hard shadow together give the blocks their print-like silhouette.

radius0px
px

Corner radius. Default 0 = square corners, brutalism's default posture (daisyUI: square or minimally rounded); the 16px cap covers the community's rounded variant, though larger radii weaken the shadow's offset-dislocation feel.

Color▾
accent#ff90e8

A single saturated accent for CTAs, highlight blocks and selected states. Default #ff90e8 is a community-common candy color sample (community value, unverified — the research records only 'a single saturated accent / saturated flat blocks' without a specific hex); production pairs it with black, white and cream bases.

Code breakdown

Structure & DOM

Neo-brutalism has no layering, no blur, no gradients — only flat blocks plus a print-style silhouette. The DOM is an ordinary card and form:

<div class="nb-card">
  <h3 class="nb-title">Loud title</h3>
  <button class="nb-btn">Primary action</button>
</div>

Key points:

  • Every interactive element = solid fill + solid black outline + zero-blur hard offset shadow; drop any one and the style collapses;
  • The shadow color is fixed #000 (or matches the outline), with blur and spread always 0;
  • daisyUI’s tell: a 4px 4px 0 #000 hard shadow marks neo-brutalism;
  • Control behavior stays conventional — the style “wraps conventional UX in loud geometric blocks” without usability experiments.

Styling & Parameters

Four parameters map to shadow offset, outline width, radius and accent, injected via --nb-* variables:

.nb-card {
  background: #fffdf5;               /* cream paper, demo sample color */
  border: var(--nb-border) solid #000; /* default 3px, research range 2–4px */
  border-radius: var(--nb-radius);   /* default 0 = square */
  box-shadow: var(--nb-shadow) var(--nb-shadow) 0 #000; /* signature recipe: 4px 4px 0 #000 */
  color: #111111;
}

.nb-btn {
  background: var(--nb-accent);      /* single saturated accent */
  border: var(--nb-border) solid #000;
  border-radius: var(--nb-radius);
  box-shadow: var(--nb-shadow) var(--nb-shadow) 0 #000;
  font-weight: 700;
}

/* Press: translate to the shadow origin and swallow the shadow (not a shadow animation) */
.nb-btn:active {
  translate: var(--nb-shadow) var(--nb-shadow);
  box-shadow: none;
}
.nb-btn:focus-visible {
  outline: 3px solid #000;
  outline-offset: 3px;
}

Where the numbers come from:

  • box-shadow: 4px 4px 0 #000 and the 2–4px outline: the superdesign.dev brutalism page (the tell, verbatim) and daisyUI trend entry 059 (“dark outlines, hard offset shadows”);
  • Square/minimal radii: daisyUI entry 059; type typically uses geometric sans display faces like Space Grotesk / Archivo (superdesign.dev);
  • The accent default #ff90e8 is a community-common candy sample (unverified) — the research records only “a single saturated accent” without a specific hex;
  • Component reference: neobrutalism.dev (a 64-component React library on a shadcn/ui base).

Motion & Interaction

One rule governs motion: stay hard — any softening dilutes the style:

  • Press: the element translates to the shadow origin while the shadow zeroes out — like pressing the block into the paper; 0s (no transition) or a ≤0.1s micro-transition;
  • Hover: double the shadow (calc(var(--nb-shadow) * 2)) or invert the fill, both without easing;
  • Focus: outline: 3px solid #000; outline-offset: 3px — a ring outside the outline; never encode focus in the shadow alone;
  • prefers-reduced-motion: drop all transitions; press jumps straight to the final state.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
shadowOffsetstronger dislocation and volume, more “sticker”; past 8px it turns clunky and layouts must reserve shadow spacenear 0 it degrades to an outlined card and the identity fades
borderWidtha fiercer print silhouette; past 4px small controls lose clickable area to the bordera thin weak outline; at 0 only the shadow remains, reading as a plain flat card
radiusthe rounded neo-brutal variant, friendlier — but rounding and the hard shadow undercut each otherback to square orthodoxy, maximum dislocation
accentbrighter candy needs black text, deeper candy white text — verify each at 4.5:1a smaller accent share reads “restrained brutalism”; remove it entirely and the style drifts back to web brutalism

Working ranges: shadowOffset 3–6px, borderWidth 2–4px, radius 0–8px, exactly one accent. The black in outline, shadow and text must match — mixed blacks read cheap immediately.

When to use 3
  • SaaS landing pages and indie product sites — the style's 'new cool' home since 2023 (research 03 §6)
  • Design communities, portfolios, campaign pages — strong personality and an anti-polish stance
  • Forms and cards keep conventional UX — neo-brutalism 'wraps conventional UX in loud blocks' without sacrificing usability
When not to use 3
  • Long-form reading — fat outlines and saturated blocks are persistent noise
  • Serious enterprise shells and medical/finance backends — the look clashes with trust cues
  • Stacking multiple accents — the recipe is a single saturated accent; clashing candies lose the print feel
Accessibility

Black outlines naturally supply strong boundary contrast (well beyond the 3:1 of SC 1.4.11); but text on saturated candy fills must be checked case by case at 4.5:1 (dark text on bright candy, white on deep candy). Hard shadows must never be the only focus cue — add a 3px-offset outline for focus; cancel press/hover shift transitions under prefers-reduced-motion.

Browser support

border, box-shadow and transform work everywhere — no new APIs; the zero-blur hard shadow is even cheaper to render than a soft one.

Fallback

No compatibility risk; the degradation path is about readability: switch text between black and white on the saturated accent and verify 4.5:1; strip outlines and shadows and the UI falls back to plain cards — the style disappears, functionality does not.
