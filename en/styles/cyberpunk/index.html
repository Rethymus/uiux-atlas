Cyberpunk

赛博朋克 · Cyberpunk UI · 霓虹 HUD

Electric cyan / magenta / acid yellow on near-black, layered with scanlines, chromatic aberration and RGB channel split — 'glitch as atmosphere', with compressed monospace type and HUD readouts for a terminal voice.

Parameters
Geometry▾
scanGap4px
px

Scanline repeat period (the CRT dark-line cycle). The research lists scanline spacing and opacity as tunable variables (the enlighten cyberpunk page) without specific values; the 4px default is this entry's baseline. Smaller gaps read as dense CRT, larger as venetian blinds.

scanAlpha0.25

Opacity of the scanline dark line; 0 disables scanlines. The research records no specific value; the 0.25 default is this entry's baseline. The dark line only dims — it overlays the neon layer.

rgbShift2px
px

RGB channel shift (chromatic aberration): the magenta/cyan fringing distance left and right of neon type; 0 disables it. The research lists the RGB shift as a tunable variable without a value; the 2px default is this entry's baseline. Larger shifts strengthen the glitch but erode legibility faster.

glow1

Neon brightness: a multiplier on the glow layers (two blurred text-shadow layers); 0 turns the bloom off leaving flat type, 2 is a heavy neon halo. The research names the accent-to-dark-base luminance ratio as the core variable without a value; the 1 default is this entry's baseline.

Code breakdown

Structure & DOM

A cyberpunk UI is a “three-layer print”: near-black at the bottom, the neon content layer in the middle, and scanline/aberration decoration layers applied over the top via pseudo-elements (always aria-hidden, never carrying information).

<section class="cy-scene">
  <div class="cy-hud">
    <h1 class="cy-title">NEON DISTRICT</h1>
    <div class="cy-readout" role="status">LINK: STABLE · 98.2%</div>
    <button class="cy-btn">JACK IN</button>
  </div>
</section>

Key points:

  • The base must be near-black (a dark base is a hard prerequisite) — electric cyan/magenta/acid yellow only hold on it;
  • Neon = double-layer text-shadow glow + a magenta/cyan RGB split; aberration is the core move of “glitch as atmosphere”;
  • HUD vocabulary: compressed monospace type, telemetry readouts, corner-bracket frames — every decorative frame is aria-hidden;
  • The content layer stays ordinary DOM, with readouts in role="status" carrying real state.

Styling & Parameters

Four parameters map to scanline spacing, scanline opacity, RGB shift and neon brightness, injected via --cy-* variables:

.cy-title {
  color: #fcee0a;                    /* acid yellow, demo sample color */
  font-family: ui-monospace, "JetBrains Mono", monospace;
  letter-spacing: 0.06em;
  text-shadow:
    calc(-1 * var(--cy-rgb)) 0 rgb(255 43 214 / 0.8),   /* magenta fringe left */
    var(--cy-rgb) 0 rgb(0 240 255 / 0.8),               /* cyan fringe right */
    0 0 calc(10px * var(--cy-glow)) rgb(252 238 10 / calc(0.55 * var(--cy-glow))),
    0 0 calc(28px * var(--cy-glow)) rgb(252 238 10 / calc(0.30 * var(--cy-glow)));
}

/* Scanlines: a 1px dark line, period = scanGap, opacity = scanAlpha */
.cy-scene::after {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
  background: repeating-linear-gradient(
    to bottom,
    rgb(0 0 0 / var(--cy-scan-alpha)) 0 1px,
    transparent 1px var(--cy-scan-gap)
  );
}

Sources and honest labeling:

  • The research (the enlighten cyberpunk page) lists the tunable variables: scanline spacing and opacity, RGB shift, and the neon palette’s luminance ratio against the dark base — but records no specific values;
  • The four parameter defaults (4px / 0.25 / 2px / 1) are therefore this entry’s baseline settings, not official defaults; the palette uses the community’s habitual cyan #00f0ff / magenta #ff2bd6 / acid yellow #fcee0a (demo sample colors, likewise unverified as official);
  • Reference cases: the Cyberpunk 2077 site (scanlines + neon + full-screen video), the Ghost in the Shell film site, AI Utility Grid (a restrained terminal aesthetic).

Motion & Interaction

Glitch is atmosphere, not notification — every motion must degrade:

  • Glitch jitter: the title shifts horizontally by 1–2 RGB-shift units with a brief stronger split, flashing only 2–3 times per 4s cycle to avoid high-frequency strobing;
  • Cursor blink: the block cursor at the end of the telemetry row steps at 1.2s; under prefers-reduced-motion it becomes solid;
  • Degradation chain: with reduced motion, all animation turns off while the static RGB split and scanlines remain — the core identity depends on no motion;
  • Button hover intensifies the glow over 0.15s; press sinks 1px. Decoration layers are always pointer-events: none and never intercept interaction.

Working ranges: scanGap 3–6px, scanAlpha 0.15–0.3, rgbShift 1–3px, glow 0.8–1.4. All parameters act on decoration — keep one “lights-off legible” version for the body readouts.

When to use 3
  • Entertainment and game brand sites — the Cyberpunk 2077 site (scanlines + neon + full-screen video) is the benchmark (research 03 §14)
  • Music, nightlife and esports campaign pages and limited-release skins
  • Short-stay immersive heroes — strong atmosphere, low information density
When not to use 3
  • Interfaces for sustained reading — low-contrast neon hurts legibility (a limitation the research names)
  • Enterprise products and productivity tools — narrow audience and a dated feel over time
  • Projects without heavy-asset budgets — the style usually drags video/particle/shader costs (named in the research)
Accessibility

The research names 'decorative low-contrast neon text' as an accessibility hazard: check every neon string at 4.5:1, treating glow as reinforcement only; scanline and aberration layers are aria-hidden and never carry information; the glitch animation must degrade under prefers-reduced-motion to a static split, and large-area high-frequency flicker (photosensitivity risk) is to be avoided.

Browser support

repeating-linear-gradient, multi-layer text-shadow and CSS animation work everywhere; the demo's rgb(... / calc(...)) alpha math needs a modern browser — older ones can hardcode the alpha values.

Fallback

Degradation order: drop the glitch animation first (the static RGB split still reads), then the scanlines, and finally keep flat neon type + HUD frames — the core identity (near-black + electric colors) depends on no motion. Animation decorates; it never carries information.
