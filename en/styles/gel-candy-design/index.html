Gel-Candy Design

糖果果冻风 · 糖果风 · Gel-Candy Style · Candy Jelly Style

The sweet style of high-saturation candy colors + translucent gel material + capsule radii + elastic motion; its emotional axis is playful/warm, pairing with neo-brutalism's confrontational/brutal as the era's two maximalist expression routes.

Geometry▾
hue340deg
deg

The candy key hue (the scene uses the hsl(hue, 85%, 68%) family). Default 340° (coral pink) is the measured hue of the recipe's candy color #FF7AA9 (≈hsl 339); the palette convention is saturation 80–90%, lightness 60–75% (research 17 §10). The demo's mint/lemon stops are demo values derived from the palette description.

radius999px
px

Corner radius; 999px means capsule (the recipe default, research 17 §10's "capsule radii (999px)"). The capsule is the core geometry of sweetness — the squarer the corners, the weaker the sweetness and the closer to neo-brutalism's hard-edge route.

squish1

Press elasticity (the squash axis, same source as the gel-material entry): active state scales to scale(calc(1−0.06×s), calc(1−0.12×s)); s=1 is the recipe's 1:0.9 grade (research 17 §4.3). The motion half of sweetness — candy color without elasticity is just 'pink flat design'.

Code breakdown

Structure & DOM

Definition [R]: the sweet style of high-saturation candy colors + translucent gel material + capsule radii + elastic motion; its emotional axis is playful/warm, pairing with neo-brutalism’s confrontational/brutal as the era’s two maximalist expression routes (research 17 §10). The component-level material recipe lives in the gel-material entry; this entry organizes the style.

<div class="candy-scene">          <!-- light sweet base -->
  <button class="candy-btn">Like</button>   <!-- capsule + gel trio -->
  <section class="candy-card">…</section>
</div>

Key points:

  • Single-element components: the gel impressions (glossy lining / bottom density / ambient light) all live on the element’s own background + box-shadow — the style needs no wrapper layers;
  • Glass params use the ultra-thin grade (clear-frost range): candy already provides the color, so haze stays low (research 17 §10 ground rules);
  • Remove any one of the three and it is “pink flat design”: candy color (hue), capsule geometry (form), elastic feedback (motion).

Styling & Parameters

Three style-level parameters:

.candy-scene {
  background: radial-gradient(90% 70% at 18% 10%,
    oklch(0.96 0.06 calc(var(--gcd-hue) + 40) / .7), transparent 70%), oklch(0.97 0.02 var(--gcd-hue));
}
.candy-btn {
  border-radius: var(--gcd-radius);                       /* 999px = capsule (§10) */
  color: #5b2338;                                          /* deep candy ink, holds contrast */
  background:
    radial-gradient(120% 90% at 30% 18%, rgb(255 255 255 / .85), transparent 42%),
    hsl(var(--gcd-hue) 85% 68% / .8);                      /* palette: saturation 80–90%, lightness 60–75% */
  box-shadow:
    inset 0 2px 6px rgb(255 255 255 / .8),                 /* glossy lining */
    inset 0 -8px 14px hsl(var(--gcd-hue) 85% 55% / .6),    /* bottom candy density */
    inset 0 0 0 1px rgb(255 255 255 / .25),
    0 10px 22px hsl(var(--gcd-hue) 85% 60% / .4);          /* candy ambient light */
  transition: transform .18s cubic-bezier(.34, 1.56, .64, 1);
}
.candy-btn:active { transform: scale(calc(1 - .06 * var(--gcd-squish)), calc(1 - .12 * var(--gcd-squish))) translateY(1px); }
@media (prefers-reduced-motion: reduce) { .candy-btn:active { transform: none; } }

Where the numbers come from: the palette (coral pink / mint / lemon, saturation 80–90%, lightness 60–75%), the 999px capsule, the 1:0.9 squash grade, the bounce y2=1.56, and the deep candy ink demo value: research 17 §10/§4.3; the default hue 340° is the measured hue of the recipe’s candy color #FF7AA9.

Versus maximalism: the research could not verify the primary 2025–26 trend surveys — no assertion is made (stated honestly); what can be established is that gel-candy maximizes a single hue (one candy color pushed to its limits in saturation/volume/elasticity), a different strategy from multi-hue-stacking classic maximalism. Versus neo-brutalism (anchor verified: the neobrutalism.dev component library, React + Tailwind v4 on shadcn/ui, 64 components, tagline “Build bold neobrutalism layouts in minutes”): both share saturated color; they diverge in shadow hardness and the presence of borders — neo-brutalism uses thick black strokes + hard offset shadows + high-contrast flats, with no linings and no elasticity; gel-candy uses borderless soft glow + elastic highlights + translucency. The demo’s top-right “flavor switch” is this comparison made live.

Motion & Interaction

The motion half of sweetness (same source as the gel-material entry):

  • Press squash: the 1:0.9 grade + 1px sink over 0.18s; the bounce bezier’s y2>1 (1.56) creates the overshoot — the jelly trio is all-or-nothing (§11.9);
  • Reduce disables deformation: under prefers-reduced-motion: reduce, :active falls back to transform: none (the recipe keeps exactly this rule);
  • No resident animation in candy scenes: sweetness comes from material and feedback; resident bouncing/shaking turns “playful” into “jittery”; hover shifts are optional and skipped on frequent controls;
  • Focus visibility: on candy bases use a 3px saturated dark :focus-visible outline (the demo uses hsl(hue 90% 30%)), not black — black outlines are the contrasting route’s semantics.

Real-world examples

  • iOS 26 system controls’ elastic touch response: the official Glass.interactive() capability and the official “flexes and energizes on touch” narrative (WWDC25 219 / Applying Liquid Glass verified, research 17 §4.2/§10) — system-level kin of sweet elasticity;
  • rdev/liquid-glass-react: the community component parameterizing elasticity via elasticity 0.15 (GitHub README verified, 6798★);
  • neobrutalism.dev: verified evidence of the contrasting route (page verified: 64 components on a shadcn/ui base) — proof the two maximalist routes coexist in the same era; gel-candy’s own representative sites could not be verified (stated honestly) — not listed.

Parameter Sensitivity

ParameterTurning it up…Turning it down…
huerotating around the wheel changes the “flavor”; straying from the candy range (saturation 80–90% / lightness 60–75%) reads rubber/resinconverge back to the coral family; the sweetness peak is exactly the recipe’s original color
radiuspast 60px it trends capsule — the strongest sweet geometry; 999px is the style’s defaultcorners emerge and sweetness fades; at ≤24px you are in ordinary rounded-card language and the style’s identity is gone
squishpast 1.2 it over-squashes — jelly slides to plastic (the recipe’s warning); at 1.5 the elasticity narrative collapsesdeformation tightens; 0 = no elastic feedback — the trio loses “motion” and only pink flat remains

Working ranges: hue locked to the candy range (flavors may rotate), radius cards 24–32px / buttons capsule 999px, squish 0.8–1. Related entries: gel-material for the material-level recipe and trio; neo-brutalism for the era’s contrasting route; clear-frost for the ultra-thin glass grade in candy scenes; claymorphism for the other “warm” volume cue — clay is matte and inflated, gel is translucent and sweet.

When to use 3
  • Kids / education / games and playful products: the playful/warm emotional axis *is* the product's mood (research 17 §10)
  • High-frequency light-action UI (like, save, quick toggles): squash feedback gives light actions a physical 'pinch' feel
  • Brand pages and onboarding that need warmth/approachability: candy + capsule geometry lowers the psychological barrier
When not to use 3
  • Enterprise/finance/healthcare and other high-trust contexts: sweetness conflicts with trust semantics
  • Dense data and body copy: text contrast on saturated candy bases is fragile (check WCAG 1.4.3 everywhere)
  • Mixing neo-brutalism into the same components: hard black strokes cancel soft gel linings semantically (comparison in the mdx)
Accessibility

Text on saturated candy bases is checked for 4.5:1 at the brightest gloss point (WCAG 2.1 SC 1.4.3); body copy prefers dark ink (the recipe demo uses a #5B2338-family deep candy ink); press squash is input-driven feedback and deformation is disabled under prefers-reduced-motion (the gel-material recipe keeps exactly this rule); elasticity and color must never be the sole indicators of state.

Browser support

Constituent techniques are fully baseline: cubic-bezier overshoot, inset box-shadow, radial-gradient, capsule radii (research 17 §4.4); backdrop-filter Baseline 2024-09 (the gel material's see-through is optional — dropping it doesn't break the style).

Fallback

The style depends on no fragile features: without backdrop-filter the gel falls back to solid candy color (the sweetness trio remains); without overshoot curves the bounce becomes plain ease with no functional loss.
