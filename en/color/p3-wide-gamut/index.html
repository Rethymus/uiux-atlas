P3 Wide Gamut

Display P3 · 广色域 CSS · color(display-p3)

Express colors sRGB can't hold with color(display-p3 …): P3's Lab volume is ~1.5× sRGB; the progressive-enhancement trio = an sRGB fallback value + @supports + @media (color-gamut: p3).

Code breakdown

Structure & DOM

Wide gamut changes nothing about the DOM — it is two declarations at the same pick point: a base sRGB value every screen can render, plus an enhancement layer wrapped in a double guard of @supports + @media.

<button class="brand-accent">Primary action</button>
.brand-accent { color: oklch(0.8 0.24 145); }          /* 1) sRGB fallback */
@supports (color: color(display-p3 1 0 0)) {           /* 2) syntax guard */
  @media (color-gamut: p3) {                           /* 3) screen guard */
    .brand-accent { color: color(display-p3 0.511 0.903 0.463); }
  }
}

Key points:

  • All three pieces matter: @supports probes the color() syntax, @media (color-gamut: p3) probes the screen (values srgb/p3/rec2020 nest inclusively — p3 contains srgb);
  • P3 coordinates should be converted from the sRGB fallback so both branches share hue and lightness — only the saturation ceiling differs;
  • color-gamut is Baseline 2023-02 and oklch() Baseline 2023-05 (MDN, research 06 §3).

Styling & Parameters

Parameters are injected through --p3-hue / --p3-chroma; the demo pins L=0.8 (Evil Martians: any hue at that lightness pairs cleanly with black text) and exposes hue and chroma as sliders:

.accent-srgb  { color: oklch(0.8 var(--p3-chroma-srgb) var(--p3-hue)); }
.accent-p3    { color: color(display-p3 r g b); }  /* coords = f(oklch L C H) */

Where the numbers come from:

  • Lab volume (CSS Color 4 §10): sRGB 0.820M, display-p3 1.233M ≈ 1.5×, a98-rgb 1.310M, rec2020 2.042M, prophoto-rgb 2.896M;
  • A second yardstick (Evil Martians): sRGB covers only ~35% of visible colors and P3 adds 30% — different metrics, never mix them;
  • oklch chroma C: practical ceiling ≈ 0.5 (MDN, and 100% = 0.4, not 1); gamut-bounded measured max ≈ 0.37 (sRGB, slightly higher on P3 screens);
  • Empirical hue map (Evil Martians): red≈20°, yellow≈90°, green≈140°, blue≈220°, purple≈320° — the demo’s default 145° (green band) is where the P3 gain is most visible.

Motion & Interaction

Gamut has no motion of its own; the demo’s interactions form an evidence chain:

  • Gamut badge: a runtime matchMedia('(color-gamut: p3)') probe with a change listener — the badge updates live when displays are hot-plugged;
  • Control switch (JS-type param mode): switching to “sRGB only” removes the enhancement layer, reproducing how an oversaturated color looks once chroma-reduced without the trio;
  • Chroma-reduction made visible: the sRGB branch reduces chroma (hue and lightness kept) via binary search in the spirit of CSS Color 4 gamut mapping, printing the clamp 0.30 → 0.252 on the swatch; the P3 coordinates 0.385 0.924 0.321 come from the CSS Color 4 official matrices embedded in this demo (verified offline by roundtrip); on P3 screens the right swatch keeps full saturation, while on sRGB screens the browser gamut-maps it toward the left — one code path, two fates;
  • No self-driven animation, so prefers-reduced-motion does not apply.

Real-world examples

  • Tailwind CSS v4 (2025-01): the whole default palette moved from rgb to oklch, announced as “Modernized P3 color palette” — more vivid where v3 was sRGB-bounded, without breaking v3 balance; alpha via color-mix(in oklab, …) (research 06 §4);
  • Radix Colors: officially states it targets APCA contrast while shipping P3 wide-gamut values (research 06 §8) — the same-shaped approach of publishing wide-gamut scales with a downgrade path;
  • oklch.com / stylelint-gamut toolchain: Evil Martians’ official picker visualizes the gamut “hole”, and stylelint-gamut flags out-of-gamut P3 colors and enforces the manual @media (color-gamut: p3) downgrade (research 06 §2).

When to use 4
  • A punchier brand/accent color: sRGB value as the floor, P3 screens automatically get the extra saturation
  • Gradient and illustration backdrops (CSS Color 4 lets gradients interpolate in a named space; P3-space transitions stay vivid)
  • Categorical dataviz colors: the wider gamut separates hues without touching lightness
  • Media-rich pages where UI colors echo the content's colors
When not to use 3
  • Never encode information solely in 'the P3 extra vividness' — sRGB and P3 screens disagree and the signal is lost
  • Writing color(display-p3 …) with no sRGB fallback: unsupported browsers drop the whole declaration — the trio exists because each piece matters
  • Mindlessly maxing chroma on text colors: contrast must be checked per branch (WCAG AA 4.5:1) — the P3 override is not an exemption
Accessibility

Both gamut branches must pass contrast independently: body ≥4.5:1, large text ≥3:1, UI boundaries ≥3:1 (WCAG 2.1 SC 1.4.3/1.4.11, research 06 §17); when the P3 override only raises saturation and not lightness, a shared L keeps lightness contrast unchanged (Evil Martians' fixed-L workflow). The demo pins L=0.8 — per research, any hue at that lightness pairs cleanly with black text.

Browser support

@media (color-gamut) and the color() function are CSS Color 4 features; color-gamut has been Baseline widely available since 2023-02 (MDN, research 06 §3); oklch() since Baseline 2023-05 (research 06 §1). The detection pair @supports (color: color(display-p3 1 0 0)) + @media (color-gamut: p3) is the officially recommended combo. · 2023-02

Fallback

The trio IS the fallback design: ship the sRGB value first (renderable everywhere), then layer the P3 override under @supports/@media. Out-of-gamut colors are legal — browsers gamut-map them (C4's chroma-reducing algorithms), but Evil Martians notes Chrome/Safari actually still clip RGB (visibly shifting hue), so hand-write P3 overrides for critical colors; stylelint-gamut detects out-of-gamut values and enforces the manual downgrade.

Sources 3

OriginW3C CSS Color 4 defines the display-p3 predefined space and Lab volume (sRGB 0.820M, display-p3 1.233M ≈ 1.5×) plus the gamut-mapping family (reduce chroma, keep hue); @media (color-gamut) values srgb/p3/rec2020 nest inclusively, Baseline 2023-02 (research 06 §3).
