The primer is only the start — once you have finished an entry, these are the next stops: official specs, component libraries, interaction tools, inspiration galleries and deep-dive docs, each saying when to use it. All links open in a new window.

Official design specs

Apple HIG ↗ (opens in new tab) developer.apple.com/design/… Read it first for ground rules: hierarchy, progressive disclosure, cancellable motion and dark-mode base/elevated layering, all in official wording. iOS / macOS Material 3 ↗ (opens in new tab) m3.material.io The official spec when tokenizing motion and color: easing×duration pairing tables, state layers and HCT dynamic color with concrete values. AndroidToken Fluent 2 ↗ (opens in new tab) fluent2.microsoft.design The reference for Windows desktop look and acrylic/mica materials; motion and material tiers live here, with mica/acrylic details in the WinUI docs. WindowsAcrylic / Mica TDesign ↗ (opens in new tab) tdesign.tencent.com A Chinese enterprise-grade example of tokens-as-documentation: line-height and duration formulas plus pixel-level component specs, all public. 中文企业级 Arco Design ↗ (opens in new tab) arco.design Use it to study mature light/dark token mapping and the dark-mode white-opacity text ladder (90/70/50/30%). 中文双主题 Semi Design ↗ (opens in new tab) semi.design Home of 3000+ tokens and the motion-tokens-default-to-0ms accessibility architecture; worth a full read before building themable design systems. 中文DSM IBM Carbon ↗ (opens in new tab) carbondesignsystem.com The best textbook for component usage discipline: button hierarchy, data-table states and three kinds of empty states, each with its rationale. Shopify Polaris ↗ (opens in new tab) polaris.shopify.com The reference for e-commerce and merchant-tool interfaces; component docs have migrated to generic reference pages (research could not verify component-level specs). 电商

Component libraries

shadcn/ui ↗ (opens in new tab) ui.shadcn.com Copy-paste components with a semantic token convention — the pick when you want to own the code, with a registry agents can consume directly. React许可:以仓库 LICENSE 为准 Radix UI ↗ (opens in new tab) www.radix-ui.com/primitives/… The de-facto standard for accessible primitives; copy its keyboard interactions and ARIA attributes when building Dialog/Combobox/Tabs yourself. Headless许可:以仓库 LICENSE 为准 Ant Design ↗ (opens in new tab) ant.design The full toolkit for admin dashboards; motion principles (Natural/Performant) and seed tokens are well documented — good for calibrating your own spec. React中文许可:以仓库 LICENSE 为准 MUI ↗ (opens in new tab) mui.com Material-style React components; the text/contained/outlined button tiers and Snackbar notification specs translate directly into your own spec. ReactMaterial许可:以仓库 LICENSE 为准 react-bits ↗ (opens in new tab) reactbits.dev Animated/interactive component collection (demo + source + docs, for humans and agents); check its RM and performance rules paragraph by paragraph before porting ideas. MIT + Commons Clause Magic UI ↗ (opens in new tab) magicui.design Design-engineer-flavored motion components (Border Beam, Spotlight and more), installable via the shadcn registry in one command. Interaction and motion tools

cubic-bezier.com ↗ (opens in new tab) cubic-bezier.com Drag the control points to hand-tune a bezier and compare it side-by-side with built-in easings — how this site's --ease-* tokens were feel-tested. easings.net ↗ (opens in new tab) easings.net When you know the motion personality you want (bounce, decelerate, overshoot) but not the curve: 30+ easing presets with interactive demos. linear() 缓动生成器 ↗ (opens in new tab) linear-easing-generator.netlify.app For springs and bounces cubic-bezier can't express: sample them into modern CSS linear() output (repo by Jake Archibald). CSS linear() oklch.com ↗ (opens in new tab) oklch.com Convert HEX to perceptually uniform OKLCH while checking P3 wide-gamut and sRGB fallbacks — visit before defining any semantic scale. Utopia ↗ (opens in new tab) utopia.fyi/type/… Generates fluid clamp type and space scales — this site's --step-* tokens follow the Utopia method; the /space/calculator/ twin handles spacing. 字阶间距 glassmorphism.com ↗ (opens in new tab) hype4.academy/tools/… A quick start for glass: tweak blur/opacity and copy the CSS (the original domain 301s here); fine-tune back in this site's entry parameter panels. neumorphism.io ↗ (opens in new tab) neumorphism.io Skip hand-computing neumorphic dual shadows: drag light angle and intensity, copy the CSS — and remember only light backgrounds carry the style.

Inspiration galleries

Mobbin ↗ (opens in new tab) mobbin.com 600k+ real app screens organized by flow and element — the place for how mature products build a flow or control, not for visual pyrotechnics. AppFlow godly.website ↗ (opens in new tab) godly.website A gallery of visually striking sites, with OG images and app icons as their own columns — open it when you want to be startled. Land-book ↗ (opens in new tab) land-book.com A hand-picked library of landing/marketing pages with style-tag filters and ranking signals — the smoothest way to find references for one style. 落地页 Awwwards ↗ (opens in new tab) www.awwwards.com The ceiling of frontier craft (SOTDs carry jury scores); its winning-fonts filter is itself first-hand evidence of typography trends. httpster ↗ (opens in new tab) httpster.net Restrained inspiration across minimal, typographic and brutalist vibes (3000+ sites); the sidebar style counts are curation density as data.

Deep-dive docs

MDN ↗ (opens in new tab) developer.mozilla.org The authoritative manual for any CSS/JS feature; check syntax and compat tables here first, then move on to tutorials and demos. web.dev ↗ (opens in new tab) web.dev Chrome's official best practices: the high-performance animations guide, prefers-reduced-motion handling and scroll-driven tutorials live here. CSS-Tricks ↗ (opens in new tab) css-tricks.com Deep long-form write-ups of specific techniques — grainy gradients, @property number counters and more; search it by technique. WAI-ARIA APG ↗ (opens in new tab) www.w3.org/WAI/… Keyboard interaction and ARIA attribute specs for 30 component patterns; read the matching pattern before hand-rolling Tabs, Accordions or sliders. 无障碍
