图表无障碍 Chart Accessibility

Complex Images · Chart alt text · Data sonification · aria.decal

复杂图像的「两段式替代文本」:短 alt/svg aria-label 写类型+概要,页面内长描述给趋势/比例尺/颜色顺序;载体首选 figure role=group + figcaption(对所有人可见),aria-describedby 只喂纯文本;再叠直标与贴花纹理两个非色通道。

decaloff

JS 型参数(demo 订阅后叠加纹理)。柱面叠加斜线贴花 = 色相之外的第二视觉编码。ECharts aria.decal.show 官方默认 false(aria.ts 逐字核验)——贴花是色盲安全的最后兜底,但库默认关着,必须显式开启;ECharts 的 decal 由 util/decal.ts 定义(dashArrayX/dashArrayY/rotation 等参数,demo 用 SVG pattern 等效示意)。

directLabelon

JS 型参数。每根柱顶直标数值。jfly 原话:「在图上直标,而不是做远处对色的图例,远距离同色匹配极难」(08§1.1 页面已核)——直标同时服务低视力、色盲与读屏路径;关闭后退化为「仅轴刻度」,读值精度受损。

longDesctable

JS 型参数(经 ARIA tablist 切换,参数面板与 demo 双向同步)。长描述载体对照:WAI 教程首选 figure role=group + figcaption——长描述对所有人可见,惠及低视力与学习障碍用户;aria-describedby 只适合喂纯文本,结构化表格挂上去会被读屏读成连续段落(WAI 原文)。两档都要写齐 WAI 清单:趋势结论/比例尺/颜色顺序/相对高度。

代码拆解

结构与 DOM

复杂图像需要「两段式替代文本」(W3C WAI 复杂图像教程):第一段是短 alt / svg 的 aria-label,写明图表类型+内容概要;第二段是页面内的长描述,写齐趋势结论、比例尺、颜色顺序、相对高度,并且对所有人可见——首选 figure role="group" + figcaption 承载。

<figure role="group">
  <svg role="img" aria-label="柱状图:示例站点 3-8 月访问量,总体上升,详见长描述">
    <title>…</title><desc>…</desc>
    …柱与轴…
  </svg>
  <figcaption><!-- 长描述:数据表或文字,所有用户可见 -->
    <table><caption>示例站点 3-8 月访问量</caption>…</table>
  </figcaption>
</figure>

关键点:

  • aria-describedby 只适合喂纯文本:把结构化数据表挂上去,读屏会把它读成连续段落(WAI 原文)——表格请放 figcaption;
  • 正文里先用一句话概括图表,再给图——这是教程的同款顺序;
  • 色相之外必须有第二通道:直标数值(jfly 原话:「在图上直标,而不是做远处对色的图例」)与贴花纹理;
  • svg 自带 title + desc 作兜底;交互 tooltip 另须满足 WCAG 2.1 SC 1.4.13 三件套(Esc 可关/可悬停/常驻,W3C 理解页已核,详见图例与提示条目)。

样式与参数

三个参数全部为 JS 型(demo 订阅 store),默认值逐字可查:

参数默认值出处(逐字核验)
decaloffECharts aria.decal.show 官方默认 false(src/visual/aria.ts,08§3.4)——贴花是色盲安全的兜底通道,库默认关着,必须显式开启;decal 参数(dashArrayX/dashArrayY/rotation)定义于 util/decal.ts,demo 用 SVG pattern 等效示意
directLabelonjfly CUD 页原话(08§1.1 已核):直标优于远处对色图例
longDesctableWAI 教程首选 figcaption 承载长描述;table/text 两档都要写齐趋势/比例尺/颜色顺序/相对高度清单

配套默认值(ECharts aria.ts 源码核验):aria.label.enabled 默认 true——库会自动生成图形摘要供读屏;但贴花 aria.decal.show 默认 false,两者一开一关是有意设计:摘要是标配、纹理是显式选择。

/* 贴花:色相之外的第二视觉编码(SVG pattern 等效;ECharts 走 decal.ts 的 dashArray/rotation) */
<defs>
  <pattern id="decal" width="8" height="8" patternUnits="userSpaceOnUse" patternTransform="rotate(45)">
    <line x1="0" y1="0" x2="0" y2="8" stroke="rgba(255,255,255,.8)" stroke-width="2.5"/>
  </pattern>
</defs>

动效与交互

  • 长描述切换走 ARIA tablist:两枚 role="tab"(aria-selected + roving tabindex)+ role="tabpanel",方向键左右切换;demo 里 tab 点击写回参数 store,面板与视图双向同步;
  • sonification(数据声响化)说明:把数值映射为声音参数(本条 demo 自研示意:数值 → 音高 220–880Hz 正弦短音),为盲用用户提供「形状听得到」的第二感知通道;产品级 sonification 实现(具体库与默认参数)本轮调研未核验,不引具体数值——WebAudio 须在用户手势后创建 AudioContext(自动播放策略),播放状态经 aria-live="polite" 播报;
  • 贴花/直标切换即时重绘,无过渡依赖;图表本体动效纪律(数据层动画、轴静止、reduce 直出终态)见图表动效条目;
  • 读屏路径不依赖动效:数值永远可以从轴刻度、<title>、figcaption 数据表三条通道取回。

真实产品案例

  • ECharts v5.5.1(aria.ts 源码逐字核验,08§3.4):aria.label.enabled 默认 true(自动生成图形摘要供读屏)、aria.decal.show 默认 false——「摘要默认开、贴花默认关」的组合是库对无障碍的官方立场;贴花参数(dashArrayX/Y、rotation)在 util/decal.ts。
  • W3C WAI 复杂图像教程(w3.org 已核,12§13):alt 写「图表类型+内容概要」、长描述写趋势/比例尺/颜色顺序/相对高度、首选 figure role="group" + figcaption、aria-describedby 仅适合纯文本——本条 demo 的整体结构即按此搭建。
  • jfly / Okabe-Ito CUD 指南(08§1.1 页面已核):「For graphs and line drawings, label elements of the graph on the graph itself rather than making a separate color-coded key」——直标原则的原话出处;柱顶直标数值是该原则在柱状图上的直接落地。

参数敏感度

参数调大会…调小会…
decalon 后色盲用户在色相失效时仍有纹理通道;纹理过密(线宽大)会让柱面发花、直标可读性下降off 是官方默认——纯色柱依赖色相单通道,色盲场景必须靠直标/表格兜底
directLabelon 时读值不依赖轴也不依赖色;柱顶文字在窄面板可能与相邻标签相撞off 退化为仅轴刻度:读值精度下降,读屏仍可走表格,但低视力扫读通道变窄
longDesctext 档给叙事型结论,一句趋势话最快;结构化校对能力弱于表格table 档数值可复制可校对;若错挂 aria-describedby 而非 figcaption,读屏会读成连续段落

经验组合:decal=off(官方默认)+ directLabel=on + longDesc=table 是最稳的出厂态;色盲用户场景或打印灰度场景把 decal 打开;aria-describedby 留给纯文字摘要,结构化数据永远进 figcaption。

适用场景 4
  • 任何承载结论的统计图——alt 一句话 + 页面内长描述两段式,读屏与低视力都拿得到结论
  • 多系列分类图——开贴花纹理(ECharts aria.decal,默认 false 须显式开)+ 直标,色相不再是唯一编码
  • 合规/审计场景——figcaption 数据表让数值可复制、可校对,对所有人可见
  • 盲用数据探索的增强通道——sonification(数值映射音高)作为触觉/听觉补充,demo 内置自研示意
何时不要用 4
  • alt 只写「图表」或「柱状图」——WAI 要求写明类型+内容概要,空 alt 等于放弃
  • 结构化数据表挂 aria-describedby——读屏会把它读成连续段落(WAI 原文),表格请放 figcaption
  • 只换颜色区分系列而不给第二通道——色盲用户(NEI 口径约 1/12 男性)直接丢失系列信息
  • 把长描述藏进 tooltip/折叠面板——WAI 首选它对所有人可见,藏起来就只剩读屏一条窄路
无障碍

本条目即无障碍本体:svg role="img" + aria-label(类型+概要)+ title/desc 兜底;长描述用 figure role=group + figcaption 承载,写齐趋势/比例尺/颜色顺序/相对高度;tablist 遵循 roving tabindex(方向键切换);sonification 状态经 aria-live 播报;交互 tooltip 须同时满足 WCAG 2.1 SC 1.4.13 三件套(Esc 可关/可悬停/常驻,W3C 理解页已核,详见图例与提示条目)。

浏览器支持

SVG title/desc、ARIA role/aria-selected/aria-live 与 figure/figcaption 均为成熟特性,全现代浏览器可用;WebAudio(demo 的 sonification 示意)广泛可用,但 AudioContext 须在用户手势后创建(自动播放策略;各浏览器策略细节本轮未逐项核验)。

兼容回退

读屏不支持 SVG title/desc 时,figcaption 长描述仍然可见(不依赖任何 ARIA 支持);数据表是图表的天然回退——图表挂了、CSS 塌了、读屏环境里,表格都能独立传达全部数值;decal 依赖 SVG pattern,极老环境回退为纯色柱(此时直标数值成为唯一非色通道,保持 directLabel 开启)。

来源 3

起源W3C WAI 复杂图像教程(补研 12§13 抓取已核):alt 写「图表类型+内容概要」、长描述给趋势结论/比例尺/颜色顺序/相对高度、首选 figure role=group + figcaption、aria-describedby 仅适合纯文本(结构化表格会被读成连续段落)、正文先一句话概括;ECharts v5.5.1 aria.ts 源码核验(调研 08§3.4):aria.label.enabled 默认 true(自动图形摘要)、aria.decal.show 默认 false(贴花纹理须显式开启,参数见 util/decal.ts);「图上直标优于远处对色图例」原话出自 jfly CUD 页(08§1.1 已核)。
