图例与提示 Tooltip & Legend

Chart Tooltip · Legend Positioning · 悬浮提示

图表的「读值双通道」:图例管系列回指(默认右侧,ggplot2 源码默认),tooltip 管精确读值(ECharts 默认 mousemove 触发 / 100ms 延迟隐藏),并按 WCAG 1.4.13 做到 Esc 可关、可悬停、常驻。

JS 型参数(demo 订阅后重排)。right=ggplot2 源码默认(L262 legend.position="right");top=Power BI 主题预设把柱图图例压到顶部居中(BottomCenter 枚举)的常见变体;none=关掉图例,jfly 原则的落地——demo 会在首组柱上直标系列名(图上直标优于远处对色)。ECharts legend 支持四边定位,但其默认布局值源码未逐字核到位(标注)。

tooltipFollowon

JS 型参数(demo 订阅后切换定位模式)。on=提示跟随指针移动(对应 ECharts triggerOn 'mousemove' 默认);off=提示停靠在图内固定角,鼠标可轻松移入提示本体——WCAG 1.4.13 Hoverable 的最强形态。触发/隐藏沿用 ECharts 默认:showDelay 0、hideDelay 100(移出 100ms 后才隐藏,给「移入提示」留窗口)。

代码拆解

结构与 DOM

图例与 tooltip 是图表的「读值双通道」:图例解决「这条线/这组柱是谁」,tooltip 解决「这个点具体是多少」。DOM 上图例是普通文档流(顶部行或右侧列),tooltip 是悬浮层。

<div class="chart-panel">  <!-- position: relative,tooltip 的定位上下文 -->
  <div class="legend legend--top">…swatch+系列名…</div>
  <svg>…<rect class="bar" tabindex="0" aria-label="本年 1月:64" />…</svg>
  <div class="tooltip" role="status" hidden>
    本年 · 1月  值: 64
  </div>
</div>

关键点:

  • tooltip 的定位上下文是面板容器(不是 body):跟随模式下用 clientX/Y - 容器 rect 换算,停靠模式下 right/top 固定——这样不会越出卡片;
  • 柱体是可聚焦元素(tabindex=0 + aria-label),focus 触发同一 tooltip——WCAG 1.4.13 同样管辖 focus 内容,键盘用户才有读值通道;
  • 与 ECharts/D3 的取舍:ECharts tooltip 开箱即带五个默认值(trigger ‘item’ / triggerOn ‘mousemove|click’ / showDelay 0 / hideDelay 100 / transitionDuration 0.4,源码核验)与四边 legend 定位;手绘 demo 的价值是把 1.4.13 三件套(Esc/可悬停/常驻)亲手实现一遍——多数图表库的 tooltip 恰好做不全这三条,验收时要逐条核对而不是默认信任。

样式与参数

两个参数,默认值有源码级出处:

参数默认值出处
legendPosrightggplot2 theme-defaults.R L262:legend.position = "right"(源码核验);Power BI 主题预设另有 BottomCenter/Right/Left/RightCenter 枚举(官方示例)
tooltipFollowon(跟随)ECharts `triggerOn: ‘mousemove

tooltip 行为常量(ECharts v5.5.1 默认,逐字核验):trigger: 'item'、showDelay: 0、hideDelay: 100、transitionDuration: 0.4。demo 的隐藏宽限即取 hideDelay=100:移出触发区后 100ms 才消失,给「指针移入提示本体」留窗口(Hoverable)。图例缺省档 none 不是删图例了事,而是切到 jfly 原则——图上直标(demo 在首组柱顶直标系列名)。

.tooltip {
  position: absolute;
  pointer-events: auto;   /* Hoverable:提示可被指针进入 */
  /* 移出触发区后由 JS 在 100ms 后隐藏,进入提示本体则取消隐藏 */
}

动效与交互

tooltip 是全图表里最容易做过头的动效区,纪律先行:

  • 三件套(WCAG 1.4.13,Level AA):Esc 立即关闭且不动指针/焦点;指针可移入提示本体不消失;提示常驻到指针离开触发区+提示本体、用户关闭或信息失效——demo 三条全实现,可用验收清单逐条测;
  • 出现/消失:transitionDuration 0.4(ECharts 默认)属上限参考,demo 用即时显隐;若加过渡只动 opacity/transform,reduce 下取消;
  • 图例切换(top/right/none):文档流重排,无动画——位置模式切换不做过渡,避免「图例在飞」;
  • demo 的 Esc 监听仅在提示可见时挂载,窗口级 keydown 不常驻。

真实产品案例

  • ECharts v5.5.1:tooltip 五默认值(trigger ‘item’ / triggerOn ‘mousemove|click’ / showDelay 0 / hideDelay 100 / transitionDuration 0.4)在 TooltipModel.ts 源码逐字可查;无障碍侧 aria.label.enabled 默认开、aria.decal.show 默认关(v5.5.1 源码核验)。
  • ggplot2:图例默认右侧(legend.position = "right",theme-defaults.R L262),主题系统一条语句换边——「图例位置是主题属性,不是图表属性」的范式源头(源码核验)。
  • Power BI:官方主题预设的图例位置枚举 BottomCenter/Right/Left/RightCenter,示例把柱图图例压到底部居中;另有 Report Tooltips(报告页 tooltip)官方文档条目(官方 docs 已核/检索命中)。
  • jfly CUD 指南:「For graphs and line drawings, label elements of the graph on the graph itself rather than making a separate color-coded key, since matching same colors in distant places is extremely difficult」——直标优于图例的学术原话(官方页已核)。

参数敏感度

参数调大会…调小会…
legendPos图例贴顶适合宽图(水平空间充裕),none 最省空间但把回指责任压给直标——系列多时直标会互相打架right 占一条纵向列,图高换图例宽;系列 ≤4 且名字短时代价最小
tooltipFollow跟随模式读值最顺手,但提示永远差指针 14px,放大镜用户难移入(1.4.13 Hoverable 弱形态)停靠模式是 Hoverable 最强形态,代价是视线要在柱体与提示间往返

经验法则:桌面宽图 right + follow;嵌入式小图 none + 直标;无障碍审计一律按「Esc 可关/可悬停/常驻」三清单过一遍,库实现不豁免。

适用场景 4
  • 多系列图表的系列回指——图例贴顶或贴右,swatch 与系列一一对应
  • 交互式 BI 图表的精确读值——mousemove 跟随 + 100ms 隐藏宽限,快速扫值不断提示
  • 小空间嵌入图(卡片内迷你图)——关掉图例改直标,省一条图例的宽度
  • 无障碍审计的样板——Esc 可关/可悬停/常驻三件套是 WCAG 1.4.13 的验收清单
何时不要用 4
  • 图例与色块距离过远或分页——jfly 原文:远距颜色匹配极难,能直标就直标
  • tooltip 挡住指针下的数据点、或移入即消失——1.4.13 失败模式 F95(不可悬停)
  • tooltip 无 Esc 退出、指针移走仍不消失——失败模式 F114(不可关)/Persistent 被滥用
  • 只在 tooltip 里放关键数值——触屏与读屏用户拿不到;值要有第二通道
无障碍

WCAG 2.1 SC 1.4.13(Content on Hover or Focus,Level AA)三要求:①Dismissible——按 Esc 可关闭,且不移动指针/焦点;②Hoverable——指针能移入提示本体而不消失(适配放大镜/大光标);③Persistent——提示保持到触发移除、用户关闭或信息失效。demo 实现三件套:Esc 监听 + 提示可进入 + 移出 100ms 宽限(ECharts hideDelay)。配套:柱体带 aria-label;ECharts 生态另以 aria.label 自动摘要供读屏、aria.decal 纹理替代纯色相区分。

浏览器支持

demo 用原生 Pointer Events + 绝对定位 div,全现代浏览器可用;不依赖 Popper 等第三方定位库(边界钳制手写);Esc 监听为 window keydown,仅在提示可见时激活。

兼容回退

触屏无 hover:tooltip 必须同时响应 click/tap(ECharts 默认 triggerOn 本就是 'mousemove|click');键盘用户:柱体应为可聚焦元素并支持 focus 触发提示(1.4.13 同样管辖 focus 内容);提示本体承载的信息别只活在 tooltip 里——关键数值应有读值替代通道(直标/表格)。

来源 4

起源四条出处:jfly CUD 原则(「图上直标优于远处对色图例,远距颜色匹配极难」);ggplot2 theme-defaults.R L262 legend.position 默认 "right"(源码核验);ECharts v5.5.1 TooltipModel.ts(tooltip 默认 trigger 'item' / triggerOn 'mousemove|click' / showDelay 0 / hideDelay 100 / transitionDuration 0.4,源码核验);W3C WCAG 2.1 SC 1.4.13 官方理解页(hover/focus 内容必须 Dismissible+Hoverable+Persistent,失败模式 F95/F114)。
