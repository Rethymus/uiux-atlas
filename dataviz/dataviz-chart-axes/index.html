坐标轴与网格 Chart Axes & Grid

Axis Lines · Gridlines · splitLine

图表的「表格线」纪律:网格线要浅(Grafana 用主文字色 9% 透明度)、轴线可去(ECharts/ggplot2 两条路线)、刻度数克制(ECharts splitNumber 默认 5)——三参数决定一张折线图的专业度。

组件库 ★★
实例演示 官方默认
参数
几何▾
gridOpacity0.09

CSS 变量型参数(经 DemoStage 注入)。网格线不透明度,默认 0.09 逐字对应 Grafana getGridColor() 的 9% 透明度公式(暗色 rgba(240,250,255,.09) / 亮色 rgba(0,10,23,.09),随主题翻转向主文字色);ECharts 的等价落地是实色 #E0E6F1(白底下 ≈0.12 视觉等效)。0=无网格,1=网格线与文字同色同重。

tickCount5

JS 型参数(demo 订阅后按 nice-ticks 重算)。刻度档数,默认 5 逐字对应 ECharts splitNumber: 5(time 轴为 6);demo 用经典 nice-ticks 算法取整档距(1/2/2.5/5×10ⁿ),实际档数可能因取整而少 1-2 档——这与真实图表库行为一致。

动效▾
axisLineon

JS 型参数(demo 订阅后重绘)。on=轴线 #6E7079 宽 1(ECharts axisDefault 默认值,逐字核验);off=ggplot2/Grafana 路线——ggplot2 默认 element_blank() 删轴线,灰底白网格表达坐标系;Grafana 轴线(border)默认不显示。两条官方路线都成立,关键是「网格保留且极浅」。

代码拆解

结构与 DOM

轴线/网格是「参考层」,与数据层分离:同一份 SVG 里,网格与轴线画在最底,数据线画在上层,参考线永远不遮数据。

<svg viewBox="0 0 600 340">
  <!-- 参考层:值轴横向网格(opacity: var(--dvz-grid-op));类目轴不画网格 -->
  <g class="grid"><line x1="46" x2="554" y1="…" y2="…" stroke="currentColor" /></g>
  <!-- 轴层:#6E7079 宽 1;刻度线长 5;可整体隐藏(ggplot2 路线) -->
  <g class="axes" stroke="#6E7079"><line … /><line … /></g>
  <!-- 标签层:fontSize 12 / margin 8 -->
  <text x="38" y="…" text-anchor="end">25</text>
  <!-- 数据层 -->
  <polyline points="…" stroke="#0072B2" stroke-width="2.5" />
</svg>

关键点:

  • 横向网格只属于值轴:ECharts 源码强制类目轴 splitLine 关闭——网格语义是「值是多少」,类目没有值;
  • 网格线颜色用 currentColor(继承文字色)+ opacity:这正是 Grafana 公式的 demo 化——暗色亮色主题各自翻转向主文字色再取 9%,不用维护两套灰值;
  • 与 ECharts/D3 的取舍:ECharts/D3 的轴是配置项对象(axisLine.show / splitNumber / axisLabel.margin),开箱即得全部默认值;手绘 SVG 的价值是每个默认值都看得见、可单独覆盖——原型用库,对齐规范时把库默认值逐项核对成本条目的调研值。

样式与参数

三个参数,默认值全部源码级可查:

参数类型默认值出处(逐字核验)

配套常量(ECharts 默认):刻度线长 5、标签 margin: 8、fontSize: 12、网格色实色 #E0E6F1(白底下视觉 ≈0.12,与本条目 0.09 同档);ggplot2 对照:轴线 element_blank() 默认删除、面板灰底白网格、次网格线宽减半;FT Visual Vocabulary 补基线纪律:柱/面积图「Must always start at 0 on the axis」,折线图可不从零。

许可背景:ECharts 与 Grafana 均为 Apache-2.0(源码头/LICENSE 已核),ggplot2 为 MIT 系;FT 海报版权所有不可翻印,只引用原则。

动效与交互

参考层的动效原则:网格与轴线不参与动画。

  • 切 axisLine / 拖 tickCount:数据线与刻度即时重算重绘,无过渡——轴刻度变化若做动画,读者会把「刻度移动」误读为「数据移动」;
  • gridOpacity 走 CSS 变量,滑杆拖动即时生效、零 JS 重排;
  • 数据线入场动画(若有)只动 stroke-dashoffset 或 opacity,reduce 下取消;hover 数据点显示原生 <title>(系列·月份·值);
  • demo 无持续动画,尊重 prefers-reduced-motion。

真实产品案例

  • ECharts v5.5.1:默认「轴线可去、网格保留且极浅」——笛卡尔系下另一轴是类目轴时,值轴的 axisLine/axisTick 置 auto 不画,而 splitLine 默认开、色 #E0E6F1(axisDefault.ts 逐字核验;master 分支已把默认色 token 化,升级大版本留意 tokens.color.axisLine)。
  • Grafana(uPlot 底座):getGridColor() 把网格写死为「主背景反色 9%」,暗亮主题各自翻转;轴线(border)默认不显示,轴文字用主题主文字色、labelPad = 8(UPlotAxisBuilder.ts 逐字核验)。
  • ggplot2:签名主题「灰底白网格」——默认删轴线、面板底 col_mix(ink, paper, 0.92)、次网格线宽减半(theme-defaults.R L194/L271/L276 核验),是「网格表达坐标系、轴线可省」路线的学术源头。
  • FT Visual Vocabulary:轴基线权威表述「Column must always start at 0 on the axis」;line 图可不从零(引 ONS 与 Quartz 论证);海报版权所有、转载需 syndication(README 已核)——引用原则,不翻印海报。

参数敏感度

参数调大会…调小会…
gridOpacity>0.3 后网格压过数据线,折线图变「表格图」;1 时网格与文字同重0.05 以下接近无网格,读值靠数据点标签;0 时必须补 tooltip/直标
axisLineon 给图表一个明确的「框」,打印与浅屏更稳;但双轴都画线会加重边框感off 走 ggplot2/Grafana 极简路线,视觉噪音最小;前提是网格还在、标签对位清晰
tickCount8 档在 300px 高的图里开始拥挤,标签 12px 时档距 <38px;取整算法会自动并档2-3 档最克制,适合概览;但读值精度下降,交互取值场景建议 5 档以上

经验区间:gridOpacity 0.05-0.15(Grafana 0.09 居中)、刻度 4-6 档、轴线「亮底可留暗底可去」;任何情况下类目轴不画横网格、柱图零基线。

适用场景 4
  • 折线/面积/柱状图的网格密度调节——网格是值的「标尺」,浅到可忽略但不缺席
  • 暗色主题仪表盘——网格色随主题翻转向文字色再取 9%(Grafana 公式),不要照搬亮色主题的灰色
  • 极简风格图表(去轴线)——ggplot2 灰底白网格或 Grafana 隐藏轴线的路线
  • 打印/导出场景——提高 gridOpacity 或加粗轴线,屏幕上的 9% 在纸上会消失
何时不要用 4
  • 网格线重到与数据线抢注意力(gridOpacity > 0.3)——读者先看到表格后看到数据
  • 刻度数超过 8-10——ECharts 默认 5 档是有意克制,挤满刻度等于放弃取整档距
  • 柱状图纵轴不从 0 起——FT 与 ONS 的零基线权威原则,截断柱高=放大差异
  • 类目轴画横网格——ECharts 源码强制类目轴 splitLine 关闭;横网格属于值轴
无障碍

轴文字(fontSize 12,margin 8)对背景至少 4.5:1(ECharts 用 #6E7079 中灰,亮底达标;暗底请换主题文字色);网格线作为纯参考线不承载信息,不要求 3:1 非文本对比,但承载刻度语义的轴线与刻度线需要对相邻色 ≥3:1(WCAG 2.1 SC 1.4.11);gridOpacity=0 时数据点必须自带值标签或 tooltip 补值,否则读屏与低视力用户丢失取值通道。

浏览器支持

demo 为手绘 SVG + CSS 变量,无新特性依赖,全浏览器可用;网格线透明度走 SVG 属性上的 CSS opacity,axe 线/刻度/标签为普通 SVG 元素。

兼容回退

无兼容问题;真正的回退是「零基线纪律」:网格与轴线可以删,基线纪律不能破——柱状/面积图必须从 0 起(FT Visual Vocabulary:Column "Must always start at 0 on the axis"),折线图可不从零但需在轴上留截断暗示;删掉网格后若读者无法对值,应补直接标注而不是恢复网格。
