标度函数 Scale Functions

d3-scale · linear scale · log scale · normalize interpolate · domain range

一切映射的母公式:linear 标度 = normalize ∘ interpolate,即 y = r0 + (x−d0)/(d1−d0) × (r1−r0);log 标度在对数域跑同一管线——domain→[0,1]→range,demo 可调 domain/range 实时算。

社区流派 ★★★
实例演示 官方默认

动效▾

JS 型参数(demo 订阅后切换映射管线)。linear 用于均匀数据;log 用于跨数量级数据(每个十进位占同等视觉距离)——切换后同一 domain 的曲线曲率立变。

domainMin0

定义域下端 d0(数据单位)。log 模式下必须 >0:demo 会在 d0≤0 时按 1 处理并给出警告(对数在 0 与负数处无定义)。

domainMax100

定义域上端 d1。默认与 range 0→640 组成调研核验样本:scaleLinear(0,100,0,640)(50) = 320;log 模式配 domainMin=1、domainMax=1000 得核验样本 scaleLog(...)(10)=213.33。

rangeMax640px

代码拆解

结构与 DOM

demo 是一条可拖动的映射流水线:一枚输入值滑杆(数据单位)驱动两个读数——归一化 t 与映射输出 y——并把整条 domain→range 曲线画在右侧小图里,当前输入以圆点落在曲线上:

<div class="sf-panel">
  <input type="range" min="0" max="100" value="50" /><!-- 输入值 x(数据单位) -->
  <code>t = (50 − 0)/(100 − 0) = 0.5</code>          <!-- normalize -->
  <code>y = 0 + 0.5 × (640 − 0) = 320px</code>       <!-- interpolate -->
  <svg><!-- 曲线 + 当前点 --></svg>
</div>

关键点:

  • 读数严格分两行——normalize(x→t)与 interpolate(t→y),这就是 d3 continuous.js 的组合结构;
  • 曲线随 transform 切换:linear 是直线,log 是下弯曲线(每个十进位等距);
  • 切换 log 且 domain 含 ≤0 时,demo 钳到 1 并警告——对数的定义域边界可视化呈现。

样式与参数

五个参数(transform/domainMin/domainMax/rangeMin/rangeMax)由 demo 订阅,映射零依赖实现。公式(调研 14§8,源码即公式——实读 d3-scale/src/continuous.js 与 log.js):

① linear 标度 = normalize ∘ interpolate(两段仿射):

const scaleLinear = (d0, d1, r0, r1) => x => r0 + ((x - d0) / (d1 - d0)) * (r1 - r0);
scaleLinear(0, 100, 0, 640)(50);  // 320 —— 实跑 ✓(核验样本)

② log 标度 = 在对数域跑同一管线:

const scaleLog = (d0, d1, r0, r1, b = 10) => {
  const lb = Math.log(b);
  return x => r0 + ((Math.log(x)/lb - Math.log(d0)/lb) / (Math.log(d1)/lb - Math.log(d0)/lb)) * (r1 - r0);
};
scaleLog(1, 1000, 0, 640)(10);    // 213.33(1 个十进位 = 1/3 量程)—— 实跑 ✓

d3 实现细节:transformLog(x) = Math.log(x) 后复用同一 transformer;负值/镜像走 −log(−x) 分支。

③ 同构旁证(同一公式在不同场景的三次出现):

// 滚动进度归一化(scroll-driven 的 JS 等价,调研 14§6.2)
const viewProgress = (scrollY, elTop, elH, vh) =>
  Math.min(1, Math.max(0, (scrollY - (elTop - vh)) / (elH + vh)));
// Utopia clamp:S(vw) = clamp(min, intercept + slope × vw, max) —— 同一段线性回归(modular-scale-math)

核验输出(实跑):linear 中点 50→320 ✓;log 的 10→213.33(1 个十进位恰占 1/3 量程)✓。

动效与交互

  • 拖输入滑杆:t 与 y 读数逐帧更新,曲线上的圆点同步滑动——「先归一化再映射」的每一步可见;
  • 切 log:曲线从直线弯成对数曲线;domain 0→100 切 log 时 demo 钳到 1 并亮警告——定义域边界不是静默处理;
  • 调 domain/range:压缩 domain(0→20)会放大斜率,曲线更陡——「数据范围决定映射增益」用曲线斜率直接可读;
  • 交互全部由用户输入驱动,无自主动画;入场淡入尊重 prefers-reduced-motion。

真实产品案例

  • d3-scale:continuous.js 的 normalize(x) = (x−a)/(b−a) 与 interpolate 的组合就是本条公式;ObservedArray 图表库、Observable Plot 延用同一套标度思想——数据可视化的公共底座(源码实读核验);
  • CSS scroll-driven animations:规范语义 animation-range: cover 0% cover 100% 的 JS 等价正是 viewProgress 归一化公式(调研 14§6.2,Chrome 官方文档对 range 语义的说明);本站 scroll-driven-animations 条目是它的 CSS 形态;
  • OKLCH 色阶(dataviz-ordinal-scale 上游):调研核验的红→蓝 OKLCH 五站色阶(255,0,0 → 229,0,122 → 183,0,185 → 122,23,225 → 26,51,229)——把 [0,1] 的 t 喂给 OKLCH 域插值(短弧 H),中途品红过渡正是感知均匀色阶的特征,而 sRGB 域插值会中途发灰(调研 14§8.3)。

公式的量纲与边界

变量量纲取值边界退化情形
x(输入)数据单位(任意)d3 默认不钳制(可外推);clamp(true) 后钳入 [d0,d1]外推输出越界是合法语义;图表用通常显式 clamp
d0, d1(domain)数据单位d1≠d0;d0>d1 合法(镜像映射)d0=d1 除零(demo 拦截);倒置 domain 输出倒置,d3 语义一致
t(归一化)无单位0,1;外推时可越界t=0/1 是两端锚;中间 t 与数据单位无关——两段仿射的公共枢纽
r0, r1(range)输出单位(px/通道/α)r1≠r0 才有增益r0=r1 → 常量映射(标度失效,应直接用常量)
log 的 domain数据单位必须 d0>0 且 d1>0x≤0 无定义;demo 钳到最小正域并警告;d3 负值走 −log(−x) 镜像分支
b(log 底)无单位10 或 2;数学上底只改刻度不改曲线形状底数不同曲线等价(差一个常数因子),刻度标签才需要底
slope(线性增益)输出单位/数据单位(r1−r0)/(d1−d0)slope→∞(domain 收缩)曲线陡到垂直;负 slope = 反向映射(合法)
输出 y输出单位r0,r1越界 y 交给消费方裁剪(px 超画布、色值超色域)——标度不管渲染

经验口径:先问「跨几个数量级」——0 个用 linear,≥2 个考虑 log;滚动/进度归一化一律先 clamp 再映射;输出到色彩时让标度输出 t、由色带层负责插值。姊妹条目:dataviz-ordinal-scale(t→色带那段)、scroll-driven-animations(CSS 原生归一化)、modular-scale-math(同构的 clamp 线性回归)、dataviz-chart-axes(标度的可视呈现)。

适用场景 4
  • 图表坐标轴:任何 d3 风格图表的第一行代码就是一个标度
  • 滚动进度归一化:p=(scrollY−start)/(end−start) → 输出位移/透明度(scroll-driven 的 JS 等价)
  • 色阶生成:标度把数据映射到 [0,1],再喂给色带插值(dataviz-ordinal-scale 的上游)
  • 传感/金融等跨数量级数据:log 标度让 1 与 1000 在图上等距
何时不要用 4
  • log 模式喂 0 或负数——对数无定义,外推到负空间更无意义;先移位或镜像
  • d0=d1(除零)或 r0=r1(常量映射)——demo 拦截前者,后者应直接用常量而不是标度
  • 线性标度画指数增长数据——头部一柱独大、尾部全趴平;数量级跨度 >2 就该切 log
  • 忘记 clamp 语义:d3 默认外推,输入越界输出就越界——读数条会提醒当前是否外推
无障碍

标度决定『数值→视觉』的公平性:线性/对数选错会让同一份数据讲出相反的故事——轴刻度与标度类型必须在图上明示;log 轴要标注刻度是 10ⁿ;色阶映射时保持亮度单调(顺序可感知),否则色盲用户无法排序(dataviz-colorblind-safe 条目);本条公式只管映射,不替代轴标注与可读性检查。

浏览器支持

纯 JS 数学,无平台差异;输出到 SVG/Canvas/CSS 时才引入各图形 API 的支持面(全 evergreen)。CSS 侧没有原生标度函数——插值都要么 JS 预算,要么用 CSS clamp()/calc() 承担线性段(log 段 CSS 无对应物)。

兼容回退

log 模式遇到 ≤0 的数据:按领域惯例先移位(整体 +offset)或按 d3 的对称镜像 −log(−x) 分支处理,demo 取「钳到最小正域」的最保守策略并警告;线性标度不存在非法输入(除 d0=d1 除零,demo 拦截)。

来源 3

起源公式即 d3-scale 源码(continuous.js 的 normalize 与 interpolate 组合,调研实读源码);log 变换 transformLog(x)=log(x) 后复用同一 transformer(负值/镜像走 −log(−x));同构思想出现在 CSS scroll-driven progress 归一化(p=(y−start)/(end−start))与 Utopia clamp 的 slope/intercept(调研 14§8/§6.2/§1.4)。
