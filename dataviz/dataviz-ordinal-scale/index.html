序数色阶 Ordinal Scale

Sequential Scale · Color Ramp · 顺序色阶

把有序数值映射为有序颜色的色阶:单色线性(浅→深)或多色渐进,取 ColorBrewer 官方整档、中点锚定数据零点,热力图与等值线图的默认选择。

社区流派 ★★★
实例演示 官方默认
参数
几何▾
steps5

色阶档数(离散分箱数)。默认 5 对应 ColorBrewer 官方最常用的 Blues 5 档(#EFF3FF→#08519C);生产应直接取官方 3-9 档整档值(官方 JSON 齐备),禁止在成品里自行插值造档。档数越多,读者越难回指图例,打印/低质屏上相邻档趋同。

动效▾
modemonochrome

JS 型参数(demo 订阅后重绘热力格)。monochrome=Blues 单色浅→深,亮度单调递减,感知上最忠实于「值越大颜色越重」;multihue=YlGnBu 多色渐进,浅黄→蓝,同时利用亮度与色相两维,对小差异更敏感但可能被误读为类别。双向数据(RdBu)应两端饱和、正中白,并把中点锁在数据零点/均值上。

结构与 DOM

序数色阶把「值域 [0,1]」均匀分成 N 档,每档一个官方色值;热力格与图例共用同一个色阶数组,档数变化时两者同步。

<svg viewBox="0 0 512 460">
  <!-- 热力格:fill = scale[bin(value)],bin = floor(v * steps) -->
  <rect fill="#6BAED6" />  <!-- 第 3 档(Blues 5) -->
  <!-- 图例条:同一数组,浅→深 = 低→高 -->
</svg>

关键点:

  • 分箱是离散的:值 → 档号 → 官方色值,不在成品里做连续渐变(CSV/热力图语境下的「渐变」交给图表库内部插值);
  • 图例必须与格子同源——demo 里二者读同一个 scale 数组,档数联动;
  • 与 ECharts/D3 的取舍:ECharts visualMap 与 d3-scale 的 scaleQuantize 都能把值域分箱上色,且 d3-scale-chromatic 内置全部 ColorBrewer 方案(均匀 B-spline 插值出连续版);手绘 SVG 的价值是色值逐字节等于官方 JSON、图例与格子强制同源——生产图表用库,demo/规范页用手绘保证「所见即官方值」。

样式与参数

两个参数,数值全部出自 ColorBrewer 官方导出 JSON(本会话 curl https://colorbrewer2.org/export/colorbrewer.json 直下解析,35 组 scheme):

/* demo 只用 fill,格子描边 1px 用于暗色主题分隔 */
.or-chart rect { stroke-width: 1; }
方案官方 5 档 hex(JSON 核验)说明
Blues 5(单色线性)#EFF3FF #BDD7E7 #6BAED6 #3182BD #08519C亮度单调递减,「值越大颜色越重」最忠实;7 档为 #EFF3FF … #084594
YlGnBu 5(多色渐进)#FFFFCC #A1DAB4 #41B6C4 #2C7FB8 #253494亮度+色相双通道,小差异更敏感
RdBu 5(双向,MDX 参考)#CA0020 #F4A582 #F7F7F7 #92C5DE #0571B0两端饱和+正中白,中点锁数据零点/均值

参数:steps(3-9,默认 5)、mode(单色线性/多色渐进)——均 JS 型。demo 在官方 5 锚点色之间做 sRGB 线性插值只为演示 3-9 任意档数;生产必须取 ColorBrewer 官方整档(3-9 档齐备)或 d3-scale-chromatic 的均匀 B-spline 插值,两者中间档取值与线性插值不同。许可:ColorBrewer 官方渠道未明示许可文本(署名 © Brewer/Harrower/Penn State;社区流传 Apache-2.0 说法未证实);Crameri Scientific Colour Maps v9.0.0 页面称可自由使用,具体许可未证实。

动效与交互

色阶是静态映射,动效只做阅读辅助:

  • 参数面板调 steps/mode 时格子与图例同步重算重绘,无过渡(数据映射变化不做颜色渐变动画);
  • hover 单格显示原生 <title>(数值 + 档号),静态、无延迟;
  • demo 无动画,尊重 prefers-reduced-motion;若做「值扫描」演示动画,只在 transform 上动一条高亮框,reduce 下静止。

真实产品案例

  • d3-scale-chromatic:README 声明其方案「多数派生自 Cynthia A. Brewer 的 ColorBrewer」,离散 scheme 经均匀 B-spline 插值生成连续版;Viridis 系为感知均匀的连续方案(仓库已核)。
  • Fabio Crameri Scientific Colour Maps:v9.0.0,Zenodo 永久存档(DOI 10.5281/zenodo.1243862),IPCC Interactive Atlas 在用;配套论文 Crameri, Shephard & Heron (2020) 在 Nature Communications 11:5444 批评彩虹色阶扭曲数据(官方页已核)。
  • ColorBrewer 2.0(colorbrewer2.org):为地图分级设色的官方工具,三类选择法——Sequential 数值递增 / Diverging 围绕中点 / Qualitative 分类;支持 HEX/RGB/CMYK 导出(官方站与导出 JSON 已核)。

参数敏感度

参数调大会…调小会…
steps9 档时相邻档在低质屏/打印上趋同,读者难以回指图例;超过 7 档建议改注关键断点值3 档信息压缩最狠,但任意屏幕都分得清,是「概览优先」的选择
modemultihue(YlGnBu)对小差异更敏感,但黄→绿的过渡可能被误读为「另一类」monochrome(Blues)只动亮度,色盲/灰度天然安全,是默认档

经验区间:概览图 3-5 档,分析图 5-7 档,9 档仅在高保真输出上使用;双向数据一律换 RdBu 并锁中点,不要用单色阶硬扛正负值。

适用场景 4
  • 热力图/日历热力图/密度图的填充色——值序=色序,单色线性优先
  • 分级统计图(choropleth)的分级配色——ColorBrewer 本就为地图分级设色而生
  • 双向数据(偏差、盈亏、温度联想)——RdBu 双色阶,中点锁数据零点
  • 科学出版图——Crameri Scientific Colour Maps v9.0.0(IPCC Interactive Atlas 在用,感知均匀、灰度与色盲可读)
何时不要用 4
  • 无序的类别数据——序数阶暗示大小次序,类别数据请改用分类色板(dataviz-categorical-palette)
  • 彩虹多色阶(jet 类)不分场合使用——Crameri 论文(Nature Communications 11:5444)专门批评其感知不均匀、扭曲数据
  • 在成品里自行插值造中间档——生产取官方整档或 d3 B-spline,插值交给库
  • 把 diverging 中点漂离数据零点——「正中白」必须锚在 0/均值上,不许视觉漂移
无障碍

色阶的信息通道是「亮度渐变」:单色线性阶的浅→深天然携带亮度序,色盲读者与灰度打印都能读;多色阶(YlGnBu)同时动用色相,色盲下仍主要靠亮度序兜底;Crameri 色图以「Fair to the data / Readable by everyone」为设计目标(官方页已核)。热力格相邻色块对背景保持 3:1 非文本对比(WCAG 2.1 SC 1.4.11);图例必须随档数同步,超出 7 档后建议改注关键断点值。

浏览器支持

demo 为手绘 SVG + 内联十六进制色,无任何新 CSS/JS 特性依赖,所有浏览器可用;色阶值本身是设计资产,与浏览器无关。

兼容回退

无浏览器兼容问题;真正的回退是「档数来源」:demo 在官方 5 个锚点色之间做 sRGB 线性插值只为演示 3-9 任意档数,生产必须改取 ColorBrewer 官方整档 JSON 或 d3-scale-chromatic(均匀 B-spline 插值)——两者对中间档的取值与线性插值不同。灰度打印时单色线性阶天然安全,多色阶需先过灰度模拟。

来源 4

起源方法学源头是 Cynthia Brewer 的 ColorBrewer(colorbrewer2.org,© Brewer/Harrower/Penn State;35 组 scheme 的官方 JSON 已直下核验)与 Fabio Crameri 的 Scientific Colour Maps(v9.0.0,DOI 10.5281/zenodo.1243862);连续插值生态由 d3-scale-chromatic 承接(基于 ColorBrewer 的均匀 B-spline 插值)。

  1. 条目 标度函数

    搭配:色阶是映射管线的末段:t 从标度层出来后按档取色——标度条目结尾把本条目列为姊妹条目(t→色带那段)。

  2. 条目 分类色板

    对比:都叫「色板」易混:分类色板只解决「哪个系列用哪个颜色」、整表按官方顺序取用;有序值域的分档上色是序数色阶的领地——两页对读才分得清。

  3. 条目 色盲安全配色

    反向自「色盲安全配色」的精选:搭配关系,原句「模拟核查过了关,选阶再进一步:单色亮度阶只动亮度、色盲灰度天然安全——序数色阶条目把 Blues 列为默认档。」
