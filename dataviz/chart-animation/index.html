图表动效 Chart Animation

Entrance Animation · Growth Animation · Chart.js animation

入场三式——生长(从零基线长出)/ 淡入 / 扫描(clip-path 左→右揭示):时长 1000ms、easeOutQuart(Chart.js 官方默认),动画只落在数据层,轴与网格静止;prefers-reduced-motion 时直出终态。

代码拆解

结构与 DOM

图表动效的第一定律是分层:动画只落在数据层(柱/线/点),参考层(轴、网格、刻度)全程静止——「刻度在动」会被读者误读为「数据在动」(与坐标轴与网格条目同一纪律)。

<svg viewBox="0 0 600 340">
  <!-- 参考层:网格/轴/刻度,静止(透明度 0.09 = Grafana 公式) -->
  <g class="grid">…</g><g class="axes">…</g>
  <!-- 数据层:唯一被动画的层 -->
  <g class="bars"><!-- 关键帧只写 from,基态 = 终态 -->
    <rect height="…" … />
  </g>
</svg>

关键点:

  • 入场三式的分工:生长(数据层从零基线 scaleY 长出,Chart.js 默认入场即「从原点起动画」的生长语义)、淡入(整组 opacity,最克制)、扫描(clip-path inset 从右往左收,数据左→右揭示,适合「随时间推进」的叙事);
  • 关键帧只写 from:元素基态就是终态,动画被禁用/不支持时直出终态,天然零成本回退;
  • 时长与缓动走 CSS 变量(--ca-dur / --ca-ease),由参数面板实时驱动,重播通过重挂数据层触发;
  • 适用边界(Wikipedia 条目载的研究结论):动画表达趋势与运动;两个时间点之间的精确对比,交给小倍数阵列而不是播一遍扫描。

样式与参数

三个参数,默认值全部指向 Chart.js 官方动画文档(补研 12§13 抓取已核):

参数类型默认值出处
entranceJS 型growChart.js 默认入场从原点起动画(生长语义);fade/sweep 为 demo 的对照档
durationCSS 变量 --ca-dur1000msChart.js 全局 animation.duration 默认 1000(官方 docs 逐字)
easingCSS 变量 --ca-easeeaseOutQuartChart.js easing: 'easeOutQuart'(官方逐字);cubic-bezier(0.165, 0.84, 0.44, 1) 为社区通行的近似映射——系数官方未发布,标注「社区常见值,未证实」

Chart.js 配套默认值(同一文档已核):缓动共 30 种;配置三级覆盖——全局 defaults → 类型 datasets[type] → 实例 options;过渡模式 active/hide/reset/resize/show,其中 hover(active)400ms、resize 0;options.animation = false 整体禁用;onProgress/onComplete 仅在主 animation 配置下生效。

.bars {
  transform-box: fill-box;
  transform-origin: 50% 100%;
  animation: ca-grow var(--ca-dur, 1000ms) var(--ca-ease, ease-out) both;
}
@keyframes ca-grow { from { transform: scaleY(0); } }
@keyframes ca-fade { from { opacity: 0; } }
@keyframes ca-sweep { from { clip-path: inset(-8% 100% -8% 0); } }
@media (prefers-reduced-motion: reduce) { .bars { animation: none; } } /* 直出终态 */

动效与交互

  • 入场一次,重播受控:demo 的「重播」按钮通过重挂数据层重触发 CSS 动画;仪表盘真实场景里入场只在首屏发生一次,不做循环;
  • 完成播报:入场完成经 aria-live="polite" 播报(补研 12§13 片段的 onComplete → ariaLive("图表加载完成") 模式),读屏用户不看动画也知道数据就绪;
  • reduce 直出终态:prefers-reduced-motion: reduce 下 animation: none——因为关键帧只写 from,元素立即呈现终态(Baseline 自 2020-01,MDN 已核);
  • 结构性变化不动画:resize 过渡 Chart.js 官方写死 duration 0——布局重排即时到位,动效预算留给数据;
  • 时长档位参考:hover 更新 400ms、入场 1000ms、resize 0;ECharts 的 tooltip 过渡 transitionDuration: 0.4 秒(源码逐字核验,见图例与提示条目)也是同一量级纪律。

真实产品案例

  • Chart.js(官方动画文档,补研 12§13 已核):默认 duration: 1000 + easing: 'easeOutQuart',30 种缓动可选;三级配置覆盖(全局→类型→实例);过渡模式 active 400ms、resize 0;animation: false 一键禁用——「入场 1 秒、hover 0.4 秒、重排 0 秒」的完整默认值体系。
  • Wikipedia「Small multiple」条目(12§13 已核):地图场景研究结论——动画胜在呈现趋势与运动,小倍数胜在时间点之间的对比;扫描式入场讲「进程」,并排面板讲「对比」,不要互换。
  • ECharts v5.5.1(TooltipModel.ts 逐字核验,调研 08§6):tooltip 的 transitionDuration: 0.4 / hideDelay: 100 / showDelay: 0——图表动效不只是入场,交互层浮动的时长档位同样是库默认值纪律的一部分。

参数敏感度

参数调大会…调小会…
entrancesweep 最具叙事感但传达「进程」,用于对比场景会诱导误读;grow 最能表达「量级从无到有」fade 最克制,减少动效用户与弱设备上最稳;三式在 reduce 下都直出终态
duration超过 2000ms 读者开始等动画而不是读数据;仪表盘高频刷新场景会叠影低于 300ms 接近直出,入场引导意义减弱;0ms 即直出终态(options.animation=false 等效)
easing过冲型曲线让柱子越过真实值再回落——一瞬间呈现假数据,数据图禁用线性(linear)显得机械;easeOutQuart 类「快出缓收」是数据入场的通行选择

经验区间:入场 800–1200ms(Chart.js 1000 居中)、hover 400ms、resize 0;缓动收敛不过冲;轴/网格永远静止;prefers-reduced-motion 直出终态是不可协商项。

适用场景 4
  • 仪表盘/报告首屏的入场引导——数据层一次性生长或淡入,给读者「数据到了」的完成信号
  • 时间序列的扫描式入场(左→右揭示)——强调「随时间推进」的叙事感
  • 数据更新过渡(hover 高亮 400ms 一档)——Chart.js active 过渡的默认时长档
  • onComplete 回调接 aria-live 播报「图表加载完成」——动效与读屏反馈同步
何时不要用 4
  • 轴/网格/刻度参与动画——「刻度在动」会被误读为「数据在动」(坐标轴条目同一纪律)
  • 对比两时点的场景用扫描动画代替并排面板——地图研究结论:时间点对比小倍数胜过动画
  • resize/布局重排做过渡——Chart.js 官方把 resize 过渡写死 duration 0,结构性变化即时到位
  • 过冲型 spring 曲线用于数据层——数值先越过真实值再回落,一瞬间呈现假数据
无障碍

prefers-reduced-motion: reduce 时跳过入场直接渲染终态(demo 用 @media 关闭 animation;终态=基态,零 JS 判断也能成立);入场完成用 aria-live="polite" 播报(补研 12§13 片段的 onComplete → ariaLive 模式),读屏用户不依赖视觉动画也能知道数据就绪;动效不是传达数据的唯一通道——数值仍有轴刻度、<title> 与表格兜底。

浏览器支持

CSS keyframes / transform / opacity / clip-path 均为广泛可用特性;prefers-reduced-motion Baseline 自 2020-01 广泛可用(MDN,补研 12§5 已核);clip-path 各浏览器版本矩阵本轮未逐项核验,demo 对不支持者自然回退为整块出现。

兼容回退

三式动画只定义 from 关键帧,基态即终态:CSS animation 不支持/被禁用时元素直接呈现终态,天然零成本回退;clip-path 不支持时 sweep 退化为整块出现——关键场景可改 fade 兜底;时长 0 或 options.animation=false 是显式的「直出终态」开关。

来源 3

起源数值出处:Chart.js 官方动画文档(补研 12§13 抓取已核)——全局 animation.duration 默认 1000、easing 默认 'easeOutQuart'(30 种缓动可选)、hover 过渡 400ms、resize 过渡 0、options.animation=false 整体禁用、onProgress/onComplete 仅在主 animation 配置生效;「地图场景动画胜趋势/运动、小倍数胜时间点对比」的适用边界取自 Wikipedia Small multiple 条目(12§13 已核)。
