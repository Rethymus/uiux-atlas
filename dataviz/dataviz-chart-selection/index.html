图表选型 Chart Selection

Chart Chooser · Visual Vocabulary · 图表类型选择 · 选型决策树

先判断数据关系再挑图表:比较→柱状、趋势→折线、分布→直方图、构成→堆叠柱;柱/面积必须零基线,折线可例外。

参数
动效▾
relationcompare

JS 型参数(demo 订阅后重绘 SVG)。四种数据关系各配一种基线图表:比较→柱状图(长度编码最利于等宽比较)、趋势→折线图(时间演化)、分布→直方图(数值分箱计数)、构成→堆叠柱(部分到整体)。关系选错(时间趋势用饼图、离散类别用折线)比样式瑕疵致命得多——选型是图表可读性的第一决策。

baselinezero

JS 型参数(demo 订阅后重算 y 轴域)。zero=轴从 0 起;truncated=把 y 轴下限抬到数据附近放大差异。FT 判据:柱 "Must always start at 0 on the axis",调研概括为「柱/面积必须零基线」;折线图可不从零(FT 引 ONS《Does the axis have to start at zero?》两篇文章),Lollipop 不强制。柱系截断时 demo 给出 Carbon danger(#da1e28,官网已核)警示徽标——demo 数据 49 vs 78 零基线差 1.6 倍,截断到 40 起即画成 4.2 倍。

labelsdirect

JS 型参数(demo 订阅后切换标注方式)。direct=数值/系列名直接标在图形上(柱顶、线端、段内);legend=右侧对色图例。jfly CUD 原文:"For graphs and line drawings, label elements of the graph on the graph itself rather than making a separate color-coded key, since matching same colors in distant places is extremely difficult." 直标是首选;放不下时(如堆叠段高 <14px)自动省略并退回图例。

代码拆解

结构与 DOM

选型发生在画 SVG 之前:先判断数据关系,再决定图形。demo 用一个 <svg> 承载四种基线图表,DOM 只随关系切换 <rect> / <path> / <text> 的组合:

<div class="stage">
  <svg viewBox="0 0 640 340" role="img" aria-label="图表选型演示:按数据关系切换基线图表">
    <!-- 比较:一排 <rect>;趋势:一条 <path> + 数据点;
         分布:贴轴的 <rect> 直方;构成:每季度一个四段堆叠 <rect> -->
  </svg>
  <div class="map">   <!-- 四关系→四图表的映射条 -->
  <div class="readout" role="status"><!-- 基线判据 / 标注方式 徽标 --></div>
</div>

关键点:

  • 「比较 / 趋势 / 分布 / 构成」四关系分法是图表选型指南的社区通行分类(FT Visual Vocabulary 海报按数据关系组织图表族,本调研未转录其完整族谱,分类学不标注为 FT 官方);
  • 关系→图表的默认映射:比较→柱状(等宽柱的长度编码最利于比较)、趋势→折线(时间演化)、分布→直方图(数值分箱计数)、构成→堆叠柱(部分到整体);
  • 零基线判据(FT 仓库 README 原文,调研 08§5.4):Column “Must always start at 0 on the axis”,调研概括为「柱/面积必须零基线」;折线图可不从零(FT 引 ONS《Does the axis have to start at zero?》),Lollipop 不强制。

样式与参数

三个参数全部为 JS 型,demo 订阅 store 后重绘,无 CSS 变量:

/* demo 只用 fill/stroke + 1px 轴线,不引图表库 */
.cs-bar { stroke: var(--border-strong); stroke-width: 1; }
/* 截断警示徽标用 Carbon danger #da1e28(官网已核,调研 08§1.3) */
.cs-chip[data-warn="true"] { color: #da1e28; border-color: #da1e28; }
参数默认数值出处
relationcompare四关系映射为社区通行分类;每档配一种基线图表(柱状/折线/直方/堆叠)
baselinezeroFT 判据:柱系零基线、折线例外(README 已核);truncated 档在柱系上触发 #da1e28 警示
labelsdirectjfly CUD 原文「图上直标优于远处对色图例」(调研 08§1.1);段高 <14px 时直标自动省略退回图例

demo 数据全部确定性:比较 4 类目(64/49/78/57)、趋势 12 月、分布 8 箱(40 样本)、构成 4 季度×4 段。截断的失真可算:49 vs 78 零基线差 1.6 倍,截断到 40 起即画成 4.2 倍——这就是「柱系必须零基线」的几何原因。

动效与交互

  • 参数切换即时重绘,无过渡动画——数据映射变化不应伪装成颜色渐变(与 dataviz-categorical-palette 同一准则);
  • 基线警示徽标是唯一的状态色变化(border/color 0.2s 过渡),prefers-reduced-motion: reduce 下关闭;
  • 直标/图例切换只增删 <text> 与图例组,不动图形本体;
  • 悬停读数用原生 <title>(可悬停、随指针移开消失);完整的 WCAG 1.4.13 三件套见 dataviz-tooltip-legend。

真实产品案例

  • FT Visual Vocabulary:chart-doctor 仓库与英/日/繁中/简中四语海报,按数据关系组织图表族;README 判据 Column “Must always start at 0 on the axis” 即本条目零基线参数的出处。README 尾部声明 FT 版权所有、转载需 syndication 授权——引用原则而非翻印海报(README 已核,调研 08§5.4)。
  • ONS 零基线之辩:FT 仓库引用英国国家统计局《Does the axis have to start at zero?》两篇文章,讨论折线图轴域何时可不从零——「柱零基线、折线可例外」这对判据的权威出处(调研 08§5.4 转载其引用关系,原文未直接核)。
  • Cleveland & McGill《Graphical Perception》:FT 海报标注的方法论引用,编码精度排序的实验源头——「为什么柱比饼好比」的文献起点;具体排序见原论文,本调研未转录。

参数敏感度

参数调大会…调小会…
relation换到构成档:堆叠段只靠色相区分、中段基线漂移,跨段比较最易误读比较档是等宽柱贴零基线的最稳形态,长度编码精度最高
baselinetruncated 在柱系上是红线级错误:demo 数据差距从 1.6 倍放大成 4.2 倍;折线档则合法zero 是柱系唯一安全档;分布档截断还会把第一箱(计数值 2)直接削没
labelslegend 腾出图形区,但读者要远处对色(jfly:极其困难);适合直标放不下的密集图direct 让数值贴在图形上,读数零回指;密集小段会自动降级回图例

经验法则:先定关系再调样式;柱系永远零基线;直标优先、图例兜底;趋势图截断轴域时必须标注轴范围。

适用场景 4
  • 拿到新数据集先过四关系判断再定图表——比较/趋势/分布/构成,一步定盘
  • 评审图表时用零基线判据快速定位误导:柱系非零即警
  • 折线图合法截断轴域以放大波动——记得标注轴范围,避免读者误读幅度
  • 高密度仪表盘优先直标省掉图例占位,悬停读数交给 tooltip(见 dataviz-tooltip-legend)
何时不要用 4
  • 用饼图讲时间趋势、用折线连离散类别——关系错配是图表误导的第一来源
  • 柱状/直方/堆叠/面积图非零截断(FT 红线);确需截断请改折线或点图
  • 堆叠柱跨段比较中段数量——段基线随堆叠漂移,只有第一段贴零基线可精读;跨系列比较改分组柱
  • 直标放得下时仍用远处对色图例——jfly 原文:远处颜色匹配极其困难
无障碍

图表元素对相邻颜色保持 ≥3:1 非文本对比(WCAG 2.1 SC 1.4.11,调研 06§17);直标减少读者远处对色的认知负担(jfly CUD);SVG 需 role="img" 与概述图表目的的 aria-label,逐点数值给原生 <title>,完整悬停三件套(Esc 可关/可悬停/常驻)见 dataviz-tooltip-legend;颜色只作冗余通道,关键区分靠文字与位置兜底(CUD 原则 2)。

浏览器支持

demo 为手绘 SVG + React,不依赖新 CSS/JS 特性,所有现代浏览器可用;y 轴域与柱高全部由 JS 计算,无 layout 引擎依赖。

兼容回退

无浏览器兼容回退;真正的「回退」是选型纠偏:发现关系判断错误(时间趋势被画成构成、分布被画成折线)时,先回到四关系判断再换图表类型,而不是继续调样式。空间放不下直标时退回图例,并保持 swatch 与系列一一对应。SVG 文字用 <text> 而非位图,保证缩放、选中与读屏可达。
