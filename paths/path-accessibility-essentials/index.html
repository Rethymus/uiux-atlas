无障碍必修 Accessibility Essentials

5 步

学完你能:对任一页面跑完 WAI Easy Checks 全项;保证纯键盘可完成核心任务且焦点永远可见;在强制增强对比下保持文字/描边/焦点环可读;把两条偏好落到表单控件(标签/错误/描述);并给图表类复杂图像配文本替代与数据表,让色彩不单独承载含义。

目标人群 要把可访问性从「上线前检查表」变成「日常手艺」的团队:WCAG 清单、键盘导航、对比度公式逐条落地。

路径步骤

  1. 01

    WCAG 快速清单 ENTRY

    为什么现在学 先拿官方「全图 + 自检法」:WAI Easy Checks 本就是官方新手顺序,对任一条目页跑完全项再往下走。

  2. 02

    键盘导航全景 ENTRY

    为什么现在学 第一硬依赖:键盘先行是行为层无障碍的地基——纯键盘完成核心任务,焦点永远可见。

  3. 03

    对比度偏好适配 ENTRY

    为什么现在学 从行为偏好进入呈现偏好:强制增强对比是呈现层的考官,文字/描边/焦点环都要经得起它。

  4. 04

    输入框 ENTRY

    为什么现在学 键盘与对比两条判据的最常交汇处是表单:M3 把每个组件页第四节固定为 accessibility——学完偏好立即在组件上收口。

  5. 05

    图表无障碍 ENTRY

    为什么现在学 收官用最难的媒体类型(图表)综合运用前四步:复杂图像要有文本替代与数据表,色彩不单独承载含义。

完成自测

逐条勾选自测判据;进度保存在本浏览器(localStorage),不同步到服务器。
