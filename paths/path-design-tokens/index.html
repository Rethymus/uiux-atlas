设计令牌工程 Design Tokens

6 步

学完你能:定义 primitive/semantic/component 三层令牌清单;用「一套词表、多份映射」支撑多主题(切映射零组件改动);给主题切换挂过渡并带 reduced-motion 闸门;用 clamp 把字号与间距做成随视口流动的响应式令牌;最后从 brand 源色自动派生全部 roles——换源色 + 切主题 + 缩窗口三者叠加无回归。

目标人群 要把设计语言落成代码资产的前端/设计工程师:三层 token、多主题映射与 registry 工程化。

路径步骤

  1. 01

    语义色三层架构 ENTRY

    为什么现在学 词表先行:平台无关的令牌方法学是一切后续的地基——M3 把 design-tokens 置于 Foundations 尾段、customization 之前,「先学令牌再谈换肤」。

  2. 02

    多主题 Token ENTRY

    为什么现在学 词表之上学「一套词表、多份映射」:M3/Semi/Arco 三家官方主题机制共同给出「令牌 → 多主题 → 定制」的官方序,三主题只切映射文件、零组件改动。

  3. 03

    主题切换过渡 ENTRY

    为什么现在学 主题有了之后才有「切换」:View Transitions 承载换肤过渡,且必须挂 prefers-reduced-motion 闸门降级为直切。

  4. 04

    流式字阶 ENTRY

    为什么现在学 从「静态映射」升级到「响应式 token 值」:clamp 让字号随视口流动,M3 type-scale tokens 提供档位参照。

  5. 05

    流式间距 ENTRY

    为什么现在学 与上一步同一工具(clamp/calc)换到间距轴——刻意相邻形成迁移练习,间距随视口连续缩放、断点无跳变。

  6. 06

    品牌色系统 ENTRY

    为什么现在学 收束到完整产线:源色 → 调色板 → roles 自动派生是 M3 dynamic color 官方链路,换源色后全部 roles 同步再生、组件零改。
