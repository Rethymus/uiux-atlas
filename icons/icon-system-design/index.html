图标系统设计 Icon System Design

icon grid audit · 图标一致性 · keyline shapes · 键程 · 图标命名规范 · icon audit

把「感觉不齐」变成机器可判的审计:24×24 栅格 + Material 键程(方 18×18/圆 Ø20)+ 1px 安全区 + 统一线宽 + kebab-case 命名,六枚迷你图标在网格/键程/安全区叠加层下跑一致性审计,违规项逐条标红。

系统标准线宽(CSS 变量,SVG 用户单位)。默认 2px = Lucide/Feather 源码定值(defaultAttributes stroke-width: 2)与 Material 2dp 基准(07 §1.1/§2);Heroicons 24 outline 是 1.5px 例外(实测源文件,07 §1.3)。线宽是 SVG 用户单位:显示放大到 72px 线宽仍按 24 网格的比例走——要更粗/更细应换权重体系(wght 100–700 轴),不是缩放图标(07 §1.5)。审计把 arrow-right 的硬编码 1.5 与本参数对照判违规。

代码拆解

结构与 DOM

一套迷你图标系统 = 共享几何契约的 SVG 文件族:每个图标都是 24×24 viewBox 的独立文档,但栅格、线宽、线帽、命名全部受同一份规范约束:

<!-- 每枚图标一个文件;根元素写死公共契约(Lucide defaultAttributes 同构) -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M4 11L12 4L20 11"/>  <!-- X/Y 全整数;内容不越修剪区 -->
  <path d="M6 10V20H18V10"/>
</svg>

系统的四层契约(由外到内):

  1. 命名层:kebab-case、全小写、无重复——命名是最先崩塌的防线,混入 search_icon/arrowRIGHT 后按名检索与 tree-shaking 双双失灵;
  2. 栅格层:24×24 网格,X/Y 坐标必须整数(Material 官方规则,07 §2);键程 shapes 定基准——方 18×18、圆 Ø20、竖 16×20/横 20×16,「圆比方大 2dp」是官方光学铁律(07 §2/§3.1);
  3. 安全区层:live area 20×20(四周 2dp padding),修剪区 = 完整 24dp 且内容绝不可出;Lucide 补充:描边距画布边 ≥1px、相邻元素间隙 ≥2px(07 §2/§3.2);
  4. 线宽层:系统标准一条(默认 2px = Lucide/Feather 源码定值),Heroicons 的 1.5px 是独立体系不可混入;连续变粗细走 Material Symbols 的 wght 100–700 轴,绝不缩放 SVG 硬改(07 §1)。

样式与参数

四个参数把审计台搭起来:一个 CSS 变量 + 三个 JS 开关:

/* 系统标准线宽:SVG 用户单位,写在一个地方,全部图标继承 */
.isd-tile svg { stroke-width: var(--isd-stroke, 2px); }
  • overlay 叠加层三种几何全部由调研数值驱动:键程档画出方 18×18/圆 Ø20/两块长方形;栅格档每 2 单位一条线,专查「整数坐标」;安全区档绿框 = live area 20×20、橙框 = 1px 安全区边界;
  • audit 注入三类真实缺陷:search 手柄端点 (19.5, 19.5)(整数坐标规则)、home 屋顶 y=1(修剪区红线)、arrow-right 硬编码 1.5px(线宽一致性)——违规元素标红、tile 亮红环、审计表给判定;
  • naming 注入 Home / search_icon / arrowRIGHT 三个命名违例,违例名标红;
  • 审计表四行(命名/栅格/线宽/安全区)每行都写明标准与出处,判定机器可复核。

数值出处:2px 线宽(Lucide defaultAttributes.ts 源码 + Material 2dp)、键程四值与 2dp padding/整数坐标(m2.material.io system-icons)、1px 安全区与 2px 元素间距(Lucide 贡献规范)、wght 100–700 轴(Material Symbols README)——全部 07 章一手。

动效与交互

  • overlay 切换(JS 型参数):六枚 tile 的 SVG 内叠加层整体换装,键程 shapes ↔ 像素栅格 ↔ 安全区;0.2s 边框过渡,prefers-reduced-motion: reduce 下直切;
  • audit 切换:违规注入瞬间可见——红环、红路径、审计表三处同步翻红;合规档一键恢复;
  • stroke 拖动(CSS 变量):全部图标(含 24px 原生档)同步变粗变细,展示「线宽是用户单位、显示放大比例不变」;调到 1.5 时 arrow-right 的违规判定恰好消失(巧合对齐仍是坏味道,表内注明);
  • 24px 原生档:同一组图标以原生尺寸并排,对照大图验证缩小后仍可辨(模糊法验收的静态版);
  • 无位移动画;所有反馈都是状态切换而非运动。

真实产品案例

  • Material 官方栅格模板:24dp 修剪区/20dp live area/键程四形状的数值出处,官方随页分发 AI 源文件模板(Apache 2.0),自建系统可直接对表(07 §2);
  • Lucide 贡献规范:把「1px 安全区、2px 元素间距、2.41px 斜角半径、模糊法验收、光学偏心」写成贡献者必须过的检查单——开源图标集用机器可判规则管理社区 PR 的真实范本(07 §3.2);
  • Heroicons 三档网格:24/20/16 三个独立重绘的 viewBox(实测源文件)而非缩放——密集布局「换档重绘」而非「硬缩」的行业先例(07 §1.3)。

参数敏感度

参数调大会…调小会…
stroke3px 视觉变重,模糊法灰度加深;仍保持用户单位比例1px 触及 WCAG 1.4.11 的「避免特别细线条」警戒(抗锯齿稀释后更淡,07 §3.3);1.5 时 arrow-right 巧合过关
overlaykeylines 档一眼看出键程偏差;safe 档同时暴露 live area 与 1px 边界none 档看成品观感——审计靠叠加层,验收靠成品
auditviolations 档三类缺陷(坐标/修剪区/线宽)同时点亮,表内逐条给出处pass 档六枚全绿——但只有跑过 violations 档,才知道审计在查什么
namingmixed 档三个违例名标红:大小写/分隔符混用让检索与 tree-shaking 双失灵kebab 档全绿;命名规范没有「调大调小」,只有一致或崩溃

锚点:命名先于图形崩塌;坐标必须整数;内容不出修剪区;线宽一套一个数;更粗更细换权重体系不缩放。

适用场景 4
  • 自建图标集的设计验收:逐枚套键程/安全区叠加层,量「圆比方大 2dp」与 18×18 键程(07 §2/§3.1)
  • 团队规范落地:把 1px 安全区、2px 元素间距、整数坐标、统一线宽写成可机器判的检查单(Lucide 规范的验收法,07 §3.2)
  • 视觉重量仲裁:与 circle/square 并排整体模糊后比灰度——「感觉太重/太轻」变成可复核流程(Lucide 模糊验收法,07 §3.2)
  • 多尺寸体系选型:24 常规档、20 密集档(Material 桌面密集布局),16px 级独立重绘而非缩放(Heroicons micro/mini 先例,07 §1.3/§2)
何时不要用 4
  • 靠缩放 SVG 改线宽——线宽是 24 网格的用户单位,连续变粗细应走 wght 轴或换权重文件(07 §1.5)
  • 把不同体系的线宽惯例混进一套(2px 系混入 1.5px 的 Heroicons 图标)——审计表第一条就会爆(07 §1.3)
  • 让内容越过修剪区或把关键细节塞进 2dp padding——padding 只允许「加重量」的延伸,不是内容区(07 §2)
  • 用几何居中硬套不对称图形——Lucide 明文允许小幅光学偏心,几何居中不等于看着居中(07 §3.2)
无障碍

一致性即无障碍的前置:①细线在低分屏/小尺寸下会被抗锯齿稀释,WCAG 1.4.11 理解文档明确建议避免特别细的线条(07 §3.3)——系统标准线宽 ≥2px 是可读性底线;②图标必须落在键程内才有足够的识别尺寸,密集布局换 20dp 档而非硬缩;③命名一致直接服务检索与维护,间接服务替代文本的准确性(名字对了,写 aria-label 的人才找得到「动作」而不是「形状」);④模糊法顺带筛掉小尺寸下糊成一团的过度细节,保住低视力用户的可辨性(Lucide 密度控制,07 §3.2)。

浏览器支持

纯 SVG + CSS 变量渲染,全绿;键程/安全区叠加层是演示自绘几何,不依赖任何新特性。stroke-width 作为继承表示属性写在 svg 根上,所有浏览器一致。 · widely available

兼容回退

无需回退:栅格审计本质是几何约定,不依赖运行时特性。离线/无 CSS 变量环境下 stroke 退回 2px 写死值,审计规则本身(整数坐标/安全区/命名)仍然成立。

来源 3

起源数值主干两源:①Material 官方 24px 栅格(m2.material.io system-icons,07 §2):展示 24×24 dp,live area 20×20(四周 2dp padding),修剪区=完整 24dp 且内容绝不可出;键程:方形 18×18、圆形直径 20、竖/横长方形 16×20/20×16;X/Y 坐标必须整数(禁止小数);圆角默认 2dp、内部转角必须直角。②Lucide 贡献规范(design-principles.md/specification.md 一手,07 §3.2):描边距画布边 ≥1px、相邻元素间隙 ≥2px、模糊法验收视觉重量、不对称图形允许光学偏心;线宽哲学:静态系锚定 2px(Lucide/Feather 源码),Heroicons 例外 1.5px,连续变粗细走 Material Symbols 的 wght 100–700 轴,绝不缩放 SVG 硬改线宽(07 §1)。
