代码拆解

结构与 DOM

选集不是换文件名,而是换一套交付形态与风格契约。六套的实际接入形态:

<!-- SVG 文件/内联路线(Lucide / Feather / Heroicons / Phosphor core) -->
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <path d="…" />
</svg>

<!-- 框架组件包路线:@lucide/react、@heroicons/react(按路径摇树) -->
<House size={24} strokeWidth={2} aria-hidden="true" />

<!-- 变量字体路线(仅 Material Symbols):连字写词不写码点 -->
<span class="material-symbols-outlined" aria-hidden="true">home</span>

样式与参数

两个 JS 型参数驱动对照视图;demo 的图形为自绘示意(非官方库文件拷贝),风格差异落在四个可核查数值上:

// line 系:stroke-width 是每套的身份标识
Lucide/Feather → strokeWidth 2(Lucide defaultAttributes 源码定值)
Heroicons      → strokeWidth 1.5(仓库真实文件实测;README 示例仍写 2,过期文案)
Material Symbols → wght 轴 100–700(默认 400),不靠改 SVG 线宽

// solid 系:描边烘焙进填充轮廓
Phosphor  → viewBox="0 0 256 256"、fill="currentColor"(六权重实测)
经典 Material Icons → 24 网格填充路径,五样式停更

选型三件事(07 §0 核心叙事):

  1. 网格:24 是共同祖先(Lucide/Feather/Heroicons/Material 同规格);Phosphor 256 大网格是另一极;
  2. 线宽哲学:2px 锚定(Lucide/Feather)vs 1.5px 例外(Heroicons)vs 变轴(Material wght)——「绝不缩放 SVG 硬改线宽」;
  3. 许可:ISC(商业/个人免费,Lucide README 原文)、MIT ×3、Apache-2.0 ×2,全部允许商用;两处计数不一致如实并录:Lucide 官网 “1600+” vs 仓库简介 “2000+”。

动效与交互

选型对照是静态视图,demo 交互只在切换上:

  • set 切换:主预览与六迷你卡同步;迷你卡可点击(经 store 双向同步参数面板);
  • glyph 切换:同一语义跨六套重绘,线宽与填充差异一眼可辨;
  • 无运动动效,prefers-reduced-motion 无需降级;
  • 维护性提示:Feather 久未发版、经典 Material Icons 停更——「活跃度」本身就是选型动效,清单见 avoid。

真实产品案例

  • lucide 全家桶:lucide + lucide-react/vue/svelte/solid/preact/react-native/angular/astro/static 九框架包(README Packages 表);把动画留给宿主不在 SVG 内嵌 SMIL(07 §1.1/§6.3);
  • @heroicons/react 摇树导入:按 @heroicons/react/24/outline 路径引,官方不接受新图标 PR——依赖它做扩展要选别的集(07 §1.3);
  • Material Symbols 子集化:Google Fonts 服务按 icon_names 子集(如 home,palette,settings)出 1.7KB 字体、加轴组合 2.6KB,且必须 &display=block 防 FOUC——大集上首屏的唯一正道(07 §1.5)。

参数敏感度

参数调大会…调小会…
set换到 Phosphor/Symbols 获得权重弹性(Fill/Duotone/wght 轴),代价是交付形态变化(填充路径/变量字体)与子集化负担停留在 Lucide/Feather 的 2px 描边定值——能力面最窄但成本最低,生态包最全
glyph换图形不改任何风格参数——这正是「集」的价值:风格契约覆盖全库单枚图形跨集硬凑(手改线宽/填充)会同时破坏三套哲学,不如整集迁移

锚点:先定网格(24 还是 256),再定线宽哲学(定值/例外/变轴),最后核许可与维护活跃度;README 示例值一律回仓库文件实测核对。

适用场景 3
  • 新项目选型:24 网格 + 2px 描边 + currentColor 的三重默认(Lucide/Feather)是最低成本起跑线(07 §1.1/§1.2)
  • 需要填充/双层权重的场景选 Phosphor(Fill/Duotone 唯二玩家)或 Material Symbols FILL 轴(07 §1.4/§1.5)
  • Tailwind 生态/React-Vue 一等公民选 Heroicons(按路径摇树导入,07 §1.3)
何时不要用 3
  • 同页混用多集图标——网格同源但线宽哲学不同(2px vs 1.5px vs 烘焙填充),重量失衡肉眼可见(07 §0)
  • 新项目采用已停更的集(经典 Material Icons 五样式 2022 停更;Feather 久未发版)而不评估迁移(07 §1.2/§1.5)
  • 直接照抄 README 示例值(Heroicons 示例 stroke-width=2 已过期,实测 1.5)——数值以仓库文件为准(07 §1.3)
无障碍

选集不改无障碍义务:线宽受 WCAG 1.4.11 提醒约束(过细线条渲染更淡,07 §3.3);Lucide 官网 Guide 设 Accessibility 章节;Material 侧图标状态交给 FILL 轴与色彩系统(07 §4.3)。任何集的装饰实例都该 aria-hidden、语义实例靠可访问名(见 icon-aria-accessible)。

浏览器支持

六套的 SVG 交付形态(内联/组件包/雪碧图)全主流浏览器可用;Material Symbols 走变量字体路线,依赖 font-variation-settings 支持(现代浏览器均可用),且官方要求 &display=block 防 FOUC、子集化(icon_names 1.7KB)控制体积(07 §1.5)。npm 包生态:lucide 全家桶 9 框架、@heroicons/react|vue、phosphor 全平台(07 §1)。 · widely available

兼容回退

选集回退按交付形态分层:SVG 组件包无回退需求;变量字体路线(仅 Material Symbols)加载失败时退回静态 wght 400 实例;雪碧图跨域被拒时内联。选型层面:社区停止维护的集(经典 Material Icons 自 2022 停更、Feather 久未发版)应评估迁移而非新项目采用(07 §1.2/§1.5)。

来源 6

起源六套全部经官方仓库 README 与真实 SVG 源文件核验(out/design-study/07-icons.md §1):Lucide(ISC,defaultAttributes 源码定值 24/2px/round/currentColor)、Feather(MIT,24×24 网格 2px,系出同门)、Heroicons(MIT,24/20/16 三档,24/outline 实测 stroke-width=1.5)、Phosphor(MIT,六权重 256×256 viewBox 实测、fill 路径交付)、Material Symbols(Apache-2.0,opsz 默认 24、wght 100–700 变轴)、经典 Material Icons(同仓库 Apache-2.0,五样式 2022 年起停止更新)。Heroicons README 示例仍写 stroke-width=2 系 v1 旧文案,以文件为准(07 §1.3);Phosphor 权重线宽像素值官方未发布(未证实,07 §7)。
