图标动效 Icon Micro-Motion

图标微动效 · 描边绘制 · hover 动效 · Icon Motion · stroke-dashoffset

hover 触发的三招路径微动效:stroke-dashoffset 描边绘制、≤90° 旋转、fill-opacity 填充点亮——150–200ms + standard 缓动是 M3 官方区间,prefers-reduced-motion 直切终态。

Material 3 ★★★
实例演示 官方默认
参数
动效▾
effectdash

当前武装的动效技法(JS 型,未选中卡降为静态)。dash = pathLength=1 归一 + stroke-dashoffset 1→0 重绘(默认态全绘,hover 只重放);rotate = ≤90° 旋转——M3 惯例位移动效不进图标内部、rotate ≤90°/±1px(07 §6.2);fill = fill-opacity 0→1 点亮,是 Material FILL 轴("indicate user selection")的 SVG 等效通道(07 §6.1/§6.3:等效降级 = 描边版与实底版换 use)。

easingcubic-bezier(0.2, 0, 1, 1)

缓动曲线,CSS 变量注入(序列化为 cubic-bezier())。默认 [0.2, 0, 1, 1] = M3 easing.standard("simple, small, or utility-focused transitions",微动效首选,07 §6.2);emphasized-decelerate [0.05, 0.7, 0.1, 1] 用于进场型强调、emphasized-accelerate [0.3, 0, 0.8, 0.15] 用于退场——图标 hover 用 standard 即可。每次轴过渡都是字形重排,预算保持在 150–250ms 内(07 §6.1)。

几何▾
duration200ms
ms

动效时长(ms),CSS 变量注入。默认 200 = M3 duration.short4 官方值("Selection controls have a short duration of 200ms with Standard easing");150 = short3;hover 微动效惯例 150–200ms(07 §6.2)。>250ms 进入 medium 档(跨区转场),hover 场景会显得迟钝;<100ms 趋近瞬切,失去「回应感」。

代码拆解

结构与 DOM

图标动效的三招都发生在既有 DOM 上的属性过渡,不引入新结构、不用 SMIL(组件库路线把动画留给宿主,与 tree-shaking 兼容,07 §6.3):

<!-- 描边绘制:pathLength=1 归一,常驻全绘,hover 只重放 -->
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" aria-hidden="true">
  <circle cx="12" cy="12" r="8.25" pathLength="1"/>
  <path d="M12 8.5v7M8.5 12h7" pathLength="1"/>
</svg>

<!-- 旋转:transform 过渡在 svg 根 -->
<svg class="im-rot" viewBox="0 0 24 24" aria-hidden="true">…环形箭头…</svg>

<!-- 填充点亮:stroke 常驻,fill-opacity 0→1(FILL 轴的 SVG 等效) -->
<svg class="im-fill" viewBox="0 0 24 24" aria-hidden="true">…心形…</svg>
/* M3 官方 token 经 CSS 变量注入 */
.im-scene {
  --im-duration: 200ms;                          /* duration.short4 */
  --im-easing: cubic-bezier(0.2, 0, 1, 1);       /* easing.standard */
}

/* dash:pathLength=1 + dasharray 1 → dashoffset 1→0 即「重绘」 */
.im-dash path { stroke-dasharray: 1; stroke-dashoffset: 0; }
.card:hover .im-dash path,
.card[data-play="dash"] .im-dash path {
  animation: im-draw var(--im-duration) var(--im-easing);
}
@keyframes im-draw { from { stroke-dashoffset: 1; } }

/* rotate ≤90°(动效不进图标内部) */
.im-rot { transition: transform var(--im-duration) var(--im-easing); }
.card:hover .im-rot { transform: rotate(90deg); }

/* fill:fill-opacity 0→1 —— Material FILL 轴("indicate user selection")的 SVG 等效 */
.im-fill { fill: currentColor; fill-opacity: 0; transition: fill-opacity var(--im-duration) var(--im-easing); }
.card:hover .im-fill { fill-opacity: 1; }

要点:dash 默认态必须全绘(offset 0)——图标不可默认隐藏,hover 只是重放;rotate 加在 svg 根上不扰动路径;fill 用 fill-opacity(继承属性)而非换 fill 值。

样式与参数

三个参数,两个 CSS 变量型(duration/easing)+ 一个 JS 型(effect 选中武装卡):

duration 默认 200ms  = M3 duration.short4("Selection controls have a short duration of 200ms with Standard easing")
                      150ms = short3;hover 微动效钦定区间 150–200ms(07 §6.2)
easing   默认 [0.2,0,1,1] = M3 easing.standard("simple, small, or utility-focused transitions")
                      emphasized-decelerate [0.05,0.7,0.1,1] 进场 / emphasized-accelerate [0.3,0,0.8,0.15] 退场
effect   dash | rotate | fill ——未选中卡片降为静态(opacity 0.45)

变量轴动画的注意点(Material Symbols 官方,07 §6.1):先子集化再动画——1.7KB 级别才敢上首屏;每次轴过渡都是字形重排,预算 150–250ms。SVG 路线(fill-opacity)没有字体加载负担,是轻量等效。

动效与交互

本条目即动效规范本体,三档护栏:

  1. 触达通道:hover 触发 + :focus-visible 同步触发(键盘等效)+ 点击触发(触屏无 hover);demo 三卡均为真按钮;
  2. reduced-motion 降级(MDN 一等规则):@media (prefers-reduced-motion: reduce) 下 animation/transition 全禁,hover 直切终态——状态反馈保留、运动取消;官方示例把 pulse 缩放降级为 opacity 溶解,同一精神;demo 另给「模拟 reduced-motion」开关供无系统偏好的用户验收;
  3. 等效降级路线:描边版与实底版两枚 symbol 换 <use>(07 §6.1/§6.3)——零动画成本完成填充点亮,亦无前庭风险。

真实产品案例

  • Material Symbols FILL 轴:README 原文 “It can also be manipulated for an animated fill effect, to indicate user selection”——填充点亮是被官方盖章的状态语义,不是装饰(07 §6.1);
  • M3 selection controls:官方用例 200ms + Standard easing,即本条目默认值(07 §6.2);
  • MDN prefers-reduced-motion:定义、示例与降级策略的一手出处(缩放类动画可诱发前庭障碍,官方把 pulse 降级为 opacity 溶解)(07 §6.3)。

参数敏感度

参数调大会…调小会…
effectfill 是语义最强的一招(选中态),dash 最「炫」但高频使用会疲劳;rotate 适合方向类语义(刷新/发送)三招未武装时卡片降为静态——动效本身是强调通道,全静止则 hover 反馈缺失
duration>250ms 进入 medium 转场档,hover 显迟钝且字形重排开销翻倍(07 §6.1/§6.2)低于 100ms 趋近瞬切,失去「回应感」;150–200ms 是钦定区间(07 §6.2)
easingemphasized 系曲线适合进场/退场大转场,用在图标 hover 会过戏剧化standard [0.2,0,1,1] 是微动效首选;线性曲线会让「点亮」显得机械

锚点:150–200ms + standard;rotate ≤90°;dash 常驻全绘;reduced-motion 直切终态不删反馈;先子集化再动画(字体路线)。

适用场景 3
  • 选中态图标(收藏/书签)的填充点亮——FILL 轴官方盖章的语义(07 §6.1)
  • 刷新/发送类操作的 90° 旋转确认,时长 200ms standard(07 §6.2)
  • 列表项 hover 的描边重绘提示,150ms short3
何时不要用 3
  • 高频工具栏图标加动效——高频交互应省略动效(Apple HIG;07 §6.2 上下文),hover 微动效留给低频强调
  • >250ms 的图标动效——进入 medium 转场档,hover 显迟钝且字形重排开销翻倍(07 §6.1/§6.2)
  • 无 reduced-motion 降级的填充/旋转——缩放与位移类动画可诱发前庭障碍(MDN,07 §6.3)
无障碍

prefers-reduced-motion 必须降级:MDN 定义该媒体特性探测用户「remove, reduce, or replace motion-based animations」的系统偏好,官方示例把 pulse 缩放动画降级为 opacity 溶解;图标动效降级策略 = transition/animation 禁用直切终态,状态反馈不删(07 §6.3)。demo 额外提供「模拟 reduced-motion」开关供无系统偏好的用户验收。键盘可达:hover 效果同步挂 :focus-visible;触屏无 hover,提供点击触发。

浏览器支持

三招全部基于稳定 Web 平台能力:stroke-dashoffset/pathLength(SVG 1.1/2,全主流浏览器)、transform 过渡(合成器友好)、fill-opacity 过渡;@media (prefers-reduced-motion) 全现代浏览器支持(MDN)。不使用 SMIL 与 JS 动画——与组件包 tree-shaking 兼容(React/Vue 组件库路线把动画留给宿主,07 §6.3)。 · widely available

兼容回退

reduced-motion 降级是本条目的一等公民:transition/animation 全部禁用,hover 直切终态(或按 MDN 示例把缩放类降为 opacity 溶解)——不删状态反馈本身(07 §6.3)。等效降级路线:描边版与实底版两枚 symbol 换 <use>,零动画成本完成填充点亮(07 §6.1/§6.3)。极老环境(不支持 pathLength 归一)时 dash 技法退化为 rotate/fill。

来源 3

起源时长与缓动取 M3 官方 token(out/design-study/07-icons.md §6.2):duration.short3/short4 = 150/200ms(官方用例 "Selection controls have a short duration of 200ms with Standard easing"),easing.standard = cubic-bezier(0.2, 0, 1, 1)("simple, small, or utility-focused transitions");填充点亮的官方通道是 Material Symbols FILL 轴(README:"animated fill effect, to indicate user selection",07 §6.1),SVG 侧等效实现为 fill-opacity 过渡;降级护栏出自 MDN prefers-reduced-motion:缩放/平移类动画可诱发前庭障碍,官方示例把 pulse 缩放降级为 opacity 溶解(07 §6.3)。
