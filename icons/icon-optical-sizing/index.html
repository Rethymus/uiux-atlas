光学缩放 Optical Sizing

光学对齐 · 视觉补偿 · Optical Alignment · Optical Compensation · opsz

同视觉重量 ≠ 同几何尺寸:圆形键程 Ø20 比方形 18×18 光学放大 2dp(约 +11%),不对称图形允许小幅光学偏心;Material opsz 轴把补偿参数化。

px

渲染边长(px)。默认 24 = Material Symbols opsz 轴官方默认值(README:"The default is 24",07 §1.5);opsz 轴量程 20–48,且仅 20px 与 24px 版本做了完美像素栅格对齐。demo 用恒定 2px 绝对线宽(non-scaling-stroke)示意 opsz 方向——放大后线条相对变细、缩小后相对变粗;opsz 的官方补偿曲线未公开,demo 为方向示意而非曲线复刻。

动效▾
compensateon

光学补偿开关。on = 圆形键程按官方规则放大到 Ø20(方形 18×18,+11.1%),不对称三角形按 Lucide 规则做小幅光学偏心;off = 圆与方同尺寸 Ø18 的纯几何对照——并排模糊观察,圆会明显显轻(07 §2/§3.1/§3.2)。三角形偏移量 demo 取 0.5px(24 网格内),Lucide 只写 "may be moved slightly off center" 未给数值,0.5px 为演示取值(未证实为官方数)。

代码拆解

结构与 DOM

光学缩放没有独立 DOM——它是对绘制坐标的修正纪律。demo 用三枚 24 网格 SVG 并排,叠加中心十字与键程参考:

<!-- 方:几何居中,贴 18×18 键程 -->
<svg viewBox="0 0 24 24"><rect x="3" y="3" width="18" height="18" fill="none" stroke="currentColor" stroke-width="2"/></svg>

<!-- 圆:光学放大到 Ø20(比方形键程大 2dp) -->
<svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="10" fill="none" stroke="currentColor" stroke-width="2"/></svg>

<!-- 不对称三角:允许 ≤0.5 单位光学偏心 -->
<svg viewBox="0 0 24 24">
  <g transform="translate(0.5 0)">
    <path d="M8 7.5v9l7.5-4.5z" fill="none" stroke="currentColor" stroke-width="2"/>
  </g>
</svg>

要点:

  • 补偿只动尺寸与亚像素位置,不动语义;aria 信息不受影响;
  • 大尺寸渲染时线宽用 vector-effect: non-scaling-stroke 保持恒定绝对值,示意「放大后线相对变细」的 opsz 方向;
  • 十字参考线是设计期工具,交付删除。

样式与参数

两个参数都是 JS 型,换算关系:

圆直径 = compensate ? 20 : 18          // 官方键程 Ø20 = 方 18 + 2dp
渲染直径 px = 网格值 / 24 × baseSize    // baseSize 默认 24(opsz 官方默认)
三角偏移 = compensate ? +0.5px : 0     // Lucide 允许 slightly off center(数值为演示取值)

数值出处:

  • 圆 Ø20 / 方 18×18:Material system-icons 键程官方值(07 §2),圆比方案 +11.1%(20/18,07 §3.1);
  • opsz 轴 20–48、默认 24:Material Symbols README/Google Fonts 指南双证(07 §1.5);仅 20px 与 24px 版本做到完美像素对齐;
  • 不对称允许偏心:Lucide design-principles 原文 “may be moved slightly off center so they look visually centered”(07 §3.2);0.5px 为演示取值,官方未给数;
  • 模糊法验收:Lucide 原版技法——与 circle/square 并排整体模糊,灰度不应明显失衡(07 §3.2);demo 的「模糊法验收」按钮即此;
  • 反向应用:深底浅色图标用 GRAD −25~−50 降眩光,是光学缩放在负空间方向的应用(07 §3.1-4)。

动效与交互

光学缩放是静态纪律,demo 交互只两处:

  • compensate 切换:圆的半径与三角偏移直切,并排对照「等尺寸(几何)」vs「+11.1%(光学)」;
  • 模糊法验收按钮:对三枚图形加 filter: blur(1.5px),肉眼比对灰度重量(动画只有按钮态切换,无运动);
  • baseSize 拖动时 SVG 按 width=baseSize 缩放,恒定 2px 线宽下直观看到「放大线相对变细」;
  • 无运动类动效,prefers-reduced-motion 无需降级。

真实产品案例

  • Material Symbols opsz 轴:20–48 量程、默认 24,随尺寸自动调笔画粗细(Google Fonts 指南原文),把「缩放补偿」做成了可插值参数(07 §1.5/§3.1);
  • Lucide 贡献规范:把「几何居中≠看着居中」与「模糊法」写进验收清单——不对称图标小幅偏心是规范内正操作(07 §3.2);
  • Material GRAD 轴:黑底白图标 GRAD −25~−50 降眩光、强调态 +200,光学补偿在「负空间方向」的官方旋钮(07 §1.5/§3.1)。

参数敏感度

参数调大会…调小会…
baseSize48px 渲染时恒定 2px 线相对变细(opsz 方向),圆 +2dp 的光学优势按比例放大到 3.3px16px 处 2px 线相对变粗、易粘连;圆方补偿差缩到 1.3px,补偿量接近渲染误差
compensateon 圆 Ø20 按官方值光学放大,与方并排模糊后灰度一致off 圆退回 Ø18 与方等尺寸——几何正确、视觉显轻,行内重量失衡

锚点:补偿量 = 圆 +2dp / 偏心 ≤0.5px / 模糊法终审;超过这些量级就不再是「光学修正」,而是绘制错误。

适用场景 3
  • 自绘图标的验收:方形贴 18×18、圆形贴 Ø20、不对称元素允许 0.5px 级偏心(07 §2/§3.2)
  • 同一行混合圆/方/三角元素时消除「圆显轻、三角显偏」的观感
  • 图标从 24px 主网格扩展到 16/32/48px 渲染档时核对笔画粗细方向(opsz 思路,07 §3.1)
何时不要用 3
  • 把光学偏移当万能微调旋钮:偏移只服务「看着居中」,像素栅格让位但不能破坏形状识别(Lucide:pixel alignment should support the icon,07 §3.2)
  • 只有圆做了补偿、方与三角不补偿的半套方案——行内重量反而更乱
  • 小尺寸(<16px)仍坚持严格像素对齐而牺牲流畅曲线——官方明确栅格对齐是手段不是目的(07 §3.2)
无障碍

光学补偿不改变对比度义务:图形对象与邻接底色仍需 ≥3:1(WCAG 2.2 SC 1.4.11)。放大检查(opsz 方向)会让细线在小尺寸相对变粗、更易达标;反之放大到大尺寸时保持恒定 2px 绝对线宽会让线条相对变细,注意别跌破阈值(07 §3.1/§3.3/§4.3)。

浏览器支持

演示用到的 SVG 能力(viewBox 缩放、vector-effect: non-scaling-stroke、CSS filter: blur)全主流浏览器支持;non-scaling-stroke 为 SVG 1.1/2 标准属性。Material Symbols 的 opsz 轴本身是变量字体能力,依赖可变字体加载(见 browserSupport 基线)。 · widely available

兼容回退

无需回退:光学缩放是绘制准则,交付物是普通 SVG。若做 Material Symbols 变量字体路线,字体加载失败时退回静态 wght 400 实例(默认即 24px 光学设计),不会丢失图形。

来源 4

起源「圆溢出方」是 Material 官方栅格的硬数值:方形键程 18×18、圆形键程直径 20——同视觉重量下圆要画得比方大约 11%(20/18)(out/design-study/07-icons.md §2/§3.1);Lucide 贡献规范把「几何居中不等于看着居中」写成规则:不对称图形允许小幅偏离几何中心(07 §3.2);Material Symbols 的 opsz 轴(20–48,默认 24)随尺寸自动调笔画粗细(07 §1.5/§3.1)。
