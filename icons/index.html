Favicon 体系 现代 favicon 链的极小集:**5 图标 + 1 manifest** 覆盖所有需求,不必生成 20+ 张 PNG——ico 32×32 兜底 RSS/旧版、SVG 内嵌 prefers-color-scheme 自动换色、apple-touch 180×180 加内边距、192+512 maskable 走安全区,manifest 仅 PWA 需要。 Web 标准 ★★★ 图标语义与无障碍 装饰图标一律 aria-hidden="true" 摘出无障碍树且永不落在可聚焦元素上;语义图标用可访问名写动作(「搜索」不是「放大镜」);四种 aria-hidden × 可访问名组合逐一对照读屏行为。 Web 标准 ★★ 图标按钮 纯图标按钮 = 真实 <button>(自带 APG Button 的 Enter/Space 键盘)+ 装饰图标(aria-hidden + focusable="false")+ 写动作的可访问名;名称实现三方案(视觉隐藏文本 / hidden + aria-labelledby / aria-label)逐一对照,命中热区可量化审计(WCAG 2.5.8 ≥24×24,M3 触控 48dp)。 Web 标准 ★★★ 图标色彩与状态 currentColor 一处染色全链生效,状态色(default/hover/danger)取 IBM Carbon 已核实色板,透明度滑杆实时核算 WCAG 1.4.11 的 3:1——2.999:1 也算失败。 Web 标准 ★★★ 图标字体与 SVG 两种图标交付形态的正面对照:icon font 靠「码位→字体字形→color 染色」,失败面大(加载失败/CORS/PUA 撞 emoji);inline SVG 真矢量、CSS 可控、内嵌文档无怪异失败态——IE9+ 时代起几乎全面胜出。 Web 标准 ★★ 24px 图标栅格 24×24 是全行业共同祖先网格:展示区 24dp、活动区 20dp(四周 2dp padding)、方形键程 18×18、圆形键程 Ø20;栅格与安全区参考线实时可视化。 Material 3 ★★★ 开源图标集 六套开源图标同一枚图形对照:Lucide/Feather 2px、Heroicons 实测 1.5px、Phosphor 256 网格填充、Material 双世代——选集先看网格、线宽哲学与许可三件事。 社区流派 ★★ 图标动效 hover 触发的三招路径微动效:stroke-dashoffset 描边绘制、≤90° 旋转、fill-opacity 填充点亮——150–200ms + standard 缓动是 M3 官方区间,prefers-reduced-motion 直切终态。 Material 3 ★★★ SVG Symbol 雪碧图 一份 <symbol> 模板多处 <use> 实例化:定义不可渲染、引用深克隆进 shadow DOM,染色只走 CSS 继承——currentColor 一处上色,写死 fill/stroke 的 path 封死继承。 Web 标准 ★★ 光学缩放 同视觉重量 ≠ 同几何尺寸:圆形键程 Ø20 比方形 18×18 光学放大 2dp(约 +11%),不对称图形允许小幅光学偏心;Material opsz 轴把补偿参数化。 Material 3 ★★ 描边与填充图标 SVG 图标的第一分叉:stroke 走 currentColor 的线性描边,或 fill 吃满 currentColor 的实底填充;同一路径两种交付,线宽 1–3 与填充开关实时切换。 Web 标准 ★★★ 图标系统设计 把「感觉不齐」变成机器可判的审计:24×24 栅格 + Material 键程(方 18×18/圆 Ø20)+ 1px 安全区 + 统一线宽 + kebab-case 命名,六枚迷你图标在网格/键程/安全区叠加层下跑一致性审计,违规项逐条标红。 Material 3 ★★★
