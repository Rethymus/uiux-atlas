首启引导 Onboarding Journey

3 个条目

编排动效 + 目标梯度法则 + 空状态过渡:首启引导的组合方案。

组合条目

动效编排 Choreography 纯 CSS 的动效编排:animation-delay 按 --i 递增做交错起点,方向(上/下/左/右/无)给整组元素统一的空间语义;时长/曲线取 M3 官方配对(进入 std-decel 250ms、退出 std-accel 200ms),进入恒长于退出。 Material 3 ★★★ 空状态 数据为空时的友好占位:插画 + 简短标题 + 下一步说明 + 可选操作按钮,把『死胡同』变成引导。 组件库 ★★ 目标梯度效应 越接近目标,奔向目标的行动力越强。给清晰的进度指示、在起点预置「人为进度」,把资源投在收尾冲刺段——离目标越近,每一步的动机越足。 社区流派 ★★★

组合依据

16 号调研 §7-配方 g:Apple Onboarding 主依据——onboarding 在 launching 之后、不属于启动流程;用可交互方式教学(优于说明书);上下文相关提示就近显示(TipKit);前置流程要简短;教程可跳过且不再重复弹出;推迟非必要设置、给默认值;评分/付费请求放在体验之后(https://developer.apple.com/design/human-interface-guidelines/onboarding )。编排纪律 = TDesign「页面首次加载不用顺序动画表达内容顺序,直接呈现或淡入淡出」(https://tdesign.tencent.com/design/motion )——demo 首屏直出(纯 fade),交错只给用户触发的步进转场:choreography 条目官方默认 stagger 40ms(社区常见值,未证实;官方无交错间隔推荐值)/方向 up、入 250ms std-decel cubic-bezier(0,0,0,1)/出 200ms std-accel cubic-bezier(0.3,0,1,1) = M3 官方配对表 + Ant「出场整块消失、不设队列依次出场」(https://ant.design/docs/spec/motion-cn/ )+ M3 container transform 保引导卡→功能页连续感(https://m3.material.io/styles/motion/transitions/transition-patterns )。「目标梯度法则」四家规范未以该名收录 → 未证实(§9 清单),替代数值 = visionOS 按钮中心距 ≥60pt、M3 状态层 40dp/交互目标 48dp(https://developer.apple.com/design/human-interface-guidelines/layout ;https://m3.material.io/foundations/interaction/states/state-layers );demo 取 goal-gradient 条目官方默认 steps=10/headStart=1(起点预盖 1 章人为进度,「步骤条/会员卡预盖一枚已完成章」签名巧思)。空状态→内容过渡 = Ant Empty——无数据时显式提示 + 初始化引导、children 即 CTA(<Empty><Button>创建</Button></Empty>)、Select/Table 等组件内置 Empty 可全局统一(https://ant.design/components/empty-cn/ ;空状态模板页 https://ant.design/docs/spec/research-empty-cn/ )+ Apple Loading「show something as soon as possible」内容到达即替换(https://developer.apple.com/design/human-interface-guidelines/loading )+ M3 把 Skeleton loaders 官方列为转场模式;demo 换载零位移(空态占位尺寸 = 内容尺寸,内容到达快速淡入)。
