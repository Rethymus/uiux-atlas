分段表单流 Segmented Form Flow

4 个条目

步骤条 + M3 状态层 + 提交反馈弹簧 + 键盘导航:分步表单的组合方案。

组合条目

步骤条 把复杂任务拆成有顺序的子步骤导航:节点串在连接线上,wait/process/finish/error 四态自动推算,process 步可带进度环。 组件库 ★★★ M3 状态层 Material 3 状态层:在控件上叠一层「内容色」的低不透明度覆盖,用固定百分比区分 hover/focus/press/drag,而不是临时发明颜色。 Material 3 ★★★ Toast 弹簧入场 Toast 从屏幕边缘弹入:入场带过冲(真弹簧或 y₂>1 的过冲 bezier),退场纯缓出收尾,生命周期到点自动消失——『进攻退守,一进一出永不打架』。 组件库 ★★★ 键盘导航全景 Tab/Shift+Tab 在组件间移动,方向键在复合组件内移动(roving focus);焦点指示可见、焦点永不丢失、模态困焦必须可 Esc 释放并归还焦点。 Web 标准 ★★★

组合依据

16 号调研 §7-配方 c:步骤条用 Ant Steps——「任务复杂或有先后关系时分解成一系列步骤」,宽度 <532px 自动转竖排,status 四态可把 error 标到出错步,percent 进度环(https://ant.design/components/steps-cn/ );ProForm StepsForm 每步是完整数据、最后合并提交(https://procomponents.ant.design/components/steps-form/ );Ant 表单页模板铁律:分步表单 = 线性任务拆解 + 步骤条告知进度 + **最后一步前再次确认**(https://ant.design/docs/spec/research-form-cn/ )(§8 巧思 6「步条是承诺清单」)。表单内所有按钮/可点步骤头的交互反馈交给 M3 内容色状态层:hover +8%、focus +10%、press +10%、一次只叠一层、颜色取内容色(https://m3.material.io/foundations/interaction/states/state-layers )。提交轻反馈 = 吐司弹簧:官方弹簧依据是 M3 Expressive motion-physics(spatial springs + effects springs,https://m3.material.io/blog/building-with-m3-expressive ),demo 参数取条目 schema 默认 stiffness 300/damping 25(ζ≈0.722、过冲≈3.8%)、edge bottom、lifetime 4000ms(sonner TOAST_LIFETIME 源码值);Ant 口径:轻反馈 = message 3s、重反馈 = 结果页倒计时(https://ant.design/components/message-cn/ ;https://ant.design/docs/spec/research-result-cn/ );反面规则:TDesign「UI 一律 Cubic,Elastic 只给卡通插图」——弹簧只到轻微过冲为止(https://tdesign.tencent.com/design/motion );四家均无「表单步进弹簧参数表」→ 未证实。键盘导航 = Ant Modal keyboard Esc 默认 true + focusable{trap} 焦点陷阱(https://ant.design/components/modal-cn/ )+ Apple「主按钮绑 Return」(https://developer.apple.com/design/human-interface-guidelines/buttons ),法则引用补 WAI-ARIA APG Dialog Pattern 焦点管理(https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ );步骤头工具栏用 roving tabindex + 方向键(APG Toolbar/键盘导航条目口径)。

出处 out/design-study/16-composition-recipes.md §7 配方 c「分段表单流」+ §8 巧思 6(依据:Ant Steps/Form/message/research-form、ProForm StepsForm、M3 state-layers/m3-expressive、TDesign motion、Ant Modal focusable、Apple Buttons、WAI-ARIA APG Dialog)
