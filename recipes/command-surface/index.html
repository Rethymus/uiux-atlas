命令操作面 Command Surface

3 个条目

命令面板 + 浮层入场 + 键盘导航:键盘优先操作面的组合方案。

组合条目

命令面板 按 Ctrl+K / Cmd+K(或点页头搜索钮)唤起的全局命令浮层:子序列模糊搜索全部条目,↑↓ 选择、Enter 直达、Esc 关闭——APG combobox/listbox 语义 + focus trap + body 滚动锁定的完整零依赖实现。 Web 标准 ★★★ 浮层入场 浮层从触发钮弹入的事实标准:初态 scale 0.95 + opacity 0(+ 方向性位移 8px),200ms 到位,transform-origin 交给锚点方向;关闭永远比打开快。 组件库 ★★★ 键盘导航全景 Tab/Shift+Tab 在组件间移动,方向键在复合组件内移动(roving focus);焦点指示可见、焦点永不丢失、模态困焦必须可 Esc 释放并归还焦点。 Web 标准 ★★★

组合依据

16 号调研 §7-配方 d:命令面板组件本体四家均无官方组件(未证实,§9 清单),官方零件齐——Apple Searching(全应用一个可发现的搜索入口/给最近搜索与预测建议,https://developer.apple.com/design/human-interface-guidelines/searching )+ M3 Search(输入即出建议列表、app bar 级全局入口,https://m3.material.io/components/search/overview )(§8 巧思 8「命令面板 = 搜索模式 × 浮层 × 焦点陷阱」);demo 匹配与上限取条目 schema 默认:subsequence 子序列匹配(「gsm」能搜到 Glassmorphism,VS Code/Linear 同口径)、maxResults 8、快捷键徽标 Ctrl K(实际同时收 Ctrl+K 与 Cmd+K)。浮层入场取条目 schema 默认 initialScale 0.95/shiftY 8px/入 200ms/出 150ms/standard 曲线——官方时长带 = Ant motionDurationMid 0.2s(https://ant.design/components/message-cn/ Token 表)、TDesign 抽屉/消息通知/全局提示 280ms 档且弹窗类归 Z 轴运动(https://tdesign.tencent.com/design/motion )、M3 Enter and exit + medium 400ms+Emphasized(https://m3.material.io/styles/motion/transitions/transition-patterns ;https://m3.material.io/styles/motion/easing-and-duration/tokens-specs );出场更快且不排队(Ant「出场整块消失不排队」、TDesign ease-in 出画曲线),退场必须短于入场。键盘导航 = Ant Modal keyboard Esc 默认 true + focusable{trap} 焦点陷阱(https://ant.design/components/modal-cn/ )+ M3 focus 状态层 +10%(https://m3.material.io/foundations/interaction/states/state-layers )+ 法则引用 WAI-ARIA APG Dialog(https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ );组合衔接:输入框永久聚焦 + Esc 退栈 + 关闭归还焦点 + Esc/点击外部关闭不依赖入场动画。
