媒体头图叙事 Media Hero

3 个条目

视差滚动 + 动态排版 + 极光渐变:媒体头图的组合方案。

组合条目

视差滚动 多层滚动速率差制造深度:背景层跟随滚动慢于前景(跟随比例 p,0=钉在视口、1=与内容同步),用 scroll-driven animations 的 scroll() 时间轴按层下发位移,可运行在主线程之外;reduced-motion 直出静态分层。 Web 标准 ★★★ 动态文字 两条路线:可变字体的注册轴(wght 等)做字重/宽度渐变动画——改一个变量、零重排;或把文本拆成字符/单词做交错(stagger)揭示。演示的标题既逐字上升,也随轴值连续变重。 Web 标准 ★★★ 极光渐变 极光渐变:多层低亮度 oklch 光斑 radial-gradient 叠在一层 conic 底色上,整层 blur+saturate 后缓慢平移——大面积、可动画、几乎零成本的『氛围光』。 社区流派 ★★★

组合依据

16 号调研 §7-配方 e:视差有官方背书——M3 转场文档明写 iOS 前进/后退转场用 parallax(「background slides slower than the foreground」)以减少运动量,是减动效手段而非炫技(https://m3.material.io/styles/motion/transitions/transition-patterns )(§8 巧思 9);Apple 补 background extension effect + scroll edge effect(https://developer.apple.com/design/human-interface-guidelines/layout );demo 取条目 schema 默认 rate 0.3(官方未给推荐值,0.2–0.6 为社区常见分层,未证实)、mode css = animation-timeline: scroll() 声明式滚动驱动(可离主线程),不支持自动落 JS(rAF + scroll 事件)兜底。动态排版 = Apple Dynamic Type 层级(Large 默认档 Body 17pt/Large Title 34pt,visionOS 编辑类 Extra Large Title,https://developer.apple.com/design/human-interface-guidelines/typography )+ M3 type-scale-tokens(https://m3.material.io/styles/typography/type-scale-tokens );demo 取条目 schema 默认 stagger 40ms/rise 600ms cubic-bezier(.2,.7,.3,1)/wght 400(Inter Variable 轴域 100–900)/reveal chars,逐字 aria-hidden + 整句 aria-label 保读屏语义。极光渐变背景四家官方规范均无 → 未证实(§9 清单);落地按 Apple「Don't use Liquid Glass in the content layer」自行降级——条目 schema 默认 spots 4/blur 42px/saturate 115%/drift 18s(演示档,生产氛围光建议 60s 级)/spotA 20%/spotB 70%,文字卡独立于滤镜层保 4.5:1。动效红线:visionOS 禁 ~0.2Hz 持续振荡、反馈短促精准(https://developer.apple.com/design/human-interface-guidelines/motion );reduced-motion 时视差与漂移全停、逐字直接呈现。

出处 out/design-study/16-composition-recipes.md §7 配方 e「媒体头图叙事」+ §8 巧思 9(依据:M3 transition-patterns parallax、Apple layout/materials/motion/typography、M3 type-scale-tokens;极光渐变未证实,按条目 schema 演示默认落地)

让叙事随滚动展开

背景层以 rate 0.3 拖曳——比前景慢 70%,滚动因此被读作「更少的运动」而非炫技;文字层永远 1:1 随滚动,可读性优先。

rate 0.3 · mid 0.6blur 42px · saturate 115%drift 18s(demo)stagger 40ms · rise 600ms

视差是减动效手段(M3 官方定义)

M3 转场文档:iOS 前进/后退转场用 parallax,「背景慢于前景」以减少运动量;极光渐变无官方规范(未证实),按「内容层禁用 Liquid Glass」降级为普通渐变层 + 压暗 scrim,文字卡独立于滤镜层保 4.5:1。

reduced-motion:三层全停

视差停(所有层静态直出)、极光漂移停、逐字上升停(直接呈现);文本语义不依赖任何一层动画。visionOS 红线:避免 ~0.2Hz 持续振荡。
