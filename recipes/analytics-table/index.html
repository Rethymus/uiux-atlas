数据分析表盘 Analytics Table

4 个条目

数据表 + 图表轴 + 提示框图例(小倍数点缀):数据分析表盘的组合方案。

组合条目

表格 用行列矩阵组织结构化数据:表头承载列语义,行承载记录;排序、斑马纹与行 hover 都是为扫读服务的辅助层,不是装饰。 组件库 ★★★ 坐标轴与网格 图表的「表格线」纪律:网格线要浅(Grafana 用主文字色 9% 透明度)、轴线可去(ECharts/ggplot2 两条路线)、刻度数克制(ECharts splitNumber 默认 5)——三参数决定一张折线图的专业度。 组件库 ★★ 图例与提示 图表的「读值双通道」:图例管系列回指(默认右侧,ggplot2 源码默认),tooltip 管精确读值(ECharts 默认 mousemove 触发 / 100ms 延迟隐藏),并按 WCAG 1.4.13 做到 Esc 可关、可悬停、常驻。 组件库 ★★ 小倍数图 同标度、同轴的一组相似小图并排:每个面板只讲一个系列,靠「全部面板共用同一把尺」实现跨面板直接对比——Tufte 的定义性要求;双轴混杂图恰恰是它的反面。 社区流派 ★★

组合依据

16 号调研 §7-配方 h:数据表 = Ant Table——密度三档 size large/medium/small(cellPaddingBlock/Inline 16/12/8 而 cellFontSize 三档恒 14:密度只动间距不动字号)、固定列必须给 width 且配 scroll.x、固定表头同、sticky 表头(4.6+)、virtual 虚拟滚动(5.9+,scroll.x/y 必须为 number)、rowHoverBg #fafafa(https://ant.design/components/table-cn/ );ProTable request/schema 驱动 + options 工具栏 {reload,density,setting} 密度切换是一等能力(https://procomponents.ant.design/components/table/ );TDesign Starter「统计报表」模板(https://tdesign.tencent.com/ )。图表轴 = AntV 轴构成五件套(轴标题/轴标签/轴线/刻度线/网格线)——轴标题默认要加,单位(如「亿元」)进轴标题、轴标签省略单位,其他元素已表意时可省轴标题精简画面(https://antv.antgroup.com/zh/specification/module/axis/ );demo 取 dataviz-chart-axes 条目官方默认 gridOpacity 0.09(Grafana getGridColor 9% 透明度公式)/axisLine on(#6E7079 宽 1 = ECharts axisDefault 默认)/tickCount 5(ECharts splitNumber 默认,nice-ticks 取整档距)。提示框与图例 = AntV「信息组件」统一框架(标签 Label/图例 Legend/提示信息 Tooltip/指标卡 Index Card)——PC hover→Tooltip、移动端→指标卡平铺,「信息不丢失地转换形态」;图例位置遵循阅读动线、高阶图例带数值带操作(https://antv.antgroup.com/zh/specification/module/info/ );demo 取 dataviz-tooltip-legend 条目官方默认 legendPos right(ggplot2 源码默认)/tooltipFollow on(ECharts mousemove 触发、showDelay 0/hideDelay 100ms 悬停宽限,WCAG 1.4.13 可关/可悬停/常驻);小倍数点缀 = small-multiples 条目官方默认 layout multiples/scaleMode shared(全面板共用 0–100 同标度,Tufte 定义性要求)/panelGap 8px(Grafana GRID_CELL_VMARGIN 源码值)。表格数字排版 = AntV 数字字体三条件 → font-variant-numeric: tabular-nums 等宽数字、金融财会数值右对齐(https://antv.antgroup.com/zh/specification/language/basic/ );图表内部层级 = 「组件海拔」四档透明度(次要/辅助/正文/强调信息)。表盘级规范 = AntV graph/pubDashboard(通用)/graph/conDashboard(监控)(https://antv.antgroup.com/llms.txt 索引)+ Ant visualization-page-cn/detail-page-cn 模板文档。M3 官方无图表组件与图表指引 → 未证实(components 为通用组件集,sitemap 实测)。价值层:AntV 三价值观 信任感/轻松感/意义感——参考线/事件标记/智能洞见是表盘「意义感」的官方要求(https://antv.antgroup.com/zh/specification/principles/basic/ )。
