仪表盘数据卡 Dashboard Tile

4 个条目

bento 网格 + 密度规范 + 骨架加载 + 磁吸点缀:仪表盘数据卡的组合方案。

组合条目

便当盒布局 一个 CSS Grid 上的不等大小圆角卡槽阵列,以格子大小编码信息优先级——Apple 2022-09 发布会后成为 SaaS 功能区的默认形态;是布局不是配色。 社区流派 ★★★ 仪表盘密度 BI 网格的密度底座:Grafana 24 列 × 30px 行高 × 8px 面板间距(源码常量),联动 Power BI 官方示例字号阶梯 45/12/12/10——comfortable 与 compact 两档切换整盘呼吸感。 组件库 ★★ 骨架屏 用几何色块复刻即将出现的内容布局,叠加一道扫光脉动表示「加载中」;内容就绪后快速淡入覆盖,布局零跳动。 社区流派 ★★ 磁吸交互 指针进入吸引半径后,按钮被「吸」向指针按比例偏移,离开即回位;逐帧用 lerp 线性插值逼近目标,触屏与 prefers-reduced-motion 下直出普通 hover。 社区流派 ★★★

组合依据

16 号调研 §7-配方 b:「bento grid」官方术语未证实(§9 清单),替代依据是各系栅格数值——容器层 bento 取调研配方 repeat(4, minmax(0,1fr))/行高 180px/间隙 16px/圆角 24px(superdesign.dev 条目 schema 官方默认);面板密度层走 Grafana 面板数值 gap 8px(GRID_CELL_VMARGIN)/行高 30px(GRID_CELL_HEIGHT)/KPI 面板 3 格=90px、Power BI 字号阶梯 45/12/12/10;宏观栅格依据 = Ant 24 栅格/基数 8(https://ant.design/docs/spec/layout-cn/ )+ TDesign 基数 8px/gutter 16px(https://tdesign.tencent.com/design/layout )+ M3 spacing 线性 scale(https://m3.material.io/styles/spacing/applying-spacing )。密度切换只动间距不动字号(Ant Table 三档 cellPadding 16/12/8 而 cellFontSize 恒 14,https://ant.design/components/table-cn/ ;ProTable 密度切换是一等工具栏能力)。骨架占位尺寸=真实卡片尺寸、加载完成零位移——Ant「只在第一次加载数据时使用骨架屏」(https://ant.design/components/skeleton-cn/ )+ Apple Loading「show something as soon as possible」内容到达即替换(https://developer.apple.com/design/human-interface-guidelines/loading )+ M3 把 Skeleton loaders 官方列为六大转场模式之一(https://m3.material.io/styles/motion/transitions/transition-patterns )+ TDesign 首屏禁顺序动画(https://tdesign.tencent.com/design/motion )(§8 巧思 5「骨架屏是布局的预告片」)。磁吸按钮为点缀层(radius 0.45/lerp 0.15,条目 schema 默认),触屏与 reduced-motion 用户直接关掉磁吸走普通按压态。

出处 out/design-study/16-composition-recipes.md §7 配方 b「仪表盘数据卡」+ §8 巧思 5(依据:HIG Loading、M3 transition-patterns/skeleton loaders、Ant Skeleton/Table/layout-cn、TDesign layout/motion、Grafana/Power BI 密度数值)
