## 结构与 DOM

瑞士国际主义是一张「落在数学栅格上的纸」:海报容器本身是 `display: grid` + `repeat(N, 1fr)`,每个元素(标题、色条、图块、正文、页脚)显式声明跨列区间——**栅格不是背景装饰,是布局的语法本身**。

```html
<div class="poster" style="grid-template-columns: repeat(6, 1fr)">
  <div class="meta">Gestaltung · 1959</div>      <!-- 跨全宽 -->
  <h1 class="title">Die neue Gestaltung</h1>      <!-- 跨全宽,齐左 -->
  <div class="accentbar"></div>                   <!-- 跨 1–2 列:唯一红 -->
  <figure class="photo">…</figure>                <!-- 跨左半列:客观摄影 -->
  <div class="body">…</div>                       <!-- 跨右半列 -->
  <footer class="foot">…</footer>                 <!-- 跨全宽 -->
</div>
```

关键点:

- 栅格叠层(`.overlay`)是布局容器的镜像栅格,`aria-hidden` 纯装饰,打开后可逐列核对元素落位;
- 字阶只有一条生成规则:标题 = 基准字号 × 比率⁴,kicker = 基准 × 比率¹,正文 = 基准——**整个层级由一个比率生成,不手工调字号**;
- 图块是「客观摄影」占位(实色渐变块 + 图注),不做插画化装饰。

## 样式与参数

四个参数:两条 CSS 变量、两条 JS 型参数:

```css
.demo-stage {
  --sw-ratio: 1.414;   /* modularscale.com 记载比率:增四度 1:√2 */
  --sw-accent: #e30613; /* 社区常见基准值,非官方记载 */
}
.poster {
  grid-template-columns: repeat(6, minmax(0, 1fr)); /* cols 参数,JS 重算 */
  gap: 12px;
}
.title {
  font-family: "Helvetica Neue", Helvetica, Arial, sans-serif; /* 系统栈近似 Helvetica */
  font-size: calc(var(--sw-base) * var(--sw-ratio) * var(--sw-ratio) * var(--sw-ratio) * var(--sw-ratio));
  line-height: 0.98;
  letter-spacing: -0.02em;
}
.accentbar, .kicker, .foot strong { background|color: var(--sw-accent); } /* 唯一强调色 */
```

数值出处:

- 字阶比率四个选项(1.25 / 1.333 / 1.414 / 1.5)= **modularscale.com 记载的比率**(大三度 4:5、纯四度 3:4、增四度 1:√2、纯五度 2:3;调研 05§17 一手核对);
- 「模块网格列数/栏距/基线」「单一结构性强调色(经典瑞士红)」为调研 03§15 原文变量,均未附数值——列数 6、红 #E30613 为基准设定(#E30613 为社区常见值,未证实);
- 「数学网格是最具可读性与和谐性的信息结构手段」与「齐左不齐右」「客观摄影代替插画」皆为调研 03§15 原文特征。

## 动效与交互

瑞士风格的动效近乎「无动效」——纸张不表演:

- **入场**:海报整体淡入 + 10px 上移,0.45s,一次性;无弹跳无回摆;
- **栅格核对**:切换叠层瞬时显示/隐藏(无过渡)——核对工具不该有动画延迟;
- **hover/按压**:不添加。装饰性动效与「客观、机构感」的立场冲突,这是风格纪律的一部分;
- `prefers-reduced-motion: reduce` 时仅取消入场淡入——本来也没有别的动画可关。

## 真实产品案例

- **Müller-Brockmann 海报(1950s,巴塞尔/苏黎世)** — 模块网格 + Helvetica 体系的开创性载体,《Neue Grafik》期刊发表的标准样本(调研 03§15)。
- **纽约地铁导视(1972,Vignelli)** — 把瑞士原则(黑体字、色块线路、编号系统)带给大众的标志性公共导视,也是「单一强调色结构化信息」的最大规模实战(调研 03§15)。
- **MIT 与 1960s 美国机构/企业** — 瑞士风格在美国机构化落地的一批记载案例,奠定了「客观机构感 = 网格 + 无衬线」的当代认知;如今网格、无衬线与结构化层级已是网页默认语言(调研 03§15)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `cols` | 栅格更细,元素落位更自由、版面更「机构报告」;>6 后海报语境显得琐碎 | 跨度更粗,非对称张力更强;=2 时近乎双栏传单,层级选择变少 |
| `ratio` | display 层差更陡(1.5 纯五度),海报冲击力强,小屏标题易溢出 | 层差平缓(1.25 大三度),接近正文书的克制,海报感减弱 |
| `accent` | —(换色即换品牌语境,但必须是**一个**色;红是最历史的选择) | —(红 #E30613 对白底 ≈4.9:1;更浅的红会跌破 4.5:1,需重新核对) |
| `grid` | on 时叠层暴露每列边界——元素不落列会立刻显形,是自查工具 | off 时纯版面观感;叠层永不承载信息(aria-hidden) |

经验区间:海报 4–6 列、网页 12 列(社区惯例,未证实为规范);比率 1.333–1.414;强调色只出现在色条、kicker、页脚数字三处结构点——强调色出现在第三处以上就开始稀释「单一结构性」的纪律。
