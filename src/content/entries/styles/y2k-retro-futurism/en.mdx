## Structure & DOM

A Y2K interface is a two-layer build — "material + mood": the bottom layer is a glowing atmosphere (starfield dots, dual radial halos), and the top layer holds the **physical objects** — a player card, jelly buttons, HUD readouts — stacked in the scene like real 2000s electronics.

```html
<div class="scene">
  <!-- Mood layer: starfield dots + halos (purely decorative) -->
  <div class="grain" aria-hidden="true"></div>
  <!-- Object layer: player card -->
  <div class="player-card">
    <h1 class="chrome-title">Y2K</h1>
    <p class="hud" aria-hidden="true">SYS.OK · 2000-01-01</p>
    <button class="jelly-btn">PLAY ▶</button>
  </div>
</div>
```

Key points:

- The chrome headline is an **ordinary text node** wearing `background-clip: text` — screen readers read it normally; the decoration costs no semantics;
- HUD readouts and the pixel-grain layer are `aria-hidden` decoration and must never carry actionable information;
- The jelly button's sheen and inner shadows live on `::before`/`box-shadow` and take no part in layout.

## Styling & Parameters

Four parameters map to two CSS variables, one JS-recomputed gradient, and a `data-grain` switch:

```css
/* Jelly button: translucent fill + elliptical top specular + translucent border */
.jelly-btn {
  background: oklch(0.85 0.2 130 / var(--y2k-jelly-alpha)); /* alpha 0.55, baseline */
  border: 2px solid oklch(0.96 0.03 260 / calc(0.3 + 0.4 * var(--y2k-jelly-alpha)));
}
.jelly-btn::before {
  /* elliptical specular highlight, scaled by var(--y2k-gloss) */
  background: radial-gradient(60% 100% at 50% 0%, oklch(1 0 0 / calc(0.85 * var(--y2k-gloss))), transparent 72%);
}
/* Chrome type: multi-stop linear gradient pinned silver at both ends;
   Chromium/Safari need the -webkit- prefix */
.chrome-title {
  background: linear-gradient(100deg, silver, ice-blue, hot-pink, lavender, silver);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
```

Where the numbers come from:

- "Chrome/iridescent gradient (spectral stops), specular highlights & reflection strength, translucent jelly fill & border, low-res artifacts" are all tunable variables listed verbatim in research 03 §12, but **none come with recorded values** — 5 stops, alpha 0.55 and gloss multiplier 1 are this entry's baselines, not official numbers;
- The official qualitative referent for specular highlights is WWDC25 session 219 (research 09 §1.4d): specular highlights are named a material-defining device — a 2025 Liquid Glass cousin of this period trait, not period literature;
- The historical referent for translucent plastic: the iMac G3's transparent blobject shell (research 03 §12).

## Motion & Interaction

Y2K motion is "mechanical feedback from electronics" — short and staccato:

- **EQ bounce**: while playing, 12 gradient bars alternate at staggered 0.7–1.1s; paused they freeze at 30% height — the loop decorates, it never informs;
- **HUD blink**: the status dot flickers in 1.6s `steps(1, end)` jumps, mimicking old LEDs — no smooth fades;
- **Press feedback**: jelly buttons get `translateY(1px) scale(0.985)` on `:active`, transforming only, 0.15s;
- **Entrance**: card fades in with a 12px rise and 0.97 scale over 0.5s `cubic-bezier(0.22, 1, 0.36, 1)`, once;
- Under `prefers-reduced-motion: reduce` all of the above stop; the static chrome gradient and jelly surface remain — the period flavor lives in the material, not the motion.

## Real-world examples

- **iMac G3 (1998, Apple)** — the translucent, candy-colored blobject shell is the period prototype of "translucent jelly plastic" and still the most-cited physical reference for Y2K visuals (research 03 §12).
- **WorkOS Launch Week** — cited in the research as a full-throttle Y2K web case: chrome-gradient type, fluorescent blocks and pixel elements concentrated on short-cycle launch pages (research 03 §12).
- **Balenciaga / Palace and aespa, XG, Charli XCX** — the streetwear revival since 2018 pushed chrome silver and fluorescent orange/pink back into the mainstream; musicians now carry Y2K visuals into albums and stage design, with a Japanese "Y3K" offshoot (research 03 §12).

## Parameter Sensitivity

| Parameter | Turning it up… | Turning it down… |
| --- | --- | --- |
| `chromeStops` | packs the spectrum tighter toward an iridescent oil slick; past 6, adjacent hues blur together | collapses toward two-tone silver-grey, a cold hard metal; at 2 it's just "silver type" and the period flavor largely drops out |
| `jellyAlpha` | makes the jelly more solid and text contrast safer, but the "translucent plastic" read disappears | gets airier and crisper; below 0.3 text contrast on it becomes uncontrolled (SC 1.4.3) — decorative-only territory |
| `gloss` | blows out the sheen and spills the glow — stronger toy-plastic feel; past 1.5 highlights smear into mush | extinguishes the sheen into matte plastic; at 0 the jelly is just a translucent tint |
| `grain` | on adds the pixel grid that reads as "low-res artifact" — strong period flavor, slightly hurts legibility when over type | off returns to clean modern rendering; better wherever information density matters |

Working ranges: 4–6 stops, jelly alpha 0.4–0.7, gloss 0.8–1.3. Grain only on low-density scenes; body-text interfaces always run it off.
