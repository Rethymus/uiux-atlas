## 结构与 DOM

孟菲斯是「图案场 + 卡片」两层结构:整个场景是一块奶油层压板,黑描边几何母题以非对称方式散布全场(装饰层),一张硬偏移阴影的操作卡片浮在其上——**母题永远不让开文字的位置,卡片靠硬阴影和描边自己站出来**。

```html
<div class="scene">
  <svg class="pattern" aria-hidden="true"><!-- 蚯蚓线/之字纹/波点 --></svg>
  <div class="card">
    <h2>标题(黑描边)</h2>
    <button class="btn">Shuffle ↻</button>
  </div>
</div>
```

关键点:

- 母题全部是内联 SVG(path/polyline/circle),`aria-hidden` 纯装饰、`pointer-events: none` 不拦截交互;
- 卡片描边与硬偏移阴影(`2×描边宽` 的 `0 模糊` 阴影)是同一根黑——描边加粗,阴影跟着走;
- 母题铺排用**确定性伪随机**(整数 hash 槽位),同 seed 结果可复现,布局不会闪跳。

## 样式与参数

四个参数:一条 CSS 变量、三个 JS 型参数(订阅 store 后重排):

```css
.scene {                       /* 经典编排:调研 03§13 原文四色 */
  --mm-turquoise: #3eb8b0;     /* 色值为基准设定,调研未记载 */
  --mm-coral: #ff6f61;
  --mm-yellow: #ffd449;
  --mm-ink: #141414;
  --mm-cream: #f6f1e7;
}
.scene[data-palette="shuffle"] { --mm-a: coral; --mm-b: yellow; --mm-c: turquoise; }
.mm-pattern circle,
.mm-pattern polyline,
.mm-pattern path { stroke-width: var(--mm-stroke); } /* 描边粗细,默认 3px 基准 */
.card {
  border: var(--mm-stroke) solid var(--mm-ink);
  box-shadow: calc(var(--mm-stroke) * 2) calc(var(--mm-stroke) * 2) 0 var(--mm-ink);
}
```

数值出处:

- 「图案密度与叠放层数、冲突色板(无调和约束)、描边粗细、几何母题库(squiggle/zigzag/dot)、非对称构图」五项全是调研 03§13 原文列出的可参数化变量,**无一附数值**——描边 3px、密度 8、四色 hex 均为本条目基准设定;
- 色板纪律:只用 turquoise×coral×yellow×black 四色;「角色互换」编排只重排角色不引入第五色——这正是「无调和约束」的正解,不是无限加色;
- 硬偏移阴影是孟菲斯与新粗野主义的共享语法(对照本库 neo-brutalism 条目的 `4px 4px 0 #000`),但孟菲斯的骨架是**图案**,粗野主义的骨架是**边框**。

## 动效与交互

孟菲斯的动效是「卡片在图案场上弹跳」的平面感,无缓出长尾:

- **入场**:卡片带 2° 倾斜落位,0.45s `cubic-bezier(0.22, 1, 0.36, 1)`,一次性;
- **按钮反馈**:hover 时反向增大偏移(`translate: -1px -1px` + 阴影加长),`:active` 时按钮「压进」阴影归零——硬阴影的挤压是这类风格最诚实的按压反馈;
- **Shuffle**:换一个确定性 seed 重排母题,布局瞬时切换(无过渡),像换了一张丝网印;
- `prefers-reduced-motion: reduce` 时关闭入场与按钮过渡,Shuffle 仍然瞬时可用——动效全部可弃,交互不弃。

## 真实产品案例

- **Carlton 房间屏风(1981,Ettore Sottsass)** — 孟菲斯的首个标志物:之字纹层板与冲突色塑料层压板,是「图案堆叠 + 无调和配色」的实物原型(调研 03§13)。
- **《Miami Vice》与 Nickelodeon(1980s)** — 孟菲斯图形语言在中期 80s 至 90s 中期渗透流行文化的两个记载锚点,赛博之字形与色块至今仍是其大众记忆载体(调研 03§13)。
- **Dior 2011-12 高定与 Missoni 2015** — 时装界对孟菲斯的两次高规格致敬,证明该语言的「限量联名/活动页」用法而非整站用法(调研 03§13;网页上多为品牌资产/图案/活动页——enlighten 明示)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `stroke` | 黑边更强势,卡片硬阴影同步加厚,平面海报感更强;>4px 后细小母题糊成黑块 | 描边退化,母题变成普通彩色装饰;=1px 时失去孟菲斯的「黑骨架」 |
| `density` | 图案场更满,「堆叠」读感更强;>12 后与卡片争夺注意力 | 场面变空,退化为「点缀」;≤3 时风格几乎不可辨 |
| `motif` | —(枚举:蚯蚓线最「孟菲斯」,之字纹最锐利,波点最克制) | —(波点配低密度接近波普而非孟菲斯) |
| `palette` | shuffle 编排把冲突集中到暖色端(coral 底 yellow 卡),视觉更燥 | classic 编排(冷底暖块)是记载的历史编排,视觉更稳 |

经验区间:描边 2.5–4px、密度 6–10;母题只做装饰层,文字与操作永远在纯色卡片上;任何想把第五色相、渐变或模糊阴影加进来的冲动,都偏离了「无调和约束」的纪律。
