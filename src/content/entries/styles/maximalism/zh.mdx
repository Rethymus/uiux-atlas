## 结构与 DOM

极繁是「装饰层叠 + 一张可读卡」的结构:**图案场铺满整个场景**(色斑、波点、斜纹、贴纸逐层叠印),所有装饰都是 `aria-hidden` 的背景层;唯一的语义容器是一张双线描边的海报卡,**装饰永远不让开,卡片靠描边与纸底自己站出来**。

```html
<div class="scene">
  <div class="layer-blobs" aria-hidden="true"></div>  <!-- 撞色斑 -->
  <div class="layer-dots" aria-hidden="true"></div>   <!-- l1 波点底纹 -->
  <div class="layer-stripes" aria-hidden="true"></div><!-- l2 斜纹场 -->
  <span class="sticker" aria-hidden="true">More ★</span><!-- l3+ 贴纸 -->
  <article class="card">
    <p class="eyebrow">眉题(等宽第三族)</p>
    <h3>标题(衬线展示体 × marker 划线)</h3>
    <p>正文(45–75ch,恒为墨色)</p>
  </article>
</div>
```

关键点:

- 装饰层是场景的兄弟节点堆叠,`aria-hidden="true"` 且不拦截交互——密度不产生任何额外可聚焦元素;
- 卡内层级三件套:等宽眉题 → 大字阶标题 → 45ch 正文,缝隙用 `--mx-gap` 统一收缩;
- 贴纸、卡片允许 `--mx-tilt` 的叠印旋转——「有序」来自同一套参数,「混乱」来自叠加。

## 样式与参数

六个参数:三个 JS 型(色相数/字体档/层叠数)、三个 CSS 变量型(字阶/缝隙/旋转):

```css
.scene {
  --mx-step: 1.333;  /* 字阶跳跃(参数) */
  --mx-gap: 12px;    /* 缝隙收缩(参数) */
  --mx-tilt: 2deg;   /* 叠印旋转(参数) */
}
.card {
  rotate: var(--mx-tilt);
  border: 3px double currentColor;      /* 双线描边:叠印感骨架 */
  gap: var(--mx-gap);
}
.card h3 { font-size: clamp(1.6rem, calc(var(--mx-step) * var(--mx-step) * 1.25rem), 3.2rem); }
.mark  { box-shadow: inset 0 -0.22em 0 var(--mk); }  /* 撞色只落在划线上 */
```

数值出处(与极简逐项对照,两列均出自补研 11§7):

- **每屏色相**:极简 1–2 → 极繁建议 **≥5**(主:辅:点 ≈ 40/40/20,点缀允许高饱和撞色)——经验值,无官方数值标准;
- **字阶跳跃**:极简基准 1.125–1.25 → 极繁建议 **≥1.333**(perfect fourth);
- **装饰层叠**:极简 ≤1 层 → 极繁 **≥3 层**(底纹 + 贴纸 + 色块),允许叠印与 ±2° 旋转;
- **缝隙**:常规间距的 **0.5–0.75 倍但不为 0**——默认 12px 即 24px 的一半,保留呼吸缝(对照极简的 8px 大留白刻度);
- 正文行高可压至 1.25,行宽仍守 45–75ch(WCAG 1.4.8 优先)——密度用在装饰层,不牺牲正文;
- 八枚基准撞色 hex(#e63946/#ff8c42/#ffd60a/#2a9d8f/#1b9aaa/#3557ff/#7b2ff7/#ff5da2)为本条目基准设定,调研未记载具体色值。

## 动效与交互

极繁的动效是「纸张落位」而不是「界面过渡」:

- **入场**:卡片一次性落位,0.45s `cubic-bezier(0.22, 1, 0.36, 1)`,只动 `opacity/scale`——旋转交给参数,不进动画帧;
- **贴纸 hover**:倾角加深一档(2×),0.2s 过渡——叠印「被拨动」的暗示;
- **换序 Shuffle**:把基准色板旋转一位重排撞色关系,瞬时切换无过渡(像换了一张丝网印);层叠显隐同理直接切换,密度变化不该有中间态;
- `prefers-reduced-motion: reduce` 时取消入场与 hover 过渡——装饰可以静止,信息不依赖动效。

## 真实产品案例

- **Diko** — 大字出血 + 青红对撞 + 跑马灯页脚的整页拼贴,极繁「排版密度 + 无主导色」的网页样本(调研 03§8)。
- **Ellen Porteus 作品集** — 花卉母题铺满全屏的插画师主页,「刻意占满每一寸表面」的个人风格宣言(调研 03§8)。
- **Glitche** — 故障艺术素材与作品平台,以高频撞色与叠印图形维持品牌辨识(调研 03§8)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `hues` | 撞色关系指数式变密,>6 后画面开始「发噪」,需靠统一墨色描边压阵 | 趋近双色海报;=2 时极繁只剩「排版密度」一根支柱 |
| `fontMix` | —(枚举:trio 是极繁正解,衬线展示体的历史感最重) | duo 退化为极简排印,仅剩装饰层在支撑风格 |
| `layers` | 纸面更满,「叠印堆叠」读感最强;6 层是可辨识上限,再多开始互相糊 | 逐层剥落;=1 时只剩底纹,=0(下限 1)风格不可辨 |
| `typeScale` | 标题撞进视线,1.5+ 接近海报大字报,长标题易溢出卡片 | 层级变平;1.0 时标题与眉题同阶,极繁失去「响亮」支柱 |
| `gap` | 趋近常规版面,「占满」感减弱 | 缝隙消失,贴纸与卡片粘连读作失误;0 是红线外值 |
| `tilt` | 叠印更躁;>4° 开始读作排版失误而非故意 | 回到对齐网格;0° 时只剩平面层叠,叠印感消失 |

经验区间:色相 5–6、层叠 3–5、字阶 1.333–1.5、缝隙 10–16px、旋转 ±2°。红线只有一条:**装饰可以无限堆,正文永远坐在纯色底上、45–75ch 内、放大一倍不滚动**(补研 11§7 引 WCAG 1.4.8)。
