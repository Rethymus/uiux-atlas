## Structure & DOM

A cyberpunk UI is a "three-layer print": near-black at the bottom, the neon content layer in the middle, and scanline/aberration **decoration layers** applied over the top via pseudo-elements (always `aria-hidden`, never carrying information).

```html
<section class="cy-scene">
  <div class="cy-hud">
    <h1 class="cy-title">NEON DISTRICT</h1>
    <div class="cy-readout" role="status">LINK: STABLE · 98.2%</div>
    <button class="cy-btn">JACK IN</button>
  </div>
</section>
```

Key points:

- The base must be **near-black** (a dark base is a hard prerequisite) — electric cyan/magenta/acid yellow only hold on it;
- Neon = double-layer `text-shadow` glow + a magenta/cyan RGB split; aberration is the core move of "glitch as atmosphere";
- HUD vocabulary: compressed monospace type, telemetry readouts, corner-bracket frames — every decorative frame is `aria-hidden`;
- The content layer stays ordinary DOM, with readouts in `role="status"` carrying real state.

## Styling & Parameters

Four parameters map to scanline spacing, scanline opacity, RGB shift and neon brightness, injected via `--cy-*` variables:

```css
.cy-title {
  color: #fcee0a;                    /* acid yellow, demo sample color */
  font-family: ui-monospace, "JetBrains Mono", monospace;
  letter-spacing: 0.06em;
  text-shadow:
    calc(-1 * var(--cy-rgb)) 0 rgb(255 43 214 / 0.8),   /* magenta fringe left */
    var(--cy-rgb) 0 rgb(0 240 255 / 0.8),               /* cyan fringe right */
    0 0 calc(10px * var(--cy-glow)) rgb(252 238 10 / calc(0.55 * var(--cy-glow))),
    0 0 calc(28px * var(--cy-glow)) rgb(252 238 10 / calc(0.30 * var(--cy-glow)));
}

/* Scanlines: a 1px dark line, period = scanGap, opacity = scanAlpha */
.cy-scene::after {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
  background: repeating-linear-gradient(
    to bottom,
    rgb(0 0 0 / var(--cy-scan-alpha)) 0 1px,
    transparent 1px var(--cy-scan-gap)
  );
}
```

Sources and honest labeling:

- The research (the enlighten cyberpunk page) lists the tunable variables: **scanline spacing and opacity, RGB shift, and the neon palette's luminance ratio against the dark base** — but records **no specific values**;
- The four parameter defaults (4px / 0.25 / 2px / 1) are therefore **this entry's baseline settings**, not official defaults; the palette uses the community's habitual cyan `#00f0ff` / magenta `#ff2bd6` / acid yellow `#fcee0a` (demo sample colors, likewise unverified as official);
- Reference cases: the Cyberpunk 2077 site (scanlines + neon + full-screen video), the Ghost in the Shell film site, AI Utility Grid (a restrained terminal aesthetic).

## Motion & Interaction

Glitch is atmosphere, not notification — every motion must degrade:

- **Glitch jitter**: the title shifts horizontally by 1–2 RGB-shift units with a brief stronger split, flashing only 2–3 times per 4s cycle to avoid high-frequency strobing;
- **Cursor blink**: the block cursor at the end of the telemetry row steps at 1.2s; under `prefers-reduced-motion` it becomes solid;
- **Degradation chain**: with reduced motion, all animation turns off while the static RGB split and scanlines remain — the core identity depends on no motion;
- Button hover intensifies the glow over 0.15s; press sinks 1px. Decoration layers are always `pointer-events: none` and never intercept interaction.

## Parameter Sensitivity

| Parameter | Turning it up… | Turning it down… |
| --- | --- | --- |
| `scanGap` | a venetian-blind feel with a coarser texture; past 8px it starts fighting body text | dense CRT texture; at 2px the whole panel grays out with visible luminance loss |
| `scanAlpha` | harder scanlines, heavier CRT; past 0.4 they dim the neon and contrast starts failing | near 0 the scanlines vanish, back to a plain dark base |
| `rgbShift` | stronger misprint glitch; past 4px type edges smear and legibility drops sharply | aberration tightens; at 0 it is a clean neon word and glitch lives only in the animation |
| `glow` | halo bleed, a neon-tube feel; at 2 the type edges blur | glow tightens; at 0 only flat color remains and the neon feel is gone |

Working ranges: scanGap 3–6px, scanAlpha 0.15–0.3, rgbShift 1–3px, glow 0.8–1.4. All parameters act on decoration — keep one "lights-off legible" version for the body readouts.
