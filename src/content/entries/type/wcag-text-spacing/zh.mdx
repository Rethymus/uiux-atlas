## 结构与 DOM

无特殊结构——把文本放进普通文档流容器,关键是**别锁死**:

```html
<div class="prose">
  <p>正文段落……</p>
  <p>另一段……</p>
</div>
```

```css
.prose p {
  line-height: var(--ts-line-height);   /* 无单位,可被覆写 */
  margin-block-end: var(--ts-para-gap); /* 段距 */
  letter-spacing: var(--ts-letter-spacing);
  word-spacing: var(--ts-word-spacing);
}
```

关键点:

- 不写 `!important`、不定高裁剪——1.4.12 约束的是「用户代理覆写后内容仍可用」,锁死的样式等于直接违规;
- 文本容器用 `min-height` 而不是 `height`,行高一涨不裁剪;
- 单行截断(`white-space: nowrap` + `overflow: hidden`)与 1.4.12 天然冲突,交互文本不要用。

## 样式与参数

四个比率参数(行高/段距/字距/词距)全部经 `--ts-*` 变量注入:

```css
.prose p {
  line-height: var(--ts-line-height);        /* number,unitless;阈值 1.5 */
  margin-block-end: var(--ts-para-gap);      /* em;阈值 2em */
  letter-spacing: var(--ts-letter-spacing);  /* em;阈值 0.12em */
  word-spacing: var(--ts-word-spacing);      /* em;阈值 0.16em */
}
```

数值出处(WCAG 2.2 理解文档原文一手核对,调研 05§18):

- 行高 ≥ **1.5** 倍字号;段距 ≥ **2** 倍字号;字距 ≥ **0.12** 倍字号;词距 ≥ **0.16** 倍字号;
- 前提是「不改变其他属性时内容必须可用」——四比率是**用户覆写值**,不是设计师必须采用的默认值;默认值仍由排版决定(常见 1.5 行高、1em 段距,后者为常见惯例,未证实);
- 词距的 CSS 语义作用对象是词分隔符(空格),无空格分词的中文正文基本不受影响;字距对中文有效。

## 动效与交互

间距本身无动效;交互发生在「覆写」这件事上:

- demo 的四个滑杆模拟用户代理覆写,实时显示每个比率相对 WCAG 阈值的达标态(✓/✗ 徽标 + 阈值数值);
- 「设为 WCAG 阈值」按钮把四值一键写入参数面板(1.5 / 2em / 0.12em / 0.16em),「还原默认」回到排版默认值;
- 判定是即时的纯数值比较,无动画;覆写后文本应保持完整可见——若 demo 文本出现截断或重叠,即对应真实站点的 1.4.12 失败形态。

## 真实产品案例

- **WCAG 官方验收工具链**:W3C 理解文档随附书签工具(bookmarklet),一键向任意页面注入四比率覆写,直接观察内容是否失效——这是 1.4.12 的官方验收路径(调研 05§18)。
- **GOV.UK 设计体系**:英国政府数字服务的设计体系对正文行高、段距有明确排版规范,并长期把「文本可在用户样式下重排」作为可访问性基线,是公共部门实践 1.4.12 的代表性落地。
- **浏览器阅读模式与「更大文字」设置**:iOS/Android 系统级字号放大、浏览器阅读模式本质就是对页面间距的一次「用户覆写」——四比率留有覆写空间的站点,在这些场景下排版不会崩。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `lineHeight` | 行盒增高,密集列表/表格可能溢出容器——定高容器会裁剪 | 低于 1.5 后低于阈值;过小(≈1)行与行粘连,阅读困难 |
| `paragraphGap` | 段落边界更清晰;超过 3em 后页面变「稀」,长文滚动成本上升 | 低于 2em 时未达阈值;0 时段落粘连成块 |
| `letterSpacing` | 0.12em 后达到阈值;再大单词视觉上「散架」,窄容器更易折行 | 0 为浏览器默认;负字距紧排可读性下降,覆写场景须仍可用 |
| `wordSpacing` | 0.16em 后达到阈值;对英文可见词间隔增大 | 0 为默认;对中文正文几乎无视觉变化(CSS 语义所限) |

经验结论:四阈值是「验收形态」而非「设计默认」;默认排版自由,但每个默认形态都必须能被覆写到阈值而不坏。
