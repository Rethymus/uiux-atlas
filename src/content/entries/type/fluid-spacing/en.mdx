## Structure & DOM

Isomorphic with the fluid type scale: no extra DOM, one layer of `:root`-level spacing tokens. Every piece of whitespace (padding/gap/margin) must ride the tokens — that is the premise of fluid spacing.

```html
<section class="block">
  <div class="chips">…</div>
</section>
```

```css
:root {
  --space-3xs: clamp(0.2813rem, 0.2656rem + 0.0521vw, 0.3125rem);
  --space-2xs: clamp(0.5625rem, 0.5313rem + 0.1042vw, 0.625rem);
  --space-s:   clamp(1.125rem, 1.0625rem + 0.2083vw, 1.25rem);
  --space-m:   clamp(1.6875rem, 1.5938rem + 0.3125vw, 1.875rem);
  --space-l:   clamp(2.25rem, 2.125rem + 0.4167vw, 2.5rem);
  /* … xl / 2xl / 3xl generated the same way */
}
```

Key points:

- The base token `--space-s` takes `minSpace/maxSpace` at the viewport ends; every other token = base × multiplier, on the ladder 0.25/0.5/0.75/1/1.5/2/3/4/6 (from Utopia's multipliers, research 05 §14);
- The interpolation formula matches the type scale: slope = (max−min)÷(maxVw−minVw), viewports converted to rem at a 16px root;
- The naming 3xs/2xs/xs/s/m/l/xl/2xl/3xl follows Utopia's token names (the --space-3xs/2xs/xs/s in research 05 §14's output sample).

## Styling & Parameters

All four parameters are JS-type: the demo subscribes to the panel, generates the nine clamp tokens live, writes them as CSS variables on the sample card, and shows code and bars side by side.

```css
/* Generated by the demo defaults: 480px→1440px, 1.125rem→1.25rem */
.block  { padding: var(--space-l); }
.chips  { gap: var(--space-m); }
.chip   { padding: var(--space-2xs) var(--space-s); }
```

Where the numbers come from:

- `minSpace` 1.125rem and `maxSpace` 1.25rem defaults = the two ends of Utopia's measured `--space-s: clamp(1.125rem, 1.0739rem + 0.2273vw, 1.25rem)` (research 05 §14, first-hand); the demo formula reproduces that line byte-for-byte from its viewport inputs;
- The `minViewport/maxViewport` defaults of 480/1440px are this entry's task-spec values; Utopia's sample back-solves to ≈360/1240px (not directly documented — both stated);
- Honest delta: Utopia rounds some tokens independently (its sample --space-3xs is a static fixed value); this entry implements pure multiplier interpolation, so outputs may differ from Utopia's in the last decimal.

## Motion & Interaction

Spacing tokens are static — "motion" only happens as the viewport changes:

- clamp output changes continuously while the viewport resizes: no jumps, no transitions needed;
- The demo bars stretch instantly with the simulated-viewport slider, and the sample card's padding/gap are driven by the real clamp() variables — resize the browser to watch the whitespace breathe;
- This entry produces no animation, so no `prefers-reduced-motion` handling is needed.

## Parameter Sensitivity

| Parameter | Turning it up… | Turning it down… |
| --- | --- | --- |
| `minViewport` | shifts the curve right: small screens sit pinned at the min values and mobile whitespace goes static | starts stretching earlier — whitespace already breathes on phones, shortening the flat region |
| `maxViewport` | flattens the slope: desktop whitespace changes become subtler and the ceiling arrives later | steepens the slope: whitespace inflates quickly on large screens and pins early |
| `minSpace` | raises the whole scale: looser whitespace on small screens, lower content density | near 0.5rem the micro tokens (×0.25 → 0.125rem) get too small to separate anything |
| `maxSpace` | larger whitespace on big screens with a steeper slope — a more poster-like look | approaches `minSpace`, the slope approaches zero and the scale degenerates to static; below `minSpace` the clamp semantics invert (min wins) |

Working ranges: base spacing 1.125–1.25rem (Utopia's sample), viewport 360–1440px; keep the spacing slope gentler than the type slope, and keep micro tokens (3xs/2xs) static or with minimal span.
