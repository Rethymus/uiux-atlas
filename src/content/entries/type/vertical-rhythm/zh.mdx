## 结构与 DOM

无特殊结构——普通文章流,纪律在行高与间距的取值体系里:

```html
<article class="col">
  <h2>标题</h2>
  <p>正文段落……</p>
  <blockquote>引语</blockquote>
  <p class="cap">图注/脚注</p>
</article>
```

```css
.col  { --unit: 18px; }                          /* 基本单元 = 正文行高 */
.col p { font-size: 12px; line-height: var(--unit); }      /* 行盒 = 1 单元 */
.col h2 { font-size: 14px; line-height: 1.2857; }          /* 18 ÷ 14 反推 */
.col p + p { margin-block-start: calc(var(--unit) * 1.5); } /* 间距 = 单元倍数 */
```

关键点:

- 韵律算法(24ways 原文,调研 12§9):**定单元 = 正文行高(12px × 1.5 = 18px)→ 一切垂直尺寸(margin/padding/行高)落在单元整数倍 → 标题用「单元 ÷ 字号」反推行高(14px 标题 = 1.286,行盒恰好一格)→ 不对称 margin 也可以,只要总和是单元倍数**;
- **全部用 em 或无单位比值**——用户缩放字号时节奏不崩(24ways 原文纪律);
- 行高比 = 单元 ÷ 正文字号,18/12 = 1.5 恰好满足 WCAG 2.2 SC 1.4.12 的 ≥1.5× 阈值(调研 05§18)——韵律法与无障碍阈值在默认值上重合。

## 样式与参数

四个参数:三个 CSS 变量型 + 一个 JS 型对照开关:

```css
.col p  { font-size: var(--vr-body); line-height: var(--vr-unit); }  /* 12px / 18px */
.col h2 { font-size: var(--vr-head); /* 行高 = 单元 ÷ 字号,由 TSX 反推内联 */ }
[data-mode="free"] :is(p, blockquote) { line-height: 1.45; margin: 0 0 7px; } /* 对照:任意值 */
```

数值出处:

- 单元默认 18px、正文 12px、标题 14px:**全部取自 24ways 原文工作示例**(12×1.5=18;18÷14=1.286),是「已核方法示例值」而非当代推荐值——2006 年的 12px 正文放到今天偏小,生产请按正文 16px 体系缩放单元(16×1.5=24);
- 标题行高 1.2857(18÷14):反推法的直接结果,demo 实时显示当前比值;
- 段距 1.5× 单元(27px):24ways 允许 1×/1.5×/2× 的单元倍数;
- 12§10 补充:边框计入节奏——1px 描边 + 8px 内边距 = 9px 恰为 18px 单元的半步。

## 动效与交互

- **韵律可视化**:蓝色韵律线每单元一条(repeating-linear-gradient);正文/引语块自带逐行「行盒条带」(周期 = 单元的半透明渐变)——rhythm 模式下条带与韵律线逐行咬合,读文本像读乐谱;
- **free 对照模式**:13px/7px 任意间距 + 1.1 标题行高 + 1.45 正文行高,条带与韵律线立刻错位——「韵律破坏现场」是该条目的教学本体;
- **行高比警示**:拖大 `bodySize`(单元不动),行高比跌破 1.5 时徽标转红(WCAG 1.4.12 阈值,调研 05§18);
- 无动画,全部即时重排;`prefers-reduced-motion` 无需处理。

## 真实产品案例

- **24ways 原文本身**:2006 年《Compose to a Vertical Rhythm》确立的完整算法(单元=行高、反推标题、em 纪律),至今仍是 CSS 韵律教学的基准文献(调研 12§9 URL 已核)——文中「空间如时间」的 Bringhurst 引语是这一体系的出处锚点。
- **TDesign 的「+8 常数」**:官方放弃固定 1.5 倍行高改用「行高 = 字号 + n,n = 8」——8 让 14/16px 字号与 1.5 倍完全重合,大字号不再行距膨胀(官网 design-basic.ts,调研 02§2)——韵律常数在生产设计系统里的另一种解法。
- **本站 uiux-atlas 流式字阶**:行高随字号减小放宽(1.12→1.65)、负字距只给 ≥21px 标题的全站纪律写在 `--step-*` 变量注释里(源码 `src/styles/global.css:154-163`)——「行高是体系参数而非逐元素拍脑袋」的同源思路。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `baseUnit` | 韵律更疏朗,行盒条带间距加大;单元与字号脱钩时行高比虚高 | 紧凑但拥挤;低于「字号 × 1.5」触发 WCAG 1.4.12 警示 |
| `bodySize` | 字号上行高比下降,跌破 1.5 时徽标转红(单元须同步放大) | 小字号下韵律致密,2006 年 12px 的老惯例今天偏小 |
| `headingSize` | 大标题按反推法得到更小比值(24px → 0.75 不可能,需占多单元) | 小标题比值升到 1 以上,行盒仍占一格 |
| `mode` | free 模式展示任意值排版的「发闷」现场——教学本体 | rhythm 模式条带咬合韵律线,文本像乐谱可读 |

经验法则:单元 = 正文行高;标题行盒占整单元(行高 = 单元 ÷ 字号);间距 1×/1.5×/2×;行高永远无单位或 em;边框计入预算。今天的正文从 16px 起步,单元随之 24px——方法不变,数值按正文体系缩放。
