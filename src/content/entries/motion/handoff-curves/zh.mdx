## 结构与 DOM

曲线接力是「一段轨道 + 一个可拖拽元素」的结构,接力是**时序**而非结构:

```html
<div class="lane" role="button" tabindex="0">   <!-- Pointer 事件流 + 键盘等效 -->
  <div class="marker" aria-hidden="true"></div> <!-- 目标位(纯装饰) -->
  <div class="puck"></div>                      <!-- 被拖拽元素:transform 唯一宿主 -->
</div>
```

关键点:

- 拖拽期间**没有任何动画在跑**:pointermove 直写 `transform`,1:1 跟手;释放瞬间才启动弹簧——两段共用同一份位置与速度状态;
- 速度从指针采样来:每次 move 记录 `(x, t)`,瞬时速度 EMA 平滑,释放即得手势速度(px/s);
- `pointercancel`(来电、系统手势接管)必须按释放处理,让弹簧照常接管——手势基建与 inertia-gesture 条目同一条 Pointer 流;
- 元素位置恒用 `translate3d`(合成器路径),逐帧不触碰布局。

## 样式与参数

三个参数全部 JS 型,直接组装进积分器,无 CSS 变量:

```js
// 弹簧段:半隐式欧拉积分(调研 10§2.2 springSlot 同款,m=1)
// m·x'' + c·x' + k·(x−target) = 0
v += (−k * x − c * v) * dt;   // dt 钳制 ≤ 1/30s,防跳帧爆炸
x += v * dt;
el.style.transform = `translate3d(${x}px, 0, 0)`;
// 停机:|v| 与 |x| 双阈值(restSpeed/restDelta 思路,Motion granular 档 0.01/0.005,调研 10§2.2;demo 放宽为 0.5/0.5 并加 8s 兜底,演示值)
```

数值出处:

- `stiffness 300 / damping 25`:调研 10§2.2 springSlot 代码默认,即 §2.3 实算的「中·微弹」档(**ζ≈0.722、过冲≈3.8%、峰值时刻 262ms**);ζ = c/(2√(k·m))、过冲 % = e^(−πζ/√(1−ζ²))×100 均为该页 Python 实算公式;
- **速度接力的官方语义**:Motion「物理弹簧会把既有手势/动画的速度纳入反馈」,`velocity` 缺省取「当前值速度」;反例是 duration-based spring「从静止开始并忽略速度」(调研 10§7.3,原文逐字);SwiftUI 文档同源:「连续 spring 动画接力时**保留速度**」(调研 04§1.3);
- 释放去向判定:velocity 注入弹簧是错误抖动的推荐姿势(调研 10§4.2:给初速度,不给 keyframes),抽屉类则先过阈值——vaul 的 `VELOCITY_THRESHOLD 0.4` + `CLOSE_THRESHOLD 0.25`(速度超阈值或进度过 25% 即放走,调研 10§5.1);
- `FLICK_VELOCITY = 1500 px/s`(键盘等效甩动)与速度采样平滑系数:演示用值,非官方数值。

## 动效与交互

- **两段一线**:跟手段零缓动(缓动会让指针与元素脱钩),弹簧段从「当前值 + 当前速度」续跑——拼起来是一条 C¹ 连续的曲线,人眼感知不到交接点;
- **快甩与慢推的差别全在交接**:慢拖释放速度≈0,弹簧安静归位;快甩释放速度大,弹簧带着惯性冲过头再被阻尼收住——过冲量可由 ζ 与释放速度预估,demo 实时显示两者;
- **handoff=off 对照**:同一甩动、速度清零再启动——回程「没劲」、像被拉回去而不是自己回去;这正是固定时长缓动接管释放的通病(duration-based 反例,调研 10§7.3);
- **抄弹簧先算 ζ(调研 10§2.3 巧思 3)**:速度灌进低阻尼弹簧(ζ\<0.4)会失控过冲;demo 把 ζ 与预计过冲挂在读数上,调参先看它;
- **可中断性**:再次按下即取消弹簧、清速度重新跟手——中断/重触发天然连续,是速度接力的另一半承诺;
- **reduced-motion**:跟手段保留(直接操纵不是装饰动效),释放直出落点不积分(与 inertia-gesture 条目同口径);
- 性能:全程只写 transform;与惯性滑行的分工——inertia 没有到位回弹、越界才弹(handoff 与 inertia-gesture 条目互为对照)。

与 slot-spring 条目互链:那是「弹簧手感与档位」的专条(layoutId 库版);与 damping-craft 互链:ζ 的完整手感映射;与 smooth-craft 互链:中断接力是「丝滑工艺」的总纲之一。

## 真实产品案例

- **Motion(framer-motion 后继)的弹簧引擎**:文档承诺物理弹簧吸收手势速度、`velocity` 缺省注入当前值速度——「拖拽跟手 → 松手弹簧」在库内就是一条连续曲线(调研 10§7.3,motion.dev 一手文档);
- **vaul 底部抽屉**(sonner 同一作者):释放速度阈值 0.4、进度 25% 判定「放走还是拉回」,过渡用 transform 0.5s cubic-bezier(0.32, 0.72, 0, 1)——速度接力在开源组件里的完整落地(调研 10§5.1,源码逐字核验);
- **SwiftUI 弹簧接力**:官方文档写明连续 spring 动画接力时保留速度——iOS 系统交互(列表回弹、抽屉)跟手感的底层保证(调研 04§1.3,Apple 文档 JSON 端点实抓)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `stiffness` | ω₀↑:回程更猛、到位更快;同一 ζ 下过冲比例不变(调研 10§6.3) | 回程迟缓;极低 k 配高阻尼像在泥里爬回目标 |
| `damping` | ζ↑:波次更少、过冲指数式下降,ζ=1 临界最快无过冲复位 | ζ↓:快甩后来回弹跳;ζ\<0.4 时大速度会失控过冲(巧思 3) |
| `handoff` | on:快甩慢推各有归途,「跟手」延续到落定 | off:一切释放一个样——演示反例用,生产禁用 |

选型口诀:接力 = 位置 + 速度一起交;k/c 先算 ζ(微弹守 0.7±0.1)再决定收多少速度;抽屉类先过速度阈值再交给弹簧(vaul 范式);永远不要让固定时长缓动接管释放。
