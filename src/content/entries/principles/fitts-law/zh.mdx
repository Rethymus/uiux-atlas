## 结构与 DOM

演示是三个角色:一个**起点按钮**、一个**目标按钮**、一块捕获脱靶的舞台层。目标的位置与尺寸完全由两个参数(经 CSS 变量)驱动:

```html
<div class="ft-field" data-phase="idle">
  <button class="ft-start">起点 Start</button>
  <button class="ft-target">目标 Target</button>
  <span class="ft-miss">MISS</span>
</div>
```

关键点:

- 起点固定在左下,目标按 `--ft-distance` 从起点右侧偏移、按 `--ft-size` 决定边长——两个变量一改,实验条件立刻改变;
- 舞台层兜住「点在目标之外」的点击,计入 miss——Fitts 的另一半结论正是**快速动作 × 小目标 → 高错误率**(speed-accuracy trade-off);
- 起点与目标都是真实 `<button>`,可 Tab 聚焦、Enter/Space 激活(键位惯例见 keyboard-navigation 条目)。

## 样式与参数

```css
.demo-stage {
  --ft-size: 48px;      /* 目标边长,默认 = M3 触控目标 48dp(调研 04§2.1) */
  --ft-distance: 160px; /* 起点→目标的水平间隙 */
}
.ft-target {
  width: var(--ft-size);
  height: var(--ft-size);
  left: calc(20px + 150px + var(--ft-distance));
}
```

数值出处:

- `size` 默认 **48px**:M3 Switch 规格中的 target 48dp(调研 04§2.1);lawsofux 指导原文为「触控目标要足够大、间距充足、放在容易获取的区域」;
- WCAG 2.2 SC 2.5.8(AA)的法定下限是 24×24 CSS px——比 48px 宽松得多,demo 把范围开到 16px 是为了让人**亲眼看违法后果**;
- 演示顶部实时计算 Shannon 形式难度指数 **ID = log₂(2D/W)**:D 为距离、W 为目标宽度——这是 Fitts 定律的标准量化形式,demo 用水平边距近似幅度 D。

## 动效与交互

- 点击「起点」→ 目标开始 **1.2s 脉冲光晕**(box-shadow 扩散,合成器友好的循环动画),提示「现在是瞄准态」并开始计时;
- 命中目标 → 计时停止,成绩写入右侧面板的「最近成绩」列表(最多 4 条),目标回到静默态;
- 瞄准态中点在目标之外 → `MISS ✕` 闪现(0.5s)并累计脱靶数;计时**不中断**,脱靶本身就是实验数据;
- 改动 size / distance 不打断当前轮——参数面板与实验实时联动;
- `prefers-reduced-motion: reduce` 时取消脉冲光晕与 MISS 闪动,计时逻辑不受影响。

## 真实产品案例

- **Material 3 的触控目标**:M3 在 Switch 等控件规格中明确规定 target 48dp——点击热区远大于可视的 track(52×32dp),是 Fitts「目标做大」最成体系的落地(调研 04§2.1);
- **移动端大按钮惯例**:lawsofux 明确指出该定律「直接催生了把交互按钮做大(尤其在手指操作的移动设备上)」的惯例——今天 iOS/Android 主操作按钮的尺寸共识都源于此(调研 07§22);
- **销毁类操作的「反向 Fitts」**:把危险按钮做小、放远(远离高频点击热区),利用同一提高获取成本来防止误触,是定律的合法反向运用(07§22 指导:注意区与按钮距离尽量短的反面)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `size` | 命中变容易,耗时与脱靶同步下降;96px 已接近「整块区域」,实验失去区分度 | ID 指数上升,耗时变长;≤24px 触及 WCAG 2.2 SC 2.5.8 法定下限;16px 时脱靶率肉眼可见地上升 |
| `distance` | 手臂移动路径变长,耗时上升——符合 Fitts 1954 原始结论 | 接近 60px 时两个按钮几乎贴身,实验退化为「就近点一下」 |

经验区间:生产触控目标 44–48px 级(M3 target 48dp 为参照);WCAG 法定下限 24px;demo 的 ID 读数在 1–4 bit 区间最能拉开手感差异——同一个 ID 值下,「又小又近」与「又大又远」的耗时接近,这正是公式的含义。
