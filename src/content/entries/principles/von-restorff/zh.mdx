## 结构与 DOM

演示是一个**异类记忆测试**:网格展示 2.5s(恰有一个异类)→ 全部遮罩 → 点出异类位置 → 按线索累计正确率:

```html
<div class="vr-grid">
  <button class="vr-tile" data-odd="true" data-cue="color"></button> <!-- 异类 -->
  <button class="vr-tile" data-masked="true"></button>              <!-- 遮罩后全部同貌 -->
  <!-- ×n -->
</div>
```

关键点:

- 展示期只有异类块获得 `data-odd="true"`;遮罩后所有块视觉等同——**位置信息只能来自记忆**,测的就是隔离效应;
- 三种线索可切换:color(强调色)/ shape(圆形 vs 方形)/ motion(1.4s 慢脉冲);
- 正确率按线索分组统计——同一效应在不同线索下的强度对比,是 demo 的核心读数。

## 样式与参数

```css
.vr-tile[data-odd="true"][data-cue="motion"] { animation: vr-pulse 1.4s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) {
  .vr-tile[data-odd="true"][data-cue="motion"] {
    animation: none;
    outline: 3px solid oklch(0.58 0.17 300); /* 动效强调退化为描边强调 */
  }
}
```

- `tiles` 默认 **12**、`cue` 默认 color;SHOW_MS = 2500(demo 选择,非定律数值);
- 1.4s 慢脉冲换算约 0.7 次/秒,远低于 WCAG SC 2.3.1 的 3 次/秒闪烁阈值;reduced-motion 下退化为 3px 描边——**信号不消失,只是换了通道**;
- shape 线索刻意用「圆形 vs 圆角方块」,不依赖色觉——07§30「不要只靠颜色做对比」。

## 动效与交互

- 展示/遮罩是离散切换,无过渡——「看见什么」不该被动画模糊;
- 应答后立即显示 ✔/✕,1.2s 后自动进入下一轮;错误不打断流程;
- motion 线索的脉冲只动 `transform: scale`(合成器属性);reduced-motion 降级路径已在 CSS 内声明;
- 每轮异类位置随机(Math.random,demo 随机源,非安全用途)。

## 真实产品案例

- **每屏一个 Primary 按钮**:IBM Carbon 明确「每屏一个 primary」(调研 07§2),即页面只保留一个异类——07§30「强调要有节制,避免互相争夺」的组件级兑现;主按钮的强调色块就是整页最显眼的隔离项;
- **Google 搜索结果页的广告标注**:广告卡片整体形状/底色与自然结果不同,又保持克制(仅微妙差异)——lawsofux 原文告诫强调「不要被误认为广告」的另一半:广告自己也在用隔离效应抢记忆;
- **表单里的必填标记**:必填项用红色星号 + 必填文字(双通道),在一片灰色表单里成为可扫描的异类(编辑性泛例,呼应 07§30「不要只靠颜色」)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `tiles` | 16 块时背景相似度更高,异类更突出,但定位更难 | 6 块时任务过易,效应读数不敏感 |
| `cue` | motion 是最抢眼的线索,但对运动敏感用户不友好(reduced-motion 自动降级) | color 依赖色觉;shape 是色觉安全的通道——三者统计对比就是 demo 的教学结论 |
| SHOW_MS(固定) | 2.5s 是「看得清但记不牢」的教学窗口;更长会掩盖个体差异 | — |

经验结论:异类的价值 = 稀缺度 × 通道数;**同时只允许一个异类**——多个元素同时「不一样」等于没有异类;负面的异类(报错、警示)记得更牢,更要省着用。
