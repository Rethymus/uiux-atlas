## 结构与 DOM

24px 图标栅格是一张**创作期底图**:画布 24×24(修剪区 trim area),内容限制在活动区(live area),四条官方键程负责视觉重量。demo 用一张 SVG 同时画网格、活动区与键程参考线,示例图形叠加其上:

```html
<svg viewBox="0 0 24 24" width="192" height="192">
  <!-- 网格线(设计期参考,交付时删除) -->
  <g stroke="#94a3b8" stroke-width="0.125">
    <line x1="1" y1="0" x2="1" y2="24" /> <!-- …每 1 单位一条 -->
  </g>
  <!-- 活动区:24-2×2 = 20×20 -->
  <rect x="2" y="2" width="20" height="20" fill="none"
        stroke="#2563eb" stroke-dasharray="0.375 0.25"/>
  <!-- 键程:方形 18×18 / 圆形 Ø20 / 长方 20×16 与 16×20 -->
  <rect x="3" y="3" width="18" height="18" fill="none" stroke="#ea580c"/>
  <circle cx="12" cy="12" r="10" fill="none" stroke="#16a34a"/>
  <!-- 图形本体 -->
  <path d="…" fill="none" stroke="#0f172a" stroke-width="2"/>
</svg>
```

关键点:

- 参考线是**设计期工具**,交付 SVG 只含图形本体;
- demo 以 8 倍整数缩放渲染(1 单位 = 8px),0.125 单位描边恰好渲染 1px 细线;
- 示例「图片」图标是 24 网格原稿,切换网格档时按 `scale(gridSize/24)` 等比缩放示意——**官方做法是换档独立重绘**,缩放演示仅用于对照(见下文)。

## 样式与参数

两个参数均为 JS 型(几何重算),demo 内换算关系如下:

```text
live  = gridSize − 2×padding        // 24 档官方:24 − 4 = 20
square = live − 2                    // 方形键程:20 − 2 = 18(官方)
circle = live                        // 圆形键程:Ø20(官方)
landscape = live × (live − 4)        // 横长方:20 × 16(官方)
portrait  = (live − 4) × live        // 竖长方:16 × 20(官方)
```

数值出处(m2.material.io system-icons,调研 07 §2 逐条原文):

- 展示区 **24×24 dp**;密集布局缩至 **20dp**;
- 活动区 **20×20 dp**,四周 **2dp padding**;密集活动区 **16×16**;
- 键程:方形 **18×18**、圆形 **直径 20**、竖长方 **16×20**、横长方 **20×16**;
- X/Y 必须**整数**("on pixel");圆角默认 **2dp**,≤2dp 宽的形状转角不倒圆;
- 内容可伸入 padding 换视觉重量,**绝不可出修剪区**。

官方模板源文件:官方栅格模板 AI(Apache 2.0,07 §2)。

## 动效与交互

栅格是静态底图,demo 的交互只在参数切换上:

- **gridSize 切换**:SVG `viewBox` 重算,画布 16/20/24/32 档全部按 8px/单位渲染——视觉尺寸随档位放大,展示「换尺寸档」与「等比缩放」的区别;
- **padding 拖动**:活动区蓝色虚线实时重排,padding 走廊(画布浅灰底)直观呈现;调到 0 时活动区吃满修剪区;
- 参考线与图例均标 `aria-hidden` / 供验收;读数行 `aria-live="polite"` 播报当前键程值;
- 无动效依赖,`prefers-reduced-motion` 无需降级。

## 真实产品案例

- **Material 官方键程模板**:m2.material.io system-icons 定义了上表全部数值,并提供官方栅格模板 AI 源文件下载(Apache 2.0)——「圆比方大 2dp」是写进官方规范的硬数值,不是视觉玄学(07 §2/§3.1);
- **Heroicons 三档独立重绘**:24 / 20 / 16 三档各有独立 viewBox(仓库真实文件实测),官方路线是「换档重画」而非缩放 24 图(07 §1.3);
- **Material Symbols 的像素对齐边界**:opsz 轴默认 24,且**仅 20px 与 24px 版本做了完美像素栅格对齐**——连 Google 也只在两档上守住整数坐标(07 §1.5)。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `gridSize` | 32 档键程全部放大(推导值),细节余量更多;但无官方锚值,跨集对齐失效 | 16 档笔画间距骤减——Lucide 要求相邻元素间隙 ≥2px、镂空塞得进 2px 圆,小网格更难满足(07 §3.2) |
| `padding` | 走廊收窄(0-2),图形顶到画布边,呼吸感消失;官方允许内容伸入 padding 换重量但不可出修剪区 | padding=2 是官方默认;再往上(3-4)活动区骤缩,方形键程被压到 live−2 以下,图标显小 |

锚点:24 档 + padding 2 = 官方基准;20 档 + padding 2 = 密集布局官方值(活动区 16);其余组合是推导演示,交付前按官方路线独立重绘。
