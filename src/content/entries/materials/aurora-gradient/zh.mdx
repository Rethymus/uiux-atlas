## 结构与 DOM

极光层是「**光斑叠层 + 整层滤镜**」两层结构:光斑全部画在一个容器的多层 `background` 上,模糊/饱和/漂移只作用于这个容器,内容(文字卡)独立在其上。整体外扩 `inset:-25%`,漂移时边缘不露底:

```html
<div class="stage">            <!-- 场景,overflow:hidden -->
  <div class="aurora"></div>   <!-- 光斑层:多层 background + filter + 动画 -->
  <div class="card">…</div>    <!-- 内容层:普通文档流 -->
</div>
```

关键点:

- 光斑是 `radial-gradient` 多层叠加(MDN:渐变是 `<image>`,`background` 可叠多层);第 4 个光斑单独放一个覆盖层,便于 3/4 数量切换;
- 滤镜作用在**整层**而不是逐光斑——一次重采样,成本可控;
- 光斑亮度(L)钉在 0.6–0.75:能发光,又不至于把上层文字对比度打穿(CodeFronts 调参心法)。

## 样式与参数

六个参数中四个落在整层容器上,两个落在光斑位置:

```css
.aurora {
  position: absolute;
  inset: -25%;                       /* 外扩,漂移不露边 */
  background:
    radial-gradient(38% 42% at var(--aurora-spot-a) 25%,
      oklch(0.6 0.24 300 / .85), transparent 68%),        /* 光斑 A:CodeFronts 原值 */
    radial-gradient(42% 46% at var(--aurora-spot-b) 30%,
      oklch(0.72 0.17 195 / .8), transparent 68%),        /* 光斑 B */
    radial-gradient(50% 55% at 78% 72%,
      oklch(0.68 0.18 340 / .8), transparent 68%),        /* 光斑 C */
    conic-gradient(from 220deg at 60% 45%,               /* 1 层 conic 底色 */
      oklch(0.35 0.06 265), oklch(0.3 0.05 210), oklch(0.35 0.06 265));
  filter: blur(var(--aurora-blur)) saturate(calc(var(--aurora-saturate) / 100));
  animation: aurora-drift var(--aurora-drift, 18s) ease-in-out alternate infinite;
}
@keyframes aurora-drift {
  from { transform: translate(-2%, -1%) rotate(0.001deg) scale(1); }
  to   { transform: translate(2%, 1%) rotate(2deg) scale(1.06); }
}
/* 光斑 D 放在滤镜容器内的独立子层,3 光斑档时 display:none */
.aurora .blob-d { position: absolute; inset: 0;
  background: radial-gradient(45% 50% at 32% 88%, oklch(0.75 0.15 85 / .75), transparent 68%); }
[data-spots="3"] .blob-d { display: none; }
```

数值出处:

- 4 光斑 + conic 底、`inset:-25%`、`blur(42px) saturate(1.15)`、只动 transform、reduced-motion 停用——全部为 CodeFronts 配方原文(调研 06§14);首光斑 `38% 42% at 20% 25%` 同源;
- 「改 `at x% y%` 即 mesh 编辑器」的玩法来自 MDN 渐变指南 + CodeFronts 共同表述(调研 06§14);
- 漂移默认 18s 为本批任务规格给定的演示档;**CodeFronts 配方原文是 60s**——氛围背景建议 60s 级,已写入参数 effect;
- 光斑 B–D 的位置与色相为按「L 0.6–0.75」约束布置的演示值(调研只逐值记载了首光斑)。

## 动效与交互

动画只有一条规则:**只动整层的 transform**:

- `translate + rotate + scale` 全是合成器属性,blur 结果不重采样(滤镜作用在层上,层的变换由合成器执行),60s 级慢漂几乎不占主线程;
- `ease-in-out alternate infinite` 让漂移无接缝;换 `steps` 或快时长会变成「呼吸闪烁」,违背氛围光的定位;
- **`prefers-reduced-motion: reduce` 时 `animation: none` 直出静止终态**(demo 已实现)——静止的极光层依然成立;
- blur/saturate 参数变更触发整层重绘,属编辑期操作,可接受;不要在生产中高频动画 filter 值本身。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `spots`(3/4) | 4 光斑时色彩层次最满,也是配方原文 | 3 光斑省一层重采样,构图变素;再少(&lt;3)失去「极光」的多色交织感 |
| `blur` | 光斑边缘彻底融化,极光感最强;>80px 后色彩被洗淡,要靠 saturate 补 | 光斑显形为清晰色球;&lt;20px 出现硬边,配方失去「氛围」而变成「彩色聚光灯」 |
| `saturate` | 颜色浓烈,>140% 在暗底上开始「荧光」 | 回到渐变本色;100%(不提饱和)时 blur 洗出的灰感最重 |
| `drift` | 漂移越慢越接近「环境光」(60s 级) | 快于 6s 变成可见的来回晃动,注意力被背景抢走;0 = 静止 |
| `spotA`/`spotB` | 两个可调光斑向边缘移动时中部变空 | 两斑靠近会叠加成过亮热区,压过文字;保持对角错开 |
| (固定值) | — | 光斑 L 一旦突破 0.75,上层 4.5:1 文字对比度开始失守 |

最后两条结构提醒:光斑层必须 `aria-hidden`(或留空语义),它是装饰而非内容;上层文字卡要独立于滤镜容器,否则会被一并模糊。
