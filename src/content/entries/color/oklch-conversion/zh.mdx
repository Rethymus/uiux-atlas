## 结构与 DOM

demo 是一条**转换流水线**:输入一个 sRGB hex,面板与 demo 共享该参数,页面内把五段转换逐级跑完,每个中间值都可见:

```html
<ol class="ok-chain">
  <li><span>sRGB 8bit</span><code>255, 0, 0</code></li>
  <li><span>线性 sRGB(γ 解码)</span><code>1.0000, 0.0000, 0.0000</code></li>
  <li><span>LMS(矩阵①)</span><code>1.0000, 0.0000, 0.0000</code></li>
  <li><span>LMS′(立方根)</span><code>1.0000, 0.0000, 0.0000</code></li>
  <li><span>OKLab(矩阵②)</span><code>0.6280, 0.2249, 0.1258</code></li>
  <li><span>OKLCH(柱坐标)</span><code>L 0.628 · C 0.2577 · H 29.23°</code></li>
</ol>
```

关键点:

- 五段顺序固定:**γ 解码 → 矩阵①(线性 sRGB→LMS)→ 逐通道立方根 → 矩阵②(LMS′→OKLab)→ 柱坐标(√、atan2)**——顺序颠倒结果全错;
- demo 同时跑**反向链**回 sRGB 并显示最大往返误差(参考实现 6.7e-7);
- 每级一个小色样,「这一步还像不像原来的颜色」一眼可查。

## 样式与参数

唯一参数 `source`(hex,cssVar `--ok-source`)由面板注入;全部数学在 demo 内零依赖实现。公式逐步(调研 14§2.1/§2.2/§2.4,16 个矩阵常数逐位核对自 Bottosson 原文与 CSS Color 4):

**① γ 解码(sRGB EOTF,CSS Color 4 / WCAG 2.1 同一口径):**

```js
const srgb2lin = c => (c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4);
const lin2srgb = c => (c <= 0.0031308 ? c * 12.92 : 1.055 * Math.cbrt(c * c * c) - 0.055);
```

注:WCAG 2.1 官方注 2 明确 2021-05 前阈值是 0.03928(取自旧规范),已更新为 0.04045,实际计算无差别。

**② 正向链(两个 3×3 矩阵 + 立方根):**

```js
function srgbToOklab(r, g, b) {
  [r, g, b] = [srgb2lin(r), srgb2lin(g), srgb2lin(b)];
  const l = 0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b;   // 矩阵①
  const m = 0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b;
  const s = 0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b;
  const [l_, m_, s_] = [Math.cbrt(l), Math.cbrt(m), Math.cbrt(s)];    // 逐通道立方根
  return [0.2104542553*l_ + 0.7936177850*m_ - 0.0040720468*s_,        // 矩阵②
          1.9779984951*l_ - 2.4285922050*m_ + 0.4505937099*s_,
          0.0259040371*l_ + 0.7827717662*m_ - 0.8086757660*s_];
}
// OKLab → OKLCH:C = √(a²+b²);H = atan2(b,a)×180/π(负角 +360;C≤4e-6 时 H 置 NaN)
```

**③ 反向链(LMS′ 方向相反的矩阵 + 立方):**

```js
function oklabToSrgb(L, a, b) {
  const l_ = L + 0.3963377774*a + 0.2158037573*b,
        m_ = L - 0.1055613458*a - 0.0638541728*b,
        s_ = L - 0.0894841775*a - 1.2914855480*b;
  const [l, m, s] = [l_**3, m_**3, s_**3];
  return [4.0767416621*l - 3.3077115913*m + 0.2309699292*s,
         -1.2684380046*l + 2.6097574011*m - 0.3413193965*s,
         -0.0041960863*l - 0.7034186147*m + 1.7076147010*s].map(lin2srgb);
}
```

核验输出(实跑):白→OKLab (1, 0, 0) ✓;纯红→OKLab (0.628, 0.2249, 0.1258)、OKLCH (0.628, 0.2577, 29.234)——与 Bottosson 论文发布值 (0.6279554, 0.2248636, 0.1258463) 及 color.js 测试值一致;sRGB→OKLab→sRGB 最大往返误差 **6.7e-7**。

## 动效与交互

- **换色即换链**:面板换 `source`(或点 demo 内参考色片:白 / 纯红 / AA 灰 #767676),六行中间值逐级刷新,色样条同步;
- **自证实验**:拨到白色一行行读——线性 sRGB 是 (1,0,0),矩阵①后仍是 (1,0,0),OKLab (1,0,0)、C=0(灰色无色相,H 置 NaN)——中性轴全程不动,这是矩阵正交性的直观证据;
- **往返对账**:demo 每次都把 OKLab 送回 sRGB 并显示 max|Δchannel|,数值永远在 10⁻⁷ 量级(浮点噪声),肉眼不可能分辨;
- 无自主动画;入场淡入尊重 `prefers-reduced-motion`。

## 真实产品案例

- **CSS Color 4 / 浏览器 oklch() 实现**:规范第 13 章把同一条 XYZ(D65)→LMS→OKLab 链(64 位重算矩阵)写成 normative 算法,Chrome/Safari/Firefox 的 oklch() 解析都落到这条链——本条公式就是浏览器内建函数的手工版;
- **Bottosson 参考实现与 color.js**:作者 C++ 代码(逐位核对基准)与 color.js 测试向量对纯红的期望值 (0.6279554, 0.2248636, 0.1258463) 与本实现输出在前四位一致——开源色彩库的黄金样本;
- **Tailwind CSS v4 色板**(对照样本):官方博客说明 v4 全部色阶改为 OKLCH 定义、构建期从 OKLCH 派生 sRGB 与 P3 兼容值——正是「先 OKLCH 后 sRGB」生产化的代表(社区报道口径,调研未抓取其源码,过程方法已由本条公式核验)。

## 公式的量纲与边界

| 变量 | 量纲 | 取值边界 | 退化情形 |
| --- | --- | --- | --- |
| sRGB 输入 | 8bit 整数或 [0,1] 实数 | [0,255] / [0,1];α 不参与矩阵 | 负值或 >255 未定义——先钳制;超界输入静默出假色 |
| 线性 sRGB | 线性光强(无单位实数) | [0,1](合法域内) | γ 解码分段点:c≤0.04045 走直线段;两侧在断点处连续 |
| LMS | 长波/中波/短波视锥响应(无单位) | 合法 sRGB 域内约 [0,1];可暂为负(超色域) | 负 LMS = 超出 sRGB 色域,立方根对负值仍可算(cbrt 保号),但交付前必须裁剪 |
| OKLab L | 感知明度(无单位) | 合法域 [0,1];矩阵输出可略越界 | L=0/1 是黑/白锚点;全灰轴上 a=b≈0 |
| OKLab a、b | 感知色度分量(无单位) | 典型 ±0.4 内 | a=b=0 → 无彩色;C=√(a²+b²)≤4e-6 时 H 置 NaN(除零保护) |
| C(HSLCH) | 感知彩度(无单位) | 0–0.4 实务;sRGB 色域内随 L 有上限 | C=0 → 灰色,H 任意(未定义),实现置 NaN 而非 0 |
| H(OKLCH) | 角度(度) | [0,360);atan2 值域 (−180,180] 负角 +360 | 灰色 H 无意义;跨 0°/360° 插值需短弧修正(见 gradient-interpolation) |
| 反向输出 | sRGB [0,1] | 合法域 [0,1] | 超界(负/过亮)= 目标 OKLCH 超出 sRGB 色域,裁剪后量化到 8bit |
| 往返误差 | 通道最大绝对差 | ≤6.7e-7(参考实现实测) | 仅浮点噪声;若出现 1e-3 量级说明常数抄错 |

经验口径:**先 OKLCH 后 sRGB**——感知域插值/选色,交付前回 sRGB(或同时交 P3);γ 解码与 WCAG 相对亮度共用,一套代码两处复用。姊妹条目:**oklch-workflow**(固定 L 的选色工作流)、**oklch-space**(空间本身)、**wcag-contrast**(γ 解码的第二个消费者)、**gradient-interpolation**(H 短弧插值)。
