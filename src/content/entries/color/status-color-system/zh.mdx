## 结构与 DOM

四态同构,每态恰好三个语义变量:**底**(--st-bg)、**边**(--st-border)、**字**(--st-fg)——组件只消费这三件,换态只换变量:

```html
<div class="alert" role="status" style="--st-bg:…; --st-border:…; --st-fg:…">
  <span class="icon" aria-hidden="true"></span>
  <span class="body"><b>标题</b><span>正文</span></span>
</div>
```

```css
.alert {
  background: var(--st-bg);
  border: 1px solid var(--st-border); /* 传达状态语义 → 受 SC 1.4.11 的 3:1 约束 */
  color: var(--st-fg);
}
```

关键点:

- 三件套全部从**该态自己的色相**派生(同 h 不同 L/C),档位关系是函数关系,四态天然同构(Radix 12 步「底 1–3 / 边 6–8 / 字 11–12」的独立档位结构,调研 06§8);
- 状态语义必须**冗余编码**:图标 + 文字与颜色并行,红绿色盲用户依赖明度差与图形(色盲复核,调研 06§19);
- 图标描边用 `currentColor` 跟随文字色,天然与文字同过一道闸。

## 样式与参数

五个参数全为 JS 型(四态色相 + 共用文字明度),demo 订阅后整组重算:

```css
/* 三件套常量(本会话离线标定,四态全过 AA) */
.alert {
  --st-bg: oklch(0.97 0.04 140);      /* 淡底:L=0.97 / C=0.04 */
  --st-border: oklch(0.6 0.17 140);   /* 状态边:L=0.6 / C=0.17 */
  --st-fg: oklch(0.45 0.13 140);      /* 状态字:L=0.45 / C=0.13 */
}
```

数值出处:

- 四态默认色相取 Evil Martians oklch 色相映射:红≈20°、黄≈90°、绿≈140°、蓝≈220°(调研 06§2);
- L/C 常量为本会话标定值:底 L=0.97/C=0.04、字 L=0.45/C=0.13、边 L=0.6/C=0.17——四态文字/底实测 **6.17–6.97:1**、边框/底实测 **3.20–3.76:1**,全过两道闸;此为标定结果,非官方配方;
- 官方锚点:M3 error 基线 `#B3261E`(调研 06§7,本会话实测配白字 6.54:1)、M3 的 error / error-container + on 配对同构「底 + 字」思路;
- 阈值:正文 AA≥4.5:1、AAA≥7:1、大字减半;状态边框≥3:1(SC 1.4.11,仅默认状态,调研 06§17)。

## 动效与交互

- 拖动色相滑杆,四态三件套整组随动(0.2s ease 过渡);`prefers-reduced-motion` 时取消;
- **文字明度滑杆是校准台**:L 从 0.45 往上调,徽标逐态从 ✓ 翻 ✗——阈值行为(4.499:1 不达标、不四舍五入)当场可见;
- 徽标判定即时刷新,不给过渡动画——判定突变不该被平滑掩盖;
- 入场动画只动 `opacity/transform`,70ms 逐条递进,`prefers-reduced-motion` 时取消。

## 真实产品案例

- **Radix Colors**:12 步结构本身就是状态/组件色的工业配方——底(1–3)、边(6–8)、字(11–12)分档,步 11/12 在步 2 背景上保 APCA Lc60/90(Radix 官方,调研 06§8);
- **Material 3 error 角色**:error `#B3261E` / error-container 官方基线给出「实底 + 容器底」两档状态表达(Android 开发者文档,调研 06§7);
- **GitHub Primer**:提供 light/dark-colorblind 等 4 套色盲主题,把红绿轴状态信息重映射(调研 06§10/§19)——状态色系统的色盲冗余在大型产品的实装。

## 参数敏感度

| 参数 | 调大会… | 调小会… |
| --- | --- | --- |
| `hueSuccess` 等四色相 | 色相平移但结构不变;向邻态色相靠拢时视觉可辨识度下降(如 warning→橙、danger→品红) | 同理反向;四态互相撞色时先检查色相间隔 |
| `textLightness` | 文字变浅、对比下滑:0.5 附近逐态逼近 4.5:1,继续调高 ✗ 徽标成片出现 | 文字变深、对比上升(趋向 AAA 7:1);过低时字色发黑、色相感减弱 |
| (演示常量)底 C=0.04 | 底更浓则文字对比下降——「底越浓、字越难守 AA」 | 底趋近白,对比全线上浮,但状态感减弱 |

经验:三件套一起标定、一起复核;任何一态改值,四道闸(4×文字 + 4×边框)整组重跑;红绿两态必须补色盲复核(明度差/图标冗余,调研 06§19)。
