流式字阶 Fluid Type Scale

流式字阶 · Utopia 字阶 · clamp() 字阶

字号随视口在断点之间线性插值:clamp(下限, rem+vw, 上限) 生成 --step-0..5 字阶,小屏不小于下限、大屏不超过上限,中间平滑缩放。

Web 标准 ★★★
实例演示 官方默认
参数
几何▾
minViewport480px
px

插值起点视口宽度:低于它,字号停在每级 clamp 的 min 值。斜率 =(max−min)/(maxVw−minVw) 以此为分母起点。默认 480px 为本条目任务规格取值;调研 05§13 的 Utopia 实测输出样本反推其默认约 360px(Utopia 未直接记录视口默认值,两说并列)。

maxViewport1440px
px

插值终点视口宽度:高于它,字号停在每级 clamp 的 max 值。默认 1440px 为任务规格取值;Utopia 输出样本反推约 1240px(未直接记录,两说并列)。区间越宽斜率越缓,桌面端缩放越不明显。

minSize1rem
rem

--step-0 的下限字号,也是字阶基准(正文下限)。默认 1rem(=16px 根字号)是常见正文基准;Utopia 实测样本用 1.125rem。以 rem 计价保证浏览器字号设置与页面缩放仍然生效。

maxSize1.25rem
rem

--step-0 的上限字号(大视口下的正文尺寸)。默认 1.25rem 与 Utopia 实测输出 --step-0 的 max 值一致(调研 05§13 一手核对)。

ratio1.25

模数比率:每升一级 step 同时乘到该级 min 与 max 上(min/ratio 同向放大)。默认 1.25 是 Utopia 可选比率之一(modularscale 记作 4:5 大三度,调研 05§13/§17)。Utopia 支持最小/最大两侧各设比率(其样本为 1.2/1.25),本条目简化为单比率双乘。

代码拆解

结构与 DOM

流式字阶不需要任何额外 DOM——它是一层 CSS 自定义属性令牌:在 :root 上定义 --step-0..5,组件按语义取用。

<body>
  <h1 class="step-5">标题随视口伸缩</h1>
  <p class="step-0">正文保持基准字号。</p>
</body>
:root {
  --step-0: clamp(1rem, 0.875rem + 0.4167vw, 1.25rem);
  --step-1: clamp(1.25rem, 1.0938rem + 0.5208vw, 1.5625rem);
  /* … --step-2..5 同法生成 */
}

关键点:

  • 视口区间 minViewport/maxViewport 与字号区间 minSize/maxSize 是两条平行刻度:斜率 =(max−min)÷(maxVw−minVw),视口按 16px 根字号折成 rem;
  • 每升一级,该级的 min 与 max 都乘一次比率 ratio(Utopia 支持两侧各设比率,本条目简化为单比率);
  • 生成的 clamp 值精度取 4 位小数,与 Utopia 输出一致。

样式与参数

五个参数全部为 JS 型(无 cssVar):demo 订阅参数面板后按上述公式实时重算,把 --step-0..5 写进预览区,同时展示生成代码。

/* demo 默认参数生成:480px→1440px,1rem→1.25rem,比率 1.25 */
:root {
  --step-0: clamp(1rem, 0.875rem + 0.4167vw, 1.25rem);
  --step-5: clamp(3.0518rem, 2.6703rem + 1.2716vw, 3.8147rem);
}
h1  { font-size: var(--step-5); line-height: 1.05; }  /* 标题收紧行高 */
h2  { font-size: var(--step-3); line-height: 1.15; }
p   { font-size: var(--step-0); line-height: 1.6; }   /* 正文 ≥1.5(WCAG 1.4.12) */

数值出处:

  • 公式与输出形态 = Utopia 流式字阶生成器(调研 05§13 一手实测输出:--step-0: clamp(1.125rem, 1.0739rem + 0.2273vw, 1.25rem),demo 公式按同一输入可逐字复现该输出);
  • 比率 1.25 = Utopia 可选比率、modularscale 记作 4:5 大三度(调研 05§13/§17);
  • maxSize 默认 1.25rem 与上列 Utopia 样本的 max 值一致;minViewport/maxViewport 默认 480/1440px 为本条目任务规格取值,由 Utopia 样本反推的官方默认约 360/1240px(未直接记录,两说并列)。

动效与交互

字阶是静态令牌,「动」只发生在视口变化时:

  • 视口连续缩放时 clamp 输出连续变化,无跳变、无过渡动画——不需要 transition;
  • demo 中拖「模拟视口」滑杆与拖浏览器窗口等效,右侧 px 徽标按同一公式换算,便于在固定窗口里观察两端区间;
  • 无 prefers-reduced-motion 相关降级需求(本条目不产生任何动画)。

参数敏感度

参数调大会…调小会…
minViewport整条曲线右移:小屏(如 375px)完全停在 min 值,移动端字阶变「死」插值更早开始,手机上就开始放大——min 值区变短
maxViewport斜率变缓,桌面端缩放更不明显、更晚到达上限斜率变陡,桌面端字级差异被放大,过早停在 max 值
minSize正文与全阶下限整体抬高,--step-0 相对 --step-5 更接近,对比减弱正文下限逼近 0.8rem,长文可读性下降,违反可读下限的常见实践
maxSize大屏正文变大,斜率变陡(clamp 跨度拉大),整阶视觉更「响」接近 minSize 时斜率趋零,字阶退化为静态;低于 minSize 则 clamp 语义倒挂(min 优先)
ratio高级别 step 呈指数放大,--step-5 迅速逼近 2× 上限,展示页风格趋近 1.1 时各 step 挤在一起,层级靠字重而非字号区分

经验区间:视口 360–1440px、正文 1–1.125rem 起、比率 1.2–1.333(Utopia 样本与 modularscale 常用档);正文两端差控制在 1–2 级,行高随级别收紧。

适用场景 4
  • 全站字阶:一套 --step-0..5 变量接管正文到 display 标题,断点之间不再跳变
  • 长文页与营销页标题随屏宽伸缩,替代成摞的媒体查询字号覆盖
  • hero/display 大字在移动端自动收敛到可读下限,不会撑破版心
  • 设计令牌层:与 Utopia 流式间距同构,组成整套流式设计系统
何时不要用 4
  • 纯 vw 字号(无 rem 下限)——用户放大系统字号无法补救,违反 WCAG 1.4.4 调整文本
  • 正文 --step-0 也大幅流式——正文两端差应控制在 1–2 级,否则小屏过大、大屏过小
  • 行高不随字阶收紧——大标题沿用正文行高会松散,正文行高低于 1.5 违反 WCAG 1.4.12
  • 视口区间取过宽(如 320–2560)——斜率被摊平,桌面端几乎看不到缩放,白做流式
无障碍

字号必须以 rem 计价并保留 rem 下限:纯 vw 字号会破坏 WCAG 2.1 SC 1.4.4(调整文本)与用户浏览器字号设置;clamp 的 min 写成 rem 即可在系统放大时跟随。WCAG 2.2 SC 1.4.12 Text Spacing 要求行高 ≥1.5× 字号、段落间距 ≥2× 字号(调研 05§18)——大字号梯级要相应收紧行高而非放大行距。

浏览器支持

clamp() 为 Baseline Widely available(自 2020-07 起,MDN,调研 05§12),三大引擎当前版本均支持;调研未记录分浏览器首发版本号,此处不作逐版本断言。 · Baseline Widely available (2020-07)

兼容回退

不支持 clamp() 的旧环境回退为级联两段声明:先写固定 font-size(如 1rem),再写 clamp() 声明——新浏览器以后者覆盖;或用 @supports (font-size: clamp(1rem, 1vw, 2rem)) 包裹全部流式规则,旧浏览器整组跳过,保留固定字阶。

来源 3

起源机制 = CSS clamp()(MDN 标注 Baseline Widely available 自 2020-07,调研 05§12);主流工作流 = Utopia 流式字阶生成器,输出 --step-N: clamp(rem, rem+vw, rem)(调研 05§13 一手实测输出);比率词表出自 Tim Brown modularscale 的模数标尺(调研 05§17)。
