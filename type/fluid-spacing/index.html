流式间距 Fluid Spacing

流式间距 · Utopia 间距 · 间距标尺

间距令牌也走 clamp:--space-3xs…3xl 沿视口线性伸缩,一端定值、中间插值,布局留白随屏宽呼吸而非断点跳变。

Web 标准 ★★

几何▾
minViewport480px
px

插值起点视口:低于它,各间距令牌停在 min 值。默认 480px 为本条目任务规格取值;由调研 05§14 Utopia 实测输出样本反推其默认约 360px(Utopia 未直接记录,两说并列)。

maxViewport1440px
px

插值终点视口:高于它,各间距令牌停在 max 值。默认 1440px 为任务规格取值;Utopia 样本反推约 1240px(未直接记录,两说并列)。间距的 max−min 跨度通常远小于字号,斜率天然更缓。

minSpace1.125rem
rem

基准间距(--space-s,倍数 1)的视口下限值。默认 1.125rem 直接取自 Utopia 实测输出样本的 --space-s min(调研 05§14 一手核对);其余令牌按倍数缩小(3xs=0.25×、2xs=0.5×、xs=0.75×)。

maxSpace1.25rem
rem

基准间距(--space-s)的视口上限值。默认 1.25rem 取自 Utopia 实测输出的 --space-s max(调研 05§14);大令牌(m=1.5×…3xl=6×)按倍数放大,3xl 在大视口下可达 7.5rem。

代码拆解

结构与 DOM

与流式字阶同构:无额外 DOM,一层 :root 级间距令牌。所有留白(padding/gap/margin)统一从令牌取值,这是流式间距成立的前提。

<section class="block">
  <div class="chips">…</div>
</section>
:root {
  --space-3xs: clamp(0.2813rem, 0.2656rem + 0.0521vw, 0.3125rem);
  --space-2xs: clamp(0.5625rem, 0.5313rem + 0.1042vw, 0.625rem);
  --space-s:   clamp(1.125rem, 1.0625rem + 0.2083vw, 1.25rem);
  --space-m:   clamp(1.6875rem, 1.5938rem + 0.3125vw, 1.875rem);
  --space-l:   clamp(2.25rem, 2.125rem + 0.4167vw, 2.5rem);
  /* … xl / 2xl / 3xl 同法生成 */
}

关键点:

  • 基准令牌 --space-s 在视口两端取 minSpace/maxSpace,其余令牌 = 基准 × 倍数,倍数梯 0.25/0.5/0.75/1/1.5/2/3/4/6(取自 Utopia 的 multipliers,调研 05§14);
  • 插值公式与字阶一致:斜率 =(max−min)÷(maxVw−minVw),视口按 16px 根字号折 rem;
  • 命名 3xs/2xs/xs/s/m/l/xl/2xl/3xl 沿用 Utopia 令牌名(调研 05§14 输出样本中的 —space-3xs/2xs/xs/s)。

样式与参数

四个参数全部 JS 型:demo 订阅面板后实时生成九条 clamp 令牌,写进样例卡片的 CSS 变量并排展示代码与条形图。

/* demo 默认参数生成:480px→1440px,1.125rem→1.25rem */
.block  { padding: var(--space-l); }
.chips  { gap: var(--space-m); }
.chip   { padding: var(--space-2xs) var(--space-s); }

数值出处:

  • minSpace 默认 1.125rem、maxSpace 默认 1.25rem = Utopia 实测输出 --space-s: clamp(1.125rem, 1.0739rem + 0.2273vw, 1.25rem) 的两端(调研 05§14 一手核对);demo 公式按其视口输入可逐字复现该输出;
  • minViewport/maxViewport 默认 480/1440px 为本条目任务规格取值;由 Utopia 样本反推的官方默认约 360/1240px(未直接记录,两说并列);
  • 差异声明:Utopia 官方串对个别令牌做独立舍入(其样本 —space-3xs 为静态定值),本条目实现为纯倍数插值,允许与官方输出相差末位小数。

动效与交互

间距是静态令牌,「动」只发生在视口变化时:

  • 视口连续变化时 clamp 输出连续变化,无跳变、无需 transition;
  • demo 条形图随「模拟视口宽度」滑杆即时伸缩,样例卡片的 padding/gap 由真实 clamp() 变量驱动,缩放浏览器窗口即可看到留白呼吸;
  • 本条目不产生动画,无 prefers-reduced-motion 降级需求。

参数敏感度

参数调大会…调小会…
minViewport曲线右移:小屏完全停在 min 值,移动端留白变「死」留白更早开始伸缩,手机上就开始呼吸——min 值区变短
maxViewport斜率变缓,桌面端留白变化更细微、更晚到达上限斜率变陡,大屏留白快速放大,过早停在 max 值
minSpace基准下限抬高,整条标尺上移,小屏留白更宽松、内容密度下降逼近 0.5rem 时微间距令牌(×0.25 后 0.125rem)小到失去分隔作用
maxSpace大屏留白变大、斜率变陡,展示页风格增强接近 minSpace 时斜率趋零,标尺退化为静态;低于 minSpace 则 clamp 语义倒挂(min 优先)

经验区间:基准间距 1.125–1.25rem(Utopia 样本)、视口 360–1440px;间距斜率应缓于字阶斜率,微间距令牌(3xs/2xs)建议保持静态或极小跨度。

适用场景 4
  • 区块留白:section padding 随视口在 24–40px 间呼吸,省掉一堆断点
  • 卡片内边距与栅格 gap:一套 --space-* 令牌同时驱动 padding/gap/margin
  • 与流式字阶同源生成,组成整套流式设计系统令牌
  • 阅读型页面:正文区间留白克制,展示区区间留白放大(m/l/xl 令牌)
何时不要用 4
  • 让 3xs/2xs 这类微间距也大幅流式——3–10px 的微间距两端几乎无差,白做插值
  • 间距斜率大过字阶斜率——留白比字号变得更快会让版面比例失衡
  • 随意手写间距值绕过令牌——流式令牌的前提是所有留白都走同一标尺
  • 在极宽视口(如 2560px+)继续放大留白——超过 maxViewport 后已是定值,无需更长区间
无障碍

间距影响可读性而非对比度:WCAG 2.2 SC 1.4.12 Text Spacing 要求用户覆盖行距/段距/字距时内容仍可用(行高 ≥1.5× 字号、段距 ≥2× 字号,调研 05§18)——流式间距令牌应允许被用户样式覆盖,不要写 !important;触控目标之间的间距随令牌缩小后仍须保证可点性,密集列表用 2xs 及以上。

浏览器支持

依赖 clamp():Baseline Widely available 自 2020-07(MDN,调研 05§12);spacing 令牌本身是普通自定义属性,无额外兼容性要求。调研未记录分浏览器首发版本,不作逐版本断言。 · Baseline Widely available (2020-07)

兼容回退

与流式字阶同理:先写固定间距(如 padding: 1rem),再写使用 clamp 令牌的声明,旧浏览器按级联回退;或把整套 --space-* 定义包进 @supports,失败时提供一份静态间距令牌。

来源 2

起源机制与流式字阶同构(clamp 线性插值);工作流 = Utopia 流式间距生成器,输出 --space-3xs… 令牌并支持倍数(0.75/0.5/0.25 与 1.5/2/3/4/6)派生间距标尺(调研 05§14 一手实测输出)。实测样本:--space-s: clamp(1.125rem, 1.0739rem + 0.2273vw, 1.25rem);--space-2xs: clamp(0.5625rem, 0.5369rem + 0.1136vw, 0.625rem)。
