模数倍率公式 Modular Scale Math

模数尺 · type scale · geometric scale · Utopia clamp

字阶的数学底座:size(n)=base×ratioⁿ 几何级数出层级、calc() 链式同轴缩放、Utopia 流体 clamp——斜率走 vw、截距藏 rem、两端钳制,一行 CSS 就是一段线性回归。

代码拆解

结构与 DOM

demo 是一部实时生成的字阶梯:从 step−1 到 step+steps,每级一行——预览字样按计算值真实渲染,右侧并排该级的 px 值与流体 clamp() 串:

<div class="ms-row">
  <span class="ms-label">step 1</span>
  <span class="ms-sample" style="font-size: 20px">Aa 字</span>
  <code class="ms-value">20px</code>
  <code class="ms-clamp">clamp(1.25rem, 1.179rem + 0.3125vw, 1.5625rem)</code>
</div>

关键点:

  • 阶梯是几何级数:size(n) = base × ratioⁿ,n 可为负(下行阶梯),一行公式生成全部档位;
  • 每级的 clamp() 串由同一套 minSize/maxSize/minVw/maxVw 推出——fluidClamp(min, max×ratio, 360, 1240),字阶与流体缩放共享一个 ratio;
  • 全部数值由零依赖 JS 在页面内实跑,无任何预设表。

样式与参数

五个 JS 型参数(base、ratio、steps、minViewport、maxViewport)全部由 demo 订阅 store 消费。三个公式层层递进:

① 几何级数(调研 14§1.2,Node 实跑核验:base=16, ratio=1.25 → 10.24, 12.8, 16, 20, 25 ✓):

const typeScale = (base, ratio, n) => base * Math.pow(ratio, n);      // n 可为负
const scaleGen  = (base, ratio, n) =>
  Array.from({ length: 2 * n + 1 }, (_, i) => base * Math.pow(ratio, i - n));

② calc() 链式同轴缩放——让字号/间距/行高全部跟随一个 --ratio 自乘(calc 乘法要求一侧必须是无单位数,CSS Values 4 §calc-serialize):

:root {
  --ratio: 1.25;
  --step-0: 1rem;
  --step-1: calc(var(--step-0) * var(--ratio));   /* 链式:每步乘一次比率 */
  --step-2: calc(var(--step-1) * var(--ratio));
  --step--1: calc(var(--step-0) / var(--ratio));  /* 负阶梯用除法 */
  --lh: calc(var(--step-0) * 1.5);                /* 行高同轴 */
}

③ Utopia 流体 clamp(调研 14§1.4,自 utopia.fyi 生产 bundle 反查还原,与页面输出逐字符一致):

数学形式:S(vw) = clamp(min, intercept + slope × vw, max),其中 slope = (max − min)/(maxVw − minVw)(px/px)、intercept = min − slope × minVw(px)。生产实现把两端折成 rem、斜率折成 vw:

function fluidClamp(minPx, maxPx, minVw, maxVw, remBase = 16, digits = 4) {
  const minRem = minPx / remBase, maxRem = maxPx / remBase;
  const slope = (maxRem - minRem) / ((maxVw - minVw) / remBase); // rem per vw
  const intercept = minRem - (minVw / remBase) * slope;          // rem
  const f = x => String(+x.toFixed(digits));
  return `clamp(${f(minRem)}rem, ${f(intercept)}rem + ${f(100 * slope)}vw, ${f(maxRem)}rem)`;
}
fluidClamp(18, 20, 360, 1240); // clamp(1.125rem, 1.0739rem + 0.2273vw, 1.25rem)

黄金样本(实跑,与 utopia.fyi 页面输出逐字符一致):fluidClamp(18, 20, 360, 1240) = 页面 step-0 ✓;fluidClamp(15, 16, 360, 1240) 同构 = 页面 step−1 ✓。注意 18→20 是 Utopia 的 base 增长对(增长率 10/9,不等于字阶 ratio);demo 的每级配对取 (min, min×ratio),复制上方独立函数即可逐字复现黄金样本。

数值出处:比率表(1.067→1.618,音乐音程命名)取自 Tim Brown More Meaningful Typography(A List Apart 2011,原文抓取核对);「1.25 = 最常用的 UI 排版比率」为同一来源的标注;Utopia 页面默认 minVw=360、maxVw=1240、base 18→20、ratio 1.25。

动效与交互

  • 参数即改即看:拖动 base/ratio/steps/视口区间,阶梯逐级重算重渲染——预览字样、px 读数与 clamp 串同步刷新,级差肉眼可辨;
  • 对照实验:ratio 从 1.25 拨到 1.618,step+2 从 25px 跳到 41.9px——比率对上层的放大是指数级的;拨到 1.067 则全部挤在一起,直观展示「比率定层级张力」;
  • 边界演示:maxViewport 拉到与 minViewport 相等时,斜率除零,demo 显示「minVw 必须小于 maxVw」而不是输出 Infinityvw;
  • 无自主动画;入场淡入尊重 prefers-reduced-motion(降级为直接呈现),读数恒为静态文本。

真实产品案例

  • Utopia.fyi 流体字阶计算器:页面默认 minVw=360、maxVw=1240、base 18→20px、ratio 1.25;调研对其生产 bundle 反查公式并与页面输出对拍,两条黄金样本逐字符一致——这是「一行 clamp = 一段线性回归」的工业化标准实现;
  • modularscale.com(Tim Brown / Scott Kellum):比率表工具化的源头,把 Bringhurst 的音程比率做成可交互的模数尺,Sass 时代的字阶推导入口;
  • Ant Design 字阶(对照样本):不走几何级数——官方源码 genFontSizes.ts 用 base×e^(i/5) 自然对数曲线派生 10 级字阶(H1 38→H5 16,主字体 14/行高 22),说明模数尺是「设计选择」而非「唯一正解」;Apple Dynamic Type(iOS Large Title 34→Caption 2 11)同为实测表而非等比数列(调研 13§1.3/§3.4)。

公式的量纲与边界

变量量纲取值边界退化情形
basepx(或 rem)实务 12–24;等于正文字号即 step-0base→0 时全阶归零;base 取非正文值会让「层级」失去正文锚点
ratio无单位数必须 >1(=1 全阶坍缩);实务 1.067–1.618;CSS calc 里乘法一侧必须无单位ratio=1 时 size(n)≡base,阶梯退化为等宽列表;ratio<1 时阶梯上下颠倒
n无单位整数…,−2,−1,0,1,2,…;负 n 即除法阶梯n 越大指数爆炸:16×1.25³=31.25px、×1.618³≈67.9px——超过 4–5 级即失控
minVw / maxVwpx(视口宽)maxVw−minVw>0;Utopia 默认 360/1240maxVw=minVw → slope 除零为 ±Infinity,clamp 中间项失效;差值过小则斜率过陡、中段几乎跳变
sloperem/vw(生产)或 px/px(数学)由两端字号与视口决定,可正可负slope=0(max=min)→ clamp 退化为常量;负 slope 是「大屏缩小」的合法用法
interceptrem(生产)或 px(数学)由 slope 反解,min−slope×minVw仅为代数产物,可能为负——负截距是正常现象,不代表错误
remBasepx/rem根字号实值(默认 16)根字号 ≠16px 时按 16 折算的 rem 输出整体错位——务必传实际值
超界视口—vw<minVw 或 vw>maxVwclamp 钳制为端点值:两端外插值不发生,「fluid」只存在于区间内

经验区间:base=16、ratio=1.25(Major Third)是 Web 字阶的最大公约数组合;视口对 360–1240(Utopia 默认)覆盖主流移动到桌面;级数控制在 step−1..step+4 以内。姊妹条目:fluid-type-scale(字阶的 CSS 落地形态)、rhythm-formula(行高把字阶吸回基线网格)、fluid-spacing(同一 clamp 思路用于间距)。

适用场景 4
  • 设计系统字阶一次性推导:一个 base、一个 ratio 生成全部 --step-*
  • 无断点流体排版:标题在 360–1240px 视口间线性呼吸(Fluid Type Scale 条目的数学内核)
  • 间距/行高与字号同轴:calc() 链让派生量跟随同一 --ratio 自乘
  • 设计评审时反查:给定 clamp 串还原 slope/intercept,判断是否越界
何时不要用 4
  • 层级超过 4–5 级后继续乘 ratio——级差指数爆炸,step+3 在 16/1.25 已达 31px,再乘两倍率脱档
  • minVw/maxVw 覆盖不到的视口依赖插值(两端本就是钳制值,超界等于浪费)
  • 把比率调到 1.067 以下做正文——相邻级肉眼不可分,层级失效
  • 根字号非 16px 时直接套用按 16 折算的 rem 输出——换算错位一整档
无障碍

用户缩放文本(浏览器最小字号、Dynamic Type)时,px 基值的字阶不跟随——优先用 rem 表达 base 与 --step-*,只在 clamp 的斜率里用 vw;WCAG 1.4.4 要求页面支持 200% 文本放大,固定 px 字阶+固定容器会造成溢出,流体 rem+vw 方案天然兼容。

浏览器支持

calc() 是全 evergreen 支持的成熟特性;clamp() 亦已全 evergreen(Can I use 记载 Chrome 79+/Firefox 75+/Safari 13.1+,社区口径,本调研未逐版本核验)。rem 换算依赖根字号——fluidClamp 默认按 16px 折算,根字号不同的站点需传 remBase。

兼容回退

不支持 clamp() 的旧浏览器:在 @supports not (width: clamp(1px, 1vw, 2px)) 里给每个 --step-* 写静态 px 值(minVw 处的取值),布局退化为固定字阶而非断点跳变;calc() 链无需回退。

来源 4

起源模数尺概念出自 Robert Bringhurst《The Elements of Typographic Style》的和谐比例观,由 Tim Brown 在 A List Apart 2011《More Meaningful Typography》推广——比率取音乐音程命名,含 1:1.618 黄金比示例与模数尺构造法(本次抓取原文核对);流体 clamp 公式经调研对 utopia.fyi 页面 bundle 反查还原,并与页面真实输出逐字符对拍(调研 14§1)。
