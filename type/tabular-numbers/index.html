表格数字 Tabular Numbers

等宽数字 · tnum · tabular figures · tabular-nums

font-variant-numeric: tabular-nums 让每个数字占相同宽度,纵向列对齐、计数动画不抖动——仪表盘与数据表的可信度底座。

Web 标准 ★★
实例演示 官方默认
参数
动效▾
numericStyletabular-nums

font-variant-numeric 数字风格。tabular-nums(tnum)=全等宽,列对齐与计数不抖;proportional-nums(pnum)=按字形比例占宽,散文更紧凑但对齐失效;lining-nums(lnum)=全高数字;oldstyle-nums(onum)=3/4/5/7/9 带降部,适合行内正文。全部 OpenType 特性标签(MDN 原文,调研 12§9)。

slashedZerooff

JS 型参数(demo 加 data-zero 后缀 slashed-zero)。slashed-zero(zero)给 0 加斜杠,防止与字母 O 混淆;Inter 官方仓库明确提供 slashed zero 与表格数字特性(调研 05§24)。

几何▾
countSpeed3

计数动画每秒步进次数(演示参数,非规范值)。数字每变一次,比例宽度列的单元格宽度都在跳——这正是等宽表格数字存在的理由;prefers-reduced-motion 时停止计数,只保留静态宽度探针。

代码拆解

结构与 DOM

无特殊结构——font-variant-numeric 是普通 CSS 属性,声明在承载数字的元素上即可:

<table class="stats">
  <tr><td>营收</td><td class="num">¥ 12,830,457</td></tr>
  <tr><td>订单</td><td class="num">9,021</td></tr>
</table>
.num {
  font-variant-numeric: tabular-nums;        /* 核心:等宽数字(OpenType tnum) */
  font-variant-numeric: tabular-nums slashed-zero; /* 需防 O/0 混淆时叠加斜杠零 */
}

关键点:

  • 数字的「等宽」由字体文件里的 OpenType tnum 特性表实现,CSS 只是开关——字体不含该表时声明无效但无害(调研 12§9);
  • font-variant-numeric 可空格组合:tabular-nums slashed-zero、oldstyle-nums ordinal 都是合法组合;
  • 与 font-variant-numeric 同族的全值清单(MDN 原文,12§9):lining-nums/oldstyle-nums、proportional-nums/tabular-nums、diagonal-fractions/stacked-fractions、ordinal、slashed-zero。

样式与参数

三个参数:一个 CSS 变量型 + 两个 JS 型(斜杠零经 data-zero 后缀、计数节奏):

.tn-num {
  font-variant-numeric: var(--tn-numeric);           /* tabular-nums(默认) */
  font-family: var(--font-mono, ui-monospace, monospace); /* 等宽字体是强兜底 */
}
.tn-board[data-zero="on"] .tn-num {
  font-variant-numeric: var(--tn-numeric) slashed-zero;
}

数值出处:

  • tabular-nums 的定义「easily aligned like in tables」为 MDN 原文(12§9 一手核对);
  • Baseline Widely available:自 2020-01 起(12§9);
  • 本站 Inter Variable 含 tnum 与 slashed zero 特性(Inter 官方仓库规格,调研 05§24)——demo 的宽度探针在本站字体上可测出真实差异;
  • 全站数值执行 mono + tabular-nums 纪律:hero 统计行见源码 src/styles/global.css:896-914。

动效与交互

数字场景的动效纪律:动文本、不动布局。

  • count-up 计数:demo 用定时器步进三行 KPI,数值变化只改文本节点;等宽风格下列宽波动恒为 0,比例宽度风格下每一步都在跳——宽度计实时显示抖动幅度;
  • 宽度探针:同一字体下实测 1111111111 与 1234567890 两串的渲染宽度差,Δ≈0 即等宽生效——结论来自测量而非写死;
  • 斜杠零开关:经 data-zero 属性切换,展示 slashed-zero 对 O/0 混淆的防护;
  • 节奏参数 countSpeed 为演示参数(非规范值);prefers-reduced-motion 时计数停止,静态数值与探针保留。

真实产品案例

  • Inter 字体官方发行:仓库规格明确列出「表格数字(tabular numbers)」与「slashed zero」两个 OpenType 特性,并被 Figma、GitLab、NASA 采用(调研 05§24)——数据密集产品的 UI 字体供给层直接内置了这套能力。
  • 本站 uiux-atlas:hero 统计行与全站可数元数据统一执行「mono 字族 + font-variant-numeric: tabular-nums」纪律(源码 src/styles/global.css:896-914,spec §2.2/§6-16);补研 12§16 把「全站数字列 tabular-nums,仪表盘呼吸不抖动」列为签名巧思之一。
  • 数据密集型仪表盘的通行实践:表格数字让同一列的数字纵向严格对齐,是财务报表、订单管理类界面的默认选择(实践共识,未证实;效果可用本条 demo 的宽度探针在任意字体上自证)。

参数敏感度

参数调大会…调小会…
numericStyle换 oldstyle-nums 时 3/4/5/7/9 带降部,正文行内更融合,但表格列对齐感下降tabular-nums 是唯一严格等宽档;proportional-nums 占位更经济但对齐失效
slashedZeroon 时 0 带斜杠,O/0 不再混淆——订单号/验证码场景的防错利器off 回到普通 0,依赖字体自身数字设计区分
countSpeed步进越密,比例宽度下的列抖动越显眼(等宽档始终为 0)减速后抖动样本变少,探针读数趋于平静

经验区间:数据表/仪表盘一律 tabular-nums;正文行内数字保持默认(比例);只在与字母 O 并排的编号串上加 slashed-zero。字体是前提——先确认字体含 tnum 表,再谈对齐。

适用场景 4
  • 财务/统计表格的数字列——同行数字纵向对齐才可比
  • 仪表盘 KPI 与 count-up 计数动画——等宽让跳动不抖列
  • 价格、订单号、验证码等易误读数字串(配 slashed-zero 防 O/0 混淆)
  • 时间码、倒计时等每秒都在变化的数值
何时不要用 2
  • 长文正文的行内数字——比例宽度占位更经济,且不需要列对齐(实践共识,未证实)
  • 装饰性大字海报数字——老式数字(onum)或字型自带的数字设计往往更有味道
无障碍

tabular-nums 不改变文本语义,读屏照常朗读数值;列对齐提升的是低视力用户扫读效率。slashed-zero 降低 O/0 误读率,对抄录订单号的用户是实打实的防错。数字密集时保持足够对比度与 ≥1.5 行高(WCAG 1.4.12,见 wcag-text-spacing 条目)。onum 老式数字在小字号下辨识度需实测。

浏览器支持

font-variant-numeric Baseline Widely available(自 2020-01 起,调研 12§9);特性生效前提是字体本身包含对应 OpenType 特性表(tnum/onum/zero 等),不含表的字体声明无效但无害。

兼容回退

不支持该属性的旧浏览器忽略声明,数字回退比例宽度——表格仍可用,只是列不再严格对齐;字体缺 tnum 表时同样回退,可用 ui-monospace/等宽字体栈作为强兜底(等宽字体天然数字等宽)。

来源 3

起源MDN 对 tabular-nums 的定义原文:数字等宽、『easily aligned like in tables(像表格一样轻松对齐)』,对应 OpenType 特性 tnum(调研 12§9,MDN 原文核对)。本站 hero 统计行与全站数值均执行 mono + tabular-nums 纪律(源码 src/styles/global.css:896-914,spec §2.2/§6-16)。
