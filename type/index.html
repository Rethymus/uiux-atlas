基线网格 让垂直空间落在固定步长(如 8px,允许 4px 半步)上,并叠加基线/网格可视化开关——偏离网格的间距无处藏身。 社区流派 ★★ 中文排版 CJK 中文排版的四件套:段首缩进 2 字、两端对齐、中西文自动间距(≤¼ 汉字宽)、标点挤压——规则出自 W3C clreq,落地靠 text-indent / text-align / text-autospace / text-spacing-trim。 Web 标准 ★★★ 展示级排版 展示级大字号的三件套:字号越大字距越紧(SF Pro 官方曲线)、行高比越低(apple.com 实测 56px→1.07)、可变字重替代合成加粗——与本站 hero 同源的手法。 社区流派 ★★★ 首字下沉 Initial Letter initial-letter 让段落首字占据多行并让正文环绕(Chrome 110+/Safari 需前缀/Firefox 未支持);不支持时用 ::first-letter + float 经典兜底。 Web 标准 ★★ 流式间距 间距令牌也走 clamp:--space-3xs…3xl 沿视口线性伸缩,一端定值、中间插值,布局留白随屏宽呼吸而非断点跳变。 Web 标准 ★★ 流式字阶 字号随视口在断点之间线性插值:clamp(下限, rem+vw, 上限) 生成 --step-0..5 字阶,小屏不小于下限、大屏不超过上限,中间平滑缩放。 Web 标准 ★★★ 字体加载策略 @font-face 的 font-display 决定字体加载期间文本怎么显示:五档取值对应「封锁期/交换期」两段时间参数——web.dev 数值表:fallback 100ms/3s、optional 100ms/无交换。 Web 标准 ★★ 行长与可读性 用 ch 单位给正文栏定宽上限:平均行长保持 45–90 字符(含空格),过长难以垂直追踪回行,过短频繁换行切碎节奏。 Web 标准 ★★ 字体搭配 衬线 × 无衬线的对比搭配,或同字族多字重的单字族策略:核心是对比、职责分离与克制——最多两种字体,第三种之前先问职责。 社区流派 ★★ 模数倍率公式 字阶的数学底座:size(n)=base×ratioⁿ 几何级数出层级、calc() 链式同轴缩放、Utopia 流体 clamp——斜率走 vw、截距藏 rem、两端钳制,一行 CSS 就是一段线性回归。 社区流派 ★★★ 小型大写与开放特性 font-variant-* 高层属性直连 OpenType 特性(smcp/c2sc/liga/zero…),font-feature-settings 是低层兜底:官方明确「能用高层就用高层,不要用它启用小型大写」。 Web 标准 ★★★ 行高韵律公式 行高 × 字号 = 基线倍数:先按密度算 lh = fs×m,再吸附到基线半格 lh = round(fs×m/unit)×unit——乘法管张力、加法管秩序,中西文各有硬约束。 Web 标准 ★★ 可变字体 一个字体文件携带连续轴:font-variation-settings 拨动 wght/opsz,字重与光学字号从离散档位变成连续滑杆。 Web 标准 ★★★ 垂直韵律 以正文行高为基本单元:标题行高反推(单元 ÷ 字号)、间距取整倍数、行盒逐行叠加——韵律可视化让文本块像乐谱一样可读。 社区流派 ★★★ text-wrap 平衡换行 text-wrap 简写属性的两个样式值:balance 让各行字数尽量均衡(短文本专用,Chromium ≤6 行/Firefox ≤10 行),pretty 用更慢更优的算法给长正文防孤行。 Web 标准 ★★ 表格数字 font-variant-numeric: tabular-nums 让每个数字占相同宽度,纵向列对齐、计数动画不抖动——仪表盘与数据表的可信度底座。 Web 标准 ★★ WCAG 文字间距 WCAG 成功准则 1.4.12:用户覆写行高 1.5 倍、段距 2 倍、字距 0.12 倍、词距 0.16 倍字号时,内容不得失效——排版不要锁死这四个比率。 Web 标准 ★★★
