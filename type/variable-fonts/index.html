可变字体 Variable Fonts

可变字体 · OpenType 变体 · font-variation-settings

一个字体文件携带连续轴:font-variation-settings 拨动 wght/opsz,字重与光学字号从离散档位变成连续滑杆。

Web 标准 ★★★
实例演示 官方默认
参数
几何▾
wght400

字重轴(CSS 型,注入 --vf-wght,demo 经 font-variation-settings 消费)。Inter 标尺 100–900:Thin 100 到 Black 900 共 9 个静态档(调研 05§24),可变格式下为连续取值;默认 400(Regular)是注册轴默认,与本仓 @fontsource-variable/inter 的 metadata.json 一致。写入方式建议优先用高层属性 font-weight,需要非整数或与其它轴联控时才用 font-variation-settings。

opsz14

光学字号轴(CSS 型,注入 --vf-opsz)。Inter 标尺 14–32(rsms/inter 官方规格,调研 05§24):14 是 text 档,配高 x-height(1118/2048 UPM)提升小字号可读性;32 是 display 档(x-height 1056/2048),对比更强、更紧凑。默认 14 = 轴最小值(本仓 @fontsource-variable/inter metadata.json 同值);设 font-optical-sizing: none 才能手动控轴,auto 时浏览器按 font-size 自动选档。

代码拆解

结构与 DOM

可变字体不需要特殊 DOM——只需要一个携带 fvar 表的字体文件和一段普通文本。关键是 @font-face 声明与 轴控制声明分离:文件负责「有哪些轴」,文本样式负责「轴停在哪儿」。

<p class="display">标题用 display 光学档</p>
<p class="body">正文用 text 光学档。</p>
@font-face {
  /* 本仓经 @fontsource-variable/inter/standard.css 注入:同一文件携带 wght + opsz */
  font-family: "Inter Variable";
  font-weight: 100 900; /* 区间声明 = 可变字重的标志 */
}

关键点:

  • OpenType 规范定义五个注册轴:wght/wdth/slnt/ital/opsz,各字体可只支持子区间;自定义轴须大写命名(调研 05§20);
  • Inter Variable 的标尺:opsz 14–32、wght 100–900(rsms/inter 官方规格,调研 05§24);
  • 轴名大小写敏感,font-variation-settings 一旦声明须整体重申所有轴值。

样式与参数

两个 CSS 型参数经 --vf-wght/--vf-opsz 注入,demo 的样张直接消费变量:

.vf-sample {
  font-family: "Inter Variable", system-ui, sans-serif;
  font-optical-sizing: none; /* 关掉 auto,手动控 opsz 才不被覆盖 */
  font-variation-settings: "wght" var(--vf-wght), "opsz" var(--vf-opsz);
  /* 高级语法:font-variation-settings: "wght" 375, "GRAD" 88; */
}

数值出处:

  • wght 默认 400(Regular)= 注册轴默认;opsz 默认 14 = 轴最小值——两者均与本仓 @fontsource-variable/inter 的 metadata.json 记载一致(wght 100–900/默认 400,opsz 14–32/默认 14);
  • 轴端点 100–900 与 14–32 出自 rsms/inter 官方技术规格(调研 05§24 一手核对);
  • x-height 对照:opsz=14 时 1118/2048 UPM(text 档,高 x-height 利于小字),opsz=32 时 1056/2048(display 档,对比更强)。

动效与交互

轴是连续的,但「动」要克制:

  • 面板滑杆改动后字形即时重绘——可变字体的优势正是不用换字体文件即可连续过渡;
  • hover 微移字重(±50)可行,但会改变字形宽度、引起换行漂移,只在短标签上使用;
  • 字重/光学字号动画(如滚动标题由细变粗)每帧重排字形,代价高且分散注意力,生产中避免;
  • 本条目 demo 无动画,不需要 prefers-reduced-motion 降级。

参数敏感度

参数调大会…调小会…
wght笔画变粗、字面变「黑」,900 接近 Black;标题层级感增强但挤占字距笔画变细,100(Thin)仅适合大字号装饰性场景;小字号可读性骤降
opsz切向 display 档:对比度增强、字面更紧凑、x-height 降低(1056/2048)——大标题更精致切向 text 档:x-height 抬高(1118/2048)、字形更舒展——小字号更易读
(组合)wght 高 + opsz 高 = 海报级 display 组合,仅适合超大字号wght 低 + opsz 低 = 长文阅读组合,正文最舒适的区间

经验区间:正文 wght 400–450 且 opsz 14;text 标签 500–600;display 标题 600–800 且 opsz 24–32。声明低层轴控时务必先写 font-weight 兜底,并整体重申所有轴值。

适用场景 4
  • 设计系统的字重细谱:350/450/650 这类非静态档位,一行 CSS 完成
  • 标题排版用 display 光学档(opsz 调高)、小字 UI 用 text 档(opsz 调低)
  • 单一字体文件替代 9 个静态字重回退,减少请求数与 FOUT 概率
  • hover/交互态在字重轴上做 ±50 微移(克制使用,避免布局抖动)
何时不要用 4
  • 正文用极细字重(接近 100)——细字重在低分辨率与低对比环境下可读性差
  • 把 font-variation-settings 当唯一字重来源却不写 font-weight 兜底——旧浏览器整条丢失
  • 字重动画铺开到整段正文——每帧重排字形,性能与可读性双输
  • 手写轴名拼错大小写(如 Wght)——轴名大小写敏感,静默失效
无障碍

字重直接影响可读性:正文建议 ≥400,标题可用更重档位;极细字重在小字号与低对比度下难以辨认,应避免(WCAG 1.4.3 对比度之外的字形可读性考量)。opsz 的 text 档(Inter 14,高 x-height)专为小字号设计——小字 UI 显式选低 opsz,大标题选高 opsz。字重变化会改变字形宽度,注意不要引起文本换行点漂移导致内容跳动。

浏览器支持

可变字体(fvar)与 font-variation-settings 在三大引擎的现代版本均可用;调研 05 未记录分浏览器首发版本号(未证实),此处不作逐版本断言。写法上先给 font-weight 兜底,再用 font-variation-settings 叠加轴控制。

兼容回退

不支持 font-variation-settings 的浏览器把整条声明当作无效丢弃:先写 font-weight(高层属性映射 wght 轴)保住字重,再写 font-variation-settings 叠加精细控制;opsz 无高层等价物,可依赖 font-optical-sizing 的默认 auto 让支持的环境自动选档。字体文件层面,@font-face 未加载成功时按 font-family 栈回退到系统字体。

来源 4

起源机制 = OpenType 字体变体(fvar 表):五个注册轴 wght/wdth/slnt/ital/opsz,取值标尺在轴注册时定义、各字体可支持子区间;高级语法 font-variation-settings 轴名大小写敏感且须整体重申所有轴值(MDN 可变字体指南 + Microsoft OpenType 规范,调研 05§20)。demo 字体 Inter 的轴标尺 opsz 14–32、wght 100–900 出自 rsms/inter 官方技术规格(调研 05§24)。
