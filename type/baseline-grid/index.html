基线网格 Baseline Grid

基线对齐 · 8px 网格 · baseline grid · 8pt grid

让垂直空间落在固定步长(如 8px,允许 4px 半步)上,并叠加基线/网格可视化开关——偏离网格的间距无处藏身。

社区流派 ★★
实例演示 官方默认
参数
几何▾
unit8px
px

网格步长。8px 是本站与业界常见的 4/8 空间网格基础步(社区惯例,未证实;生产实例:本站 spec「间距:4/8 网格」、TDesign 的 +8 常数)。调大后更疏朗,调小(4px)即退化为像素级自由排版。

fontSize16px
px

正文字号。行盒高度 = 字号 × 行高比,决定文本落在网格上的位置;配合 lineHeight 1.5 时 16px 字号的呼吸空间恰为 8px(与 TDesign「行高=字号+n」常数同构,调研 02§2)。

lineHeight1.5

行高比(无单位)。默认 1.5 同时满足 WCAG 2.2 SC 1.4.12 的行高阈值(≥1.5×,调研 05§18)并让 16px 字号落在 3×8px 的行盒上;调偏后基线可视化会立刻暴露错位。

动效▾
overlayboth

JS 型参数(切 data-overlay)。可视化开关:grid=每 unit 一条淡线;baselines=按当前行盒高度画的近似基线线(基线在行盒内的精确位置因字体度量而异,可视化按 ~80% 行高近似,属教学近似而非测量);none 恢复普通渲染。

代码拆解

结构与 DOM

无特殊结构——普通文档流即可,纪律在 CSS 的垂直尺寸上:

<article class="col">
  <p class="kicker">眉标</p>
  <h2>标题</h2>
  <p>正文段落</p>
  <div class="card"><p>描边卡片内文</p></div>
</article>
.col   { font-size: 16px; line-height: 1.5; }      /* 行盒 24px = 3×8px */
.col > * { margin-block-end: calc(var(--unit) * 2); } /* 段距 = 2 步 */
.card  { border: 1px solid; padding: 7px; }         /* 1px 描边计入预算:1+7=8px */

关键点:

  • 三个量纲共同决定节奏:字号 × 行高比(行盒)+ margin/padding(间距)+ 边框(常被忘掉的一环);
  • 判据是「步长整数倍或半步」:8px 步长允许 4px 半步——本站 4/8 间距网格即此规则(源码 src/styles/global.css:165);
  • Bringhurst 名言「空间如时间,比例化间隔远胜任意值」经 Rutter 24ways 文章转述(调研 12§9);
  • 可视化叠加层是教学层:repeating-linear-gradient 画线,pointer-events:none + aria-hidden,关掉即普通页面。

样式与参数

四个参数:三个 CSS 变量型 + 一个 JS 型可视化开关:

.col { font-size: var(--bl-size);      /* 16px */
  line-height: var(--bl-lh);           /* 1.5 → 24px 行盒 */
  --bl-unit: 8px;                      /* 步长 */
}
/* overlay 经 data-overlay 切换,叠加层按 var(--bl-unit) 与 var(--bl-size)*var(--bl-lh) 画线 */

数值出处:

  • 步长默认 8px:本站 spec「间距:4/8 网格(禁止非 4 倍数 padding/margin 字面值)」;业界 8pt grid 为社区惯例(未证实);
  • 行高默认 1.5:同时是 WCAG 2.2 SC 1.4.12 的行高阈值(≥1.5× 字号,调研 05§18),16px × 1.5 = 24px = 3 步;
  • 呼吸空间常数 8:与 TDesign 官方公式「行高 = 字号 + n,n = 8」同构(官网 design-basic.ts,调研 02§2)——16/14px 常用字号下 1.5 倍与 +8 完全重合;
  • 1px 描边 + 8px 内边距 = 9px:12§10 记载的经典半单元案例(18px 单元体系里 9px 恰为半步;8px 体系里判违规,把 unit 调到 18 可见审计转绿)。

动效与交互

  • 可视化开关:overlay 参数(none/grid/baselines/both)经 data-overlay 切换两组渐变层的 opacity(0.2s 过渡,prefers-reduced-motion 时关闭过渡);网格线每 unit 一条,基线线按当前行盒高度绘制在 ~80% 处(基线精确位置因字体度量而异,教学近似);
  • 偏移审计:对每个块实测 getBoundingClientRect().top 相对列顶的偏移,判据「步长整数倍或半步」,✓/✗ 逐块列出——参数一动,审计实时重算;
  • 调参互动:拖 unit 到 18px,9px 的卡片内文从违规变达标;拖 lineHeight 偏离 1.5,行盒离开网格,基线层立刻显示文本漂移。

真实产品案例

  • TDesign:官方公式 line-height = font-size + 8(常数 8 让 14/16px 字号与 1.5 倍行高完全重合,大字号不再行距膨胀),写在官网字体页 design-basic.ts 里(调研 02§2,官方源码一手核对)——「8 的呼吸常数」进入了主流设计系统的正式规范。
  • 本站 uiux-atlas:间距 token 全表即 4/8 网格(--space-1: 4px … --space-16: 64px),并明文「禁止非 4 倍数 padding/margin 字面值」(源码 src/styles/global.css:165)——半步规则作为硬约束写进了工程规范。
  • Rutter 的 24ways 经典方法:2006 年《Compose to a Vertical Rhythm》确立「基本单元 = 正文行高(12px × 1.5 = 18px)、标题行高反推、间距取整倍数、全部用 em」的完整算法(调研 12§9,URL 已核)——至今仍是基线网格教学的基准文本。

参数敏感度

参数调大会…调小会…
unit网格更疏朗,对齐更醒目;32px 步长下小间距元素被迫挤在同一格4px 起接近像素自由排版,审计噪音增多;纪律性下降
fontSize字号上行盒变高,若 size×lh 不再是步长倍数,基线层立即显示漂移文本变小,行盒落格更容易,但可读性下降
lineHeight行盒拉高;偏离「步长倍数」时文本在基线间漂移(1.5 是 16px 的落格点)低于 1.5 触发 WCAG 1.4.12 阈值风险;低于字号时行间重叠
overlayboth 最严格:网格定步长、基线定行盒,两层错位一眼可见关闭后回归普通视图,只剩审计列表兜底

经验区间:unit 8px(半步 4)、正文 16px × 1.5、段距 2 步;1px 描边必须计入预算(1+7=8 或 1+8=9 半步)。多字号混排时允许局部豁免(实践共识,未证实)。

适用场景 4
  • 长文档/落地页的排版系统校准——标题、正文、图片、按钮落在同一步长上
  • 多组件拼接的仪表盘:间距一致性审计(配合 4/8 半步规则)
  • 设计系统间距 token 设计(本站 --space-* 即 4/8 网格,src/styles/global.css:165)
  • 代码评审与视觉走查:开基线可视化逐块核对偏移
何时不要用 2
  • 多字号混排的复杂编辑排版——严格基线网格维护成本高,社区实践允许局部豁免(实践共识,未证实)
  • 像素级自由的海报/插画式页面——纪律本身与自由排版目标相悖
无障碍

可视化叠加层 pointer-events:none、aria-hidden,不进可访问性树;行高默认 1.5 兼顾 WCAG 2.2 SC 1.4.12(≥1.5×,调研 05§18);网格纪律本身不改变文本内容,只约束留白——低视力用户从一致的行距与呼吸空间中获益更多。

浏览器支持

无新特性门槛:可视化用 repeating-linear-gradient,叠加层 pointer-events:none 纯装饰;布局本体与审计逻辑只依赖 getBoundingClientRect/computedStyle 等广泛可用 API。

兼容回退

基线网格是排版纪律而非浏览器特性,无回退问题;把 overlay 切到 none 即恢复普通视图。唯一约束:可视化叠加层必须 aria-hidden 且不影响命中测试,避免被读屏朗读或拦截交互。

来源 3

起源Bringhurst《The Elements of Typographic Style》:「空间如时间,比例化间隔远胜任意值」,经 Richard Rutter《Compose to a Vertical Rhythm》(24ways, 2006)转述(调研 12§9,URL 已核);8px 生产实例:本站 4/8 间距网格(src/styles/global.css:165「禁止非 4 倍数 padding/margin 字面值」)与 TDesign 行高常数公式 line-height = 字号 + 8(官网 design-basic.ts,调研 02§2)。
