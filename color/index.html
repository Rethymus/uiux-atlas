内建混色:color-mix() 在指定色彩空间插值(默认 oklab),相对颜色语法 rgb(from …) 把原色解构成通道变量做 calc 运算——派生色全部声明式,零硬编码 hex。 Web 标准 ★★★ UI 色彩心理 色彩对情绪与行为的影响属编辑性经验总结(本调研未系统证实):暖色相常关联紧迫与行动、冷色相常关联信任与冷静、高饱和=高唤起、高明度=轻。工程上可控的是 oklch 三轴——明度定对比度、色度定唤起强度、色相定情绪域。 社区流派 ★★ HCT 色调调色板 Material 的调色板原子:固定 HCT 的色相与色度,只沿 tone(= CIE L*)展开 13 档——Android 系统每个关键色都这样成列。 Material 3 ★★★ 明暗自适应 CSS 内建双值取色函数:light-dark(浅色值, 深色值) Material 3 ★★★ 动态取色 从一个 source 色相出发,按变体配方展开 5 个调色板,再按角色 tone 映射成 primary/on-primary/container 等语义色——亮暗主题共用同一套 token。 Material 3 ★★★ 暗色设计模式 暗色不是浅色的反转:Apple 原文「not necessarily inversions」。四个模式——分层(base/elevated 靠提亮)、饱和度(accent 提亮降饱和)、阴影(层级让位给表面)、品牌色(accent 换对、图片压暗)。 社区流派 ★★★ 多主题 Token 三套品牌主题共享同一份组件 CSS:换肤只替换 primitive 层的一个 --brand 变量,语义层用 color-mix Web 标准 ★★★ OKLCH 色彩空间 CSS 官方感知均匀色彩空间 oklch(L C H / A):数值变化即人眼感知变化——本条讲空间本身的四个分量与坐标语义。 Web 标准 ★★★ P3 广色域 用 color(display-p3 …) 表达 sRGB 装不下的颜色:P3 的 Lab 色域体积约为 sRGB 的 1.5 倍;渐进增强三件套 = sRGB 兜底值 + @supports + @media (color-gamut: p3)。 Web 标准 ★★ 状态色系统 success / info / warning / danger 四态,每态一套「底 / 边 / 字」三件套:同色相派生,文字过 AA 4.5:1、边框过非文本 3:1,demo 逐态实时复核。 社区流派 ★★★ Radix 色阶 每个 hue 一条 12 步色阶,步位即语义:1–2 背景、3–5
