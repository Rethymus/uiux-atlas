# Goal-Gradient Effect / 目标梯度效应

- 页面 / Page: /uiux-atlas/principles/goal-gradient/

- 别名 / Aliases: 目标梯度 · Goal-Gradient
- 简介 / Tagline: 越接近目标,奔向目标的行动力越强。给清晰的进度指示、在起点预置「人为进度」,把资源投在收尾冲刺段——离目标越近,每一步的动机越足。
- Tagline (EN): Effort toward a goal intensifies as the goal gets closer. Give clear progress indicators, pre-seed 'artificial progress' at the start, and invest in the final stretch — the nearer the goal, the stronger each step's pull.

## 适用场景 / When to use

- 会员卡/集章/积分体系:起点预盖一枚章(人为进度),收尾阶段集中投放激励 / Loyalty cards, stamp collecting, points systems: pre-stamp one slot (artificial progress) and concentrate rewards on the final stretch
- 多步流程(注册/结账/引导):清晰的步骤条 + 百分比,让「还差两步」可见 / Multi-step flows (sign-up/checkout/onboarding): a clear stepper + percentage makes 'two steps left' visible
- 加载等待:≥10s 的操作给 percent-done 进度条(NN/g,调研 07§20),进度线本身就是目标梯度的载体 / Waiting: percent-done progress bars for ≥10s operations (NN/g, research 07 §20) — the progress line is itself a goal-gradient carrier

## 何时不用 / When not to use

- 虚报进度:预盖章必须如实标注为「人为进度」,把剩余量谎报为已完成是欺骗(虚幻进度研究的伦理边界) / Misreporting progress: pre-stamped slots must be disclosed as artificial progress; passing remaining work off as done is deception (the ethical edge of illusory-progress research)
- 把进度藏在最后一屏才揭晓——梯度需要「越来越近」的持续感知 / Hiding progress until a final reveal — the gradient needs a continuously felt 'getting closer'
- 目标过大且无中间里程碑(如 0→100% 只有一根空进度条):没有近目标,就没有加速 / One huge goal with no milestones (e.g. an empty 0→100% bar): no near goal, no acceleration
