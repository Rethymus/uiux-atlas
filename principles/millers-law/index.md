- 简介 / Tagline: 普通人工作记忆大约只能保持 7±2 项。对策是把内容分块(chunking),但「神奇数字七」不能为不必要的设计限制辩护。
- Tagline (EN): The average person keeps about 7±2 items in working memory. The fix is chunking — but the 'magical number seven' must not justify unnecessary design limitations.

## 参数 / Parameters

| name | type | default |
|---|---|---|
| digits | number · 个 | 10个 |
| chunk | number · 位/组 | 3位/组 |

## 适用场景 / When to use

- 电话号/卡号/序列号输入框按 3–4 位分块显示 / Phone/card/serial inputs displayed in 3–4 digit chunks
- 导航与设置页分组(每组 3–7 项),而非 20 项平铺 / Nav and settings grouped into 3–7 item sections instead of a flat 20
- 把长流程拆成「每步只记 1–2 件事」的向导 / Wizards that ask you to remember 1–2 things per step

## 何时不用 / When not to use

- 拿 7±2 当「只能放 7 个导航项」的教条——lawsofux 原文告诫:不要为不必要的设计限制辩护 / Using 7±2 as a 'only 7 nav items' dogma — the Laws of UX caveat: never justify unnecessary design limitations with it
- 同一屏幕塞 10+ 个平权且无分块的输入项 / 10+ flat, unchunked, equal-weight inputs on one screen
