系列位置效应 Serial Position Effect

序列位置效应 · 首因效应 · 近因效应

系列中的首尾项记忆最好(首因 + 近因):把最不重要的放中间,关键动作放导航的最左与最右。

社区流派 ★★
实例演示 官方默认
参数
几何▾
items9个
个

每轮呈现的词数。默认 9:中间段足够长,首尾优势清晰;6 个时几乎人人全记,12 个时中间段的遗忘更刺眼。

dwell600ms
ms

每个词的呈现时长(demo 节奏参数,非定律结论)。过快(<300ms)来不及编码,整条曲线一起塌;600ms 让首因(有时间复述)与近因(仍在工作记忆)双双成立。

代码拆解

结构与 DOM

演示是一个自由回忆实验:词语逐个呈现 → 隐藏 → 任意顺序输入 → 按位置计分 + 累计柱状图:

<div class="sp-stage">苹果</div>       <!-- 逐词呈现,每个 dwell ms -->
<input id="sp-in" placeholder="如:苹果 空格分隔…" />
<svg> <!-- 各位置命中柱状图,多轮累计 --> </svg>

关键点:

  • 每轮从 12 词池随机抽 items 个、随机顺序——「词的内容」不是变量,「位置」才是;命中按词匹配后映射回原位置;
  • 任意顺序回忆、按位置计分:自由回忆范式是序位效应的标准测法;
  • 序列呈现与完成态经 aria-live 播报;柱状图旁有逐位置数值文本(双通道)。

样式与参数

// items / dwell 是 JS 型参数:demo 订阅 store 驱动
pool.forEach((w, i) => {
  timers.push(setTimeout(() => setCurrent({ word: w, idx: i }), dwell * i));
});
  • items 默认 9、dwell 默认 600ms:两者都是 demo 教学参数(效应本身是定性的),600ms 给首因留出复述时间、给近因留出工作记忆鲜活度;
  • 累计逻辑:每轮把本轮命中向量累加到 tally,图表展示「每个位置被回忆的次数」——单轮太抖,3 轮以上 U 形才稳定;
  • 判定用词面匹配:同义词/错别字不计命中(口径从简,demo 如实)。

动效与交互

  • 词的呈现是离散替换(整词出现/消失,无位移无淡入):回忆实验里任何入场动效都会污染「呈现时长」这一变量;prefers-reduced-motion 下同样成立,因为本 demo 本来就没有动画;
  • 输入阶段自动聚焦(用户主动发起的流程内);Enter 记分;
  • 「清零统计」重置累计,便于换参数(如 items=6 vs 12)后重新积累。

真实产品案例

  • 底部导航的两端布局:高频入口放最左与最右(如「首页」与「我的」)——lawsofux 指导「关键动作放导航最左与最右」在移动 tab bar 上的直接体现;lawsofux 同时记载 Apple、Electronic Arts、Nike 的流行设计在利用该效应;
  • 菜单/列表的「中段沉没」:低频项(设置、关于)沉进菜单中段,首尾留给高频项——07§29 指导「把最不重要的项放中间」的通行信息架构;
  • 长列表的分页端点:第一屏首项与最后一屏末项记忆最深,排序与分页因此成为产品决策而非纯技术实现(编辑性泛例,07§29 结论的推论)。

参数敏感度

参数调大会…调小会…
items12 个时中间段的遗忘更刺眼,U 形更深6 个时几乎人人全记,曲线拉平
dwell过长节奏拖沓;过短(<300ms)编码不足,整条曲线一起塌,首尾优势也被淹没600ms 附近首因(有时间复述)与近因(仍在工作记忆)双双成立
累计轮数轮数越多,U 形越平滑稳定;单轮受词难度影响大—

经验结论:序位效应是信息架构的免费杠杆——排序决策(谁在首、谁在尾)本身就是设计;但读屏用户按 DOM 顺序线性访问,「中间不重要」不成立,关键动作仍需语义优先。

适用场景 3
  • 底部导航:高频入口放两端(如「首页」与「我的」)
  • 菜单与列表:最不重要的项沉到中段
  • 表单分组:第一组放最重要的字段(首因)
何时不要用 2
  • 把关键操作埋进长列表中段
  • 用该效应为「信息架构不做排序」辩护——首尾优势不改变中段仍需可寻性
无障碍

位置优势不能成为唯一的信息架构依据:读屏用户按 DOM 顺序线性访问,「中间不重要」不成立——重要的动作仍需语义优先(landmark、heading、跳转链接)。演示的柱状图配完整数值文本,不依赖读图;序列呈现对读屏经 aria-live 播报。

浏览器支持

演示为 DOM 序列呈现 + 输入框 + 内联 SVG 柱状图,全现代浏览器可用。

兼容回退

效应的工程出口在信息架构层:导航/tab 条的两端放高频关键动作,中段放次级入口;列表页的排序与分页同样受它约束(第一屏首项与末屏末项记忆最深)。没有可降级的 CSS 特性。

来源 1

起源术语由 Hermann Ebbinghaus 提出:序列位置影响回忆准确率,开头项(primacy)与结尾项(recency)的回忆都显著优于中间项(Jon Yablonski,Laws of UX)。lawsofux 记载 Apple、Electronic Arts、Nike 等公司的流行设计都在利用该效应;指导:最不重要的项放列表中间,关键动作放导航最左与最右(调研 07§29)。

  1. 条目 峰终定律

    搭配:两条「记忆 ≠ 全程平均」的定律:序位给首尾位置加权,峰终给强度时刻加权——排序定谁站首尾,峰终定首尾发生什么。

  2. 条目 Miller 7±2 法则

    搭配:自由回忆的近因段就活在 7±2 里:末尾几项尚未被挤出容量所以记得最牢——millers 页的容量账(10 位按 3 分块 = 4 个组块)是同一套算法。

  3. 条目 Jakob 定律

    反向自「Jakob 定律」的精选:搭配关系,原句「底部标签栏是两条定律的公共现场:范式要求「高频沉底、5 个左右」,序位要求「关键入口放最左最右」——熟悉感与记忆位同格对齐。」
