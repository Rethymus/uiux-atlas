冯·雷斯托夫效应 Von Restorff Effect

隔离效应 · Isolation Effect · oddball effect

相似物体中与众不同者最易被记住。让关键动作视觉凸显——但强调要有节制,且不能只靠颜色。

社区流派 ★★★
实例演示 官方默认
参数
几何▾
tiles12块
块

网格块数(6–16,取偶数)。默认 12:异类的「背景相似度」足够高,隔离效应明显;6 块时任务过易。

动效▾
cuecolor

异类的隔离线索。color=强调色填充;shape=圆形 vs 方形;motion=缓慢脉冲(1.4s 循环,命中 prefers-reduced-motion 时自动退化为加粗描边——07§30「用动效强调要考虑运动敏感用户」)。

代码拆解

结构与 DOM

演示是一个异类记忆测试:网格展示 2.5s(恰有一个异类)→ 全部遮罩 → 点出异类位置 → 按线索累计正确率:

<div class="vr-grid">
  <button class="vr-tile" data-odd="true" data-cue="color"></button> <!-- 异类 -->
  <button class="vr-tile" data-masked="true"></button>              <!-- 遮罩后全部同貌 -->
  <!-- ×n -->
</div>

关键点:

  • 展示期只有异类块获得 data-odd="true";遮罩后所有块视觉等同——位置信息只能来自记忆,测的就是隔离效应;
  • 三种线索可切换:color(强调色)/ shape(圆形 vs 方形)/ motion(1.4s 慢脉冲);
  • 正确率按线索分组统计——同一效应在不同线索下的强度对比,是 demo 的核心读数。

样式与参数

.vr-tile[data-odd="true"][data-cue="motion"] { animation: vr-pulse 1.4s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) {
  .vr-tile[data-odd="true"][data-cue="motion"] {
    animation: none;
    outline: 3px solid oklch(0.58 0.17 300); /* 动效强调退化为描边强调 */
  }
}
  • tiles 默认 12、cue 默认 color;SHOW_MS = 2500(demo 选择,非定律数值);
  • 1.4s 慢脉冲换算约 0.7 次/秒,远低于 WCAG SC 2.3.1 的 3 次/秒闪烁阈值;reduced-motion 下退化为 3px 描边——信号不消失,只是换了通道;
  • shape 线索刻意用「圆形 vs 圆角方块」,不依赖色觉——07§30「不要只靠颜色做对比」。

动效与交互

  • 展示/遮罩是离散切换,无过渡——「看见什么」不该被动画模糊;
  • 应答后立即显示 ✔/✕,1.2s 后自动进入下一轮;错误不打断流程;
  • motion 线索的脉冲只动 transform: scale(合成器属性);reduced-motion 降级路径已在 CSS 内声明;
  • 每轮异类位置随机(Math.random,demo 随机源,非安全用途)。

真实产品案例

  • 每屏一个 Primary 按钮:IBM Carbon 明确「每屏一个 primary」(调研 07§2),即页面只保留一个异类——07§30「强调要有节制,避免互相争夺」的组件级兑现;主按钮的强调色块就是整页最显眼的隔离项;
  • Google 搜索结果页的广告标注:广告卡片整体形状/底色与自然结果不同,又保持克制(仅微妙差异)——lawsofux 原文告诫强调「不要被误认为广告」的另一半:广告自己也在用隔离效应抢记忆;
  • 表单里的必填标记:必填项用红色星号 + 必填文字(双通道),在一片灰色表单里成为可扫描的异类(编辑性泛例,呼应 07§30「不要只靠颜色」)。

参数敏感度

参数调大会…调小会…
tiles16 块时背景相似度更高,异类更突出,但定位更难6 块时任务过易,效应读数不敏感
cuemotion 是最抢眼的线索,但对运动敏感用户不友好(reduced-motion 自动降级)color 依赖色觉;shape 是色觉安全的通道——三者统计对比就是 demo 的教学结论
SHOW_MS(固定)2.5s 是「看得清但记不牢」的教学窗口;更长会掩盖个体差异—

经验结论:异类的价值 = 稀缺度 × 通道数;同时只允许一个异类——多个元素同时「不一样」等于没有异类;负面的异类(报错、警示)记得更牢,更要省着用。

适用场景 3
  • 主按钮:页面唯一的强调色块,一屏一个(呼应每屏一个 Primary,07§15/§30)
  • 关键状态徽章(如「新」「必填」):短时且克制的异类
  • 价格/权益中的关键项:异类让「必看」从扫读中跳出
何时不要用 3
  • 一屏多个强调色块互相争夺——全部失效(07§30)
  • 只靠颜色做异类(色觉障碍用户丢失信号,SC 1.4.1)
  • 闪烁式强调——运动敏感用户的不适源(07§30/SC 2.2.2 精神)
无障碍

异类信号必须多通道:颜色 + 形状 + (可选)动效,demo 三种线索可切换对比;闪烁动画遵循 3 次/秒内阈值(SC 2.3.1),demo 用 1.4s 慢脉冲;reduced-motion 下降级为描边加粗,信号不消失。

浏览器支持

纯 CSS 网格与动画,全现代浏览器可用;conic/动画退化路径同 gestalt 条目。

兼容回退

「异类」的降级序列:动效强调 → 位移/缩放动画;reduced-motion → 描边加粗;色彩不可用 → 形状差。工程红线:同时只允许一个异类——多个异类互相争夺,强调全部失效(07§30「强调要有节制」)。

来源 1

起源德国精神科与儿科医生 Hedwig von Restorff(1906–1962)1933 年实验发现:同类列表中混入一个孤立异类项,该项的记忆显著改善(Jon Yablonski,Laws of UX;调研 07§30)。lawsofux 指导:重要信息与关键动作要视觉凸显;强调要有节制,避免互相争夺、避免被误认为广告;不要只靠颜色做对比(照顾色觉障碍);用动效强调时考虑运动敏感用户。
