Fitts 定律 Fitts's Law

费茨定律 · Fitts Law

获取目标的时间取决于目标的距离与大小:目标越小、越远,命中越慢、错误越多。触控目标要大、间距要足、离注意力区要近。

结构与 DOM

演示是三个角色:一个起点按钮、一个目标按钮、一块捕获脱靶的舞台层。目标的位置与尺寸完全由两个参数(经 CSS 变量)驱动:

<div class="ft-field" data-phase="idle">
  <button class="ft-start">起点 Start</button>
  <button class="ft-target">目标 Target</button>
  <span class="ft-miss">MISS</span>
</div>

关键点:

  • 起点固定在左下,目标按 --ft-distance 从起点右侧偏移、按 --ft-size 决定边长——两个变量一改,实验条件立刻改变;
  • 舞台层兜住「点在目标之外」的点击,计入 miss——Fitts 的另一半结论正是快速动作 × 小目标 → 高错误率(speed-accuracy trade-off);
  • 起点与目标都是真实 <button>,可 Tab 聚焦、Enter/Space 激活(键位惯例见 keyboard-navigation 条目)。

样式与参数

.demo-stage {
  --ft-size: 48px;      /* 目标边长,默认 = M3 触控目标 48dp(调研 04§2.1) */
  --ft-distance: 160px; /* 起点→目标的水平间隙 */
}
.ft-target {
  width: var(--ft-size);
  height: var(--ft-size);
  left: calc(20px + 150px + var(--ft-distance));
}

数值出处:

  • size 默认 48px:M3 Switch 规格中的 target 48dp(调研 04§2.1);lawsofux 指导原文为「触控目标要足够大、间距充足、放在容易获取的区域」;
  • WCAG 2.2 SC 2.5.8(AA)的法定下限是 24×24 CSS px——比 48px 宽松得多,demo 把范围开到 16px 是为了让人亲眼看违法后果;
  • 演示顶部实时计算 Shannon 形式难度指数 ID = log₂(2D/W):D 为距离、W 为目标宽度——这是 Fitts 定律的标准量化形式,demo 用水平边距近似幅度 D。

动效与交互

  • 点击「起点」→ 目标开始 1.2s 脉冲光晕(box-shadow 扩散,合成器友好的循环动画),提示「现在是瞄准态」并开始计时;
  • 命中目标 → 计时停止,成绩写入右侧面板的「最近成绩」列表(最多 4 条),目标回到静默态;
  • 瞄准态中点在目标之外 → MISS ✕ 闪现(0.5s)并累计脱靶数;计时不中断,脱靶本身就是实验数据;
  • 改动 size / distance 不打断当前轮——参数面板与实验实时联动;
  • prefers-reduced-motion: reduce 时取消脉冲光晕与 MISS 闪动,计时逻辑不受影响。

真实产品案例

  • Material 3 的触控目标:M3 在 Switch 等控件规格中明确规定 target 48dp——点击热区远大于可视的 track(52×32dp),是 Fitts「目标做大」最成体系的落地(调研 04§2.1);
  • 移动端大按钮惯例:lawsofux 明确指出该定律「直接催生了把交互按钮做大(尤其在手指操作的移动设备上)」的惯例——今天 iOS/Android 主操作按钮的尺寸共识都源于此(调研 07§22);
  • 销毁类操作的「反向 Fitts」:把危险按钮做小、放远(远离高频点击热区),利用同一提高获取成本来防止误触,是定律的合法反向运用(07§22 指导:注意区与按钮距离尽量短的反面)。

参数敏感度

参数调大会…调小会…
size命中变容易,耗时与脱靶同步下降;96px 已接近「整块区域」,实验失去区分度ID 指数上升,耗时变长;≤24px 触及 WCAG 2.2 SC 2.5.8 法定下限;16px 时脱靶率肉眼可见地上升
distance手臂移动路径变长,耗时上升——符合 Fitts 1954 原始结论接近 60px 时两个按钮几乎贴身,实验退化为「就近点一下」

经验区间:生产触控目标 44–48px 级(M3 target 48dp 为参照);WCAG 法定下限 24px;demo 的 ID 读数在 1–4 bit 区间最能拉开手感差异——同一个 ID 值下,「又小又近」与「又大又远」的耗时接近,这正是公式的含义。

适用场景 3
  • 移动端主要操作按钮与底部导航项——用 48px 级目标(04§2.1)
  • 销毁类操作:目标做小 + 远离高频区,是 Fitts 的合法反向运用
  • 工具栏与表单:把主按钮放在注意力停留处附近
何时不要用 2
  • 密集小图标按钮相互贴身排列——间距不足会放大误触
  • 把关键操作移到屏幕远角以「腾地方」
无障碍

WCAG 2.2 SC 2.5.8(目标尺寸最低,AA)要求指针目标至少 24×24 CSS px;M3 的 target 48dp 是更宽松的生产参照(调研 04§2.1)。仅靠 hover 呈现的目标对触屏与运动障碍用户不可用;小目标必须配足间距,否则与相邻目标互相抢命中区。

浏览器支持

心理学定律本身无浏览器支持问题;演示用 Pointer 事件计时,全现代浏览器可用。

兼容回退

定律不可「降级」,但落地到 UI 有两条工程底线:触控目标的最小可命中尺寸交给 CSS(padding/min-width 保证),误触的后果交给撤销与确认,而不是把按钮做小。

来源 2

起源1954 年心理学家 Paul Fitts 研究人类运动系统时提出:移动到目标的时间随距离增加、与目标大小成反比;快速动作配小目标会因速度-精度权衡而放大错误率(Jon Yablonski,Laws of UX)。该定律直接催生了「移动端交互按钮要大」的惯例(调研 07§22)。
