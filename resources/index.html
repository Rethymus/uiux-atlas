官方设计规范

Apple HIG ↗ (在新窗口打开) developer.apple.com/design/… 想给产品定底层原则时先读它:层次、渐进披露、可中断动效、暗色 base/elevated 分层都有官方原文。 iOS / macOS Material 3 ↗ (在新窗口打开) m3.material.io 需要把动效与色彩 token 化时查官方规格:缓动×时长配对表、state layer、HCT 动态色都给到具体值。 AndroidToken Fluent 2 ↗ (在新窗口打开) fluent2.microsoft.design 做 Windows 桌面观感与 acrylic/mica 材质时对照;动效与材质档位的官方页面(mica/acrylic 细则见 WinUI 文档)。 WindowsAcrylic / Mica TDesign ↗ (在新窗口打开) tdesign.tencent.com 「token 即文档」的中文企业级范例:行高常数公式、时长双端公式、组件像素规格全部一手公开。 中文企业级 Arco Design ↗ (在新窗口打开) arco.design 查亮暗双主题 token 映射与暗色白透明度文字阶梯(90/70/50/30%)的成熟实践时用它。 中文双主题 Semi Design ↗ (在新窗口打开) semi.design 3000+ token 加「动效默认 0ms」的无障碍架构出自这里;做主题变装(DSM)前值得通读。 中文DSM IBM Carbon ↗ (在新窗口打开) carbondesignsystem.com 组件用法纪律的最佳教科书:按钮层级、数据表三态、空状态三类,每条都讲「为什么」。 Shopify Polaris ↗ (在新窗口打开) polaris.shopify.com 电商与商家工具类界面的规范参照;组件级文档已迁移,以站内通用参考页为准(调研未能取得组件一手内容)。 电商

组件库

shadcn/ui ↗ (在新窗口打开) ui.shadcn.com 复制粘贴式组件 + 语义 token 约定;想「拥有」组件代码而不是装依赖时首选,registry 还能直接喂给 agent。 React许可:以仓库 LICENSE 为准 Radix UI ↗ (在新窗口打开) www.radix-ui.com/primitives/… 无障碍原语的事实标准;自定义 Dialog/Combobox/Tabs 的键盘交互与 ARIA 属性照它的文档抄最稳。 Headless许可:以仓库 LICENSE 为准 Ant Design ↗ (在新窗口打开) ant.design 中后台场景的全家桶;动效原则(Natural/Performant)与 seed token 文档化程度高,适合对照着定规范。 React中文许可:以仓库 LICENSE 为准 MUI ↗ (在新窗口打开) mui.com Material 风格 React 组件;按钮 text/contained/outlined 三档强调与 Snackbar 通知规格可直接对照。 ReactMaterial许可:以仓库 LICENSE 为准 react-bits ↗ (在新窗口打开) reactbits.dev 动效/交互组件集(demo+源码+文档,人与 agent 通吃);抄实现思想时逐段核对它的 RM 与性能红线。 MIT + Commons Clause Magic UI ↗ (在新窗口打开) magicui.design Design Engineer 风格动效组件(Border Beam、Spotlight 等),shadcn registry 一条命令直装。 MITshadcn registry

交互与动效工具

cubic-bezier.com ↗ (在新窗口打开) cubic-bezier.com 拖控制点手调贝塞尔曲线,并能与内置缓动并排对比;为本站选 --ease-* 就是在这里找的手感。 easings.net ↗ (在新窗口打开) easings.net 只知道想要的运动性格(回弹/减速/过冲)却写不出曲线时,来这查 30+ 缓动预设与可交互演示。 linear() 缓动生成器 ↗ (在新窗口打开) linear-easing-generator.netlify.app cubic-bezier 表达不了的弹簧/回弹,用它采样成现代 CSS linear() 直接输出(仓库:Jake Archibald)。 CSS linear() oklch.com ↗ (在新窗口打开) oklch.com 把 HEX 换成感知均匀的 OKLCH,顺带检查 P3 宽色域与 sRGB 降级色;定语义色阶前先来这里。 Utopia ↗ (在新窗口打开) utopia.fyi/type/… 生成 clamp 流式字阶与间距刻度(本站 --step-* 用的就是 Utopia 法);配套 /space/calculator/ 管间距。 字阶间距 glassmorphism.com ↗ (在新窗口打开) hype4.academy/tools/… 玻璃感起点速查:调 blur/透明度直接拷 CSS(原域名 301 至此);精修请回本站条目页的参数面板。 neumorphism.io ↗ (在新窗口打开) neumorphism.io 新拟物双层阴影不想手算时,拖光照角度与强度直接出 CSS;注意浅色底才撑得住这种风格。

灵感画廊

Mobbin ↗ (在新窗口打开) mobbin.com 60 万+ 真实 App 截图,按 flow/element 分层;找「成熟产品怎么做这个流程/控件」而不是找视觉炫技。 AppFlow godly.website ↗ (在新窗口打开) godly.website 视觉冲击型站点灵感库,OG 图与 App 图标也单独成列;想被「吓一跳」时再开。 Land-book ↗ (在新窗口打开) land-book.com 手挑的落地页/营销站灵感库,按 style 标签过滤 + 排序信号;找「这一类风格」的参照时最顺手。 落地页 Awwwards ↗ (在新窗口打开) www.awwwards.com 前沿工艺天花板(SOTD 带评委分);得奖字体过滤器本身就是排版趋势的一手证据。 httpster ↗ (在新窗口打开) httpster.net 极简/文字主导/粗野主义的克制灵感(3000+ 站);侧栏的风格计数就是策展密度信息。

深学文档

MDN ↗ (在新窗口打开) developer.mozilla.org 任何 CSS/JS 特性的权威说明书;新特性先在这里查语法与兼容表,再去看教程与演示。 web.dev ↗ (在新窗口打开) web.dev Chrome 官方最佳实践:高性能动画指南、prefers-reduced-motion 适配、scroll-driven 教程都在这里。 CSS-Tricks ↗ (在新窗口打开) css-tricks.com 具体技法的深度长文出处:grainy gradients、@property 数字滚动等,适合按技法检索。 WAI-ARIA APG ↗ (在新窗口打开) www.w3.org/WAI/… 30 个组件模式的键盘交互与 ARIA 属性规范;手写 Tabs/Accordion/滑杆之前先读对应 pattern。 无障碍
