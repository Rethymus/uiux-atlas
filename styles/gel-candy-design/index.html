糖果果冻风 Gel-Candy Design

糖果果冻风 · 糖果风 · Gel-Candy Style · Candy Jelly Style

高饱和糖果色 + 半透明凝胶材质 + 大圆角胶囊 + 弹性动效的「甜感」风格;情绪轴在「玩趣/亲和」,与 neo-brutalism 的「对抗/粗野」构成同代两条最大化的表达路线。

代码拆解

结构与 DOM

定义 [R]:高饱和糖果色 + 半透明凝胶材质 + 大圆角胶囊 + 弹性动效的「甜感」风格;情绪轴在「玩趣/亲和」,与 neo-brutalism 的「对抗/粗野」构成同代两条最大化的表达路线(调研 17 §10)。组件级材质配方见 gel-material 条目;本条是流派级组织。

<div class="candy-scene">          <!-- 浅色糖感底 -->
  <button class="candy-btn">点赞</button>   <!-- 胶囊 + 凝胶三件套 -->
  <section class="candy-card">…</section>
</div>

关键点:

  • 单元素组件:凝胶观感(高光内衬/底部加浓/环境光)全部长在自身的 background + box-shadow,流派不需要额外包装层;
  • 玻璃参数用超薄档(clear-frost 域):糖果色已经供色,雾度反而要低(调研 17 §10 实现基调);
  • 三要素缺一即「粉色扁平」:糖果色(色)、胶囊几何(形)、弹性反馈(动)。

样式与参数

三个流派级参数:

.candy-scene {
  background: radial-gradient(90% 70% at 18% 10%,
    oklch(0.96 0.06 calc(var(--gcd-hue) + 40) / .7), transparent 70%), oklch(0.97 0.02 var(--gcd-hue));
}
.candy-btn {
  border-radius: var(--gcd-radius);                       /* 999px = 胶囊(§10) */
  color: #5b2338;                                          /* 深糖色墨水,保对比 */
  background:
    radial-gradient(120% 90% at 30% 18%, rgb(255 255 255 / .85), transparent 42%),
    hsl(var(--gcd-hue) 85% 68% / .8);                      /* 色板:饱和 80–90%、亮度 60–75% */
  box-shadow:
    inset 0 2px 6px rgb(255 255 255 / .8),                 /* 高光内衬 */
    inset 0 -8px 14px hsl(var(--gcd-hue) 85% 55% / .6),    /* 底部糖色加浓 */
    inset 0 0 0 1px rgb(255 255 255 / .25),
    0 10px 22px hsl(var(--gcd-hue) 85% 60% / .4);          /* 糖色环境光 */
  transition: transform .18s cubic-bezier(.34, 1.56, .64, 1);
}
.candy-btn:active { transform: scale(calc(1 - .06 * var(--gcd-squish)), calc(1 - .12 * var(--gcd-squish))) translateY(1px); }
@media (prefers-reduced-motion: reduce) { .candy-btn:active { transform: none; } }

数值出处:色板(珊瑚粉/薄荷/柠黄,饱和度 80–90%、亮度 60–75%)、胶囊 999px、squash 1:0.9 档、回弹 y2=1.56、深糖色墨水 demo 值:调研 17 §10/§4.3;默认 hue 340° 为配方糖果色 #FF7AA9 的实测色相。

与 maximalism 的对照:调研未能核验 2025–26 趋势综述原文,不做断言(如实标注)——只能确立 gel-candy 自身是「单色相最大化(同一糖果色的饱和/体积/弹性全部拉满)」,与多色相堆砌的 classic maximalism 在策略上不同源。与 neo-brutalism 的对照(锚点已核验:neobrutalism.dev 组件库,React + Tailwind v4 / shadcn/ui / 64 组件,口号 “Build bold neobrutalism layouts in minutes”):两者共享「饱和色」,分歧在阴影的硬度与边界的有无——neo-brutalism 粗黑描边 + 硬偏移投影 + 高对比平色,无内衬无弹性;gel-candy 无边柔光 + 弹性高光 + 半透明。demo 右上角「风味切换」即这一对照的现场版。

动效与交互

甜感的动效半边规则(与 gel-material 条目同源):

  • 按压 squash:1:0.9 档压缩 + 1px 下沉,0.18s;回弹贝塞尔 y2>1(1.56)产生 overshoot——果冻三件套缺一不可(§11.9);
  • reduce 禁形变:prefers-reduced-motion: reduce 时 :active 回退 transform: none(配方原样保留);
  • 不要给糖果场景加常驻动画:甜感来自材质与反馈,常驻弹跳/摇晃会把「玩趣」变成「躁动」;hover 位移属于可选,高频操作省略;
  • 焦点可见性:糖果色底上用 3px 高饱和深色 :focus-visible 描边(demo 用 hsl(hue 90% 30%)),不用黑描边——那是对照路线的语义。

真实产品案例

  • iOS 26 系统控件按压的弹性光响应:Glass.interactive() 官方能力,「flexes and energizes on touch」的官方叙事(WWDC25 219 / Applying Liquid Glass 核验,调研 17 §4.2/§10)——甜感弹性在系统级的近亲;
  • rdev/liquid-glass-react:以 elasticity 0.15 参数化弹性的社区组件(GitHub README 核验,6798★);
  • neobrutalism.dev:对照路线 neo-brutalism 的组件库实证(页面核验:64 组件、shadcn/ui 基座)——两条最大化路线并存的同代证据;gel-candy 自身的代表站点调研未能核验(如实标注),不列。

参数敏感度

参数调大会…调小会…
hue跨色相环旋转换「口味」;偏离糖果色域(饱和 80–90%/亮度 60–75%)后像橡胶/树脂收敛回珊瑚粉一族;甜感峰值恰在配方原色
radius>60px 趋向胶囊,甜感几何最强;999px 是流派默认棱角渐显,甜感减弱;≤24px 已进入普通圆角卡语言,流派特征消失
squish>1.2 过度压扁,果冻滑向塑料(配方警告);1.5 时弹性叙事崩塌形变收敛;0 = 无弹性反馈,三件套缺「动」——只剩粉色扁平

经验区间:hue 锁定糖果色域(可轮换口味)、radius 卡片 24–32px / 按钮胶囊 999px、squish 0.8–1。与 gel-material 条目互参:材质级配方与三件套;与 neo-brutalism 条目互参:同代对照路线;与 clear-frost 条目互参:糖果场景玻璃用超薄档;与 claymorphism 条目互参:同为「亲和系」体积暗示,clay 哑光充气、gel 透光含糖。

适用场景 3
  • 儿童/教育/游戏与轻趣产品:玩趣/亲和的情绪轴就是产品情绪(调研 17 §10 情绪轴)
  • 高频轻操作界面(点赞、收藏、快捷开关):squash 反馈让轻操作有「捏下去」的实体感
  • 品牌需要「亲和可接近」的营销页与 onboarding:糖果色 + 胶囊几何降低心理门槛
何时不要用 3
  • 企业工具/金融/医疗等高可信场景:甜感与可信度语义冲突
  • 密集数据与正文:高饱和糖果底上文字对比脆弱(WCAG 1.4.3 需逐处核对)
  • 与 neo-brutalism 混搭同一组件:硬黑描边 + 软果冻内衬的语义互相抵消(对照见 mdx)
无障碍

高饱和糖果底上的文字按最亮高光处核对 4.5:1(WCAG 2.1 SC 1.4.3),正文优先深色字(配方 demo 用 #5B2338 系深糖色);按压 squash 是输入驱动反馈,prefers-reduced-motion 时禁用形变(gel-material 配方原样保留该规则);弹性与颜色不得作为状态的唯一指示。

浏览器支持

组成技法全基线:cubic-bezier 过冲、inset box-shadow、radial-gradient、胶囊圆角(调研 17 §4.4);backdrop-filter Baseline 2024-09(凝胶材质的透底可选,去掉不破坏风格)。

兼容回退

风格不依赖任何高危特性:无 backdrop-filter 时凝胶退为实底糖果色(甜感三件套仍在);无过冲曲线支持时回弹变普通 ease,功能无损。
