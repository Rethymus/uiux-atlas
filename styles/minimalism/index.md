- 别名 / Aliases: 极简主义 · Minimal Web Design · 极简网页
- 简介 / Tagline: 用最少的元素完成任务:2 个字族、受限调色板(中性色+一个强调色)、统一间距刻度、留白替代边框与卡片——不是趋势而是基线。
- Tagline (EN): Do more with less: two typefaces, a restrained palette (neutrals + one accent), a uniform spacing scale, whitespace instead of borders and cards — not a trend but the baseline.

| name | type | default |

## 适用场景 / When to use

- 内容优先的落地页、文档站与编辑型网站——一个想法一个屏幕 / Content-first landing pages, docs and editorial sites — one idea per screen
- 单一 CTA 的转化页:留白把视线推向唯一动作 / Single-CTA conversion pages: whitespace pushes the eye to the one action
- 以字阶做层级的界面——层级来自字号差而非装饰 / Interfaces with type-driven hierarchy — levels from size differences, not decoration

## 何时不用 / When not to use

- 仪表盘等数据密集场景——调研明示极简不适用于数据密集界面 / Dashboards and data-dense scenes — the research explicitly rules minimalism out for dense data
- 多任务并行的工具界面——弱层级导致扫描成本上升 / Multi-task tool UIs — weak hierarchy raises scanning cost
- 依赖边框/卡片区分区域的密集表单——留白层级撑不住复杂结构 / Dense forms relying on borders/cards to zone content — whitespace cannot carry the complexity
