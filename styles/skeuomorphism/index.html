拟物化 Skeuomorphism

拟物 · 拟物设计 · Skeuomorph UI

模拟真实材质与机械控制器的 UI 传统:材质贴图(皮革/拉丝金属/纸纹/木纹)、顶缘受光的凹凸光照模型、可按压/可旋转的机械控制隐喻——2026 年以「新材质家族」四分支回潮。

代码拆解

结构与 DOM

拟物化是「一块材质面板 + 真实控件」的结构:面板底是 CSS 渐变近似的材质(皮革粒面/拉丝金属/纸纹/木纹),上面坐真实控件(拨动开关、步进旋钮)——装饰(材质/缝线/凹凸)全部是 aria-hidden 层,语义全部由真实控件承载。

<div class="panel"> <!-- 材质底 + 缝线 ::after -->
  <h2>Studio Console</h2>
  <div class="plate">Master Bus — Analog</div> <!-- 凹凸铭牌:光照模型示意 -->
  <button role="switch" aria-checked="true" class="switch">
    <span class="nub">ON</span>
  </button>
  <button class="knob" aria-label="增益旋钮:33%,点击步进"></button>
</div>

关键点:

  • 凹凸(box-shadow inset)永远成对出现:顶缘亮内阴影 + 底缘暗内阴影,方向由 --sk-angle 统一驱动——这就是「光照模型」的最小实现;
  • 开关是 role="switch" + aria-checked,旋钮是按钮 + aria-live 读数;机械感是皮肤,语义是骨架;
  • 缝线用 ::after 的 dashed 内边框,pointer-events: none 不拦截交互。

样式与参数

两条 CSS 变量、两条 JS 型参数:

.demo-stage { --sk-angle: 135deg; --sk-emboss: 1; }
/* 材质贴图(CSS 近似,无外部贴图):皮革 = 粒面 radial×2 + 底色 */
.sk-scene[data-texture="metal"] .sk-panel {
  background-image: repeating-linear-gradient(90deg, 细线 1px 3px), linear-gradient(…); /* 拉丝 */
}
/* 光照模型:凹凸渐变统一由 --sk-angle 定向,强度乘 --sk-emboss */
.sk-switch .sk-nub {
  background: linear-gradient(var(--sk-angle), 亮, 中 60%, 次亮);
  box-shadow:
    inset 0 1.5px 1px oklch(1 0 0 / calc(0.95 * var(--sk-emboss))),   /* 顶缘受光 */
    inset 0 -1.5px 1px oklch(0 0 / calc(0.55 * var(--sk-emboss))),    /* 底缘落影 */
    0 2px 3px oklch(0 0 / 0.5);                                       /* 投影 */
}

数值出处:

  • 「材质贴图、机械控制隐喻、光照模型」为调研 03§18 汇总表原文列出的可参数化变量,全部未附数值——135° 光角、emboss 倍率 1、四种材质渐变配方均为本条目基准设定;
  • 顶缘受光内高光取值与调研 09§1.4d 的复刻惯例同构(亮色 rgba(255,255,255,.25~.4),报告标注「推导,非官方数值」);
  • 2026 回潮的四分支(历史手稿/实木/发光生态/Y2K 科技拟物)为调研 03§18 记载的 daisyUI 2025 词条 008/022/023/024。

动效与交互

拟物的动效是「物理直觉」——重量、摩擦、下沉:

  • 拨杆:0.15s 位移到另一端;:active 时滑块内阴影反转(暗影翻到顶缘)——「按进去」的物理下沉,不用发光;
  • 旋钮:点击步进 4 档(0/33/66/100%),rotate 0.2s 转到对应角度(-135°→-45°→45°→135°),读数经 aria-live 播报;
  • 入场:面板淡入 + 10px 上移,0.5s 一次性;
  • prefers-reduced-motion: reduce 时过渡全部取消——位移与旋转瞬时完成,物理感靠静态凹凸维持。

与扁平化的历史对照:拟物与扁平是同一段历史的正反两面——2013 年 iOS 7 转向扁平的公开理由正是「装饰干扰内容」;调研 03§17 记载 2020 年代中期扁平又被玻璃系(Glassmorphism)取代,而调研 03§18 记载拟物在 2026 年以四分支「新材质家族」回潮。三种材质观在同十年内轮替,各自的边界条件见本条目 scenarios。

真实产品案例

  • iOS 6 及更早的原生 App(2007–2013,Apple) — 拟物巅峰期的公认样本:日历的缝线皮革与撕页、Game Center 的毛毡台面、备忘录的黄色便笺——「材质贴图 + 机械隐喻」的教科书集。
  • daisyUI 2026「新材质家族」四分支 — 调研 03§18 记载的当代回潮:历史手稿拟物/实木拟物/发光生态拟物/Y2K 科技拟物,拟物从「过时」重回趋势词汇表的直接证据。
  • 复古收音机/车载仪表类 App — 拉丝金属面板、旋钮与拨杆的机械隐喻与内容(收音/调音)同构,是拟物至今仍最成立的局部场景(社区公认用法,非调研记载)。

参数敏感度

参数调大会…调小会…
texture—(枚举:皮革最「iOS 6」,金属最工业,纸纹最轻,木纹最家具感;材质语义必须与内容语境同构)—(paper 配 emboss=0 即拟物→扁平的退化路径终点)
lightAngle光源绕面板旋转,凹凸高光/暗影整体转向;偏离 135° 后「左上来光」惯例被打破,凹凸读感变怪趋近顶光(90°)凹凸最「正」;=180°(正前光)凹凸几乎消失
emboss凸起更立体,但内阴影吞掉控件边界对比——>1.5 必须补 1px 实色描边保 3:1(SC 1.4.11)趋向平面化;=0 时只剩材质底色,拟物退化为扁平贴图
stitchon 时皮革的年代感最强,但缝线在金属/纸纹材质上是语义错位(should off)off 更通用;缝线细节与材质绑定的纪律比缝线本身重要

经验区间:光角 120–150°、emboss 0.7–1.3;材质只在面板级使用(控件级材质会互相打架);凹凸与描边永远成对核对——这是拟物可访问性的第一道闸。

适用场景 3
  • 音乐/收音机/复古主题的播放器与调音界面——旋钮、拨杆、拉丝金属的机械隐喻与内容语境同构
  • 儿童与教育产品——「像真东西一样可抓握」的心理暗示降低学习成本(与 2026 发光生态拟物分支的场景重合)
  • 仪式感/纪念性场景(证书、票据、会员卡)——纸纹与皮革的材质语义传递「值得保存」
何时不要用 3
  • 高密度生产力界面——材质噪点与凹凸阴影吃掉信息对比度,表格/代码编辑器不成立
  • 系统级 UI 全铺开——iOS 7 放弃拟物的历史原因(装饰干扰内容)至今成立,拟物只适合局部主题化
  • 可访问性关键路径——凹凸阴影会稀释控件边界对比,务必核对 3:1 非文本对比(SC 1.4.11),必要时补描边
无障碍

拟物的装饰层(贴图/缝线/凹凸)必须 aria-hidden,语义靠真实控件承载(按钮/开关用 role 与 aria-checked);凹凸的顶缘亮边与底缘暗边会压缩控件边界的有效对比,按 SC 1.4.11 核对 3:1,不足时叠加 1px 实色描边;旋钮/开关的可操作状态必须同时有 aria 状态与视觉状态;leather 底上的浅色文字按最暗粒面区域核对 4.5:1(SC 1.4.3)。

浏览器支持

全部材质与光照用 CSS 渐变近似(repeating-linear-gradient 做拉丝/木纹、radial-gradient 做皮革粒面),无外部贴图、无滤镜链——支持面为 CSS Image Values 基线;凹凸用 box-shadow inset,基线能力。性能上比真实贴图/滤镜便宜一个量级。

兼容回退

渐变不支持时退化为单色底 + 描边,凹凸(inset shadow)失效后控件仍以形状与位置表达可交互性;拟物的降级终点天然是扁平——把 emboss 调 0、texture 换 paper 即可预览这条退化路径。
