# Claymorphism / 黏土拟物

- 页面 / Page: /uiux-atlas/styles/claymorphism/
- English page: /uiux-atlas/en/styles/claymorphism/
- 本页 / This file: /uiux-atlas/styles/claymorphism/index.md
- 分类 / Category: styles 风格流派 / Styles
- 来源体系 / System: 社区流派 / Community
- 参数化程度 / Parameterization: 3/3
- 别名 / Aliases: 黏土拟物 · Clay UI · 黏土风
- 简介 / Tagline: 粉彩底、超大圆角、双内阴影+外投影做出的「充气黏土」质感——元素浮在页面之上而非从背景挤出,以此修复新拟物的对比度失败。
- Tagline (EN): Pastel bases, oversized radii, and a puffy 'inflated clay' look built from dual inner shadows plus an outer shadow — elements float above the page instead of being extruded from it, fixing neumorphism's contrast failure.

## 参数 / Parameters

| name | type | default |
|---|---|---|
| radius | dimension · px | 32px |
| shadowY | dimension · px | 35px |
| innerAlpha | number | 1 |

## 适用场景 / When to use

- 儿童产品、教育科技与插画型落地页——2026 年该风格的主要落点(调研 03§4) / Kids' products, edtech and illustrated landing pages — the style's main 2026 habitat (research 03 §4)
- CTA 按钮与奖励弹层——厚按钮 3D 挤出感(Duolingo 式)转化表现好 / CTAs and reward dialogs — thick extruded buttons (Duolingo-style) convert well
- 进度、成就、积分等游戏化组件,充气质感强化正反馈 / Gamified progress, achievements and points — the puffy look amplifies positive feedback

## 何时不用 / When not to use

- 数据密集后台与长文阅读——大圆角+厚阴影挤占内容空间 / Data-dense backends and long-form reading — big radii and fat shadows crowd out content
- 成熟企业产品主界面——利基风格与工具型产品的克制基调冲突 / Mature enterprise product shells — a niche style clashes with the restrained tone of tooling
- 深色主题直接套用——配方的高光内阴影(白 .65)在暗底上会变成刺眼描边 / Dark themes as-is — the white .65 top inner highlight turns into a glaring rim on dark bases
