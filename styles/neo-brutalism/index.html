新粗野主义 Neo-Brutalism

新粗野主义 · Neubrutalism · Neo Memphis

黑描边+零模糊硬偏移阴影+糖果色几何块面:粗野主义的「可商用化」分支,把常规 UX 包在响亮的块面里。

社区流派 ★★★

几何▾

px

硬偏移阴影的 x/y 偏移量(零模糊、纯黑)。默认 4px 取自判定配方 box-shadow: 4px 4px 0 #000——「出现 4px 4px 0 #000 硬阴影即新粗野主义」(superdesign.dev)。这是该风格最强的身份特征。

borderWidth3px
px

黑色实线描边宽度。调研区间 2–4px(daisyUI 词条 059 与 superdesign.dev 均记载);默认 3px 为本条目基准(区间中值)。描边与硬阴影共同构成块面的「印刷感」轮廓。

radius0px
px

圆角半径。默认 0=直角,粗野主义的默认姿态(daisyUI:直角或极小圆角);上限 16px 覆盖社区常见的「圆角新粗野」变体,但圆角越大硬阴影的「错位感」越弱。

色彩▾
accent#ff90e8

单一饱和强调色,用于 CTA、高亮块与选中态。默认 #ff90e8 为社区常见糖果色示例(社区常见值,未证实——调研只记载「单一饱和强调色/高饱和扁平色块」,未给出具体色值);生产中常与黑、白、奶油底搭配。

结构与 DOM

新粗野主义没有叠层、没有模糊、没有渐变——只有平面块面加一道印刷式轮廓。DOM 就是普通卡片与表单:

<div class="nb-card">
  <h3 class="nb-title">响亮标题</h3>
  <button class="nb-btn">主操作</button>
</div>

关键点:

  • 每个可交互元素 = 实色填充 + 黑实线描边 + 零模糊硬偏移阴影,三者缺一风格即垮;
  • 阴影颜色固定 #000(或与描边同色),blur 与 spread 恒为 0;
  • daisyUI 判定口诀:出现 4px 4px 0 #000 硬阴影即新粗野主义;
  • 控件行为仍是常规 UX——这个风格「把常规 UX 包裹在响亮的几何块里」,不做可用性实验。

样式与参数

四个参数对应阴影偏移、描边宽、圆角与强调色,经 --nb-* 变量注入:

.nb-card {
  background: #fffdf5;               /* 奶油纸底,demo 示例色 */
  border: var(--nb-border) solid #000; /* 默认 3px,调研区间 2–4px */
  border-radius: var(--nb-radius);   /* 默认 0 = 直角 */
  box-shadow: var(--nb-shadow) var(--nb-shadow) 0 #000; /* 判据配方:4px 4px 0 #000 */
  color: #111111;
}

.nb-btn {
  background: var(--nb-accent);      /* 单一饱和强调色 */
  border: var(--nb-border) solid #000;
  border-radius: var(--nb-radius);
  box-shadow: var(--nb-shadow) var(--nb-shadow) 0 #000;
  font-weight: 700;
}

/* 按压:位移到阴影原点并吞掉阴影(非阴影动画) */
.nb-btn:active {
  translate: var(--nb-shadow) var(--nb-shadow);
  box-shadow: none;
}
.nb-btn:focus-visible {
  outline: 3px solid #000;
  outline-offset: 3px;
}

数值出处:

  • box-shadow: 4px 4px 0 #000 与描边 2–4px:superdesign.dev 粗野主义页(判定口诀原文)与 daisyUI 趋势词条 059(「深色描边、硬偏移阴影」);
  • 直角/极小圆角:daisyUI 词条 059;字体常用 Space Grotesk/Archivo 等几何无衬线展示体(superdesign.dev);
  • 强调色默认 #ff90e8 为社区常见糖果色示例(未证实)——调研只记载「单一饱和强调色」,未给具体色值;
  • 组件参照:neobrutalism.dev(shadcn/ui 基座的 64 个 React 组件库)。

动效与交互

动效规则只有一条:硬,任何柔化都会稀释风格:

  • 按压:元素 translate 到阴影原点、阴影归零——像把块面按进纸里;0s(无过渡)或 ≤0.1s 的极短过渡;
  • 悬停:阴影加倍(calc(var(--nb-shadow) * 2))或填充反色,均无缓动曲线;
  • 焦点:outline: 3px solid #000; outline-offset: 3px,在描边外再画一圈,绝不只靠阴影表达焦点;
  • prefers-reduced-motion:取消全部过渡,按压直接切换终态。

参数敏感度

参数调大会…调小会…
shadowOffset错位感与体积感增强,「贴纸」味变浓;超过 8px 开始显得笨重,布局要预留阴影占位趋近 0 时退化为纯描边卡片,风格身份大减
borderWidth印刷轮廓更狠,块面感更强;超过 4px 在小控件上吃掉可点区域轮廓变细弱;0 时只剩阴影,像普通的扁平卡片
radius圆角新粗野变体,更友好;但圆角与硬阴影的错位感互相削弱回到直角原教旨,错位感最强
accent更亮的糖果色需配黑字,更深的配白字——逐色核对 4.5:1强调色占比越小越「克制粗野」;全部去掉则只剩黑白,风格偏回 web brutalism

经验区间:shadowOffset 3–6px、borderWidth 2–4px、radius 0–8px、单一强调色。描边、阴影、文字三者的黑色必须一致,杂色黑会立刻显得廉价。

适用场景 3
  • SaaS 落地页与独立产品品牌站——2023 年起的「新酷」主场(调研 03§6)
  • 设计社区、作品集、活动与营销页,需要强个性与反抛光姿态
  • 表单与卡片仍走常规 UX——新粗野主义「把常规 UX 包在响亮块面里」,不牺牲可用性
何时不要用 3
  • 长文阅读界面——粗描边与高饱和色块对持续阅读是持续噪音
  • 企业级严肃产品主界面与医疗/金融后台——风格气质与信任基调冲突
  • 多强调色堆叠——判据是单一饱和强调色,糖果色互相冲撞会失去印刷感
无障碍

黑描边天然提供强边界对比(远超 SC 1.4.11 的 3:1);但高饱和糖果色上的文本必须逐个核对 4.5:1(深色文本于亮糖果色、白色文本于深糖果色)。硬阴影不得作为唯一焦点线索——焦点态加 3px offset 的 outline;按压/悬停位移在 prefers-reduced-motion 下取消过渡。

浏览器支持

border、box-shadow、transform 全平台可用,无任何新 API;零模糊硬阴影甚至比柔影渲染更便宜。

兼容回退

无兼容风险,退化方案只关乎可读性:高饱和强调色上的文本若对比不足,把文本色在黑/白之间切换并核对 4.5:1;描边+阴影全部移除后界面退回默认卡片,风格消失但功能不损。

来源 3

起源daisyUI 风格库将其定义为「late-2010s 和 2020 年代的数字风格,把常规 UX 包裹在响亮的几何块、深色描边、硬偏移阴影、平面色块和夸张字体里」,又称 Neo Memphis;2023 年起在 SaaS 落地页与独立产品中成为「新酷」(调研 03§6)。

  1. 条目 糖果果冻风

    对比:同代两条最大化路线共享「饱和色」,分歧在阴影的硬度与边界的有无:粗黑描边+硬投影 vs 无边柔光+弹性高光。

    对比:硬偏移阴影是共享语法,骨架却不同:孟菲斯以图案为骨架,新粗野主义以描边为骨架——同款 4px 4px 0 #000 两种用法。

  3. 条目 经典粗野主义

    反向自「经典粗野主义」的精选:对比关系,原句「判据差异一表分清:阴影(无 vs 硬偏移)、色彩(黑白灰 vs 高饱和)、字体(系统默认 vs 展示体)——共同只有直角与黑边。」
