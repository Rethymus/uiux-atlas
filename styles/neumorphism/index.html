新拟物 Neumorphism

新拟物 · Soft UI · 软拟物

元素与背景完全同色,仅靠「一侧暗、对侧亮」的双阴影把界面从底色里挤出或压入——低对比软塑料质感,2020 年达峰后因可访问性迅速退潮。

社区流派 ★★★
实例演示 官方默认
参数
色彩▾
base#e0e5ec

页面与元素共用的基准底色。默认 #e0e5ec 是社区经典值(superdesign.dev):新拟物的塑形完全依赖双阴影,底色一旦与元素不同色,风格即失效。demo 用 color-mix 由底色现算暗影(底色加深 15%:#e0e5ec→#bec3c9)。

几何▾
offset9px
px

双阴影偏移量。默认 9px 取自经典凸起配方 9px 9px 18px #bec3c9, -9px -9px 18px #ffffff(superdesign.dev);经典压入配方用 6px。经验法则:blur≈2×offset。

blur18px
px

阴影模糊半径。默认 18px 为经典凸起配方值(=2×9px 偏移);经典压入配方用 12px(superdesign.dev)。模糊过大软影发虚,过小则变成硬边浮雕。

动效▾
moderaised

JS 型参数(demo 订阅后切换 data-mode)。raised=凸起:暗影在右下、亮影在左上;inset=压入:阴影翻入内侧。经典压入配方为 inset 6px 6px 12px(superdesign.dev),demo 沿用当前 offset/blur 内凹以便对比。

代码拆解

结构与 DOM

新拟物只有一层结构,却要求页面与元素完全同色:塑形不在 DOM 里,而在阴影里。

<div class="neu-page">
  <div class="neu-card">
    <input class="neu-input" type="text" />
    <button class="neu-btn">按压我</button>
  </div>
</div>

关键点:

  • .neu-page 与 .neu-card 用同一个底色(默认 #e0e5ec),之间没有任何边框或描边;
  • 凸起(raised)与压入(inset)是同一对阴影的两种朝向,靠切换 box-shadow 表达;
  • 元素内部的内容(文字、图标)是普通文档流——阴影只负责「外壳」。

样式与参数

四个参数对应底色、偏移、模糊与凸/压模式,经 --neu-* 变量注入:

.neu-page { background-color: var(--neu-bg); }  /* #e0e5ec 经典值 */

/* 凸起:经典配方 9px 9px 18px #bec3c9, -9px -9px 18px #ffffff */
.neu-card {
  border-radius: 20px;            /* 调研区间 16–24px */
  color: #3a4453;                 /* 文本用高对比墨色 */
  box-shadow:
    var(--neu-offset) var(--neu-offset) var(--neu-blur)
      color-mix(in srgb, var(--neu-bg) 85%, black),  /* 底色加深 15% */
    calc(-1 * var(--neu-offset)) calc(-1 * var(--neu-offset)) var(--neu-blur)
      #ffffff;                    /* 亮影=纯白,经典配方值 */
}

/* 压入:阴影翻入内侧(经典配方 inset 6px 6px 12px) */
[data-mode="inset"] .neu-card {
  box-shadow:
    inset var(--neu-offset) var(--neu-offset) var(--neu-blur)
      color-mix(in srgb, var(--neu-bg) 85%, black),
    inset calc(-1 * var(--neu-offset)) calc(-1 * var(--neu-offset)) var(--neu-blur)
      #ffffff;
}

数值出处(superdesign.dev 新拟物页):

  • 基准色 #e0e5ec、凸起配方 9px 9px 18px #bec3c9, -9px -9px 18px #ffffff、压入配方 inset 6px 6px 12px;
  • 暗影=底色加深 15%:color-mix(in srgb, #e0e5ec 85%, black) 精确等于经典暗影 #bec3c9;
  • blur≈2×offset:经典凸起 18px=2×9px、压入 12px=2×6px;
  • 圆角集中在 16–24px;暗色模式需重调两个阴影,不能反色了事。

⚠️ 可访问性反例:典型新拟物元件的边缘对比仅约 1.4:1,低于 WCAG 2.2 SC 1.4.11 要求的组件边界 3:1 非文本对比,且在保留柔和质感的前提下不可修复——调研明确记载这是该风格 2021 年退潮的核心原因。使用时文本一律用高对比墨色、控件边界补实色描边或直接退回常规卡片。

动效与交互

凸起⇄压入是这套语言里唯一的「动词」:

  • 按压反馈:按钮 :active 时把凸起阴影换成 inset 阴影,0.15s 过渡;小元素上可以接受,大面积卡片避免过渡(阴影过渡走重绘,代价高于 transform);
  • 开关语义:滑杆轨道常驻 inset(槽位),旋钮凸起;拖动只动 transform;
  • 入场:整卡淡入即可;prefers-reduced-motion 时取消过渡与入场动画,直接呈现终态;
  • hover 位移、阴影加深一类的装饰动效应当省略——低对比材质经不起更多含糊线索。

参数敏感度

参数调大会…调小会…
base偏深或偏彩的底色让暗影差更明显,塑料感变「橡胶感」更亮的底色整体更「奶油」,但亮影(纯白)与底色的差被拉大,质感变脆
offset浮雕更立体,控件显得更「厚」;超过 16px 后阴影占位感过强,布局变松趋近 0 时退化为平面色块,凸/压几乎不可辨
blur软影更弥散、氛围更柔;远超 2×offset 后阴影发虚,边界更难读硬边浮雕,接近「刻上去」的效果;低于偏移量会丢失软塑料质感
modeinset 全局化让整个界面像「凹模」,只适合状态面板类演示raised 是默认形态;两者切换是最自然的按压反馈

经验区间:offset 4–12px、blur 取 2×offset、圆角 16–24px。底色、暗影、亮影三者必须同源推导,混入无关灰色会立刻显得「脏」。

适用场景 3
  • 音乐播放器、计算器等「软塑料」控制面板(该风格最初的流行场景)
  • 开关、滑杆、按钮组等低频控件,按压态凸起⇄压入语义清晰
  • 氛围优先的品牌页与概念稿,数据密度低、装饰性优先
何时不要用 3
  • 正文文本与关键信息——典型边缘对比仅约 1.4:1,低于 WCAG 2.2 SC 1.4.11 的 3:1(调研 03§3 反例)
  • 数据密集仪表盘与表单页——层级线索太弱,扫描成本高
  • 暗色主题直接反色——暗色下需重调两个阴影而非简单反转(superdesign.dev)
无障碍

反例警示:典型新拟物元件的边缘对比仅约 1.4:1,无法满足 WCAG 2.2 SC 1.4.11 组件边界 3:1 非文本对比,且在保留柔和质感的前提下不可修复——这正是其 2021 年退潮的核心原因。补救:文本一律用高对比墨色并独立核对 4.5:1;控件边界补 1px 实色描边或改回常规卡片;焦点态不得只靠阴影表达。

浏览器支持

box-shadow 全平台可用;demo 用 color-mix() 由底色现算暗影(Chrome 111+/Edge 111+/Firefox 113+/Safari 16.2+),旧浏览器可直接写死经典色对 #bec3c9/#ffffff。

兼容回退

双阴影无法传达层级时的退化方案:回到常规浅色卡片——保留同色底,补 1px 实色边框与常规投影区分边界,文本改用高对比墨色;交互态(按下/焦点)必须改用边框、填充或下划线等非阴影线索表达。

来源 3

起源术语为 neo + skeuomorphism 合成词,2019 年由 Jason Kelly 创造;Alexander Plyuto 在 Dribbble 的银行 App 拟物稿引爆传播,雏形见于 2019 年华为鸿蒙智慧屏界面;2020 年 11 月 macOS Big Sur 被认为带明显新拟物特征;2021 年因可访问性问题迅速退潮(调研 03§3)。

  1. 条目 毛玻璃

    对比:同为 2018–2020 的质感风潮:玻璃靠模糊+亮边透出背景,新拟物靠同色明暗挤压——两种「柔和立体」的材质观互为对照。

  2. 条目 柔光设计

    对比:都做柔和立体,可读性下限天差地别:新拟物同色挤压对比天生孱弱,柔光设计由实底内容层兜底。

  3. 条目 黏土拟物

    反向自「黏土拟物」的精选:对比关系,原句「分野在结构上就能看出来:黏土元素自带底色浮于页面之上,新拟物与背景同色被对比度反噬——修复者与被修复者对照读。」
