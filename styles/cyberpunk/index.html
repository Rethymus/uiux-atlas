赛博朋克 Cyberpunk

赛博朋克 · Cyberpunk UI · 霓虹 HUD

近黑底上的电光青/品红/酸黄,叠加扫描线、色差与 RGB 通道错位——「故障即氛围」,压缩等宽字体与 HUD 网格读数构成终端语感。

结构与 DOM

赛博朋克 UI 是「三层叠印」:近黑底在最下,霓虹内容层在中间,扫描线/色差等装饰层用伪元素盖在最上(且必须 aria-hidden,不承载信息)。

<section class="cy-scene">
  <div class="cy-hud">
    <h1 class="cy-title">NEON DISTRICT</h1>
    <div class="cy-readout" role="status">LINK: STABLE · 98.2%</div>
    <button class="cy-btn">JACK IN</button>
  </div>
</section>

关键点:

  • 底色必须是近黑(暗底是硬性前提),电光青/品红/酸黄只在这个底上成立;
  • 霓虹感 = 双层 text-shadow 辉光 + 品红/青 RGB 分离;色差是「故障即氛围」的核心手法;
  • HUD 语言:等宽压缩字体、遥测读数、角标框线——装饰框线全部 aria-hidden;
  • 内容层仍是常规 DOM,读数用 role="status" 承载真实状态。

样式与参数

四个参数对应扫描线间距、扫描线透明度、RGB 位移与霓虹亮度,经 --cy-* 变量注入:

.cy-title {
  color: #fcee0a;                    /* 酸黄,demo 示例色 */
  font-family: ui-monospace, "JetBrains Mono", monospace;
  letter-spacing: 0.06em;
  text-shadow:
    calc(-1 * var(--cy-rgb)) 0 rgb(255 43 214 / 0.8),   /* 品红左错位 */
    var(--cy-rgb) 0 rgb(0 240 255 / 0.8),               /* 电光青右错位 */
    0 0 calc(10px * var(--cy-glow)) rgb(252 238 10 / calc(0.55 * var(--cy-glow))),
    0 0 calc(28px * var(--cy-glow)) rgb(252 238 10 / calc(0.30 * var(--cy-glow)));
}

/* 扫描线:1px 暗线,周期 = scanGap,透明度 = scanAlpha */
.cy-scene::after {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
  background: repeating-linear-gradient(
    to bottom,
    rgb(0 0 0 / var(--cy-scan-alpha)) 0 1px,
    transparent 1px var(--cy-scan-gap)
  );
}

数值出处与诚实标注:

  • 调研(enlighten cyberpunk 页)记载的可调变量:扫描线间距与透明度、RGB 位移量、霓虹色板对暗底亮度比——但未记载任何具体数值;
  • 因此四个参数的默认值(4px / 0.25 / 2px / 1)均为本条目基准设定,不是官方默认;色板取社区惯用的青 #00f0ff/品红 #ff2bd6/酸黄 #fcee0a(demo 示例色,同样未证实为官方值);
  • 代表参照:Cyberpunk 2077 官网(扫描线+霓虹+全屏视频)、攻壳机动队电影站、AI Utility Grid(克制的终端美学)。

动效与交互

故障是氛围,不是通知——动效必须全部可降级:

  • glitch 抖动:标题周期性横移 1–2 个 RGB 位移并短暂加强分离,4s 周期内只闪 2–3 次,避免高频频闪;
  • 光标闪烁:遥测读数行尾方块光标 1.2s 步进闪烁;prefers-reduced-motion 时改为常亮;
  • 降级链:reduced-motion 下关闭全部动画,保留静态 RGB 分离与扫描线——核心识别不依赖动效;
  • 按钮 hover 辉光增强 0.15s;按压下沉 1px。装饰层永远 pointer-events: none,不拦截交互。

参数敏感度

参数调大会…调小会…
scanGap百叶窗感,底色纹理变粗;>8px 开始干扰正文密集 CRT 质感;2px 时整屏发灰,亮度损失明显
scanAlpha扫描线更狠,CRT 味更重;>0.4 压暗霓虹,对比度开始失守趋近 0 扫描线消失,回到纯暗底
rgbShift故障感与「印刷错版」味增强;>4px 文字边缘发散,可读性骤降色差收敛;0 时变成干净的霓虹字,故障感全靠动画
glow泛光晕染,霓虹管灯感;2 时文字边缘开始糊辉光收敛;0 时只剩平色文字,霓虹感消失

经验区间:scanGap 3–6px、scanAlpha 0.15–0.3、rgbShift 1–3px、glow 0.8–1.4。所有参数都在装饰层上生效,正文读数区务必留一个「关灯也清晰」的版本。

适用场景 3
  • 娱乐与游戏品牌站——Cyberpunk 2077 官网(扫描线+霓虹+全屏视频)是标杆案例(调研 03§14)
  • 音乐、夜生活、电竞活动页与限定发布皮肤
  • 短时停留的沉浸式首屏——强氛围、低信息密度
何时不要用 3
  • 需要长时间阅读的界面——低对比霓虹文字伤害可读性(调研明示局限)
  • 企业产品与生产力工具——受众窄、时代感强易过时
  • 重资产预算紧张的项目——该风格常伴随视频/粒子/着色器成本(调研明示)
无障碍

调研明示「装饰性低对比霓虹文字伤害可访问性」:霓虹文字逐一核对 4.5:1,辉光只是增强不承担对比;扫描线与色差层 aria-hidden,绝不承载信息;glitch 动画必须响应 prefers-reduced-motion 降级为静态分离,并避免大面积高频闪烁(光敏性不适风险)。

浏览器支持

repeating-linear-gradient、多层 text-shadow、CSS 动画全平台可用;demo 的 rgb(... / calc(...)) alpha 计算需现代浏览器,旧环境可写死 alpha 值。

兼容回退

降级顺序:先关 glitch 动画(静态 RGB 分离仍成立),再关扫描线,最后保留纯色霓虹文字+HUD 边框——核心识别(近黑底+电光色)不依赖任何动效。动画只装饰,不承载信息。

  1. 条目 极光渐变

    搭配:电光青/品红/酸黄只在近黑底上成立——极光渐变正是暗底氛围光的成熟配方:多层低亮度光斑缓慢平移。

  2. 条目 全息铬光

    对比:同在暗场舞台,构图相反:赛博朋克以故障、扫描线铺满氛围,全息铬光只给一件反光主体当主角。

  3. 条目 玻璃色散边

    反向自「玻璃色散边」的精选:搭配关系,原句「色散边是赛博朋克「故障即氛围」的材质级实现:扫描线与 RGB 通道错位之外,真实光学也提供红蓝错位。」
