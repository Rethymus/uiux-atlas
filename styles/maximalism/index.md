## 适用场景 / When to use

- 品牌快闪/活动/节日营销页——单页封面,读者停留短、需要情绪冲击 / Brand drops, campaigns, seasonal specials — single cover pages where dwell time is short and emotional punch matters
- 时尚、音乐与潮流文化:巡演海报页、专辑落地页、潮牌 lookbook / Fashion, music and street culture: tour poster pages, album landing pages, lookbooks
- 创意作品集与插画师主页——个人风格的宣言式表达 / Creative portfolios and illustrator homepages — manifesto-style personal statements
- 印刷物数字化:杂志专题、海报档案——原语言就是高密度纸面 / Print digitized: magazine features, poster archives — the source language is already dense paper

## 何时不用 / When not to use

- 数据密集界面:仪表盘、表单、后台——图案场会吞掉数据可读性 / Data-dense UI: dashboards, forms, admin panels — pattern fields swallow data legibility
- 长文阅读页——正文行宽被装饰挤压,违背 45–75ch 红线 / Long-form reading — decorations squeeze the measure, breaking the 45–75ch red line
- 关键任务路径:支付、错误提示、设置——撞色与叠印增加认知负担 / Critical task paths: checkout, error states, settings — clashing hues and overprint add cognitive load
- 小屏弱网:多层背景与渐变合成开销大,移动端密度失控 / Small screens on slow networks: multi-layer backgrounds cost compositing time and density gets unmanageable
