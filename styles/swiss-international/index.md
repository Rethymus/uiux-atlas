## 适用场景 / When to use

- 导视系统、文档站、报告与年报——网格 + 中性无衬线 + 单强调色的信息秩序场景 / Wayfinding, documentation, reports and annual reviews — information-order contexts of grid + neutral sans + one accent
- 字驱动的海报与展览物料:巨大 display 层差 + 齐左不齐右的非对称断行 / Type-driven posters and exhibition collateral: giant display gaps + flush-left ragged-right asymmetry
- 需要「客观、机构感」的品牌页面——调研 03§15:1960s 起企业/机构拥抱,如今是网页默认语言 / Brand pages that need to read 'objective, institutional' — research 03 §15: embraced by corporations/institutions since the 1960s, now the web default language

## 何时不用 / When not to use

- 情绪化营销场景——刻意压制的表达会让 CTA 失去张力,需另配插画/摄影情绪层 / Emotional marketing contexts — deliberately suppressed expression drains CTA tension; pair it with an illustrative/mood layer
- 把强调色用成多色系统——「单一结构性强调色」是纪律,第二个强调色出现即破格 / Turning the accent into a multi-color system — 'a single structural accent' is the discipline; a second accent breaks the style
- 非 Helvetica/Univers 语感的花式展示字体——瑞士的「中性」要求几何无衬线,手写体/装饰体直接破坏风格 / Fancy display faces outside the Helvetica/Univers voice — Swiss 'neutrality' demands geometric sans; script or decorative faces break the style outright
