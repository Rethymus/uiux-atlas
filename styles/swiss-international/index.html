瑞士国际主义 Swiss International Style

瑞士风格 · 国际主义排版风格 · International Typographic Style

数学网格 + 中性无衬线 + 单一结构性强调色:齐左不齐右、以尺寸/字重/位置建立纯结构层级、客观摄影代替插画——今天的「网页默认语言」正是它的直系遗产。

几何▾
cols6

模块网格列数。调研把「模块网格列数/栏距/基线」列为可调变量但未记载具体数字(design-styles.enlighten-media.net swiss 页);网页栅格社区常见 12 列(未证实为规范值),海报语境本条目取 6 列为基准设定。JS 型参数——demo 订阅后重算栅格跨列与叠层。

动效▾
ratio1.414

字阶比率(major scale)。四个选项全部来自 modularscale.com 计算器记载的比率:大三度 4:5=1.25、纯四度 3:4≈1.333、增四度 1:√2≈1.414、纯五度 2:3=1.5(调研 05§17,页面文案一手核对)。默认 1.414:瑞士海报的巨大 display 层差需要激进比率。标题字号 = 基准字号 × ratio⁴,经 CSS calc 链驱动。

gridoff

JS 型参数(demo 订阅后切换 data-grid)。on 时叠加 N 列栅格参考叠层,展示「数学网格是最具可读性与和谐性的信息结构手段」(调研 03§15 原文)——叠层为纯装饰,aria-hidden。

色彩▾
accent#E30613

单一结构性强调色——经典瑞士红。调研 03§15 记载「单一结构性强调色(经典瑞士红)」但未记载色值;#E30613 为社区常见基准值(未证实为规范值),按 WCAG 相对亮度公式对白底计算对比度约 4.9:1,可通过 SC 1.4.3 正文阈值。

代码拆解

结构与 DOM

瑞士国际主义是一张「落在数学栅格上的纸」:海报容器本身是 display: grid + repeat(N, 1fr),每个元素(标题、色条、图块、正文、页脚)显式声明跨列区间——栅格不是背景装饰,是布局的语法本身。

<div class="poster" style="grid-template-columns: repeat(6, 1fr)">
  <div class="meta">Gestaltung · 1959</div>      <!-- 跨全宽 -->
  <h1 class="title">Die neue Gestaltung</h1>      <!-- 跨全宽,齐左 -->
  <div class="accentbar"></div>                   <!-- 跨 1–2 列:唯一红 -->
  <figure class="photo">…</figure>                <!-- 跨左半列:客观摄影 -->
  <div class="body">…</div>                       <!-- 跨右半列 -->
  <footer class="foot">…</footer>                 <!-- 跨全宽 -->
</div>

关键点:

  • 栅格叠层(.overlay)是布局容器的镜像栅格,aria-hidden 纯装饰,打开后可逐列核对元素落位;
  • 字阶只有一条生成规则:标题 = 基准字号 × 比率⁴,kicker = 基准 × 比率¹,正文 = 基准——整个层级由一个比率生成,不手工调字号;
  • 图块是「客观摄影」占位(实色渐变块 + 图注),不做插画化装饰。

样式与参数

四个参数:两条 CSS 变量、两条 JS 型参数:

.demo-stage {
  --sw-ratio: 1.414;   /* modularscale.com 记载比率:增四度 1:√2 */
  --sw-accent: #e30613; /* 社区常见基准值,非官方记载 */
}
.poster {
  grid-template-columns: repeat(6, minmax(0, 1fr)); /* cols 参数,JS 重算 */
  gap: 12px;
}
.title {
  font-family: "Helvetica Neue", Helvetica, Arial, sans-serif; /* 系统栈近似 Helvetica */
  font-size: calc(var(--sw-base) * var(--sw-ratio) * var(--sw-ratio) * var(--sw-ratio) * var(--sw-ratio));
  line-height: 0.98;
  letter-spacing: -0.02em;
}
.accentbar, .kicker, .foot strong { background|color: var(--sw-accent); } /* 唯一强调色 */

数值出处:

  • 字阶比率四个选项(1.25 / 1.333 / 1.414 / 1.5)= modularscale.com 记载的比率(大三度 4:5、纯四度 3:4、增四度 1:√2、纯五度 2:3;调研 05§17 一手核对);
  • 「模块网格列数/栏距/基线」「单一结构性强调色(经典瑞士红)」为调研 03§15 原文变量,均未附数值——列数 6、红 #E30613 为基准设定(#E30613 为社区常见值,未证实);
  • 「数学网格是最具可读性与和谐性的信息结构手段」与「齐左不齐右」「客观摄影代替插画」皆为调研 03§15 原文特征。

动效与交互

瑞士风格的动效近乎「无动效」——纸张不表演:

  • 入场:海报整体淡入 + 10px 上移,0.45s,一次性;无弹跳无回摆;
  • 栅格核对:切换叠层瞬时显示/隐藏(无过渡)——核对工具不该有动画延迟;
  • hover/按压:不添加。装饰性动效与「客观、机构感」的立场冲突,这是风格纪律的一部分;
  • prefers-reduced-motion: reduce 时仅取消入场淡入——本来也没有别的动画可关。

真实产品案例

  • Müller-Brockmann 海报(1950s,巴塞尔/苏黎世) — 模块网格 + Helvetica 体系的开创性载体,《Neue Grafik》期刊发表的标准样本(调研 03§15)。
  • 纽约地铁导视(1972,Vignelli) — 把瑞士原则(黑体字、色块线路、编号系统)带给大众的标志性公共导视,也是「单一强调色结构化信息」的最大规模实战(调研 03§15)。
  • MIT 与 1960s 美国机构/企业 — 瑞士风格在美国机构化落地的一批记载案例,奠定了「客观机构感 = 网格 + 无衬线」的当代认知;如今网格、无衬线与结构化层级已是网页默认语言(调研 03§15)。

参数敏感度

参数调大会…调小会…
cols栅格更细,元素落位更自由、版面更「机构报告」;>6 后海报语境显得琐碎跨度更粗,非对称张力更强;=2 时近乎双栏传单,层级选择变少
ratiodisplay 层差更陡(1.5 纯五度),海报冲击力强,小屏标题易溢出层差平缓(1.25 大三度),接近正文书的克制,海报感减弱
accent—(换色即换品牌语境,但必须是一个色;红是最历史的选择)—(红 #E30613 对白底 ≈4.9:1;更浅的红会跌破 4.5:1,需重新核对)
gridon 时叠层暴露每列边界——元素不落列会立刻显形,是自查工具off 时纯版面观感;叠层永不承载信息(aria-hidden)

经验区间:海报 4–6 列、网页 12 列(社区惯例,未证实为规范);比率 1.333–1.414;强调色只出现在色条、kicker、页脚数字三处结构点——强调色出现在第三处以上就开始稀释「单一结构性」的纪律。

适用场景 3
  • 导视系统、文档站、报告与年报——网格 + 中性无衬线 + 单强调色的信息秩序场景
  • 字驱动的海报与展览物料:巨大 display 层差 + 齐左不齐右的非对称断行
  • 需要「客观、机构感」的品牌页面——调研 03§15:1960s 起企业/机构拥抱,如今是网页默认语言
何时不要用 3
  • 情绪化营销场景——刻意压制的表达会让 CTA 失去张力,需另配插画/摄影情绪层
  • 把强调色用成多色系统——「单一结构性强调色」是纪律,第二个强调色出现即破格
  • 非 Helvetica/Univers 语感的花式展示字体——瑞士的「中性」要求几何无衬线,手写体/装饰体直接破坏风格
无障碍

瑞士风格天然亲和可访问性:齐左不齐右避免不均匀断行伤害阅读(SC 1.4.8 语义);层级只靠尺寸/字重/位置,不依赖颜色区分(SC 1.4.1 Use of Color);单一强调色红 #E30613 对白底约 4.9:1(WCAG 相对亮度公式计算),过 SC 1.4.3 正文阈值——但小号红字仍应慎用,红只作结构与强调;栅格叠层为 aria-hidden 装饰,永不承载信息。

浏览器支持

布局依赖 CSS Grid 的 repeat() 与 CSS 变量代入 calc()——两者均为全现代浏览器基线(CSS Grid 基线 2017);栅格叠层用纯 background 渐变绘制,无前缀需求。字阶 calc 链只乘 unitless 变量,无兼容坑。

兼容回退

不支持 CSS Grid 的极旧环境退化为单栏文档流:标题、图块、正文按序排列,层级靠字号与字重维持——瑞士的层级本来就是纯结构(尺寸/字重/位置),不依赖任何新特性,天然可降级。

来源 4

起源1930s–1950s 成形的系统性平面设计方法:1918 年 Ernst Keller 在苏黎世应用艺术学校开创课程(「设计方案应从内容中产生」);1950s 巴塞尔/苏黎世 Hofmann 与 Müller-Brockmann 以《Neue Grafik》发表网格 + Helvetica 体系;1959 年期刊 New Graphic Design 将运动推向国际;Univers 引出 Neue Haas Grotesk→Helvetica;1960s 起被 MIT 等美国机构拥抱;1972 年 Vignelli 纽约地铁导视把瑞士原则带给大众(调研 03§15)。
