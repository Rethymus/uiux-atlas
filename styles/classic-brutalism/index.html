经典粗野主义 Classic Brutalism

经典粗野主义 · Web Brutalism · Classic Brutalism

默认、未加修饰的 HTML:系统字体、黑白硬对比、1–2px 黑边框、浏览器默认链接蓝、零阴影零圆角——「诚实材料」的心态而非视觉配方。

几何▾

实心黑边框宽度,经 --cb-border 驱动全部容器。调研 03§5 记载区间 1–2px,默认取上限 2px;对照新粗野主义的 2–4px 黑描边(本库 neo-brutalism 条目)——更细的边框是经典与 neo 的第一肉眼差异。

色彩▾
linkColor#0000EE

链接色,默认即浏览器默认链接蓝 #0000EE(调研 03§5 逐字记载)。「链接像链接」:下划线永远保留,链接色就是浏览器默认色——不装饰、不品牌化,这正是「诚实材料」宣言的直接执行。

动效▾
typefacesystem

JS 型参数(demo 订阅后切换 data-typeface)。system=系统默认衬线(Times New Roman 系,补研 11§6 判据「系统默认字体」);mono=等宽栈 ui-monospace/"JetBrains Mono"/Courier New(调研 03§5 记载)。两者都是经典粗野主义的合法字面——共同点是「不加载字体文件」。

hoverInverton

JS 型参数(demo 订阅后切换 data-hover-invert)。on=hover 硬反色(黑↔白)零过渡(调研 03§5 记载);off=hover 仅补下划线,用于对照「反色不是唯一合法反馈」。无论哪档,transition 都保持 0——经典粗野主义不用缓动。

结构与 DOM

经典粗野主义的 DOM 就是「浏览器会渲染的最普通结构」:h1 / p / a / ul / table 直接承载内容,没有装饰层、没有卡片包装、没有背景层——结构即视觉。99designs 判据:「brutalism 更多描述一种心态而非视觉特征」,在 Web 上即「默认、未加修饰的 HTML」。

<main class="page">
  <h1>THE BRUTALIST WEB</h1>
  <hr />
  <div class="box">
    <h2>Manifesto</h2>
    <ul><li>内容优先</li><li>链接像链接</li><li>性能即设计</li></ul>
  </div>
  <table>…</table>
  <a href="#">Default link</a>
  <button class="btn">Submit Query</button>
</main>

关键点:

  • 语义标签裸露使用,删除全部 CSS 后页面仍完全可读、可导航——这是本风格的设计承诺,不是缺陷;
  • border-radius: 0、box-shadow: none、transition: none 三件套全局成立:零圆角、零阴影、零过渡;
  • 全大写标题(text-transform: uppercase + letter-spacing: -0.02em)与超大字号是仅有的两处「姿态」。

样式与参数

四个参数:两条 CSS 声明、一个字体档开关、一个 hover 反馈开关:

.page {
  --cb-border: 2px;    /* 实心黑边框(参数,调研区间 1–2px) */
  --cb-link: #0000EE;  /* 浏览器默认链接蓝(参数,默认即默认) */
  font-family: "Times New Roman", Times, Georgia, serif; /* 系统默认字 */
  background: #fff;
  color: #000;
}
.page * { border-radius: 0; box-shadow: none; transition: none; }
.box, .btn, th, td { border: var(--cb-border) solid #000; }
a { color: var(--cb-link); text-decoration: underline; }   /* 下划线永不剥除 */
.btn:hover { background: #000; color: #fff; }              /* 硬反色,零过渡 */

数值出处:

  • 边框 1–2px 实心黑、链接蓝 #0000EE、hover 硬反色无过渡、等宽栈 ui-monospace/"JetBrains Mono"/Courier New、正文 ≥16px:全部为调研 03§5 逐字记载;
  • 系统默认字体(Times New Roman 系)、黑白灰单色、直角矩形、裸功能、模块化重复:补研 11§6(99designs + brutalistwebsites.com 宣言);
  • 与新粗野主义判据差异(补研 11§6 速查表,本条目成立的四行):阴影——经典无(或裸边框)vs neo 无模糊硬阴影;色彩——黑白灰单色 vs 高饱和撞色;字体——系统默认字 vs 实验性展示字体;核心——诚实裸露的原生 HTML vs 设计过的「粗」。共同的只有「直角」与「黑边」两个远亲特征。

动效与交互

经典粗野主义的动效规范是「没有动效」:

  • hover 硬反色:黑↔白瞬时切换,transition: 0——反色是状态回执,不是动画;
  • 焦点环保留浏览器默认 outline,不去除、不自绘——裸焦点环本身就是风格的一部分;
  • 无入场动画、无滚动视差、无缓动曲线;prefers-reduced-motion 对本风格天然成立——本来就没有任何运动需要豁免;
  • 判据红线:任何「加一点过渡会更精致」的冲动都是对风格的背叛——「摒弃装饰」包括摒弃动效装饰。

真实产品案例

  • Craigslist — 数十年几乎保持浏览器级默认渲染的分类目录,「功能型粗野主义」常青的代表(调研 03§5)。
  • Hacker News — 系统字体 + 默认蓝链接 + 橙色徽标的极简裸页,流量与年龄都证明「性能即设计」可以成立(调研 03§5)。
  • Gucci PF18 与 A$AP Rocky 的 AWGE — 出现在 brutalistwebsites.com 画廊的「风格型粗野主义」:奢侈品牌与嘻哈厂牌借裸页做反差表达——画廊式的一次性用法,而非长期皮肤(调研 03§5;调研同时提示风格型易过时:需求 2026-03 达峰 3.6% 后回落)。

参数敏感度

参数调大会…调小会…
borderWidth>2px 逐步滑向新粗野主义的描边区间(neo 为 2–4px),风格边界开始模糊0 时容器失去边界,退化为纯默认渲染——接近「未装修」而非「宣言」
linkColor改成品牌色即违背「链接像链接」;紫红 #551A8B(已访问默认色)是唯一合法旁支保持默认蓝是判据本体;任何自定义都让「裸 HTML 感」打折
typeface—(枚举:system 最「裸」,mono 的 Hacker News 感更重)—(两档都是合法字面;共同点是零字体下载)
hoverInverton=黑↔白反色,反馈最响亮off=仅下划线,更接近浏览器默认行为;两档都必须保持零过渡

经验区间:边框 1–2px、正文 ≥16px、黑白二色为主(灰阶允许用于辅助文字)。风格边界记住一条:一旦出现硬偏移阴影(4px 4px 0 #000)或高饱和色块,你写的就是新粗野主义,不是它——判据口诀出自调研 03§5(「出现 4px 4px 0 #000 硬阴影即新粗野主义」)。

适用场景 4
  • 功能型内容站:文档、论坛、目录、新闻聚合——Craigslist/Hacker News 一脉的「常青用法」(调研:功能型粗野主义常青)
  • 宣言式作品集与杂志专题——用「反装饰」本身做表达,2014 画廊一脉的风格型用法
  • 原型与 MVP——零样式预算下用浏览器默认渲染先上线
  • 性能极限场景:弱网、低功耗设备——无字体/无装饰图片就是最快的首屏
何时不要用 4
  • 消费级品牌站——「未抛光」与品牌信任感直接冲突
  • 数据可视化与富交互应用——黑白灰单色撑不起多维信息编码
  • 把「风格型粗野」当长期皮肤:调研明示其易过时(2026-03 需求峰值 3.6% 后回落)
  • 密集表单与支付流——默认渲染的控件外观在品牌一致性上会失守
无障碍

黑白硬对比天然过线:黑字白底即 WCAG 对比上限 21:1,任何文字色核对都轻松过 SC 1.4.3。链接永远保留下划线(「链接像链接」=可及性线索不剥除);焦点环使用浏览器默认 outline、不去除——裸焦点环本身就是本风格的一部分。hover 反色不承载信息、纯装饰,键盘路径不依赖它。

浏览器支持

零新特性依赖:系统字体、链接下划线、border、ul/table 全是 Web 元老特性,所有浏览器一致渲染;不存在任何 @supports 分支。

兼容回退

该风格的 fallback 就是它自己:把 CSS 整个删掉,页面仍完全可读、可导航、可操作——「默认、未加修饰的 HTML」意味着浏览器默认渲染即是兜底。这也是它「性能即设计」宣言的来源:无字体下载、无图片装饰、无 JS 依赖。

来源 4

起源源自战后建筑 béton brut(素混凝土),1952 年柯布西耶马赛公寓为建筑起点;2014 年 Pascal Deville 的 brutalistwebsites.com 将其「法典化」为独立数字风格——「对轻飘、乐观、讨好式现代网页设计的年轻代反叛」;David Bryant Copeland 宣言:「诚实材料:内容优先、链接像链接、性能即设计」(调研 03§5;补研 11§6)。

  1. 条目 新粗野主义

    对比:判据差异一表分清:阴影(无 vs 硬偏移)、色彩(黑白灰 vs 高饱和)、字体(系统默认 vs 展示体)——共同只有直角与黑边。

    对比:都做「去装饰」但立场相反:扁平是设计过的系统纪律,经典粗野是未装修的诚实默认——两种朴素别混。

    反向自「字体搭配」的精选:搭配关系,原句「配字的零依赖极值:经典粗野停在系统默认字(Times New Roman 系)实现「零字体下载」,越过这条边界,配字问题本身消失了。」
