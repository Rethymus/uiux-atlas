柔光玻璃 Soft-Glow Glass

柔光玻璃 · 发光玻璃 · Glow Glass · Lit-Edge Glass

玻璃基底 + 向内渗光(inner bleed)+ 向外泛光(bloom)+ 受光亮边(lit edge)三件套:面板自己成为场景里的光源之一,而不只是被动模糊背景。

代码拆解

结构与 DOM

柔光玻璃与普通 glassmorphism 的差别不在模糊,而在光学事件的注入:玻璃基底之外,再叠「向内渗光(inner bleed)+ 向外泛光(bloom)+ 受光亮边(lit edge)」三件套,让面板自己成为场景里的光源之一(调研 17 §1.1)。官方对应物是 Liquid Glass 的「reflects color and light of surrounding content」(WWDC25 219 核验)。

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="soft-glow">          <!-- 玻璃基底:blur + 低填充 -->
    <h3>标题</h3>
  </div>
</div>

关键点:

  • 结构与毛玻璃条目相同:背景 → 玻璃面板 → 内容三层;光学事件全部长在面板自己的 box-shadow 与 ::after 上,不增加 DOM;
  • 单一方向光源:顶角再叠一层 radial-gradient 环境光(::after),模拟场景里只有一盏灯——柔光的「柔」来自光源的单一性;
  • 光色与内容主色同族,面板才会像「被照亮」而不是「贴了滤镜」。

样式与参数

五个参数对应配方(调研 17 §1.3,[R] 本站工程配方,box-shadow 顺序依据 MDN 规则「第一条阴影在最上层」):

.soft-glow {
  --glow: hsl(var(--sgg-hue) 90% 78%);           /* 渗光色,与内容主色同族 */
  background: rgb(255 255 255 / .08);            /* 低填充,让 backdrop 透上来 */
  -webkit-backdrop-filter: blur(var(--sgg-blur)) saturate(1.6) brightness(1.08);
  backdrop-filter: blur(var(--sgg-blur)) saturate(1.6) brightness(1.08); /* brightness 抬亮=光感 */
  box-shadow:
    inset 0 1px 0 rgb(255 255 255 / var(--sgg-edge)),              /* ① 顶缘受光 lit edge */
    inset 0 0 18px 2px color-mix(in srgb, var(--glow) var(--sgg-bleed), transparent), /* ② 内渗光 */
    0 0 0 1px rgb(255 255 255 / .18),                              /* ③ 1px 亮描边 */
    0 0 var(--sgg-bloom) 4px color-mix(in srgb, var(--glow) 35%, transparent),        /* ④ 外泛光 bloom */
    0 12px 40px rgb(0 0 0 / .25);                                  /* ⑤ 落影 */
}
.soft-glow::after {   /* 顶角定向光源 */
  content: ""; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background: radial-gradient(120% 70% at 50% -20%, rgb(255 255 255 / .22), transparent 55%);
}

数值出处(调研 17 §1.3/§1.7 数值域建议):

  • blur 默认 14px、bleed 默认 30%(域 22–32%)、bloom 默认 40px(域 32–48)、edge 默认 45%、glowHue 默认 32°——全部为配方记载值;bloom alpha 固定 35%,超过 .45 会把面板「洗白」;
  • lit edge 的可行性由社区仓库 hyalite 的 rim-light 做法(Fresnel sheen + specular line + inset-shadow 边)背板——后两者在 Safari/Firefox 也能稳定渲染(README 全文核验);
  • 官方锚点:SwiftUI Glass.tint()(染色)与 .interactive()(触控光响应)证明「色相」与「交互光」在官方模型里就是两个独立参数(调研 17 §1.5);
  • 浏览器支持:backdrop-filter Baseline 2024-09;@property Baseline 2024-07;多层 box-shadow 全基线。

动效与交互

柔光玻璃本体是静态材质,动效克制:

  • 入场:卡片淡入 + 10px 上移,只动 opacity/translate(合成器属性);prefers-reduced-motion 时取消;
  • 不要让光自己动:持续呼吸的辉光是独立材质 breathing-glow 的职责;柔光的「光」来自构图,不来自动画;
  • 交互光:官方 .interactive() 的触控光响应(光从指尖下方点亮)可用随指针的 radial 高光近似,属输入驱动而非自主运动(参照 liquid-glass 条目的触碰辉光近似);
  • backdrop 每帧重采样开销:大面积玻璃上动画只落在 transform/opacity(同 backdrop-filter 条目的性能准则)。

真实产品案例

  • iOS 26 / iPadOS 26 / macOS Tahoe 26 全系统 Liquid Glass:柔光玻璃的官方母题——环境光在玻璃上回渗、控件受光(HIG Materials 页核验,调研 17 §1.6);
  • Apple 官方示例应用 Landmarks:「Building an app with Liquid Glass」官方教学场景(Liquid Glass 总览页核验);
  • itsEricWu/ericwu.me:liquid-glass bento grid 个人站(Next.js 16 + React 19 + Tailwind v4,GitHub API 核验 373★)——柔光玻璃在真实站点级产品中的社区落地。

参数敏感度

参数调大会…调小会…
glowHue色相偏离内容主色时,光变成「贴上去的滤镜」;跨色相环大幅旋转后与场景脱节渗光/泛光偏向冷色;与主色同族时最像「环境在照亮面板」
blur背景更不可辨;>16px 开始与普通毛玻璃无异,柔光辨识度反而下降背景细节穿透,渗光被纹理干扰;低于 8px 玻璃感失效(与毛玻璃条目的下限一致)
bleed内缘光晕变厚,边缘「发热」感增强;>45% 开始糊住内缘文字光向内衰减消失,只剩泛光;0 = 回到普通玻璃,「柔光」名不副实
bloom环境光污染加重,暗底上像霓虹灯;>48px 且 alpha 高时洗白面板泛光收窄成描边状;0 = 无外光,面板退回「受光而不发光」
edge顶缘亮线更硬更白,像金属包边;>55% 与柔光气质冲突受光感消失,面板像悬浮贴纸;0 = 失去「玻璃厚度暗示」

经验区间(调研 17 §1.3):blur 12–16px、saturate 1.5–1.8、内渗光半径 14–24px / alpha .22–.32、bloom 半径 32–48px / alpha .28–.4。与 liquid-glass、backdrop-filter、swiftui-materials 条目互参:官方材质语义在那些条目,本条是「发光维度」的 web 工程配方。

适用场景 3
  • 暗场氛围面板:音乐播放器、媒体卡片、英雄区主视觉——面板成为场景光源(调研 17 §1.1)
  • 导航层浮动玻璃——与 Liquid Glass「只在导航层、节制使用」的官方定位一致(调研 17 §11.10)
  • 品牌强调卡:光色与品牌主色同族时的氛围强调
何时不要用 3
  • 内容层正文与密集数据——发光稀释对比度,Apple 明确玻璃不进内容层(调研 17 §0)
  • 浅色亮底场景:bloom 泛光在亮背景上不可见且易洗白文字
  • 全站超过三层的玻璃堆叠——层级感先死(调研 17 §11.10)
无障碍

文字按「透出的最亮/最暗背景 + 自身泛光」三种极端核对 4.5:1(WCAG 2.1 SC 1.4.3);bloom alpha 保持在 .4 以下防止洗白文字;发光层不得作为传达关键信息的唯一手段;发光动画遵循 prefers-reduced-motion(见 breathing-glow 条目)。

浏览器支持

backdrop-filter:MDN 标注 Baseline 2024 Newly available(2024-09 起跨主流浏览器);@property:Baseline 2024(2024-07);多层 box-shadow、conic/radial 渐变、color-mix 全基线(调研 17 §1.4)。Safari 9–17 需 -webkit-backdrop-filter 前缀。

兼容回退

不支持 backdrop-filter 的旧浏览器:用 @supports not (backdrop-filter: blur(1px)) 把填充不透明度提高到 .7+ 保住文字可读;渗光/泛光/亮边三层 box-shadow 全基线,回退后仍保留发光观感(调研 17 §1.4)。

来源 5

起源官方对应物是 Apple Liquid Glass 的「reflects color and light of surrounding content」(WWDC25 session 219,调研 17 §1.1/§1.2 核验);lit-edge 阴影层的可行性由社区仓库 hyalite 的 rim-light 做法(Fresnel sheen + specular line + inset-shadow 边,GitHub README 全文核验)直接支撑。CSS 配方为本站工程综合 [R](调研 17 §1.3)。
