颗粒噪点渐变 Grain Gradient

噪点渐变 · Grainy gradients · feTurbulence noise

噪点渐变:SVG feTurbulence 生成灰噪点铺在渐变上,再推 contrast/brightness 变成颗粒——主作用是杀死廉价屏上的渐变色带(banding)。

社区流派 ★★★
实例演示 官方默认
参数
几何▾
baseFrequency0.65

feTurbulence 噪点频率,控制颗粒粗细。默认 0.65 为 CSS-Tricks 配方原文(fractalNoise + baseFrequency='0.65');CodeFronts 轻量变体用 0.9。JS 型参数:demo 改值后重写 SVG 属性并重建 data-URI。

numOctaves3

湍流倍频数,越大细节越碎、渲染越贵。默认 3 为 CSS-Tricks 配方原文(numOctaves='3')。JS 型参数:demo 改值后重写 SVG 属性并重建 data-URI。

contrast170%
%

把灰噪点推向颗粒感的 contrast 滤镜值。默认 170% 为 CSS-Tricks 配方原文(filter: contrast(170%) brightness(1000%));原配方同时 brightness(1000%),本条目把它固定在 demo 内不再单列。

grainOpacity0.16

噪点层整体不透明度。默认 0.16 取自 CodeFronts 轻量变体(内联 data-URI feTurbulence baseFrequency='0.9' numOctaves='2',噪点层 opacity: .16)——足以杀死色带又不显脏(调研 06§15)。

结构与 DOM

噪点渐变是「渐变底 + 噪点覆盖层」的双层结构:噪点由内联 SVG 的 feTurbulence 滤镜生成(以 data-URI 平铺,零请求),渐变一端留透明让噪点透出:

<div class="scene">          <!-- isolation: isolate,防止混合模式外溢 -->
  <div class="gradient"></div>
  <div class="grain" aria-hidden="true"></div> <!-- 噪点层:data-URI + filter + opacity -->
</div>
<!-- 噪点 SVG 本体(baseFrequency/numOctaves 由参数驱动) -->
<svg><filter id="n"><feTurbulence type="fractalNoise" baseFrequency="0.65"
  numOctaves="3" stitchTiles="stitch"/></filter>
  <rect width="100%" height="100%" filter="url(#n)"/></svg>

关键点:

  • type='fractalNoise' + stitchTiles='stitch' 让噪点无缝平铺(CSS-Tricks 配方);
  • 叠加顺序:background: linear-gradient(..., transparent), url(noise.svg)——渐变一端透明是让噪点可见的前提;
  • 噪点层永远 aria-hidden,可整层移除而不丢信息。

样式与参数

四个参数中两个写进 SVG 滤镜(JS 型,改值需重建 data-URI),两个走 CSS 变量:

.grain {
  position: absolute;
  inset: 0;
  opacity: var(--grain-opacity);               /* 0.16,CodeFronts 轻量变体 */
  filter: contrast(var(--grain-contrast)) brightness(1000%); /* 170% / 1000%,CSS-Tricks */
  mix-blend-mode: multiply;                    /* 精修:只与渐变混合 */
}
.scene { isolation: isolate; }                 /* 防止 multiply 混到页面背景 */
.grain {
  background-image: url("data:image/svg+xml,..."); /* feTurbulence baseFrequency=0.65 numOctaves=3 */
  background-size: 180px 180px;                /* data-URI 无法自然平铺,显式定尺寸 */
}

数值出处:

  • fractalNoise / baseFrequency 0.65 / numOctaves 3 / stitchTiles stitch 与 contrast(170%) brightness(1000%):CSS-Tricks《Grainy Gradients》配方原文(调研 06§15);
  • 噪点层 opacity 0.16 与「主作用是杀死渐变色带」:CodeFronts 轻量变体(该变体用 baseFrequency 0.9 / numOctaves 2 / rect opacity 0.55,调研 06§15)——本条目默认取 CSS-Tricks 的滤镜参数 + CodeFronts 的层透明度,组合已在参数 effect 注明;
  • mix-blend-mode: multiply + 父容器 isolation: isolate 是 CSS-Tricks 给出的精修路线;其评论区同时提示:极端 contrast/brightness 会丢色彩,mask 方案可能更高效——如实并列。

动效与交互

本条目默认完全静止——噪点是空间质感,不是时间动效:

  • 无 CSS 动画;若要「胶片颗粒抖动」,必须限帧(如 steps 动画切 background-position)并在 prefers-reduced-motion 时停用;
  • baseFrequency/numOctaves 改值时 demo 重建 data-URI:一次背景重绘,编辑期操作可接受;
  • contrast 参数走 CSS 变量,无需重建 SVG,改动即时生效。

参数敏感度

参数调大会…调小会…
baseFrequency颗粒变细变密(0.9 = CodeFronts 轻量变体);>0.9 接近电视雪花颗粒变粗成「块状噪斑」;<0.2 只剩几个大色块,失去均匀质感
numOctaves细节层次更多、更「胶片」;渲染成本同步上涨噪点更平更均匀;1 时几乎无层次但仍保留消色带作用
contrast灰噪点推向黑白硬颗粒,风格化最强;>220% 色彩被吃掉(CSS-Tricks 评论提示)噪点退回均匀灰雾;100% 以下几乎看不出颗粒,只剩轻微 dither
grainOpacity噪点压过渐变,「脏旧」感上升;>0.4 时文字下方开始干扰趋向纯渐变;<0.08 时消色带作用在部分屏上失效——0.16 是 CodeFronts 给的消带甜点

经验区间:消色带用途 opacity 0.12–0.2 + contrast 100–170%;风格化用途 contrast 170–250% + opacity 0.25–0.5,但都要重新核对文字对比度。

适用场景 4
  • 大面积单色渐变上的消色带层:0.16 级低透明度噪点在廉价屏上效果最明显
  • 海报感/印刷感的氛围纹理——contrast 推高后成为可见颗粒风格
  • 深色 UI 的『哑光』处理:细颗粒弱化 OLED 深底的色带与烧屏观感
  • 渐变 hero、按钮、卡片的背景增质,成本几乎为零(data-URI 内联)
何时不要用 4
  • 文字正上方的高对比噪点——contrast/brightness 极端值会吃掉色彩并干扰小字(CSS-Tricks 评论区提示)
  • box-shadow 上直接套用——该技术不作用于阴影,需要另行处理(CSS-Tricks 原文)
  • numOctaves 拉满 + 大面积铺满——渲染成本随倍频数上涨,大画布会卡
  • 期待噪点改善可访问性——它是纯装饰,对比度验收仍按无噪点底色计算
无障碍

噪点是纯装饰:层上 aria-hidden、不承载任何信息;消色带作用属于视觉舒适度而非可访问性指标;其上文字对比度按未加噪点的底色核算(WCAG 2.1 SC 1.4.3);对前庭敏感用户无动效负担(本条目默认静止)。

浏览器支持

SVG 滤镜 feTurbulence 与 CSS filter 均为老基线能力(全主流浏览器多年支持);data-URI SVG 作 background-image 通用。本次调研未逐浏览器核验 feTurbulence 的兼容矩阵,按 MDN 惯例视为基线。

兼容回退

不支持 SVG 滤镜的环境直接退回纯渐变(少一层质感,不丢信息);contrast 滤镜缺失时噪点保持灰色平铺——仍保留消色带作用;噪点层永远 aria-hidden 装饰,可整层移除。

来源 2
