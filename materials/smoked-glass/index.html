烟熏玻璃 Smoked Glass

烟熏玻璃 · 熏黑玻璃 · 黑色玻璃 · 暗色磨砂 · Smoked Glass · Dark Glass

深色基底 + 顶部拉丝高光 + 极低透底的「黑色玻璃」:磨砂密度轴(§3.3)推到暗色端,背景只剩色温不剩信息,文字对比天然稳固。调研 17 §12.3 如实标注:参数域是 §3 mist 的暗色分支,工程推演。

参数
几何▾
density0.9

磨砂密度轴 d(§3.3 公式,应用于深色基底为本条 [R] 推演):blur=2+38d px、saturate=1.9−1.0d、contrast=1−0.15d、填充 alpha=.05+.35d。默认 0.9 取「极低透底」档(§12.3 定义);0.8 为 §3.3 mist 档参照。要点沿用:blur≥24px 才「没信息」、saturate<1 是雾与磨砂的分水岭(§3.3)。

highlight45%
%

顶部拉丝高光强度(1px 顶缘亮线 + 顶部渐变受光的 alpha)。默认 45% 取 §1.3 ① 层顶缘镜面高光 white/.45;「拉丝」细纹(顶部叠 repeating-linear-gradient 1px 细线)为本条工程推演 [R](§12.3 只定义了「顶部拉丝高光」,未记载数值)。0 = 关闭高光,纯哑光黑玻璃。

色彩▾
tint#0B0F14

深色基底色。默认 #0B0F14 取 §9 暗场基调「暗底 #0B0F14 级别」[R];预设 #111928 为调研 03§1 生产实测深玻璃 rgb(17,25,40) 的 hex(本站 glassmorphism 条目深色变体沿用),供对照。基底用低饱和冷灰黑而非纯黑,避免雾里死黑(§3.3「基底不用白」的暗色版,工程推演)。

结构与 DOM

烟熏玻璃是磨砂密度轴(§3.3)的暗色端(调研 17 §12.3):深色基底 + 顶部拉丝高光 + 极低透底。结构与 mist-glass 同族——玻璃面板浮在丰富背景上,只是填充换深色、模糊推高档:

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="smoked-card">
    <h3>标题</h3>
    <p>正文</p>
  </div>
</div>

关键点:

  • 玻璃面板是背景的兄弟层,backdrop-filter 采样面板身后的一切;深色填充层挡掉绝大部分信息,只留色温;
  • 填充 = 双层结构:本体透明,::before 铺实色 tint、opacity 承载密度公式值——不依赖 color-mix,基线能力;
  • 顶部拉丝高光压在填充层之上(::after):1px 顶缘亮线 + 顶部渐变受光 + 1px 细线纹理,模拟单一方向环境灯擦过烟熏表面的反光;
  • 深基底使文字对比天然稳固——clear-frost 在亮背景上必须加 35% 暗色 dimming 层(HIG §2.3【S】),烟熏把这层「长」在了材质里。

样式与参数

三个参数对应 §3.3 密度轴公式的暗色应用([R],公式本身为 §3.3 记载值):

.smoked-card {
  position: relative;
  border-radius: 20px;
  background: transparent;
  -webkit-backdrop-filter:
    blur(calc(2px + 38px * var(--sm-density)))          /* blur = 2+38d */
    saturate(calc(1.9 - var(--sm-density)))             /* sat  = 1.9−d */
    contrast(calc(1 - 0.15 * var(--sm-density)));       /* ct   = 1−0.15d */
  backdrop-filter:
    blur(calc(2px + 38px * var(--sm-density)))
    saturate(calc(1.9 - var(--sm-density)))
    contrast(calc(1 - 0.15 * var(--sm-density)));
  box-shadow:
    inset 0 1px 0 rgb(255 255 255 / calc(var(--sm-highlight) / 100)),  /* 顶缘亮线 §1.3 ① */
    0 12px 40px rgb(0 0 0 / 0.25);                                      /* 落影 §1.3 ⑤ */
}
/* 深色填充层:实色 tint + 密度公式 alpha(fill = .05+.35d) */
.smoked-card::before {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  background: var(--sm-tint);
  opacity: calc(0.05 + 0.35 * var(--sm-density));
  pointer-events: none;
}
/* 顶部拉丝高光:渐变受光 + 1px 细线纹理(工程推演 [R]) */
.smoked-card::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  pointer-events: none;
  background:
    repeating-linear-gradient(100deg,
      rgb(255 255 255 / 0.05) 0 1px, transparent 1px 4px),
    linear-gradient(180deg,
      rgb(255 255 255 / calc(var(--sm-highlight) / 100)), transparent 48%);
}
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .smoked-card::before { opacity: 0.96; }   /* §3.4 mist 回退思路 */
}

数值出处:

  • 密度轴四条公式 blur=2+38d / fill=.05+.35d / sat=1.9−1.0d / ct=1−0.15d:§3.3 记载值(亮色分支);应用于深色基底为本条 [R] 推演(§12.3 原话「参数域是 §3 mist 的暗色分支」);
  • 默认 d=0.9:「极低透底」档(§12.3 定义);d=0.8 即 §3.3 mist 档,可对照;
  • 顶缘亮线 white/.45:§1.3 ① 层记载值;落影 0 12px 40px black/.25:§1.3 ⑤ 层记载值;
  • tint 默认 #0B0F14:§9 暗场基调「暗底 #0B0F14 级别」[R];预设 #111928 = 调研 03§1 生产实测深玻璃 rgb(17,25,40) 的 hex(本站 glassmorphism 深色变体沿用);
  • 回退 .96:§3.4 mist 回退值;拉丝细纹 1px/4px 周期与受光渐变 48% 为工程推演 R。

动效与交互

烟熏玻璃是静态材质,动效克制:

  • 入场淡入 + 8px 上移;prefers-reduced-motion 时取消(本材质无自主动画,仅此一处);
  • 密度/tint/highlight 全部经 CSS 变量即时生效,切换不做过渡动画(参数是配方轴,不是状态);
  • 悬浮导航条场景下,深色玻璃可以随滚动加深(如 iOS 滚动条模式),实现为 opacity 过渡而非每帧重采样——大半径 blur 的每帧重采样代价高(§1.4);
  • 高亮态用顶缘亮线 alpha 提亮即可,不必动 blur。

真实产品案例

  • 按 §12.3 如实处理:「烟熏玻璃」为工程推演概念,调研未核验逐站点例——本条目不引用未核验站点;
  • 官方对应物【S】:SwiftUI Material.ultraThick / thick 最厚档(§3.2 枚举核验,背景透过度最低)+ 深色环境,是烟熏的官方档位锚点(visionOS 1.0+ 平台表核验);
  • 姊妹配方已核验:§3 mist 配方(本条公式的来源)、§2 clear-frost 的 35% dimming 规则(§2.3 HIG【S】)、§9 暗场基调值。

参数敏感度

参数调大会…调小会…
densityblur→40px、填充→40%,信息彻底归零、只剩色温;采样开销同步上升(高档 blur)趋向普通深色玻璃;d<0.4 时透底信息回来,「烟熏」名不副实;0.8 = §3.3 mist 档
tint越黑越「墨镜」,但纯黑会杀死透底色温(基底要低饱和冷灰黑)偏灰偏蓝则雾感变「晨雾」;预设 #111928(调研 03 生产实测)比默认略透亮
highlight>60% 顶缘开始「镀银」,像金属而非烟熏玻璃趋近哑光;0 = 高光全关,只剩深基底与落影(纯哑光黑玻璃)

经验区间:density 0.75–0.95、tint 低饱和冷灰黑(L≤12%)、highlight 35–55%;亮背景上文字对比漂移远小于 clear-frost(自带深基底)。与 mist-glass 条目互参:同一根密度轴的亮色端与公式出处;与 clear-frost 条目互参:对数轴另一端 + 35% dimming 规则(HIG【S】);与 dimming-layer 条目互参:烟熏是「把 dimming 长进材质」的形态;与 specular-highlight 条目互参:顶缘亮线的光学语义。

适用场景 3
  • 亮背景(照片/视频)上需要稳文字对比的浮层——对照 clear-frost 需加 35% 暗色 dimming 层(§2.3【S】),烟熏自带深基底
  • 暗色仪表盘、播放器与影院模式面板(§3.6 车机/客厅大屏的暗色分支)
  • 悬浮导航条与工具条——玻璃导航层特权(§11.10)的暗色兑现
何时不要用 3
  • 浅色主题大面积使用:深面板与浅主题的层级语言互相打架
  • 数据密集表格:极低透底已接近实底,不值得付 backdrop-filter 的高档 blur 采样成本(§3.3 要点①)
  • 正文小字直接压在玻璃上:文字应放在内容层的实底上,玻璃只做导航层(§11.10)
无障碍

深色基底让文字对比天然稳固,但仍须按「透出的最亮背景」核对 4.5:1(WCAG 2.1 SC 1.4.3)——烟熏透底极低,对比漂移远小于 clear-frost;顶部拉丝高光与描边纯装饰,不承载信息;本材质无自主动画,prefers-reduced-motion 仅取消入场。

浏览器支持

backdrop-filter Baseline 2024 Newly available,自 2024-09 起跨主流浏览器(§1.4,MDN 核验【S】);Safari 9–17 需 -webkit- 前缀;calc() 在自定义属性中的用法为基线能力(§3.4);saturate/contrast/brightness 均为合法滤镜函数(§3.2,MDN backdrop-filter Formal syntax 核验【S】);color-mix 不需要——填充层用「实色 + opacity」双层结构,基线能力。

兼容回退

不支持 backdrop-filter 时:按 §3.4 mist 的回退思路(.96 不透明)把深色填充层 opacity 提到 .96,玻璃退为近实底深色面板——烟熏本体就是深色,回退几乎无损(深基底、顶部高光、描边全部保留,只损失透底色温)。

来源 2
