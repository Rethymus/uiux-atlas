雾面玻璃 Mist Glass

雾面玻璃 · 雾玻璃 · Mist Glass · Heavy Frost

高雾度、低对比:背景被重度均质化(大半径 blur),同时降低饱和与对比,让透出的内容只剩「色温」而非「信息」。与清透磨砂是同一根轴的对数两端。

社区流派 ★★
实例演示 官方默认
参数
几何▾
density0.8

雾度轴 d∈[0,1](调研 17 §3.3 统一 frost-density 参数化):blur = calc(2px + 38px×d)、fill = calc(.05 + .35×d)、saturate = calc(1.9 − 1.0×d) 同时联动。默认 0.8(mist 档);d≈0 为清透磨砂、d≈0.4 为常规磨砂、d→1 趋于不透明。建议作为站点级 token。

contrast0.88

对比衰减(contrast 滤镜)。默认 0.88 = 配方公式 1 − 0.15×d 在 d=0.8 处的值(调研 17 §3.3)——雾的关键是「糊掉但变灰变柔」,对比必须与模糊同步衰减。

色彩▾
base#F5F7FA

基底色(rgb 三元组 245 247 250 的十六进制形式)。调研 17 §3.3 雾感三要点之三:基底用低饱和冷灰白而不是纯白,避免雾里发蓝。presets 为同一低饱和家族的相邻档,工程推演示值。

结构与 DOM

雾面玻璃与清透磨砂(clear-frost)是同一根清亮度轴的对数两端:超薄档要「糊掉但更艳」,雾面要「糊掉但变灰变柔」——透出的内容只剩色温,没有信息(调研 17 §3.1)。

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="mist">          <!-- 高雾度:大 blur + 低饱和 + 降对比 -->
    <h3>通知</h3>
  </div>
</div>

关键点:

  • DOM 与 glassmorphism/clear-frost 条目同构:背景 → 雾面板 → 内容;差异全在参数域;
  • 「mist glass」没有官方独立定义(调研 17 §3.2 如实标注)——参数域由 Apple Material 的 ultraThick/thick 最厚档语义反向推得;
  • 雾面板通常承载长文案(通知、面板标题),这是它与超薄档的分工差异。

样式与参数

核心是一根 fog density 轴联动三个滤镜函数(调研 17 §3.3,[R] 本站工程配方):

/* d ∈ [0,1]:0=clear frost,0.4=regular frost,0.8=mist,1=不透明 */
.mist {
  --mg-blur: calc(2px + 38px * var(--mg-d));    /* 2 → 40px */
  --mg-fill: calc(0.05 + 0.35 * var(--mg-d));   /* .05 → .40 */
  --mg-sat:  calc(1.9 - 1.0 * var(--mg-d));     /* 1.9 → 0.9(雾要降饱和) */
  background: color-mix(in srgb, var(--mg-base) calc(var(--mg-fill) * 100%), transparent);
  -webkit-backdrop-filter: blur(var(--mg-blur)) saturate(var(--mg-sat)) contrast(var(--mg-ct));
  backdrop-filter: blur(var(--mg-blur)) saturate(var(--mg-sat)) contrast(var(--mg-ct));
  border-radius: 24px;
  box-shadow: inset 0 1px 0 rgb(255 255 255 / .3), 0 10px 32px rgb(15 23 42 / .18);
}

数值出处:

  • 三条公式与默认 --d: 0.8、contrast = 1 − 0.15×d(默认 0.88)、基底 rgb(245 247 250):全部为调研 17 §3.3 配方记载值;
  • 雾感三要点(调研 17 §3.3):① blur ≥ 24px 才开始「没信息」;② saturate < 1 是雾与磨砂的分水岭;③ 基底用低饱和冷灰白(245 247 250)而不是白,避免雾里发蓝;
  • 滤镜函数链 blur/saturate/contrast 均为 backdrop-filter 合法函数(MDN Formal syntax 核验);Apple Material.ultraThick 原文 “resembles heavily frosted glass” 是最厚档的官方描述(SwiftUI Material 页核验)。

动效与交互

雾面的价值在静态稳定,动效需求比清透档更低:

  • 入场:淡入 + 8px 上移;prefers-reduced-motion 时取消;
  • 不要给雾面加「呼吸/流动」效果——雾的语义是「背景被抹平」,任何雾层自身的波动都会重新引入视觉噪声;
  • 背景大幅变化(切换场景)时,雾层参数不需要动画过渡:大半径 blur 的重采样本身就昂贵,直接切换更稳(backdrop-filter 条目同款性能准则);
  • 嵌套警告:雾面板内部再放 backdrop-filter 元素,子级只能采样到「父雾层」为止(MDN backdrop root 陷阱,调研 17 §11.4)——demo 卡内的四枚档位胶囊即此现象的现场展示。

真实产品案例

  • iOS 通知中心 / 锁屏毛玻璃:厚磨砂族的系统级主场,通知文字直接压在重均质化的雾层上(SwiftUI Material 枚举对应,调研 17 §3.6);
  • 车机 / 客厅大屏面板:背景杂乱时只要色温不要信息——HIG standard materials 的目标场景(HIG Materials 页核验)。

参数敏感度

参数调大会…调小会…
densityblur/fill 联动上升、saturate 联动下降:雾更浓,信息更不可辨;d→1 趋于不透明面板跨过 d≈0.4 后进入常规磨砂域,d≈0 已是清透磨砂——「雾」的卖点消失;中间态(高饱和低雾度)最容易显脏
contrast对比保留更多,雾里透出的明暗结构更清楚;>1 是「磨砂」而非「雾」雾更灰更柔,只剩色温;<0.8 后整个面板发闷、文字与雾层的 micro-contrast 一并丢失
base冷灰白偏冷,雾感发「钢」;蓝相过重时雾里发蓝(要点③反例)偏暖偏黄的基底让雾像旧灯泡罩;偏离低饱和家族后雾变成「脏色块」

经验区间:d 用 0.8 起步(mist 档),通知类可到 0.9;contrast 跟随公式 1−0.15×d;base 锁定 245 247 250 一族。与 clear-frost 条目互参:同一根轴的另一端;与 swiftui-materials 条目互参:厚度的官方五档语义;与 backdrop-filter 条目互参:backdrop root 与函数链语法。

适用场景 3
  • iOS 通知中心/锁屏式毛玻璃:厚磨砂族的系统级场景(Material 枚举对应,调研 17 §3.6)
  • 车机/客厅大屏面板:背景杂乱时只要色温不要信息(HIG standard materials 的目标场景,调研 17 §3.6)
  • 需要长文案可读性的浮层:雾度稳定后文字对比不再随背景内容跳动
何时不要用 3
  • 想让背景色彩/内容可辨识的场景——那是清透磨砂(clear-frost)的职责
  • saturate < 1 且 blur < 24px 的中间态:既不雾也不透,是最容易显脏的参数域
  • 纯白基底:雾里会发蓝(调研 17 §3.3 要点③)
无障碍

雾面的优势是对比稳定:背景信息被均质化后,文字对比不再随滚动内容跳动——但仍需按雾层成像后的实际色核对 4.5:1(WCAG 2.1 SC 1.4.3);雾层不得作为传达关键信息的唯一手段。

浏览器支持

backdrop-filter:Baseline 2024 Newly available(2024-09 起;MDN),Safari 9–17 需 -webkit- 前缀;自定义属性中的 calc() 为基线能力(调研 17 §3.4)。

兼容回退

不支持 backdrop-filter 时回退为不透明 rgb(241 244 248 / .96)(调研 17 §3.4)——雾面本来就在「接近不透明」档,回退几乎无损;保留描边与圆角。

来源 2

起源「mist glass」作为独立命名在权威来源中未见官方定义(调研 17 §3.2 如实标注,为本站命名的工程概念);参数域由 Apple 官方厚度枚举反向推得——Material.ultraThick/thick 是最厚档,背景透过度最低(SwiftUI Material 页核验);滤镜函数链 blur/saturate/contrast 均为 backdrop-filter 合法函数(MDN Formal syntax 核验)。配方为本站工程综合 [R](调研 17 §3.3)。
