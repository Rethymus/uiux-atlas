光晕描边 Halo Glow Border

光晕描边 · 光环描边 · Halo Border · Lit Border

边缘光环/辉光描边:用 conic 渐变绘制 1–2px 环,再叠一层同源渐变的模糊副本外溢成「光晕」——同一渐变的双实例:锐利层做线,模糊层做光。

结构与 DOM

光晕描边的本质是同一渐变的双实例(调研 17 §5.1):锐利层做线,模糊层做光。用 conic/linear 渐变绘制 1–2px 环,再叠一层同源渐变的模糊副本外溢成「光晕」。

<div class="halo">          <!-- 玻璃基底(可选)+ 两个伪层 -->
  <h3>标题</h3>
</div>

关键点:

  • 环与光都是伪层(::before/::after),本体只需是 position: relative 的容器——不新增 DOM;
  • 双 mask 挖空环:linear-gradient(#000 0 0) content-box + mask-composite: exclude(Webkit 系双写 -webkit-mask-composite: xor),padding 即环宽;
  • 模糊孪生层 z-index: -1 垫到卡后、inset 外扩数像素,「光溢出边界」才成立;两层都 pointer-events: none。

样式与参数

四个参数对应配方(调研 17 §5.3,[R];「画环」技法谱系出自 CSS-Tricks「Gradient Borders in CSS」全文核验):

@property --hg-spin { syntax: "<angle>"; inherits: false; initial-value: 0deg; }
.halo {
  position: relative; border-radius: 18px;
  background: rgb(255 255 255 / .06);
  -webkit-backdrop-filter: blur(12px) saturate(1.4);
  backdrop-filter: blur(12px) saturate(1.4);
}
.halo::before, .halo::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background: conic-gradient(from calc(var(--hg-angle) + var(--hg-spin)),
    rgb(255 176 32 / .9), rgb(255 86 168 / .9), rgb(86 128 255 / .9), rgb(255 176 32 / .9));
  padding: var(--hg-ring);                                   /* 挖空成 1–2px 环 */
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
}
.halo::before { filter: drop-shadow(0 0 6px rgb(255 150 80 / .45)); animation: spin 6s linear infinite; }
.halo::after  { inset: -3px; filter: blur(var(--hg-blur)); opacity: calc(var(--hg-op) / 100%); z-index: -1; animation: spin 6s linear infinite; }
@keyframes spin { to { --hg-spin: 360deg; } }
@media (prefers-reduced-motion: reduce) { .halo::before, .halo::after { animation: none; --hg-spin: 90deg; } }

数值出处:

  • 环宽 1.5px、光晕 blur(10px)、opacity .55、6s 旋转、三色色标(琥珀/洋红/蓝)+ 首尾同色闭合、reduce 静止 90°:全部为调研 17 §5.3 配方记载值;建议域:环宽 1–2px、halo-blur 6–14px、halo-opacity 40–70%(§5.5);
  • @property 注册了角度,conic 边框才会转:未注册的自定义属性不可插值——这是 2024-07(Baseline)前后 halo 能不能动起来的分水岭(调研 17 §11.8;MDN @property 页核验);
  • conic-gradient 的 from/at 语法与角度色标:MDN 全文核验;静态版(无动画)可直接换 CSS-Tricks 谱系的双背景法:background: linear-gradient(#111,#111) padding-box, linear-gradient(120deg, gold, magenta) border-box; border: 1px solid transparent(该文核验原文);
  • rim 光的可行性另由 hyalite 的 Fresnel sheen + specular line + inset-shadow rim 做法背书(README 全文核验)。

动效与交互

  • 旋转:两层同步转(同 keyframes),6s/圈线性;依赖 @property 角度插值,旧浏览器里环静止但显示正常(initial-value 兜底,调研 17 §5.4【S】);
  • prefers-reduced-motion: reduce:动画取消、相位静止在 90°——保留静态光晕而不是黑掉(MDN 官方「替换为不引发前庭反应的替代状态」的示范思路,调研 17 §8.2 同源原则);
  • 选中/焦点态:光圈出现即状态——出现/消失用 opacity 过渡(0.25s),不要让整圈「飞入」;
  • 光晕层 pointer-events: none:光不拦截指针,卡片交互不受影响。

真实产品案例

  • hyalite demo 的 rim 光:Fresnel sheen + specular line + inset-shadow rim 的边缘光处理,GitHub README 全文核验(demo:https://vii-cae.github.io/hyalite—liquid-glass/demo/index.html,仓库元数据核验);
  • CSS-Tricks「Gradient Borders in CSS」(Chris Coyier,2018):渐变边框六法的技法谱系源头——双背景 padding-box/border-box、伪元素负 z-index、clip-path 等(全文核验);
  • 深色 SaaS 控制台的高亮卡片/CTA 活动光圈属社区通行做法;逐站点代表例调研未能核验(调研 17 §5.6 如实标注),不列具体站点。

参数敏感度

参数调大会…调小会…
ring>2px 线感消失,变成彩色包边;色标渐变在宽环上更明显<1px 在高分屏上可能出现摩尔纹/断裂;0.5px 时环若隐若现
glowBlur光更弥散、氛围更「霓虹」;>14px 后光晕与落影混在一起光贴边变成第二条线;4px 时几乎没有「晕」
intensity>70% 光晕淹没深色底上的卡片层级,喧宾夺主光渐弱;20% 时只剩锐利环,回到普通渐变描边
angle相位决定哪段色标落在顶部受光位;与界面主色冲突时会「撞色」只影响静态起始相位;旋转场景下 angle 是初始值而非终点

经验区间:ring 1–2px、glowBlur 6–14px、intensity 40–70%、色标 3 色 + 首尾同色闭合。与 glassmorphism 条目互参:玻璃基底参数域;与 backdrop-filter 条目互参:函数链与采样域;与 soft-glow-glass 条目互参:halo 是「光在边缘」,soft-glow 是「光在体内」。

适用场景 3
  • 深色 SaaS 控制台的高亮卡片与 CTA 的活动态光圈(社区通行做法;hyalite rim 光 + CSS-Tricks 谱系为技术锚点,调研 17 §5.6)
  • 选中态/焦点态的「被点亮」暗示:光圈比加粗描边更柔和地表达状态
  • 品牌氛围强调:色标组用品牌三色(建议 3 色 + 首尾同色闭合,调研 17 §5.5)
何时不要用 3
  • 浅色亮底:光晕在亮背景上不可见,只剩一条彩线
  • 多卡片全量使用:人人发光等于无人发光,层级感先死
  • 正文容器:旋转光圈持续吸引注意力,阅读区不可承受
无障碍

光圈不得作为选中/错误的唯一指示(状态需有文字/图形冗余,WCAG 1.4.1);旋转动画遵循 prefers-reduced-motion:reduce 时静止在 90° 相位,不做淡出黑掉(保留静态光);光晕层 pointer-events: none,不挡交互。

浏览器支持

conic-gradient 全基线;@property 动画角度 Baseline 2024(2024-07 起)——旧浏览器里环静止但显示正常(initial-value 兜底,调研 17 §5.4【S】);mask-composite: exclude + -webkit-mask-composite: xor 双写覆盖 Chromium/Safari/Firefox;无 conic 的极端回退用 linear-gradient 双背景法(2018 年起全支持)。

兼容回退

不支持 @property 插值的浏览器:旋转停摆,环以 initial-value 静态显示;不支持 mask-composite 时改用 CSS-Tricks 谱系的静态双背景法:background: linear-gradient(#111,#111) padding-box, linear-gradient(120deg, …) border-box; border: 1px solid transparent(该文核验原文)。

来源 4

起源「画环」技法谱系出自 CSS-Tricks「Gradient Borders in CSS」(Chris Coyier,2018-12-28,全文核验:双背景 + background-origin padding-box/border-box、伪元素负 z-index、clip-path 等六法);conic 渐变 from/at 语法与角度色标(MDN 全文核验);旋转的前提是 @property 注册角度自定义属性(Baseline 2024-07,MDN 核验);rim 光的可行性另由 hyalite 的 Fresnel sheen + specular line + inset-shadow rim 做法背书(README 全文核验)。双 mask 挖空 + 模糊孪生层的组合配方为本站工程综合 [R](调研 17 §5.3)。
