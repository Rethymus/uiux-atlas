清透磨砂 Clear Frost

清透磨砂 · 超薄磨砂 · Ultra-Thin Frost · Clear Frost Glass

超薄磨砂:最低限度的模糊半径 + 最低限度的白色填充 + 高饱和 backdrop,让背景色彩尽量原样透过。官方对应 SwiftUI ultraThinMaterial 与 Liquid Glass 的 clear 变体。

frost0.25

代码拆解

结构与 DOM

清透磨砂是玻璃家族的「超薄档」,与 mist-glass(雾面)处在同一条清亮度轴的两端。官方对应:SwiftUI Material.ultraThin(visionOS 1.0+)与 Liquid Glass 的 clear 变体——HIG 原文「highly translucent… ideal for prioritizing the visibility of the underlying content」(调研 17 §2.1/§2.2 核验)。

<div class="scene">
  <img class="backdrop" src="photo.jpg" alt="" />
  <div class="clear-frost">          <!-- 超薄玻璃:只糊细节不糊色彩 -->
    <strong>播放中</strong>
  </div>
</div>

关键点:

  • 结构与 glassmorphism 条目完全同构:背景 → 玻璃面板 → 内容;差别全在参数域,不在 DOM;
  • 超薄档必须搭配加粗字重/纯白文字(调研 17 §2.3 配对规则)——填充太薄,字重是最后的对比度手段;
  • 亮背景场景多一层 ::before 深色 dimming 薄层,这是官方唯一给死数值(35%)的地方。

样式与参数

四个参数,其中 frost 厚度轴按调研 17 §2.5 的官方五档厚度语义映射模糊:

.clear-frost {
  background: rgb(255 255 255 / var(--cf-fill));   /* 默认 8%(配方域 .06–.10) */
  -webkit-backdrop-filter: blur(calc(2px + 8px * var(--cf-t))) saturate(var(--cf-sat));
  backdrop-filter: blur(calc(2px + 8px * var(--cf-t))) saturate(var(--cf-sat));
  border-radius: 20px;
  box-shadow: inset 0 0 0 1px rgb(255 255 255 / 0.10);  /* 超薄档内描边(对照常规档 .16+顶光) */
}
/* Apple 官方规则【S】:clear 叠亮背景(照片/视频)之上时,加 35% 暗色 dimming 层 */
.clear-frost.on-bright::before {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  background: rgb(0 0 0 / var(--cf-dim));
}

数值出处:

  • blur 4px、saturate 1.8、fill .08、内描边 white/.10:调研 17 §2.3 超薄档配方;右侧对照列(常规磨砂 blur 18–24px / sat 1.1–1.3 / fill .22–.30)出自同表——同一根轴的两个档位;
  • frost 轴公式 blur = 2px + 8px×t:调研 17 §2.5,以 Apple Material 五档厚度枚举(ultraThin→ultraThick)锚定;默认 t=0.25 → 4px;
  • dimming 默认 35%:HIG 官方数值(调研 17 §0【S】),dimming-layer 条目对这一层有专文;
  • 社区量化:rdev/liquid-glass-react 的 blurAmount: 0.0625 + saturation: 140 即社区对超薄档的量化(README 核验)【S】;
  • WWDC 219 同时要求:clear 与 regular 不混用于同类控件(调研 17 §2.3 核验)。

动效与交互

超薄档比常规玻璃更需要克制的动效——底内容每帧都在透过来:

  • 变体/场景切换:demo 在雪山(亮场景)自动启用 dimming 层,0.25s opacity 过渡;prefers-reduced-motion 时取消过渡直出终态;
  • 入场:淡入 + 8px 上移,只动 opacity/translate;
  • 高饱和 backdrop 让任何背景运动(视频、滚动)都直通面板——大玻璃面积 + 视频背景的组合要评估每帧重采样开销(backdrop-filter 条目同款性能准则);
  • 按压反馈用透明度/描边微调即可,不做位移类装饰动效。

真实产品案例

  • visionOS 窗口与控件:系统玻璃默认 ultraThin 档保住空间通透感(SwiftUI Material API 平台表核验 visionOS 1.0+,调研 17 §2.6);
  • iOS 26 控制中心 / 媒体播放控件:clear 变体的官方目标场景「float above media backgrounds」(HIG 核验);
  • rdev/liquid-glass-react:社区组件以 blurAmount 0.0625 + saturation 140 实现超薄档(GitHub README 核验,6798★)。

参数敏感度

参数调大会…调小会…
frost厚度向 thin/regular 档靠拢,细节抹平、开始「磨砂」;t=1 时已不是清透档趋近裸背景 t=0(2px,ultraThin 级);过度调低只剩色块感
saturate背景色彩更浓艳,媒体场景更「活」;>2.2 开始失真发腻色彩回填消失,超薄模糊会让画面发灰发闷;<1 时跨入雾面玻璃的参数域(见 mist-glass)
fill更白更实,可读性上升但「清透」卖点消失;>20% 已是常规磨砂的域接近裸背景;0 时文字完全无衬底,对比度不可控
dimming亮背景上文字对比更稳;>50% 玻璃发闷、清透感死亡亮背景上文字顶穿 4.5:1;0 = 裸 clear——官方 35% 就是为亮背景兜底的

经验区间:blur 2–6px、saturate 1.6–1.9、fill 6–10%、dimming 亮背景 35% 起步。与 swiftui-materials 条目互参:五档厚度的官方语义在那里;与 liquid-glass 条目互参:clear 变体与 dimming 层的官方规则在那里;与 backdrop-filter 条目互参:函数链语法与 backdrop root 陷阱在那里。

适用场景 3
  • 媒体类丰富背景之上的浮动控件:控制中心、媒体播放、快捷开关——clear 变体的官方目标场景(调研 17 §2.6)
  • visionOS 窗口与控件:系统玻璃以 ultraThin 档保住空间感(Material API 平台表核验 visionOS 1.0+)
  • 想让照片/视频色彩原样透过的字幕条与角标
何时不要用 3
  • 亮背景(照片/视频)上不加 dimming 层直接放文字——官方为此给死了 35% 数值
  • 常规正文与密集数据:填充太薄,对比度不可控(与 glassmorphism 条目的 avoid 一致)
  • 与 regular 档混用于同类控件——WWDC 219 明确两变体不应混用(调研 17 §2.3)
无障碍

超薄档的文字对比是全玻璃家族最脆弱的一档:加粗字重 + 纯白文字是配对规则;亮背景必须先叠 35% 深色 dimming 层再核对 4.5:1(WCAG 2.1 SC 1.4.3);clear 与 regular 不混用于同类控件,避免可读性预期不一致。

浏览器支持

backdrop-filter:Baseline 2024 Newly available(2024-09 起跨主流浏览器;MDN),Safari 9–17 需 -webkit- 前缀;calc() 与自定义属性运算为基线能力(调研 17 §2.4)。不依赖 color-mix。

兼容回退

不支持 backdrop-filter 时,不透明填充直接设 .72 左右保住文字可读,保留 1px 内描边与圆角;35% dimming 层是普通 rgba 层,全浏览器可用(调研 17 §2.4)。

来源 4

起源官方锚点(调研 17 §2.1/§2.2 全部核验):SwiftUI Material 枚举 ultraThin(visionOS 1.0+)与 Liquid Glass clear 变体(HIG:「highly translucent… ideal for prioritizing the visibility of the underlying content」);clear 叠亮背景时官方唯一给死的数值是 35% 深色 dimming 层。CSS 配方为本站工程综合 [R](调研 17 §2.3)。
