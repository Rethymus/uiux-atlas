接触阴影 Contact Shadows

接触阴影 · Contact Shadow · Ambient Occlusion · AO · 贴地阴影

元素贴着表面时脚下那道紧贴的深色椭圆软阴影,模拟 3D 渲染的环境光遮蔽(AO);与悬浮投影(偏移大、更弥散)构成「贴地/悬浮」两档高度语言。

社区流派 ★★★
实例演示 官方默认
参数
几何▾
distance6px
px

元素底面到表面的贴合距离:贴地椭圆挂在该距离处,高度 = 2×distance、下探 = distance(椭圆一半藏在元素底边后、一半露出)。默认 6px 取自调研配方(椭圆 bottom:-6px、height:12px,即 distance=6);0 = 完全贴合,椭圆被元素自身遮住(物理正确)。距离越大椭圆越长、元素读作「被抬离表面」。

spread6px
px

贴地椭圆的模糊半径(filter: blur)。默认 6px 取自调研配方 blur(6px)。「软接触」的软就来自它:越大阴影越软越融,过大时与表面糊成一片、失去「接触感」。

alpha0.25

贴地椭圆的基础不透明度;默认 0.25 取调研配方 hsl(... / 0.25)。悬浮投影(Comeau 分层配方)按同透明度原则缩放:每层 0.2 = 0.25×0.8。分层原则:各层透明度一致,靠倍增偏移/模糊造层次。

色彩▾
color#3366cc

阴影基色。原则:阴影不叠纯黑——取背景色相、降饱和降亮度;默认 #3366cc 即调研示例的蓝底配方 hsl(220deg 60% 50%) 的等值 hex。带色相的阴影在浅色界面上比纯黑更干净、与背景同源。

动效▾
modecontact

JS 型参数,demo 订阅后切换 data-mode。contact = 贴地接触阴影(椭圆伪元素 + blur,模拟 AO——元素「坐」在表面上);float = 悬浮投影(Comeau 五层倍增配方:1/2/4/8/16px 偏移与模糊同步倍增、每层同透明度 0.2——元素「漂」在表面上方)。两式共用同一阴影色与光源比例(水平:竖直 = 1:2)。

代码拆解

结构与 DOM

接触阴影是「表面 + 悬浮元素」两层结构,阴影本身是悬浮元素的伪元素:元素贴着表面时,脚下有一道紧贴、色深、边缘柔和的椭圆暗影,模拟 3D 渲染里的环境光遮蔽(AO);元素悬浮时则切换为偏移大、更弥散的投影。

<div class="scene">
  <div class="floor"></div>      <!-- 表面:接触阴影的落点 -->
  <div class="card">内容</div>   <!-- 悬浮元素;::after 即贴地椭圆 -->
</div>

关键点:

  • 椭圆挂在元素的 ::after 上、z-index: -1——叠在表面之上、元素之下,被元素底边遮住一半;
  • 元素与表面的间距(distance)决定椭圆的长度与下探量:间距越大椭圆越长,元素读作「被抬离表面」;
  • 同一场景所有元素共享单一光源:同一阴影色相、同一偏移比例(如水平:竖直 = 1:2),这是「整套 UI 像被同一盏灯照亮」的前提(调研 12 §7)。

样式与参数

四个 CSS 变量型参数 + 一个 JS 型模式开关,椭圆几何与配色全部由调研配方给出:

.card::after {
  content: "";
  position: absolute;
  z-index: -1;
  left: 10%; right: 10%;                    /* 椭圆内收,不顶满卡宽 */
  height: calc(var(--cs-distance) * 2);     /* 12px @ 默认 6 */
  bottom: calc(var(--cs-distance) * -1);    /* 下探 6px */
  border-radius: 50%;
  background: color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 100%), transparent);
  filter: blur(var(--cs-spread));           /* 6px */
}

/* float 模式:Comeau 五层倍增悬浮投影,每层同透明度(默认档 0.2 = alpha 0.25×0.8) */
[data-mode="float"] .card {
  box-shadow:
    1px 2px 2px    color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 80%), transparent),
    2px 4px 4px    color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 80%), transparent),
    4px 8px 8px    color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 80%), transparent),
    8px 16px 16px  color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 80%), transparent),
    16px 32px 32px color-mix(in srgb, var(--cs-color) calc(var(--cs-alpha) * 80%), transparent);
}

数值出处:

  • 贴地椭圆配方:bottom: -6px + height: 12px + blur(6px) + hsl(阴影色 / 0.25) = 调研 12 §7 的可复用片段(distance=6 恰好还原该配方);
  • 分层悬浮投影:偏移与模糊按 1/2/4/8/16px 倍增、每层同透明度——同篇调研记载的 Comeau 分层原则(示例用 0.2/层);
  • 阴影基色 #3366cc = 调研示例 hsl(220deg 60% 50%)(蓝底示例)的等值 hex——「阴影不叠纯黑」的落地;
  • color-mix() Baseline 自 2023-05;box-shadow/filter 均为 Baseline 广泛可用。

动效与交互

接触阴影的动效服务于「高度叙事」——抬升与落下:

  • 拖拽抬升:抓起时 distance 增大(椭圆拉长下探、元素上移),落点弹回贴地;过渡只落在 transform/filter 等可合成属性上;
  • 模式切换(contact↔float):两套阴影直接置换,不做逐帧动画——调研明确「分层阴影渲染开销大,不建议对其做动画」(调研 12 §7);
  • 阴影不承载交互语义:可点击性仍由光标、焦点环等常规指示表达;
  • prefers-reduced-motion 时取消全部过渡。

真实产品案例

  • Josh Comeau 博客(joshwcomeau.com):分层着色阴影 + 贴地椭圆的配方出处,作者在该文中自述其卡片阴影体系即「同透明度分层 box-shadow + 背景色相阴影变量」(调研 12 §7 的来源文章);
  • iOS 26 Liquid Glass:官方定性「玻璃 flex/morph 成大元素时……更深阴影、更明显的 lensing」(WWDC25 219 [422–445s],调研 09 §8.4)——阴影随体积/高度加深的高度语言在系统材质中的对应;
  • WinUI/Fluent 拖拽抬升:「被拖起的元素临时提高 z,落点恢复」——Fluent 深度模型的典型交互(见 theme-shadow 条目,调研 02 §C5),接触阴影↔悬浮投影的切换正是其 web 落地形态。

参数敏感度

参数调大会…调小会…
distance椭圆拉长、元素上移,读作「悬浮中」;>16px 接近悬浮投影的领地,接触感流失元素贴向表面;<2px 椭圆几乎被卡底遮住,阴影形同消失;0 = 完全贴合(椭圆藏于卡后,物理正确)
spread阴影更软更融,「软接触」的软感增强;过大(>12px)与表面糊成一片、失去接触感边缘变硬,像贴了一片深色胶带;0 = 无模糊的实心椭圆,最生硬
color色相越接近背景越「隐形和谐」;偏离背景色相会产生彩色溢光(特效向)越接近纯黑越压灰褪色——调研明令禁止的做法
alpha阴影更实更显眼;>0.4 开始喧宾夺主,像一处污渍越淡越含蓄;<0.1 在浅表面上几乎不可感知(深表面更甚)
mode → float悬浮投影:偏移大、弥散、多层的「漂在上方」,适合抓起/弹层等高程状态贴地接触:紧、深、边缘柔,适合静置/落点的默认态

经验区间:distance 4–8px(默认 6 即调研配方)、spread 4–8px、alpha 0.2–0.3;深色表面与低 alpha 的组合要专门实测——深表面上阴影是所有材质线索里最先失效的一个。

适用场景 4
  • 拖拽排序中被抓起的卡片:抬升时接触阴影拉长变淡,落点弹回贴地——高度叙事的核心道具
  • 底部吸附元素(FAB、Dock、工具条)与表面的贴合感
  • 3D/AR 视图、产品陈列、卡片桌面等「物体放在平面上」的隐喻界面
  • 贴地卡与悬浮卡的层级区分——两式阴影对照表达高度差
何时不要用 4
  • 对分层悬浮阴影做逐帧动画——渲染开销大,调研明确不建议(调研 12 §7)
  • 阴影叠纯黑——压灰褪色、与背景脱节(调研 12 §7)
  • 多光源混用——全站应共享单一光源与同一偏移比例(如水平:竖直 = 1:2)
  • 用阴影表达可点击——阴影表达高度与材质,不表达交互性
无障碍

阴影是纯装饰深度线索:不可作为传达层级或状态的唯一手段(需配合位移/尺寸/文字);控件边界仍需满足 3:1 非文本对比(WCAG 2.1 SC 1.4.11);深色表面上阴影可感知度下降,需按实际背景核对;阴影不承载交互语义,焦点指示仍需可见(WCAG 2.1 SC 2.4.7)。

浏览器支持

box-shadow / filter / 渐变均 Baseline 广泛可用(调研 12 §7);demo 的 color-mix() 需 Baseline 2023-05(Chrome 111+ / Safari 16.2+ / Firefox 113+,调研 12 §11)。颜色参数本身是普通 hex,无兼容门槛。

兼容回退

不支持 color-mix() 时退回 8 位 hex 写死透明度(如 #3366cc40);极老环境不支持 filter: blur 时椭圆退回纯色半透明(边缘略硬,仍是有效的接触阴影)。阴影是纯装饰层,任何降级都不影响功能与可读性。

来源 1

起源术语来自 3D 渲染的环境光遮蔽(ambient occlusion);CSS 社区惯用「椭圆伪元素 + blur」实现,属实践共识,调研未找到单一权威文档定义(out/design-study/12-expansion.md §7,如实标注);分层阴影与「阴影不叠纯黑、单一全局光源」原则经 Josh Comeau《Designing Shadows》核验;阴影随体积/高度加深的定性规则见 WWDC25 219(out/design-study/09-apple-materials.md §8.4)。

  1. 条目 景深层次

    对比:同是把 3D/摄影语汇搬进 UI,深度线索不同:接触阴影用环境光遮蔽做「贴地」,景深用 blur 分层做「焦外」。

  2. 条目 柔光设计

    搭配:两者共享「单一光源」纪律:同一盏灯照亮整套 UI,阴影色相与辉光同源才有物理可信度。

  3. 条目 Fluent 主题阴影

    反向自「Fluent 主题阴影」的精选:对比关系,原句「高度语言的两档:「贴地」是紧贴椭圆接触阴影,「悬浮」是偏移大、更弥散的投影——先分清高度叙事再选阴影。」
