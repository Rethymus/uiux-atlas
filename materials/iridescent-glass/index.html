极光玻璃 Iridescent Glass

极光玻璃 · 虹彩玻璃 · 薄膜干涉玻璃 · 油膜玻璃 · Iridescent Glass · Oil-slick Glass

hue 随相位漂移的薄膜干涉质感玻璃:同一 conic 渐变的双实例(锐利层做环、模糊层做光)+ 向内渗光,色相沿环缓慢流转,像肥皂膜/油膜上的结构色。与既有 aurora-gradient(背景层渐变)不同,这是面板材质。

drift6s

色相环旋转周期(--ig-spin 从 0deg 转到 360deg 一圈的时间)。默认 6s 为 §5.3 halo 配方记载值(「animation: spin 6s linear infinite」);0 = 停止漂移,静止在 90deg 相位(与 reduce 分支同相)。其余周期档位为演示范围,调研未记载,按工程值对待。

hue32

薄膜色相基准角(无单位数值,deg 由消费方 hsl() 隐含;cssVar 以纯数字注入以便 hsl(calc(基準±偏移)) 运算),环上三色色标由它派生(基准 / +90° / +200°,首尾同色闭合,派生规则为本站工程推演 [R])。默认 32° 兼顾两处已核验锚点:§1.3 --glow-hue 初值 32;§5.3 首色标 rgb(255 176 32) 的实测色相 ≈34°(工程换算)。halo 配方的固定三色(32/255 86 168/86 128 255)即本参数默认档的近似形态。

bleed30%
%

向内渗光强度(inset 泛光层 alpha,§1.3 ② 层「inset 0 0 18px 2px,渗光色 30%」)。默认 30% 为配方记载值;§1.3 数值域 .22–.32,上限 40% 之外即进入「洗白」警戒(bloom alpha 超 .45 洗白,§1.3 警告,渗光同理保守对待)。0 = 关闭渗光,只剩虹彩环。

代码拆解

结构与 DOM

极光玻璃是hue 随相位漂移的薄膜干涉质感(调研 17 §12.2):配方为 §5 conic 环 + §1 渗光的组合推广 [R]。结构与 halo-glow-border 同族——同一渐变的双实例——再加一层内渗光:

<div class="scene">
  <div class="iridescent">       <!-- 玻璃本体:backdrop-filter + 渗光 box-shadow -->
    <h3>标题</h3>
    <p>正文</p>
  </div>
</div>

关键点:

  • 环 = 锐利层:::before 以双 mask 挖空出 1.5px 细环(-webkit-mask-composite: xor / mask-composite: exclude 双写),色标由 --ig-hue 派生、首尾同色闭合;
  • 光 = 模糊孪生层:::after 是同源渐变的模糊副本(外扩 3px、blur(10px)、降透明度),垫在卡后外溢成光晕——§5.3「锐利层做线、模糊层做光」原样沿用;
  • 渗光在 box-shadow 里:§1.3 ② 层 inset 0 0 18px 2px 渗光色 30%,让环色向面板内部衰减;
  • 旋转的前提是注册:@property --ig-spin { syntax: "<angle>" }——未注册的自定义属性不可插值,这是 2024-07(Baseline)前后「能不能转」的分水岭(§11.8);
  • 与既有条目 aurora-gradient(极光渐变)的区别:那是背景层的极光色块渐变,本条是面板材质——结构色长在玻璃边缘与内衬上。

样式与参数

三个参数经 --ig-* 变量注入:

@property --ig-spin { syntax: "<angle>"; inherits: false; initial-value: 0deg; }

.iridescent {
  position: relative;
  border-radius: 20px;
  background: rgb(255 255 255 / 0.08);                 /* §5.3 本体低填充 */
  -webkit-backdrop-filter: blur(12px) saturate(1.4);   /* §5.3 */
  backdrop-filter: blur(12px) saturate(1.4);
  /* 渗光(§1.3 ②)+ 落影(§1.3 ⑤),alpha 由 --ig-bleed 驱动 */
  box-shadow:
    inset 0 0 18px 2px hsl(var(--ig-hue) 90% 78% / calc(var(--ig-bleed) / 100)),
    0 12px 40px rgb(0 0 0 / 0.25);
}
.iridescent::before, .iridescent::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  pointer-events: none;
  background: conic-gradient(from calc(90deg + var(--ig-spin)),
    hsl(var(--ig-hue) 90% 62%),
    hsl(calc(var(--ig-hue) + 90) 85% 62%),
    hsl(calc(var(--ig-hue) + 200) 85% 62%),
    hsl(var(--ig-hue) 90% 62%));                        /* 首尾同色闭合 */
  padding: 1.5px;
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
  animation: ig-spin var(--ig-period) linear infinite;
}
.iridescent::before { filter: drop-shadow(0 0 6px hsl(var(--ig-hue) 90% 70% / 0.45)); z-index: 1; }
.iridescent::after  { inset: -3px; padding: 3.5px; filter: blur(10px); opacity: 0.55; z-index: -1; }

@keyframes ig-spin { to { --ig-spin: 360deg; } }
@media (prefers-reduced-motion: reduce) {
  .iridescent::before, .iridescent::after { animation: none; --ig-spin: 90deg; }
}

数值出处:

  • --ig-spin 注册、conic 三色首尾闭合、双 mask 挖空、blur(10px)、opacity .55、6s 旋转、reduce 静止 90deg:全部为 §5.3 halo 配方记载值;
  • 渗光 inset 0 0 18px 2px、渗光色 hsl(hue 90% 78%)、alpha 30%:§1.3 ② 层记载值(--glow 定义 hsl(var(—glow-hue) 90% 78%));
  • hue 默认 32°:§1.3 --glow-hue 初值;±90°/±200° 色标派生与静态相位 from 90deg + spin 为工程推演 [R];
  • drift 其余档位为演示范围(调研只记载 6s),effect 中已如实标注。

动效与交互

虹彩是缓慢的氛围动画,节制定在「只动角度」:

  • 唯一的动画是 --ig-spin 角度插值(§5.3 spin 原样),不位移、不缩放任何元素——缩放与平移是前庭触发源(§8.2 MDN 核验);
  • prefers-reduced-motion: reduce:静止在 90deg 相位,保留静态结构色(§5.3 reduce 分支原样沿用——替换为无动效状态,而不是黑掉);
  • drift 归零 = 停止漂移,同样静止在 90deg;demo 中 0 周期不会产生抖动(动画直接摘除);
  • 玻璃本体在导航层节制使用(≤3 层,§11.10);内容层退回标准磨砂五档。

真实产品案例

  • 按 §12.2 如实处理:「极光玻璃」配方为工程推演,未见权威综述核验——本条目不引用未核验站点;
  • 已核验的技术谱系锚点:MDN conic-gradient 与 @property 两页(§5.2 全文核验),halo-glow-border 条目的 §5.3 配方(同源双实例),soft-glow-glass 条目的 §1.3 渗光配方;
  • 相邻社区实践:hyalite 的 rim 光处理(Fresnel sheen + specular line + inset-shadow 边,README 全文核验【S】)证明「边缘光学事件可用 box-shadow/渐变实现」。

参数敏感度

参数调大会…调小会…
drift周期变长,流转更慢更「矿物的」;12s 接近静止陈列品流转加快;过短(<3s)开始读作「转灯」而非薄膜干涉;0 = 静止 90deg
hue整组结构色沿色轮平移;与内容主色同族时(§9 光色同族)最稳0°/360° 红端;色标派生跨 300°+,任何基准都保证三色互异
bleed>40% 进入「洗白」警戒(bloom 超 .45 洗白,§1.3 警告同源)渗光衰减;0 = 单关渗光,只剩虹彩环(环与渗光解耦,仿 chromatic-edge「独立归零」约定)

经验区间:drift 4–8s、hue 与内容主色 ±30° 内、bleed 22–32%(§1.3 数值域);@property 未注册环境自动退化为静态环,无回退成本。与 halo-glow-border 条目互参:同源双实例的母配方;与 soft-glow-glass 条目互参:渗光三件套(渗光/泛光/lit edge);与 chromatic-edge 条目互参:「独立参数可归零」的约定;与 aurora-gradient 条目互参:背景层极光与面板材质的分野。

适用场景 3
  • 暗场品牌 hero、演出/音乐界面的氛围强调卡(结构色是暗场语言)
  • 「柔光玻璃时代」光谱的高端档:比 soft-glow 更彩、比 halo 更柔的面板点睛
  • 状态徽章与荣誉卡等小面积「奖牌感」场景
何时不要用 3
  • 内容层大面积使用——玻璃是导航层特权,超三层层级感先死(§11.10)
  • 承载文字正文的表面:虹彩色相流转会持续改变局部背景,正文对比度不可控
  • 浅色主题大面积使用:结构色依赖暗底衬托,浅底上退成杂色
无障碍

虹彩与渗光均为纯装饰:不承载任何信息,环/光层 pointer-events: none 且不进入无障碍树;色相漂移只动渐变角度(--ig-spin),不位移不缩放任何元素(前庭安全,§8.2 MDN 核验);prefers-reduced-motion: reduce 时静止于 90deg 相位并保留静态结构色(§5.3);面板上的正文按透出的最亮/最暗背景核对 4.5:1。

浏览器支持

conic-gradient 全基线(§5.4);@property 注册角度为 Baseline 2024-07(2024-07 起)——旧浏览器环静止但显示正常(initial-value 兜底,§5.4【S】);mask-composite: exclude + -webkit-mask-composite: xor 双写覆盖 Chromium/Safari/Firefox(§5.4);backdrop-filter Baseline 2024-09(§1.4);色标用 hsl(calc(…)) 派生为基线能力。

兼容回退

无 @property 时旋转停止,静态虹彩环正常显示(initial-value 兜底,§5.4);不支持 backdrop-filter 时提高填充不透明度到 .7+ 保住可读性(§1.4);prefers-reduced-motion: reduce 时 --ig-spin 静止在 90deg(§5.3 reduce 分支原样沿用),静态结构色保留;drift 归零同样静止在 90deg。

来源 2

起源工程综合 [R]:调研 17 §12.2 记载「极光玻璃 iridescent glass:hue 随视角/时间漂移的薄膜干涉质感(§5 conic 环 + §1 渗光的组合推广);配方为工程推演,未见权威综述核验」。已核验构件【S】:MDN conic-gradient(from/at 语法、角度色标、插值,§5.2 全文核验)、MDN @property(Baseline 2024-07,注册后自定义属性可参与动画,§5.2 全文核验)、box-shadow 多层叠序(§1.3/§7.2 MDN 核验)。配方母体:§5.3 halo 配方(@property --spin <angle>、conic 三色首尾同色、双 mask 挖空、spin 6s、reduce 静止 90deg)与 §1.3 soft-glow 配方(--glow-hue 初值 32、内渗光 inset 0 0 18px 2px alpha 30%)。「iridescent glass」作为独立材质名未见权威定义(未证实)。
