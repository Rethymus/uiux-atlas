内发光面板 Inner-Glow Panel

内发光面板 · 内泛光 · Inner Glow · Inset Glow

inset 光感面板:不发外光,光被「关在」面板内部——整体内泛光 + 上沿受光 + 下沿环境暗,是发光层的「静音版」。常用于深色仪表盘容器、代码块、选中态。

结构与 DOM

内发光面板是发光层的「静音版」:不发外光,光被「关在」面板内部——整体内泛光 + 上沿受光 + 下沿环境暗(调研 17 §7.1)。语法基础是 MDN box-shadow 的 inset 关键字,官方语义原文「as if the content is pressed into the box」(box-shadow 页核验)。

<section class="inner-glow">   <!-- 单元素:全部光层都在 box-shadow 里 -->
  <h3>概览</h3>
  …
</section>

关键点:

  • 单元素材质:泛内光、上沿受光、下沿环境暗、外描边四层全部是 box-shadow 层,无伪元素、无 DOM;
  • 叠序即光序(MDN:先声明的在最上):主光层写最前,落暗层写最后——顺序错了上沿受光会被泛光吃掉(与 contact-shadows/theme-shadow 条目共用这条语法规则);
  • inset 阴影画在 background 之上、content 之下(MDN 原文核验):所以内光不会盖住面板自己的文字。

样式与参数

四个参数对应配方(调研 17 §7.3,[R]):

.inner-glow {
  background: rgb(255 255 255 / .04);
  border-radius: 16px;
  box-shadow:
    inset 0 0 var(--ig-size) 2px color-mix(in srgb, var(--ig-color) var(--ig-a), transparent), /* 泛内光(主光) */
    inset 0 1px 0 rgb(255 255 255 / .35),        /* 上沿受光 */
    inset 0 -1px 0 rgb(0 0 0 / .30),             /* 下沿环境暗(厚度) */
    0 0 0 1px rgb(255 255 255 / .08);            /* 可选外描边 */
}
/* 单侧光:改第一层的 y 偏移即可定向,负 spread 收紧 */
.inner-glow--top {
  box-shadow:
    inset 0 18px 24px -12px color-mix(in srgb, var(--ig-color) 30%, transparent),
    inset 0 -1px 0 rgb(0 0 0 / .3);
}

数值出处:

  • 泛内光 inset 0 0 24px 2px rgb(120 180 255 / .18)(配方 intensity 18%,演示默认提至建议域上缘 22%——SJ-11「静音但可辨」/ spread 24px / #78B4FF)、上沿 white/.35、下沿 black/.30、外描边 white/.08、单侧光 inset 0 18px 24px -12px / alpha .30:全部为调研 17 §7.3 配方记载值;
  • 数值域:泛内光 blur 18–32px / alpha .12–.22;定向内光负 spread 收紧在 −8 ~ −16px(调研 17 §7.3);
  • inset 语义与叠序:MDN box-shadow 页核验【S】;iOS 深色模式卡片/键盘按键的按压内陷感是该语义的系统级用例。

动效与交互

内光是静态光,动效需求极低:

  • 入场:淡入 + 8px 上移;prefers-reduced-motion 时取消;
  • 选中态切换:内光 alpha 以 0.2s opacity/box-shadow 过渡即可;但状态必须同时有图形/文字冗余(demo 的圆点 + aria-selected)——不得只靠光(WCAG 1.4.1);
  • 不要给内光加呼吸动画:呼吸是独立材质(breathing-glow)的职责,且 MDN 点名缩放/平移是前庭触发源——内光若要动,只动 box-shadow 的 alpha/blur 并遵守同一套 reduce 规则;
  • 零重排:box-shadow 变更不触发布局,但大面积面板的 repaint 仍要留意——静态是内光的默认形态。

真实产品案例

  • iOS 深色模式卡片 / 键盘按键的按压内陷感:inset 语义即「pressed into the box」,MDN 原文核验(调研 17 §7.6)——按压时内陷光正是「光被关进元素内部」的系统级表达;
  • 深色仪表盘容器/代码块/选中态是工程通行场景(调研 17 §7.1);逐站点代表例调研未能核验(调研 17 §7.6 如实标注),不列具体站点。

参数敏感度

参数调大会…调小会…
intensity>25% 内光开始糊住面板自身内容,「静音版」失守光退成薄晕;0 = 面板只剩上下沿的受光/落暗,退回普通深色卡
spread光向面板中心漫延,大面积低 alpha 时像「雾化」;>32px 后边缘光感稀释光贴边成圈;12px 时更像描边而非泛光
glowColor偏离冷色域(如高饱和橙红)后内光变「警报」,语义反转趋白趋灰,「活着的表面」暗示消失;与内容主色同族时最自然
direction → top光从上方进入,「受光面」叙事更强;负 spread 让光带更锐利集中回到 omni:整圈均匀泛光,最安静也最中性

经验区间:intensity 12–22%、spread 18–32px、定向负 spread −8 ~ −16px、光色锁冷色低饱和族。与 soft-glow-glass 条目互参:内外发光的分野;与 breathing-glow 条目互参:内光若要动,共用「只动 alpha/blur」铁律;与 theme-shadow/contact-shadows 条目互参:box-shadow 叠序语法同源。

适用场景 3
  • 深色仪表盘的容器/分区:面板被「内部」照亮,不向外污染布局(调研 17 §7.1)
  • 代码块、终端窗格:冷蓝内光是「活着的表面」的最低调表达
  • 选中态/激活分区:内光把注意力收在元素内部,比外发光更安静
何时不要用 3
  • 需要「元素在场景中发光」的叙事——那是 soft-glow-glass/breathing-glow 的职责
  • 浅色底材:内光在亮面板上几乎不可见,只剩脏边
  • alpha 超过 ~25%:内光开始糊住面板自身内容,「静音版」失守
无障碍

内光是装饰:面板的选中/激活状态需有文字/图形冗余指示(不得只靠光,WCAG 1.4.1);面板内文字对比按内光最亮处核对 4.5:1(WCAG 2.1 SC 1.4.3);本材质无自主动画。

浏览器支持

inset box-shadow 全基线(MDN 页历史能力,核验),零回退成本(调研 17 §7.4);color-mix(Baseline 2023)仅 demo 用于把 hex 转透明层,生产可直接写 rgba()。

兼容回退

无需回退:inset box-shadow 全基线(调研 17 §7.4)。唯一注意点是叠序——内光层要写在最前(MDN:先声明的在最上),顺序错了上沿受光会被泛光吃掉。

  1. 条目 柔光设计

    搭配:内泛光是柔光设计语言里的静音档:暗场容器不向外溢光,只留上沿受光与下沿环境暗。

  2. 条目 呼吸光晕

    对比:发光方向二选一:内泛光把光关在面板内部当「静音版」,呼吸辉光让光斑以 2–6s 周期向外往复——一静一动。

  3. 条目 柔光玻璃

    反向自「柔光玻璃」的精选:对比关系,原句「同是玻璃面板的发光,方向相反:渗光/泛光向外,内泛光把光关在内部——发光层的两个音量档。」
