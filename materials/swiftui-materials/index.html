SwiftUI 材质 SwiftUI Materials

SwiftUI 材质 · 系统材质 · UIBlurEffect · vibrancy

SwiftUI 的六档背景材质(ultraThin…ultraThick、bar):介于前景与背景间的半透明层,前景自动获得 vibrancy;Web 端只能用 CSS 变量做近似对照。

结构与 DOM

SwiftUI 官方语境里,材质不是视图,而是介于前景与背景之间的半透明层,『类似重度磨砂玻璃的混合效果』;材质之上的前景自动获得 vibrancy(A8)。Web 近似复刻的结构是『背景 → 薄层(伪材质)→ vibrancy 文字层级』:

// 官方 API(iOS 15+,调研 02 §1 A8)
ScrollView { … }
  .background(.ultraThinMaterial)   // 六档之一:ultraThin/thin/regular/thick/ultraThick/bar
  .foregroundStyle(.secondary)      // 或依赖材质自动 vibrancy
<div class="scene">
  <img class="bg" src="photo.jpg" alt="" />
  <section class="mat"> <!-- 薄层:伪材质 -->
    <p class="v-default">default 主级</p>
    <p class="v-secondary">secondary 次级</p>
    <hr class="v-sep" />
  </section>
</div>

关键点:材质厚薄表达的是层级承诺——越厚越接近实色、文字越稳;vibrancy 是材质赠予前景的对比策略,不是随便调透明度。

样式与参数

Web 端用 CSS 变量按档位近似六档透明度与模糊(社区近似值,官方未公布数值):

.mat {
  border-radius: 16px;
  -webkit-backdrop-filter: blur(var(--sm-blur));
  backdrop-filter: blur(var(--sm-blur));
  background: rgb(255 255 255 / var(--sm-alpha));
}
/* 社区近似表(未证实):ultraThin .08/12px · thin .18/16px · regular .30/20px
   thick .44/24px · ultraThick .60/28px · bar .36/16px */
.mat[data-material="thick"]     { --sm-alpha: 0.44; --sm-blur: 24px; }
.mat[data-material="ultraThick"]{ --sm-alpha: 0.60; --sm-blur: 28px; }

/* vibrancy 层级:对比度递减(A10),近似以前景透明度表达 */
.v-default    { color: rgb(0 0 0 / 1); }
.v-secondary  { color: rgb(0 0 0 / 0.65); }
.v-tertiary   { color: rgb(0 0 0 / 0.45); }
.v-quaternary { color: rgb(0 0 0 / 0.30); } /* ultraThin/thin 上官方禁用 */

数值出处:

  • 六档名称与语义:SwiftUI Material 文档(A8,调研 02 §1);bar 为工具条专用档;
  • vibrancy 层级 default→quaternary、separator 一级、quaternary 在 ultraThin/thin 上禁用:HIG Materials(A10);
  • 透明度/模糊数值:官方未公布——上表为社区近似对照值,Web 端只能示意趋势(越厚越暗越保对比),换真机仍以系统渲染为准。

动效与交互

  • 材质切换:薄层透明度/模糊用 0.25s 过渡,营造『材质变厚』的连续感;prefers-reduced-motion 时取消过渡;
  • 层级切换:vibrancy 四级行逐行淡入 0.25s,当前选中行加左侧指示条;
  • 禁用组合(quaternary + ultraThin/thin)出现时,警告条淡入并停止其他动效——这是需要用户读到的状态,不该被动画稀释;
  • demo 的背景保持静态:材质厚薄的对比不需要动效陪衬,静态最利于对比度核对。

参数敏感度

参数调大(更厚的档位)…调小(更薄的档位)…
material越厚越不透明:文字对比度更稳,但『材质感』减弱,ultraThick 接近实色卡片越薄越透:背景色彩透出更多、更『液』,但文字对比度完全依赖 vibrancy/加粗,ultraThin 上连 quaternary 都被官方禁用
vibrancy层级越低(→quaternary)对比度越弱:适合时间戳、占位符等次要信息;在厚材质上才安全层级越高(→default)对比度越强:正文与关键信息必须落在 default/secondary
组合(材质×层级)厚材质 × 低层级:信息可读但偏『噪』,注意别让装饰性层级进正文薄材质 × 低层级:官方禁用组合——demo 会警告,生产中直接避免

经验法则:层级承诺与内容重要度对齐——工具条用 bar、正文支撑用 regular 以上、装饰性浮层才用 ultraThin;vibrancy 每降一级都要在真机/两极端背景上重核 4.5:1(WCAG 2.1 SC 1.4.3)。

适用场景 3
  • 工具条与标签栏(bar 材质的官方场景),列表行、卡片底等支撑层
  • 临时浮层:sheet、popover、菜单——按厚薄档位表达层级
  • 需要前景 vibrancy 的标签/图标层(材质之上前景自动获得 vibrancy,A8)
何时不要用 3
  • ultraThin/thin 上放 quaternary 层级内容——官方禁用,对比度不足(A10)
  • 用自定义前景色替代 vibrancy 后仍期待系统对比度——自定义 foregroundStyle 会关闭 vibrancy(A8)
  • 把 Web 近似数值当成官方数值——Apple 未公布材质的透明度/模糊数值
无障碍

材质上的文字对比度按『透出背景最亮/最暗』两端核对 4.5:1(WCAG 2.1 SC 1.4.3,调研 06 §五 §17);薄档材质(ultraThin/thin)上避免低对比层级(quaternary,官方禁用);vibrancy 不可用时用次级文字色等价替代。

浏览器支持

官方材质仅 Apple 平台:iOS 15+/macOS 的 SwiftUI Material 与 UIBlurEffect(调研 02 §1 A7/A8)。Web 近似依赖 backdrop-filter:Chrome 76 / Firefox 103 / Safari 9(-webkit- 前缀,Safari 18 起无前缀)(调研 02 §4 D2 / 03 §1)。

兼容回退

Web 近似的透明度/模糊数值均为社区对照值——不支持 backdrop-filter 时,按所选材质档位提高填充不透明度(越厚越接近实色)保住文字可读;vibrancy 在 Web 无法复刻,文字对比度需按最亮/最暗透出背景手工核对。

来源 3

起源SwiftUI Material 六种:iOS 15+ 的 ultraThinMaterial / thinMaterial / regularMaterial / thickMaterial / ultraThickMaterial / bar(调研 02 §1 A8);前身是 UIKit UIBlurEffect 的 Style 常量族(A7);HIG vibrancy 层级 label/fill 多级 + separator(A10)。Web 端透明度近似为社区做法,官方未公布数值。
