折射文字 Glass Text

折射文字 · 玻璃文字 · 文字透镜 · 文字色散 · Glass Text Effect

文字级的透镜变形与边缘色散:SVG feDisplacementMap 位移滤镜天然适用于文本,把玻璃色散边从容器缩到字形上——字形边缘出现轻微扭曲与红蓝错位,像隔着一块小透镜看字。

代码拆解

结构与 DOM

折射文字是文字级的透镜变形/边缘色散(调研 17 §12.5):玻璃色散边的 SVG 位移滤镜天然适用于文本。两条实现路线,与容器级 chromatic-edge 的 A/B 分法一致:

<!-- 路线 A:SVG 滤镜真位移,元素级 filter: url() 挂在标题上 -->
<svg width="0" height="0" aria-hidden="true">
  <filter id="gt-lens" x="-20%" y="-20%" width="140%" height="140%"
          color-interpolation-filters="sRGB">
    <feTurbulence type="fractalNoise" baseFrequency="0.008" numOctaves="1" seed="7" result="map"/>
    <feDisplacementMap in="SourceGraphic" in2="map" scale="4"
                       xChannelSelector="R" yChannelSelector="G"/>
  </filter>
</svg>
<h1 class="gt-lens">折射文字</h1>   <!-- filter: url(#gt-lens) -->

<!-- 路线 B:双层文字副本(全浏览器),本体 + data-text 属性,无新增 DOM -->
<h1 class="gt-faux" data-text="折射文字">折射文字</h1>

关键点:

  • 文字本体必须是真实 DOM 文本(可选中、可朗读);路线 A 的滤镜与路线 B 的 ::before/::after 副本(content: attr(data-text))都是纯装饰,不进入无障碍树;
  • 路线 A 在调研 17 §6.3 配方上把容器级滤镜缩到文字:baseFrequency 0.008 / numOctaves 1 / seed 7 / scale 4 全部为该配方记载值;元素级 filter: url() 的逐浏览器矩阵调研未核验(调研只核验了 backdrop-filter: url() 的 Chromium-only 矩阵,§6.4),失效时静默降级为清晰文字;
  • 路线 B 是「假位移」:两个 background: transparent 的字形副本,色相错开 + screen 混合近似红蓝折射率差——文字没有「边缘蒙版」可挖,所以副本整体叠印而非只留边缘;
  • 文字级先例未核验:hyalite/rdev 均为容器级(§12.5 如实标注),本条配方按工程推演 [R] 对待。

样式与参数

三个参数,两个 CSS 变量型 + 一个 SVG 属性型:

.gt-faux { position: relative; }
.gt-faux::before, .gt-faux::after {
  content: attr(data-text);
  position: absolute; inset: 0;
  mix-blend-mode: screen; opacity: 0.5;
  pointer-events: none;
}
.gt-faux::before { transform: translateX(var(--gt-shift)); filter: hue-rotate(calc(var(--gt-hue) * -1)) saturate(3); }
.gt-faux::after  { transform: translateX(calc(var(--gt-shift) * -1)); filter: hue-rotate(var(--gt-hue)) saturate(3); }

/* 路线 A:元素级滤镜 */
.gt-lens { filter: url(#gt-lens); }
// lensScale 是滤镜 primitive 属性,不接受 CSS 变量——demo 订阅后改写属性(工程约束)
lens.setAttribute("scale", String(store.get("lensScale")));

数值出处:

  • dispersion 默认 2px:社区量化参考 rdev/liquid-glass-react 的 aberrationIntensity: 2(README 核验【S】);
  • lensScale 默认 4:§6.3 路线 A 配方 scale="4";MDN 示例 50 为强扭曲,玻璃/文字档建议 2–6(MDN feDisplacementMap 页核验【S】);
  • hueAngle ±28°、saturate(3):路线 B 配方记载值(§6.3);
  • 副本 opacity 0.5 与 screen 混合为本站 demo 验证值(文字副本要压住本体又不能盖过,工程推演)。

动效与交互

色散文字是静态材质,几乎不需要动效:

  • 入场淡入 + 6px 上移;prefers-reduced-motion 时取消(本材质无自主动画,仅此一处);
  • 不要把位移绑到指针:文字逐帧重排会触发整行重绘,且字形持续抖动会滑向「故障风」而非玻璃质感;
  • 路线切换(真位移 ↔ 假位移)是离散开关,切换时不做过渡动画——两种路线的成像机理不同,中间态没有意义;
  • 大字号 hero 场景里色散可以随加载入场一次性「定格」,之后保持静止。

真实产品案例

  • hyalite demo:SDF 透镜 + per-channel 色散的完整容器级实现,demo 地址 https://vii-cae.github.io/hyalite—liquid-glass/demo/index.html(仓库元数据核验);
  • rdev/liquid-glass-react:以 aberrationIntensity(默认 2)参数化色散的社区组件(GitHub API + README 核验,6798★);
  • 文字级独立先例未核验:调研 17 §12.5 如实记载「hyalite/rdev 均为容器级,文字级实现为工程推演,未核验先例」——本条目是该工程推演的站点落地,不引用未核验站点。

参数敏感度

参数调大会…调小会…
dispersion>3px 开始吃掉细笔画,字形边缘出现「裂影」;斜体/细字重更早崩色差收窄;0 = 单关色散,字形回到清晰版(chromatic-edge 同款「独立归零」约定)
lensScale>8 字形明显扭波(wave),像隔着厚透镜;MDN 的 50 是海报级强扭曲趋近平面文字;0 = 无位移,只剩路线 B 的色相分离
hueAngle±28° 以上红/青偏更浓;>45° 变「3D 红蓝眼镜」效果两层色相靠拢;0 = screen 混合同色,色散不可见,只余 opacity 叠印发淡

经验区间:dispersion 1.5–3px、lensScale 2–6(MDN 玻璃档建议)、hueAngle ±20–32°;只在 ≥32px 的大字形上启用。与 chromatic-edge 条目互参:容器级色散的边缘蒙版挖空法;与 liquid-glass 条目互参:官方 lensing 定性与「文字级不进内容层」的节制原则;与 backdrop-filter 条目互参:url() 引用的浏览器矩阵。

适用场景 3
  • 品牌标语 / hero 大字号标题:字形面积大,色散读得出来且不伤小字辨识
  • 玻璃主题站点与 liquid-glass 面板的配套字形点睛(容器级透镜的文字对应物)
  • 科技 / 光学主题的海报、封面与 404 页的整句标语
何时不要用 3
  • 正文与小号文字:位移直接吃掉笔画,可读性崩坏(笔画越细越不可位移)
  • 用 CSS.supports 检测启用路线 A:检测会撒谎(调研 17 §6.4【S】),必须接受静默降级
  • 笔画密集的表意文字长句(汉字/假名长文):逐字位移叠加后整行发虚
无障碍

文字本体必须是真实 DOM 文本(可选中、可朗读、可缩放),滤镜与副本层纯装饰:副本经 ::before/::after content 或 aria-hidden,均不进入无障碍树,pointer-events: none;正文对比度按未加滤镜版本核对 4.5:1(WCAG 2.1 SC 1.4.3);本材质无自主动画,prefers-reduced-motion 仅取消入场。

浏览器支持

feDisplacementMap 本身 2015-07 起全浏览器(MDN 核验【S】)。路线 A 经元素级 filter: url(#svg) 挂到文字——该路线的逐浏览器矩阵调研未核验,如实标注(调研 17 §6.4 只核验了 backdrop-filter: url() 的 Chromium-only 矩阵与「CSS.supports 会撒谎」【S】,元素级 filter 不能援引该结论,也不能用 CSS.supports 判断);路线 B(双层文字副本 + hue-rotate + screen 混合)为纯 CSS 基线能力,全浏览器。

兼容回退

路线 B 即回退:双层 attr() 文字副本 + hue-rotate + screen 混合,不依赖 SVG 滤镜;路线 A 失效时表现为无位移的清晰文字(滤镜被静默丢弃),信息无损——文字本体始终是真实 DOM 文本,滤镜与副本层只是装饰,装饰消失不改变内容。

来源 3

起源容器级透镜与色散在社区仓库已核验:hyalite(SDF 位移贴图 + per-channel 色散,README 全文核验【S】)与 rdev/liquid-glass-react(aberrationIntensity 默认 2,README 核验【S】);feDisplacementMap 位移公式 P'(x,y) ← P(x + scale·(XC−0.5),…) 与 in/in2/scale/xChannelSelector/yChannelSelector 属性(MDN 全文核验【S】)。文字级实现为工程推演 [R]:调研 17 §12.5 明确记载「hyalite/rdev 均为容器级,文字级实现为工程推演,未核验先例」,本条配方全部按 [R] 对待;路线 A 配方构件(feTurbulence baseFrequency 0.008 / numOctaves 1 / seed 7 / scale 4、per-channel 偏移)取自 §6.3 路线 A 已记载值。
