呼吸光晕 Breathing Glow

呼吸光晕 · 呼吸灯 · Breathing Glow · Pulsing Halo

环境呼吸辉光动画:柔和光斑以 2–6s 周期在 alpha/blur 上往复,用于在线状态、通知点、品牌氛围。铁律:只动 box-shadow 的 alpha/blur,不动 scale/translate。

代码拆解

结构与 DOM

呼吸光晕是环境呼吸辉光动画:柔和光斑以 2–6s 周期在 alpha/blur 上往复,用于在线状态、通知点、品牌氛围(调研 17 §8.1)。它的全部本体就是一个元素 + 一条 keyframes——没有结构可言,纪律比结构重要。

<span class="breathing" aria-hidden="true"></span>  <!-- 光点本身纯装饰 -->
<span>在线 Online</span>                            <!-- 状态文字必须冗余存在 -->

关键点:

  • 光点元素 aria-hidden="true":光斑是装饰,状态由旁边的文字/图形承载(WCAG 1.4.1);
  • 铁律:只动 box-shadow 的 alpha/blur,不动 scale/translate——MDN 原文指出缩放/平移大对象是 “vestibular motion triggers”(前庭触发源),breathing 的合法性全靠遵守这条(调研 17 §8.1/§8.2【S】);
  • keyframes 只有 0%/100%(静息帧)与 50%(峰值帧)两态,cubic-bezier(.4, 0, .6, 1) 让两端缓、中间匀。

样式与参数

三个参数对应配方(调研 17 §8.3,[R]):

@keyframes breathe {
  0%, 100% { box-shadow: 0 0 10px 0 color-mix(in srgb, var(--brg-color) 22%, transparent); }
  50%      { box-shadow: 0 0 26px 4px color-mix(in srgb, var(--brg-color) var(--brg-amp), transparent); }
}
.breathing { animation: breathe var(--brg-period) cubic-bezier(.4, 0, .6, 1) infinite; }
@media (prefers-reduced-motion: reduce) {
  .breathing {
    animation: none;
    /* 取中间帧静态值:blur 18px / spread 2px / alpha 取 .22 与峰值的中点 */
    box-shadow: 0 0 18px 2px color-mix(in srgb, var(--brg-color) calc((22% + var(--brg-amp)) / 2), transparent);
  }
}

数值出处:

  • keyframes 两帧值(静息 alpha .22 / blur 10px;峰值 alpha .55 / blur 26px / spread 4px)、周期 3.2s、曲线 cubic-bezier(.4, 0, .6, 1)、reduce 静态帧(18px / 2px / alpha .38):全部为调研 17 §8.3 配方记载值;
  • 约定:时长 2.4–4s(呼吸节律)、幅度峰值 alpha ≤ .6、reduce 时用中间帧静态值——等价于 MDN 官方「替换为不引发前庭反应的替代状态」的示范思路(原文核验),而不是黑掉;
  • 默认色 #6EE7B7 = 配方 rgb(110 231 183);媒体查询 Baseline since January 2020(MDN prefers-reduced-motion 页核验【S】)。

动效与交互

本条目的「动效」就是动效本体,规则即全部:

  • 节律:2.4–4s 是呼吸感区间;状态灯可到 2s,氛围光斑可放慢到 6s——周期越长刺激越低;
  • 幅度:峰值 alpha ≤ .6;更强的光用色相/面积表达,不加大闪烁;
  • reduce 收敛为静态:取中间帧(alpha 中点 + blur/spread 中点),保留「光存在」而不是让状态点变暗——「替换而非删除」是 MDN 官方示范的思路(§8.2 核验);
  • 动画失败即静态:不支持动画的环境停在第一帧,本身就是合法终态(§8.4);
  • 呼吸点旁必须有文字/图形冗余状态指示,不得只靠光(WCAG 1.4.1)。

真实产品案例

  • 系统在线状态点、录音/直播状态指示:呼吸/脉冲光斑的通用模式(调研 17 §8.6;逐站点核验未做,如实标注);
  • iOS 26 系统控件按压的弹性光响应是「光响应交互」的官方近亲(Glass.interactive(),核验)——但那是输入驱动,与呼吸的自主动画不同源,仅作谱系参照;
  • 逐站点代表例未核验,不列具体站点。

参数敏感度

参数调大会…调小会…
period>5s 进入「氛围光斑」域,刺激最低但状态感知变钝;<2s 接近闪烁,前庭风险上升节律更快,状态感更「急」;1.2s 端已不属呼吸,属警示脉冲
amplitude呼吸更明显;超过 .6 违反配方约定,光敏不适风险上升呼吸渐弱;0 = 静态光晕(合法终态,reduce 分支的极限形态)
glowColor偏离语义色(绿=在线/蓝=信息/橙=提醒)后状态语义混乱;高饱和色在深底上刺眼收敛回薄荷绿一族;语义色优先于品牌色

经验区间:period 2.4–4s(状态灯 2s / 氛围 4–6s)、amplitude 35–55%、色锁语义色。与 inner-glow-panel 条目互参:内光若要动,共用「只动 alpha/blur」铁律与同一 reduce 策略;与 soft-glow-glass 条目互参:静态光感的另一形态;与 prefers-reduced-motion 的官方语义(MDN)一脉相承。

适用场景 3
  • 在线状态点、录音/直播状态指示:光斑往复=「活着」(通用模式;调研 17 §8.6,逐站点核验未做如实标注)
  • 通知点/未读徽章的低刺激注意引导:比抖动/弹跳安静一个量级
  • 深色场景的品牌氛围光斑:慢周期(4–6s)+ 低幅度
何时不要用 3
  • 用 scale/translate 实现「呼吸」——MDN 点名的前庭触发源,直接违反本材质铁律(调研 17 §8.2)
  • 幅度超 .6 的强闪烁:光敏不适风险,且已不是「呼吸」而是「闪烁」
  • 正文阅读区的常驻呼吸:任何常驻动画都在偷走阅读注意力
无障碍

呼吸是状态暗示,不得作为传达关键信息的唯一手段(WCAG 1.4.1);`prefers-reduced-motion: reduce` 时收敛为**中间帧静态光晕**(alpha 取 .22 与峰值的中点,blur/spread 同取中点)——等价于 MDN 官方「替换为不引发前庭反应的替代状态」的示范思路,而非黑掉(调研 17 §8.3【S】);峰值 alpha ≤ .6;只动 box-shadow 的 alpha/blur。

浏览器支持

prefers-reduced-motion 媒体查询 Baseline since January 2020(MDN 核验【S】,调研 17 §8.4);@keyframes/box-shadow 动画为基线能力;动画不支持时自然停在第一帧(静态光)。

兼容回退

媒体查询/动画不支持时,元素停在第一帧的静态光晕——本身就是合法终态,无需额外回退(调研 17 §8.4);reduce 分支用中间帧静态值,而不是黑掉。

来源 1

起源无障碍锚点为 MDN prefers-reduced-motion(全文核验【S】):`no-preference`/`reduce` 两值;原文指出缩放/平移大对象是「vestibular motion triggers」(前庭触发源),官方示范用不引发前庭反应的替代动画(如 cross-fade)替换而非简单删除;媒体查询 Baseline since January 2020(调研 17 §8.2)。对应 WCAG 2.x「Animation from Interactions」(2.3.3)——调研未核验原文页,引用以 MDN 为准并如实标注。配方(2.4–4s 节律、峰值 alpha ≤ .6、reduce 取中间帧静态值)为本站工程综合 [R](调研 17 §8.3)。
