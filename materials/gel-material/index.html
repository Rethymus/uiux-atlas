果冻凝胶材质 Gel Material

果冻凝胶材质 · 果冻材质 · Jelly Material · Gel / Jelly

半透明糖果色 + 高光内衬(顶部 inset 白光)+ 底部糖色加浓(体积感)+ 弹性形变暗示(按压 squash & overshoot 回弹)。材质有体积、会形变——这是它与「发光」的柔光玻璃的分野。

社区流派 ★★★
实例演示 官方默认
参数
色彩▾
candy#FF7AA9

糖果色。默认 #FF7AA9 = 调研 17 §4.3 配方 RGB 三元组 255 122 169;薄荷 #75F0C7 / 柠黄 #F4E272 为本站按 §10 色板描述(珊瑚粉/薄荷/柠黄,饱和度 80–90%、亮度 60–75%)派生的演示值。高光内衬与底部加浓都从这一色派生。

几何▾
squish1

果冻度:按压形变缩放轴。active 态 scale(calc(1−0.06×s), calc(1−0.12×s)),s=1 时即配方的 1:0.9 压缩比档(.94/.88,调研 17 §4.3);配方同时警告过度压扁(如 .8 档)会从果冻滑向塑料。

highlight18%
%

高光位:顶部 radial 高光中心的纵坐标(配方 120% 90% at 30% 18%,调研 17 §4.3)。果冻三件套之一——顶部 inset 白高光(内衬)是「有体积」的第一暗示;下移会让高光像从侧面打光,体积感错乱。

动效▾
bouncecubic-bezier(0.34, 1.56, 0.64, 1)

回弹贝塞尔(overshoot)。默认 cubic-bezier(.34, 1.56, .64, 1) 取调研 17 §4.3 配方——y2>1(1.56)是 overshoot 的来源,与社区量化锚点 rdev 的 elasticity 0.15 同族(README 核验)。时长固定 0.18s(配方值)。

结构与 DOM

果冻凝胶与柔光玻璃(soft-glow-glass)的分野:gel 是「材质有体积、会形变」,soft-glow 是「材质发光」(调研 17 §4.1)。它由四层观感合成:半透明糖果色 + 高光内衬(顶部 inset 白光)+ 底部加浓(体积感)+ 弹性形变暗示(按压 squash & overshoot 回弹)。

<button class="gel">按我一下</button>   <!-- 单元素即可:全部观感长在自身与伪层 -->

关键点:

  • 单元素材质:不需要额外 DOM——高光内衬与底部加浓都是 box-shadow 的 inset 层,高光是 background 上的 radial 层;
  • 2025–26 的兴起与 Liquid Glass 的弹性交互直接相关:WWDC25 219 官方描述其「flexes and energizes on touch」(核验);SwiftUI .interactive() 是官方 API 对应物(与 liquid-glass 条目互参);
  • 形变只落在 transform,且只在按压瞬时发生——果冻的「弹」是反馈,不是常驻动画。

样式与参数

四个参数对应配方(调研 17 §4.3,[R] 本站工程配方;「gel」独立命名未核验到权威综述,如实标注):

.gel {
  background:
    radial-gradient(120% 90% at 30% var(--gm-hy), rgb(255 255 255 / .85), transparent 42%),
    color-mix(in srgb, var(--gm-candy) 55%, transparent);
  -webkit-backdrop-filter: blur(6px) saturate(1.5);
  backdrop-filter: blur(6px) saturate(1.5);
  border-radius: 999px;
  box-shadow:
    inset 0 2px 6px rgb(255 255 255 / .80),                /* 高光内衬:顶部 */
    inset 0 -10px 18px color-mix(in srgb, var(--gm-candy) 55%, transparent), /* 底部糖色加浓=体积 */
    inset 0 0 0 1px rgb(255 255 255 / .25),                /* 表面张力皮层 */
    0 10px 24px color-mix(in srgb, var(--gm-candy) 38%, transparent);      /* 糖色环境光 */
  transition: transform .18s var(--gm-bounce);             /* overshoot 回弹 */
}
.gel:active { transform: scale(calc(1 - .06 * var(--gm-squish)), calc(1 - .12 * var(--gm-squish))) translateY(1px); }
@media (prefers-reduced-motion: reduce) { .gel:active { transform: none; } }

数值出处:

  • 压缩比 1:0.9 档(squish=1 → scale(.94/.88))、回弹贝塞尔 y2=1.56、时长 .18s、高光位 at 30% 18%、糖果色 RGB 三元组 255 122 169(#FF7AA9):全部为调研 17 §4.3 配方记载值;配方同时警告过度压扁(如 .8 档)会从果冻滑向塑料;
  • 社区量化锚点:rdev/liquid-glass-react 的 elasticity: 0.15(README 核验【S】)——与 bounce 参数一一对应;
  • MDN box-shadow 的 inset 语义(“as if the content is pressed into the box”)是「内衬」观感的语法基础(box-shadow 页核验);
  • 糖果色板(珊瑚粉/薄荷/柠黄,饱和度 80–90%、亮度 60–75%):调研 17 §10 描述,demo 的薄荷/柠黄 preset 为按描述派生的演示值。

动效与交互

果冻三件套的动效规则(调研 17 §4.3):

  • 按压 squash:X/Y 按 1:0.9 档压缩 + 1px 下沉,0.18s——形变发生在按住期间,松手由过渡曲线自然回弹;
  • overshoot 回弹:贝塞尔 y2>1(1.56)产生过冲,是「软弹」手感的来源;三件套缺一不可——少了任意一件都只是半透明按钮(调研 17 §11.9);
  • prefers-reduced-motion: reduce 时禁用形变(配方原样保留该规则):按压反馈退回颜色/描边变化;
  • 镜面高光不随交互移动:高光位是材质常数,移动它等于宣告光源变了。

真实产品案例

  • iOS 26 系统控件按压的弹性光响应:Glass.interactive() 的官方能力——「applies the same responsive and fluid reactions」(Applying Liquid Glass 文章核验,调研 17 §4.2/§4.6);
  • rdev/liquid-glass-react 的 elastic hover:社区组件以 elasticity 0.15 实现弹性交互(GitHub README 核验,6798★);
  • Framer 模板中的果冻按钮:未核验(调研 17 §4.6 如实标注),不列。

参数敏感度

参数调大会…调小会…
candy偏离糖果色域(饱和度 80–90%、亮度 60–75%)后像橡胶/树脂;深色糖底会吃掉高光内衬收敛回珊瑚粉/薄荷/柠黄一族;糖感最足的恰是配方原值 #FF7AA9
squish>1.2 过度压扁,「果冻滑向塑料」(配方警告);1.5 时已无弹性可言形变收敛;0 = 无按压反馈,三件套缺了「会形变」这一件
highlight高光下移像侧光,体积感错乱;>35% 内衬变成「腰带」高光贴顶,内衬变薄;0 = 无内衬,体积感少一件
bouncey2 再加大(如 >1.8)过冲成 Q 弹玩具,高频操作会晕y2≤1 无过冲,回弹变普通 ease;0 过冲时「弹」的手感消失

经验区间:squish 0.8–1、bounce y2 1.4–1.6、highlight 15–22%、candy 锁定糖果色域。与 soft-glow-glass 条目互参:「发光」与「有体积」是两条材质轴;与 claymorphism 条目互参:同为体积暗示,clay 靠三段阴影「充气」,gel 靠内衬+加浓「含糖」;与 clear-frost 条目互参:糖果场景玻璃用超薄档(调研 17 §10)。

适用场景 3
  • 高频主操作按钮与开关:按压 squash 给「按下去真的软」的反馈(iOS 26 系统控件按压弹性光响应的官方能力对应,调研 17 §4.6)
  • 儿童/游戏/轻趣味产品的卡片与徽章:糖果色 + 体积感传达亲和
  • 与超薄玻璃(玻璃参数用 clear-frost 档)组合:糖果色已供色,雾度要低(调研 17 §10)
何时不要用 3
  • 正文与数据界面:果冻的形变暗示会让信息承载元素显得不可靠
  • 过度压扁(squish 拉满到 1.5):从果冻滑向塑料(调研 17 §4.3 配方警告)
  • 全站铺开:果冻是强调材质,大面积使用后糖感疲劳、层级感消失
无障碍

果冻三件套是装饰性暗示,不得替代状态传达(按压态仍需 aria/焦点样式);文字与糖果底的对比按最亮高光处核对 4.5:1(WCAG 2.1 SC 1.4.3);按压形变是输入驱动的瞬时反馈,`prefers-reduced-motion: reduce` 时禁用 transform 形变(配方原样保留该规则,调研 17 §4.3)。

浏览器支持

cubic-bezier 过冲、inset box-shadow、radial-gradient:全基线;backdrop-filter Baseline 2024-09(MDN;调研 17 §4.4)。gel 不强依赖 backdrop-filter——去掉只损失透底,材质三件套仍在。

兼容回退

不支持 backdrop-filter 时整段去掉即可(调研 17 §4.4):高光内衬 + 底部加浓 + 回弹三件套全基线,只损失透底能力;老浏览器里回弹贝塞尔静止回终态,不破坏功能。

来源 4

起源2025–26 的兴起与 Liquid Glass 的弹性交互直接相关:WWDC25 session 219 官方描述 Liquid Glass 「flexes and energizes on touch」(调研 17 §4.2 核验【S】);SwiftUI Glass.interactive() 提供同一弹性光响应;社区量化锚点是 rdev/liquid-glass-react 的 elasticity 默认 0.15(README 核验【S】)。如实标注:「gel/jelly material」作为独立材质名未核验到权威综述文,CSS 配方为基于以上构件的工程综合 [R](调研 17 §4.2/§4.3)。
