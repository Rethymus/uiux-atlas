Fluent 亚克力 Fluent Acrylic

亚克力 · Acrylic · Fluent 亚克力

Microsoft Fluent 的半透明材质画刷:背景模糊 + 亮度混合 + 色调层 + 噪点,分 background(透出桌面)与 in-app(应用内)两型;Web 复刻用 tintOpacity / tintLuminosityOpacity 近似。

Fluent ★★★
实例演示 官方默认
参数
几何▾
tintOpacity0.6

色调层不透明度(官方参数名 AcrylicBrush.TintOpacity,调研 02 §3 C1)。官方未公布默认数值——默认 0.6 为社区常见值(未证实):调大色调更实、背景更不可见;调小更透,深色背景上文字对比度更难守住。

tintLuminosityOpacity0.35

亮度色调不透明度(官方参数名 TintLuminosityOpacity,与背景做亮度混合,调研 02 §3 C1)。官方未公布默认数值——默认 0.35 为社区常见值(未证实):调大整体越亮越『雾』,亮背景上更稳;0 关闭亮度补偿,深底上亚克力发闷。

动效▾
fallbackoff

对应官方 AlwaysUseFallback 强制回退开关(调研 02 §3 C1):on 时跳过模糊/亮度/噪点层,改用纯色表面。真实环境还会在无 backdrop-filter 支持或省电模式下自动触发回退;demo 手动切换便于对照两种状态。

代码拆解

结构与 DOM

官方 Acrylic 是 XAML 材质画刷:WinUI 里经 AcrylicBrush 或 Window.SystemBackdrop / DesktopAcrylicBackdrop 挂到窗口(调研 02 §3 C1)。分两型:background acrylic 透出桌面壁纸与其他窗口(用于 transient UI),in-app acrylic 只在应用内做层次。Web 复刻按『模糊背景 → 亮度层 → 色调层 → 噪点层 → 内容』叠层:

<div class="scene">
  <img class="wallpaper" src="photo.jpg" alt="" />
  <section class="acrylic">   <!-- in-app acrylic 面板 -->
    <div class="lum"></div>   <!-- 亮度层:TintLuminosityOpacity -->
    <div class="noise"></div> <!-- 噪点层:feTurbulence -->
    <div class="content">…</div>
  </section>
</div>

关键点:两型的差别在采样源(桌面 vs 应用内),Web 无法透出桌面,只能以照片模拟 wallpaper 场景;AlwaysUseFallback 是官方的强制回退开关(C1)。

样式与参数

三个参数经 --fa-* 变量注入;TintColor 等固定层色为社区近似(WinUI 浅色主题底 ≈ #F3F3F3):

.acrylic {
  position: relative;
  /* 模糊半径未公布;blur 24px + saturate 125% 为 Web 社区常见近似 */
  -webkit-backdrop-filter: blur(24px) saturate(1.25);
  backdrop-filter: blur(24px) saturate(1.25);
  background: rgb(243 243 243 / var(--fa-tint-opacity)); /* TintColor × TintOpacity */
}
.acrylic .lum { position: absolute; inset: 0; background: #fff; opacity: var(--fa-lum-opacity); }
.acrylic .noise {
  position: absolute; inset: 0; opacity: 0.04;
  background-image: url("data:image/svg+xml,…feTurbulence baseFrequency='0.9' numOctaves='2'…");
}
/* 回退:官方 AlwaysUseFallback 开关 + 无 backdrop-filter 支持时自动触发 */
.acrylic[data-fallback="on"] { background: #f3f3f3; }
@supports not (backdrop-filter: blur(1px)) {
  .acrylic { background: #f3f3f3; }
}

数值出处:

  • tintOpacity / tintLuminosityOpacity / AlwaysUseFallback / TintTransitionDuration:官方参数名(调研 02 §3 C1);官方未公布默认数值——demo 默认 0.6 / 0.35 为社区常见值(未证实);
  • 两型(background / in-app):官方文档(C1);
  • 噪点配方 feTurbulence baseFrequency=0.9 numOctaves=2:调研 06 §四 §15 的轻量噪点层(消 banding);
  • 支持:backdrop-filter Chrome 76 / Firefox 103 / Safari 9(BCD,调研 02 §4 D2)。

动效与交互

  • 调参即时可见:两个 opacity 变量直接改写色调/亮度层,拖动滑杆立刻看到『材质变实/变透』;
  • fallback 切换:材质层 0.25s 淡出、纯色淡入——对应官方 TintTransitionDuration(色调切换动画时长,C1)的存在,数值未公布,demo 取 0.25s;
  • prefers-reduced-motion 时取消过渡,直接切换;
  • demo 背景静态:亚克力的层次感用静态对比最容易核对;大面积逐帧动画背景会让 backdrop-filter 采样开销失控。

参数敏感度

参数调大会…调小会…
tintOpacity色调层更实:背景更不可见、文字对比度更稳;1.0 退化为实色卡片更透更显材质;深色背景上浅色文字会顶穿 4.5:1,0 等于只剩模糊+噪点
tintLuminosityOpacity整体越亮越『雾』:亮背景(白天壁纸)上更协调,暗色主题里会发灰亮度补偿消失:深底上亚克力发闷,浅色色调层与暗背景的过渡变硬;0 完全关闭
fallbackon:纯色表面,可读性最高、性能最好,代价是失去材质感off:完整亚克力栈;不支持 backdrop-filter 或省电模式下系统仍会强制回退

经验区间:tintOpacity 0.5–0.8(支撑层)、0.3–0.5(强调透出的浮层);tintLuminosityOpacity 0.2–0.5。所有数值除参数名外均未获官方证实,生产复刻以 WinUI 真机渲染为准。

适用场景 3
  • in-app acrylic:应用内侧栏、命令栏、浮出面板等支撑层(官方适用)
  • background acrylic:transient UI——菜单、弹出层短暂透出桌面(官方适用)
  • 需要『表面有材质感但不抢内容』的卡片与容器
何时不要用 3
  • 正文阅读区与密集数据——色调+噪点层会稀释对比度
  • 高流动性内容上大面积使用——每帧重采样代价高
  • 把 Web 复刻的 tintOpacity 数值当官方默认——调研仅记载参数名,数值未证实
无障碍

亚克力上的文字按『透出背景最亮/最暗』两端核对 4.5:1(WCAG 2.1 SC 1.4.3,调研 06 §五 §17);噪点层对比度极低、仅质感用途,不得承担信息(调研 06 §四 §15 把噪点定位为消 banding 的质感层);fallback 纯色态必须同样可读。

浏览器支持

真身仅 Windows(XAML/WinUI 的 AcrylicBrush 与 DesktopAcrylicBackdrop,调研 02 §3 C1)。Web 复刻:backdrop-filter 支持 Chrome 76 / Firefox 103 / Safari 9(-webkit- 前缀,调研 02 §4 D2);噪点层用 SVG feTurbulence(调研 06 §四 §15 配方),全浏览器可用。

兼容回退

AlwaysUseFallback(或无 backdrop-filter 支持/省电模式)时改纯色表面——本 demo 以 fallback=on 演示,并用 @supports 在不支持 backdrop-filter 的浏览器自动落回纯色;TintTransitionDuration(官方参数)可用 0.25s 过渡近似切换过程。
