评分 Rate

星级评分 · Star Rating · Rating

用一排星星对事物打分:悬停预览、点击落值,支持半星与再次点击清空;键盘按 radiogroup 漫游选择。

几何▾

JS 型参数(demo 订阅后增减星星数)。对应 antd Rate 的 count,**官方默认 5**(补研 12§15)——五星制是评分组件的默认心智。

代码拆解

结构与 DOM

评分的视觉是一排叠层星形,语义骨架是 radiogroup:容器 role="radiogroup",每颗星(半星档下每半区)是 role="radio"——APG 官方 Rating Radio Group Example 的实现方式(补研 12§15):

<div class="rate-group" role="radiogroup" aria-label="评分">
  <span class="rate-star">
    <span class="rate-glyph" aria-hidden="true">★</span>   <!-- 灰色底星 -->
    <span class="rate-fill" aria-hidden="true">★</span>    <!-- 金色填充,宽度裁切 -->
    <span class="rate-zone" role="radio" aria-checked="true"
          aria-label="4 星:推荐" tabindex="0"></span>      <!-- 透明命中区 -->
  </span>
  <p class="rate-out" aria-live="polite">当前:4 星 · 推荐</p>
</div>

关键点:

  • 星形字符分两层:灰底星(描边档)+ 金色填充星(用 overflow: hidden 宽度裁切表达半星);两者都 aria-hidden,数值与含义由 radio 的 aria-label 与下方文字回显承载;
  • 命中区(透明的 role="radio" 元素)叠在星形之上:整星档每星一个,半星档拆左右两个(aria-label 写「3.5 星」)——roving tabindex 让整组只有一个 Tab 停靠点;
  • 悬停预览只改视觉,不改 aria-checked;只有点击/Space 选中才改变 checked——focus ≠ selection(调研 07§35);
  • 当前值用 aria-live="polite" 文字回显,星级含义永远有文案(tooltips 语义,补研 12§15)。

样式与参数

三个 JS 型参数(count / allowHalf / allowClear)+ 一个 CSS 变量型参数(activeColor):

.rate-star  { width: 24px; height: 24px; transition: scale .15s ease-out; }
.rate-star:hover { scale: 1.12; }
.rate-glyph { color: #d9d9d9; }                          /* colorBorder 描边档 */
.rate-fill  { color: var(--rate-active, #faad14); }      /* gold #FAAD14 */
.rate-fill > span { display: block; }                    /* 半星:width 50% */
.rate-zone[data-half="left"]  { right: 50%; }
.rate-zone[data-half="right"] { left: 50%; }
.rate-zone:focus-visible { outline: 2px solid #1677ff; outline-offset: 2px; }

数值出处:

  • count 默认 5、allowClear 默认 true 均为 antd Rate 官方记载(补研 12§15);allowHalf 默认值调研未记载,demo 默认 off 为社区常见值,未证实;
  • 激活色 --rate-active 默认 #faad14 = antd gold 主色/seed 金 #FAAD14(设计调研 06§1.2/§2.2)——antd Rate 官方默认色 token 调研未证实,取 gold 档为社区常见值;空星描边 #d9d9d9 = colorBorder(06§2.2);
  • 焦点环 #1677ff = colorPrimary(06§2.2);星间 gap 4px = antd sizeXXS 档(06§2.3④,借档);
  • 星形 24px 为 demo 教学尺寸(社区常见 20–24px,未证实;antd 未记载 Rate 几何数值);
  • tooltips 文案(tooltips[] 语义,补研 12§15)在 demo 中为「很差/较差/还行/推荐/超赞」五个档位标签,内容为 demo 自拟。

动效与交互

  • 悬停预览:mousemove 进入半区即以 --rate-active 预览到该档,离开组即回落当前值;预览不改变 aria-checked,下方文字显示「预览 Preview」与「当前 Current」双态;触屏无 hover,点击直接落值;
  • 点击落值 / 清空:allowClear=on(官方默认)时再次点击当前值清空回 0——「再点一次撤销」是评分区别于普通单选组的关键交互(补研 12§15);off 时重复点击维持原值;
  • 键盘 radiogroup:方向键在星组内漫游(roving tabindex)、Space/Enter 选中(APG Rating Radio Group Example,补研 12§15;radio 方向键组内移动,调研 07§36);Tab 一次进出整组;
  • hover 缩放:悬停星 1.12 倍放大 0.15s,只动 scale(合成器属性);命中 prefers-reduced-motion 时缩放取消(调研 07§37);
  • 评分是低频确认型输入,不做连续动画;落值后的状态变化由文字回显即时传达。

真实产品案例

  • 电商/外卖评价:淘宝、美团订单完成后默认五星制,星级旁配文字标签(差评→好评),半星档常见于骑手/商家服务分——「星级 + 文案」是降低理解成本的标准组合;
  • 应用商店评分:App Store / Google Play 的应用页五星评分 + 汇总均值,用户点击即提交,无需表单——评分是「一击即达」的输入控件;
  • 内容平台的影游评分:豆瓣电影/游戏平台的用户打分聚合为均值,半星与整星档并存影响聚合精度(编辑性泛例:聚合型平台的常见档位取舍)。

参数敏感度

参数调大会…调小会…
count更多星档让表达更细,但选择时间上升(Hick 定律,调研 07§23),10 星是实用上限3 星以下语义过粗(好/中/差),丢失区分度
allowHalfon 给出 0.5 档,聚合均值更平滑,命中区减半off 每星命中区翻倍,移动端更易点中
allowClearon 提供「点错撤销」出口,误触成本低off 用户点错只能整组重置,挫败感更强
activeColor高饱和金/橙是评分的默认心智,偏离太远(如蓝)会削弱「星级」联想低饱和激活色与空星描边区分度下降,扫读变慢

经验区间:五星制 + 文案标签是默认配置;每颗星命中区不小于 24px(Fitts 定律,调研 07§22);当前值必须文字回显;半星只在「用户评分会被聚合」的场景启用。

适用场景 4
  • 订单完成后的服务/商品评价:五星制 + 文案标签(很差→超赞)降低理解成本
  • 内容消费前的质量预期:应用商店、点评平台的商家/影游评分
  • 轻量 NPS 式打分:一屏一问,星星即答案
  • 需要精细刻度的评价:半星档区分「还行」与「还不错」
何时不要用 4
  • >10 星的刻度——决策时间随选项上升(Hick 定律,调研 07§23),五星或十分制足够
  • 没有文字标签的裸星星——星级含义(1 星是差还是最低?)因文化而异,须配文案
  • 离散二选一(推荐/不推荐)——thumbs up/down 或 radio 更直接
  • 把评分当进度条用——进度语义请用 Progress,不要混用星形隐喻
无障碍

视觉是星星,语义是单选组:容器 role="radiogroup"(aria-label「评分」),每颗星(半星档每半区)是 role="radio"[aria-checked],方向键在组内漫游(roving tabindex)、Space/Enter 选中——APG 官方 Rating Radio Group Example 的实现方式(补研 12§15;radio 方向键组内移动,调研 07§36);每枚 radio 的 aria-label 带数值与文案(「4 星:推荐」),半星标注「3.5 星」;焦点环不可移除(WebAIM,调研 07§36);悬停预览不改变 aria-checked,只有选中才改变——focus ≠ selection(调研 07§35);状态含义不单独依赖颜色,星级数值同时以文字回显。

浏览器支持

评分是纯 DOM/CSS/JS 自绘:视觉上是叠层文字星形,交互骨架是 role="radiogroup"+role="radio"[aria-checked](APG 官方 Rating Radio Group Example,补研 12§15),方向键漫游与 Space 选中需脚本实现;半星的左右分区命中判定用 mousemove 几何计算,触屏无 hover,点击直接落值。

兼容回退

无 JS 环境退化为原生 radio 组(一星一 radio,含半星则每星两个)或一个 number input(min 0 max count step 0.5);无 hover 的触屏环境悬停预览自动失效,点击直接落值,功能不受损。

来源 2

起源评分组件定位是「对某物评分」(补研 12§15);APG 没有独立的 rating 模式,官方提供 Rating Radio Group Example——五角星用 role="radiogroup" + role="radio"[aria-checked] 实现方向键漫游(roving tabindex)、Space 选中(补研 12§15)。生产参照系是 Ant Design Rate(补研 12§15 记载 API:count 默认 5、allowHalf、allowClear 默认 true、tooltips[]、character(可换字/图标/汉字)、disabled、value/defaultValue、onChange、onHoverChange,2026-11-22 抓取 ant.design 现行文档)。

  1. 条目 文字提示

    搭配:星级档位含义可走 tooltip 承载,但底线写明:任何「不看提示就做不对」的信息都不该只住在 tooltip 里——评分的文字回显是硬要求。

    搭配:星形就是图标字形:灰底星描边档、金填充星着色档——SF Symbols 的「颜色由 tint 驱动」与评分的激活色是同一套机制。

  3. 条目 开关

    反向自「开关」的精选:对比关系,原句「「一击即改」输入的二选一:开关只有二态、即改即生效;评分带档位与撤销(「再点一次撤销」)——值域不同,反馈语义也不同。」
