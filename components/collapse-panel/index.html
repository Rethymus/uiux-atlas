折叠面板 Collapse

手风琴 · Accordion · Disclosure

把成组内容收纳进「标题行 + 可展开内容区」:点标题切换显隐,多开是常规、同一时刻只开一块的手风琴是特例。

组件库 ★★
实例演示 官方默认
参数
动效▾
accordionoff

JS 型参数(demo 订阅后控制开一块是否收起其他)。对应 antd Collapse 的 accordion(补研 12§15):多开是常规、单开是特例——demo 默认 off 即多开;ant-collapse 的官方默认值调研未记载,off 为社区常见值,未证实。

expandIconPlacementstart

JS 型参数(demo 订阅后把展开箭头放到标题行首/行尾)。对应 antd Collapse 的 expandIconPlacement: start|end(补研 12§15);官方默认值调研未记载,demo 默认 start 为社区常见值,未证实。

collapsibleheader

JS 型参数(demo 订阅后切换指针点击目标)。对应 antd Collapse 的 collapsible: header|icon|disabled(补研 12§15)——header 整行可点,icon 仅箭头区可点(disabled 整块不可交互);官方默认值调研未记载,demo 默认 header 为社区常见值,未证实。键盘路径不受 collapsible 影响:标题按钮的 Enter/Space 永远可切换。

代码拆解

结构与 DOM

折叠面板是「标题行 + 可展开内容区」的成组结构,APG 骨架逐字落地:真实 heading > 原生 button,面板与标题按钮双向指认:

<ul class="cp-group">
  <li class="cp-item is-open">
    <h3 class="cp-head">
      <button type="button" id="cp-btn-invoice"
              aria-expanded="true" aria-controls="cp-region-invoice">
        <span class="cp-arrow" aria-hidden="true">▶</span> 发票开具
      </button>
    </h3>
    <div id="cp-region-invoice" class="cp-body-wrap"
         role="region" aria-labelledby="cp-btn-invoice">
      <div class="cp-body-inner">
        <p class="cp-body">电子普通发票 · 抬头…</p>
      </div>
    </div>
  </li>
</ul>

关键点:

  • 标题必须是 button(原生可 Tab、可 Enter/Space 激活),aria-expanded 实时同步开合、aria-controls 指向面板 id——APG 标准骨架(补研 12§15);
  • 面板外层挂 role="region" + aria-labelledby 指回标题按钮,让读屏可从面板内跳回标题;同开面板可能超过 6 个时省略 region,避免 landmark 泛滥(补研 12§15);
  • 内容区做两层:外层控制高度(grid-template-rows),内层 overflow: hidden 裁切——高度动画不让内容先溢出;
  • 多块面板是 ul/li 兄弟关系,is-open 类驱动样式与动画。

样式与参数

三个参数都是 JS 型(经 store 订阅改 data-*),CSS 按 data-placement / data-collapsible 分支:

.cp-item + .cp-item { border-top: 1px solid #f0f0f0; }      /* colorBorderSecondary */
.cp-btn { display: flex; gap: 8px; padding: 12px 16px;
          color: rgba(0, 0, 0, 0.88); font-weight: 500; }
.cp-stage[data-placement="end"] .cp-btn { flex-direction: row-reverse; }
.cp-arrow { transition: rotate 0.2s cubic-bezier(0.645, 0.045, 0.355, 1); }
.cp-btn[aria-expanded="true"] .cp-arrow { rotate: 90deg; }
.cp-body-wrap {
  display: grid;
  grid-template-rows: 0fr;                                   /* 收起:0 高 */
  transition: grid-template-rows 0.2s cubic-bezier(0.645, 0.045, 0.355, 1);
}
.cp-item.is-open .cp-body-wrap { grid-template-rows: 1fr; }  /* 展开:内容自然高 */
.cp-stage[data-collapsible="disabled"] .cp-btn { color: rgba(0, 0, 0, 0.25); cursor: not-allowed; }

数值出处:

  • 过渡 0.2s + cubic-bezier(0.645,0.045,0.355,1) = antd motionDurationMid + motionEaseInOut(设计调研 06§3.1/3.2;动效族含 collapse 族,06§3.3);箭头旋转同 token;
  • 文字色 rgba(0,0,0,0.88)/0.65/0.25 = antd TextPrimary/Secondary/Quaternary 透明度体系(06§2.3⑤);分隔线 #f0f0f0 = colorBorderSecondary(06§2.3⑤);
  • 标题 14px/fontWeight 500 = antd fontSize + medium 字重(06§1.3);
  • 标题 padding 12px 16px、内容底 padding 12px 为社区常见值,未证实(调研未记载 Collapse 几何数值),demo 按常见比例绘制;
  • accordion / expandIconPlacement(start|end) / collapsible(header|icon|disabled) 的取值均来自 antd Collapse 现行文档(补研 12§15);三者官方默认值调研未记载,demo 默认 off/start/header 为社区常见值,未证实。

动效与交互

  • 展开/收起:grid-template-rows 0fr→1fr 过渡 0.2s——高度随内容自然高,不用 JS 量高;箭头同步旋转 90°;命中 prefers-reduced-motion 时两组过渡全部取消,直接显隐(调研 07§37);
  • accordion=on(手风琴):打开一块即收起其余——「同一时刻只开一个」是折叠面板的特例而非默认(补研 12§15);切换时其余面板跟随收起,aria-expanded 逐块同步;
  • collapsible 三档:header 整行可点;icon 仅箭头区响应点击(icon 档下键盘 Enter/Space 仍可切换——指针限制不剥夺键盘路径);disabled 整块不可交互,aria-disabled 表达且内容仍静态可读;
  • 键盘路径:Tab 在标题按钮间移动,Enter/Space 切换(补研 12§15;WebAIM 按钮键位,调研 07§36);APG 手风琴的方向键/Home/End 为可选增强,本 demo 仅实现已记载的 Enter/Space;
  • 展开动作不改变焦点位置——焦点留在被点击的标题按钮上,收起后内容移出视野但按钮仍在原位。

真实产品案例

  • GitHub README 的 <details> 折叠块:构建日志、CI 输出、长报告收进原生折叠块,展开才看全文——原生 details/summary 是折叠面板的零 JS 兜底实现;
  • 官网 FAQ/帮助中心:常见问题一问一面板,多数配手风琴单开,保证视口里同时只有一个答案,扫读问题列表不被答案干扰;
  • 电商结算页的可选区块:京东/淘宝结账页把「发票开具」「优惠码」「配送备注」做成默认收起的折叠区——主流程(收货、支付)不被可选表单挤压(编辑性泛例)。

参数敏感度

参数调大会…调小会…
accordionon 单开让视口永远只呈现一块内容,适合问答/逐项讲解off 多开方便对比几块内容,但页面纵向长度不可控
expandIconPlacementend(箭头在右)是「行尾操作」的心智,整行更像列表项start(箭头在左)是「树形/目录」的心智,层级感更强
collapsibleicon 档把误触降到最低,但指针用户要多瞄准小箭头header 整行命中区最大(Fitts 定律,调研 07§22);disabled 只用于内容暂不可用的真禁用

经验区间:单组 3–6 块;标题一行、内容尽量一屏内;默认展开哪一块跟随任务(主流程相关的展开、可选的收起);禁用面板给出原因文字,不要只灰掉。

适用场景 4
  • 表单可选区块:发票开具、优惠码、高级选项——默认收起不干扰主流程
  • FAQ/帮助中心问答列表:一问一面板,常配手风琴单开
  • 长页面的设置分组:通知偏好、隐私、账户安全逐组收纳
  • 移动端概览页:摘要在上、详情折叠,节省纵向空间
何时不要用 4
  • 用户必须看到的内容别折叠——必读信息藏进展开区等于没写
  • 面板内超过一屏的长内容:滚动套滚动体验差,应拆分或改抽屉/独立页
  • 深层嵌套折叠(折叠里再折叠)——层级成本超过收纳收益
  • 同开面板可能超过 6 个时省略 role=region 地标,避免 landmark 泛滥(APG 建议,补研 12§15)
无障碍

APG 骨架逐字落地:标题用真实 heading(h3 带 aria-level 语义)> 原生 button[aria-expanded][aria-controls],面板可加 role="region" + aria-labelledby 指回标题按钮(可同开面板 >6 个时省略 region,补研 12§15);键盘 Enter/Space 切换(补研 12§15;WebAIM:按钮 Enter/Space,调研 07§36),Tab 在标题间移动;展开态必须实时同步 aria-expanded;焦点环不可移除;禁用面板用 aria-disabled 表达并保留内容可读。

浏览器支持

折叠面板是纯 DOM/CSS/JS 自绘:标题是原生 button(键盘无障碍),展开/收起高度动画用 CSS grid-template-rows 0fr/1fr 过渡(现代浏览器支持);读屏对 role=region 地标的播报取决于面板数量——同开面板超过 6 个时应省略 region 地标(APG 建议,补研 12§15)。

兼容回退

无 JS 环境用原生 <details>/<summary> 兜底(浏览器原生开合语义);无 CSS grid-template-rows 过渡能力时展开/收起直接显隐,功能不受损;disabled 面板务必保留静态内容可读——折叠只藏交互,不藏必读信息。

来源 2

起源折叠面板定位是「分组/隐藏复杂区域保持页面整洁;手风琴是同一时刻只开一个的特例」(补研 12§15);APG 为其提供标准骨架:heading[aria-level] > button[aria-expanded][aria-controls] + 面板(可选 role=region[aria-labelledby]),Enter/Space 切换(补研 12§15;APG 30 模式含 Accordion,调研 07§34)。生产参照系是 Ant Design Collapse(补研 12§15 记载 API:accordion、activeKey/defaultActiveKey、collapsible(header|icon|disabled)、expandIconPlacement(start|end)、ghost、destroyOnHidden 等,2026-11-22 抓取 ant.design 现行文档)。

下一步学什么

按依据排序:本条目精选 > 路径下一站 > 反向推导 > 路径与配方归属

  1. 条目 标签页

    对比:同管「内容可见性」二选一:标签页预载全部面板、切换只改显示;折叠面板默认全收、按需展开——平铺与收纳两种信息策略。

  2. 条目 下拉菜单

    对比:都把「更多」收进触发器,收的东西不同:折叠面板就地展开内容,下拉浮层展开的是动作命令——APG 对 menu button 的定义划出边界。

  3. 条目 抽屉

    反向自「抽屉」的精选:对比关系,原句「都做就地展开,重轻有别:折叠面板收放「标题行+内容区」的正文段落,抽屉承载留在主任务上下文的重子任务——同一根轴的两档。」
