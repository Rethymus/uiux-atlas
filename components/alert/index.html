警告提示 Alert

警告条 · 通知条 · 横幅提示 · Inline Alert

文档流内的四色警示块:不夺键盘焦点、默认不自动消失,经 role=alert 播报——与 toast(浮层自动消失)和 Dialog(阻断)三分反馈职责。

动效▾
typeinfo

语义四态(JS 型参数)。AntD Alert type 默认 **info**;banner 模式下默认翻转为 **warning**。配色遵循 antd seed 功能色:success #52c41a / info(primary)#1677ff / warning #faad14 / error #ff4d4f;浅底与描边按「Bg=阶1、Border=阶3」规则派生。

closableoff

是否提供手动关闭按钮(JS 型参数)。AntD Alert closable 默认 **false**。警告默认常驻(这正是它与 toast 的分界:APG 告诫警告不要自动消失,WCAG 2.2.3);开启关闭钮后由用户决定何时移除。

showIconoff

是否显示语义图标(JS 型参数)。AntD Alert showIcon 默认 **false**;banner 模式下默认翻转为 **true**。图标与颜色双通道编码(NN/g 错误准则⑤:图标+颜色照顾色盲),扫读时先认形状再读文字。

banneroff

是否渲染为页面顶部通栏(JS 型参数)。AntD Alert banner 默认 **false**;开启后去掉圆角与侧边框、横向铺满,且 type/showIcon 默认翻转为 warning/true——通栏常用于站点级公告(维护、存储告急)。

代码拆解

结构与 DOM

警告提示是文档流内的驻留警示块(与浮层 toast、阻断 Dialog 三分反馈职责):一个语义色块,可带图标、说明文字与关闭按钮。

<div class="alert" role="alert" data-type="warning">
  <svg class="icon" aria-hidden="true">…</svg>
  <div>
    <strong>标题</strong>
    <span>说明文字</span>
  </div>
  <button aria-label="关闭">×</button>
</div>

关键点:

  • 容器 role="alert":动态插入时多数屏幕阅读器自动播报,且不夺取键盘焦点——需要打断用户就升级为 alertdialog(APG Alert);
  • 图标是辅助通道:aria-hidden,靠 currentColor 与语义色同源;「仅靠颜色传达」违反 WCAG 1.4.1,颜色+图标双通道兜底;
  • 关闭按钮是真实 <button>(可聚焦、带 aria-label);警告默认不自动消失——APG 明确告诫:自动消失太快违反 WCAG 2.2.3。

样式与参数

四个参数均为 JS 型(demo 订阅 store 驱动):type 切 data-type 语义色、closable/showIcon 增删元素、banner 切换通栏布局。

.alert {
  display: flex; align-items: flex-start; gap: 10px;
  padding: 10px 14px; border-radius: 8px; border: 1px solid;
  background: color-mix(in srgb, var(--c) 10%, #fff);   /* 浅底 ≈ 色板阶1 */
  border-color: color-mix(in srgb, var(--c) 40%, #fff); /* 描边 ≈ 色板阶3 */
  color: rgba(0, 0, 0, 0.88);                            /* antd colorText */
}
.alert[data-type="success"] { --c: #52c41a; }
.alert[data-type="info"]    { --c: #1677ff; }
.alert[data-type="warning"] { --c: #faad14; }
.alert[data-type="error"]   { --c: #ff4d4f; }
.alert.is-banner { border-radius: 0; border-top: 0; border-left: 0; border-right: 0; }

数值出处(antd 6.7.1 核对):type 默认 info、showIcon/closable/banner 默认均 false;四色取 seed 功能色 colorSuccess #52c41a、colorWarning #faad14、colorError #ff4d4f、colorPrimary #1677ff(design-study 06 §2.2);「Bg=色板阶1 / Border=阶3 / 主=阶6」派生规则出自 genColorMapToken(06 §2.3⑤),demo 用 color-mix 近似阶1/阶3。banner 模式下 type 默认翻转为 warning、showIcon 默认翻转为 true(06 §4.13)。

动效与交互

  • 无入场动画是常态:警告的目标是「驻留到被读完」,toast 式的滑入滑出反而是噪音;demo 仅保留 0.15s 的轻淡入,reduced-motion 下取消;
  • 关闭交互:closable=on 时点真实按钮移除,焦点处理从简(移除的是非焦点承载元素);关闭后提供重新显示入口,避免演示不可恢复;
  • banner 模式:通栏贴顶、内容下移让位——站点级公告与页面内容分层;开关 banner 时注意 antd 的默认翻转(warning/true);
  • 不要轮播多条警告:APG 告诫频繁打断妨碍视觉/认知障碍用户(WCAG 2.2.4);多条信息合并为一条或调整页面结构。

真实产品案例

  • GitHub:仓库页顶部的通栏警告——归档仓库的「This repository has been archived」横幅、以及检测到敏感依赖时的安全告警条,均为全宽、可关闭、驻留顶部的 banner 形态;
  • Gmail:免费配额将满时,页面顶部出现通栏警告(存储空间不足,附「管理存储」入口)——不阻塞收发邮件但持续驻留,直到用户清理空间;
  • VS Code:右下角通知中心的提醒卡片带图标、说明与关闭按钮,驻留直到手动处理——编辑器内「不中断工作流的持续提醒」与流内警告同一套语义。

参数敏感度

参数调大会…调小会…
type无大小可言,换的是语义与情绪:success 收尾感、info 中性、warning 预警、error 紧急——用错语义比用错颜色更糟同上;同页多态警告时 error 数量应最少( Von Restorff:强调要有节制)
closableon:用户获得清除权,适合「读完即无用」的通知型内容off:驻留到底,适合持续有效的约束型信息(如归档状态);两者都不可自动消失
showIconon:形状先于文字被识别,扫读快、色盲可用,块高略增off:更素净,靠纯色底传达语义——弱视/色盲用户只剩文字标题一条通道
banneron:站点级强制曝光,占一整行高度,内容被迫下移;只应同时存在一条off:文档流内的普通块,可多条并存但每屏建议 ≤1 条;通栏+非通栏混用层级会乱

经验区间:每屏 1 条、error 用最少、需要站点级曝光才开 banner;文字保持「标题一行 + 说明一行」以内。

适用场景 3
  • 页面级/表单顶部的整体性错误与状态说明(Carbon:整体性错误用行内通知)
  • 存储告急、维护公告等站点级通栏(banner)
  • 成功/结果确认等需要驻留直到用户读完的反馈
何时不要用 4
  • 自动消失——那是 toast 的职责;警告自动消失太快违反 WCAG 2.2.3(APG)
  • 必须处理才能继续的信息——用 alertdialog(APG:要打断用户就升级为对话框)
  • 字段级表单校验——错误要紧贴字段(NN/g 准则③)
  • 一屏堆多个警告——信息噪音,合并为一条或改用页面结构承载
无障碍

容器 role=alert,动态插入时多数屏幕阅读器自动播报(WAI-APG);不夺取键盘焦点——需要打断用户时改用 alertdialog;不要自动消失(违反 WCAG 2.2.3)、不要频繁出现(2.2.4);图标只作辅助,颜色+图标双通道避免「仅靠颜色传达」(WCAG 1.4.1);关闭按钮真实可聚焦并带 aria-label。

浏览器支持

实现为普通文档流块级元素 + CSS color-mix 派生浅底,均为 Baseline 能力;color-mix 自 2023 年起全浏览器可用,不支持时浅底退化为白底(信息不受影响)。

兼容回退

不支持 color-mix 的旧环境直接用功能色描边 + 白底即可读;图标用 SVG currentColor 着色,不依赖图片加载;关闭按钮必须是真实 button,不能只靠 CSS 隐藏。

来源 2

起源语义取自 W3C APG Alert 模式:role=alert 显示简短重要消息、动态插入时多数屏幕阅读器自动播报、不得夺取键盘焦点;APG 特别告诫避免自动消失(WCAG 2.2.3)与频繁打断(2.2.4)。实现参数参照 Ant Design Alert:type 默认 info、showIcon/closable/banner 默认 false(antd 6.7.1 核对,调研 07§9 与 design-study 06§4.13)。
