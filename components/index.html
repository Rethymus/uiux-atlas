基础 Basic (4)

按钮 触发即时动作的按钮件:四档变体(primary/secondary/text/dashed,antd 风格)对应四级强调,loading 转圈阻断交互,disabled 置灰不可点;每屏只留一个 primary。 组件库 ★★★ 图标 线性 SVG 图标件:stroke=currentColor 单色渲染,尺寸 12–48px、线宽 1–3 实时可调;图标随文字颜色走,语义靠可访问名补齐。 组件库 ★★ 标签 标记与分类的小型标签件:五色枚举(红橙蓝绿灰,antd 预设色系),可关闭(closable)与描边(bordered)开关;删除后焦点移交下一个标签。 组件库 ★★ 文字排印 文字层级件:六档 level(h1–h4/body/caption,antd 自然指数字阶)× 三档 type(默认/次级/危险)+ 单行省略开关;同屏阶梯展示各级字号与行高。 组件库 ★★

表单 Form (8)

级联选择 从有层级关联的数据集里逐级下钻选值:展开后是「省→市→区」式的多列菜单,选中上一级即刷新下一级。 组件库 ★★ 日期选择器 从月历网格里点选日期:触发器收起为输入框,展开后是「星期表头 + 7 列日网格 + 月份切换」的浮层面板。 组件库 ★★★ 多选框 多选控件:一组里可同时选中任意多项;配一个全选框时,「部分选中」用 indeterminate 半选态表达。 组件库 ★★ 评分 用一排星星对事物打分:悬停预览、点击落值,支持半星与再次点击清空;键盘按 radiogroup 漫游选择。 组件库 ★★★ 输入框 单行文本输入:label + 原生 textbox,状态色边框、可清空后缀与计数提示是表单里最高频的三件套。 组件库 ★★★ 选择器 从一组互斥选项里选一个:收起时是带箭头的触发器,展开后是可键盘导航的 listbox 浮层。 组件库 ★★ 开关 二态即时开关:拨杆在轨道左右滑动表达 on/off,状态即改即生效,不需要「提交」按钮。 组件库 ★★★ 上传三态 点击或拖拽把文件交给系统:上传中带百分比进度、成功打勾、失败给修复指引——每个文件在列表里走完自己的状态机。 组件库 ★★★

反馈 Feedback (5)

警告提示 文档流内的四色警示块:不夺键盘焦点、默认不自动消失,经 role=alert 播报——与 toast(浮层自动消失)和 Dialog(阻断)三分反馈职责。 组件库 ★★ 抽屉 从屏幕边缘 transform 滑入的面板:不离开当前页即可承载子任务/表单/详情,Esc 关闭、可带遮罩,reduced-motion 直达。 组件库 ★★ 对话框 压在页面之上的模态层:遮罩隔离外部内容、焦点困在框内、Esc/关钮退出,承载需要用户必须处理的信息或不可逆操作确认。 组件库 ★★★ 文字提示 悬停/聚焦时出现的小气泡:纯鼠标放大器,hover 与 focus 双触发、Esc 隐藏、纯文本短句——不能承载必须阅读的信息。 组件库 ★★ 全局提示 不打断操作的轻量反馈条:固定定位浮于页面之上、按时长自动消失、经 role=alert 播报,只承载非关键信息。 组件库 ★★★

数据 Data (6)

头像 以小尺寸图像或字符代表人:圆/方两形,组内以负 margin 重叠、溢出折叠为 +N——尺寸与重叠宽度都是 token 化的,不是随手写死的。 组件库 ★★ 卡片 共同区域的具象化:一条边框或一层底色把相关内容圈成一块,头部标题 + 正文 + 操作区 + 可选封面,是信息分区最基本的容器。 组件库 ★★ 徽标数 附着在其他控件角上的状态计数:数字封顶 99+、归零隐藏、可降级为小红点——徽标的一切默认值都在替用户收敛信息密度。 组件库 ★★★ 折叠面板 把成组内容收纳进「标题行 + 可展开内容区」:点标题切换显隐,多开是常规、同一时刻只开一块的手风琴是特例。 组件库 ★★ 表格 用行列矩阵组织结构化数据:表头承载列语义,行承载记录;排序、斑马纹与行 hover 都是为扫读服务的辅助层,不是装饰。 组件库 ★★★ 时间线 按时间顺序铺陈事件的垂直轴线:每格一枚节点 + 时间 + 标题,节点色区分语义(默认蓝 / 成功绿 / 报错红 / 加载中旋转点)。 组件库 ★★

导航 Navigation (6)

面包屑 按层级排列的父页面链接列表,显示当前页在站点层级中的位置:放主内容之前的水平位置,上层任意节点可点、逐级回退。 组件库 ★★ 命令面板 按 Ctrl+K / Cmd+K(或点页头搜索钮)唤起的全局命令浮层:子序列模糊搜索全部条目,↑↓ 选择、Enter 直达、Esc 关闭——APG combobox/listbox 语义 + focus trap + body 滚动锁定的完整零依赖实现。 Web 标准 ★★★ 下拉菜单 按钮触发的临时操作菜单:点击/悬停展开一组可执行的动作列表,浮层定位在触发钮四周;与 tooltip 的区别是它承载可点击的操作,不是只读提示。 组件库 ★★ 导航菜单 将网站的信息架构分组归类并以导航的形式展示给用户,方便用户查找要获取的信息:顶部横向或侧栏纵向,二级导航聚合在下拉菜单中。 组件库 ★★★ 步骤条 把复杂任务拆成有顺序的子步骤导航:节点串在连接线上,wait/process/finish/error 四态自动推算,process 步可带进度环。 组件库 ★★★ 标签页 在同一视图内平铺切换多份平级内容:一条标签轴 + 一块内容面板,点选或方向键切换,不打断所在页面的上下文。 组件库 ★★★

其他 Other (2)

空状态 数据为空时的友好占位:插画 + 简短标题 + 下一步说明 + 可选操作按钮,把『死胡同』变成引导。 组件库 ★★ 水印 叠在内容之上的半透明平铺文字层:低透明度、轻微负角度、按 gap 重复铺满,用于防泄露威慑与归属溯源,而不妨碍阅读。 组件库 ★★★

AI 界面 AI Interfaces (6)

AI 回答安全态 回答的三种非常态:拒答卡(展示不解析)、通用错误文案 + 重试、结构化引用来源(来源卡/角标/脚注)——出错时信息不泄漏,引用时段落可追溯。 社区流派 ★★★ 生成式 UI 模型输出结构化数据 → 宿主组件映射:工具卡七态徽章、schema 驱动树、流中渐进渲染——模型只能请求 UI,渲染权永远在白名单手里。 社区流派 ★★★ AI 建议操作 Chips 回答结束后的下一步引导:点击即发送的官方用法、轮次边界才更新的换牌纪律、防重复点击的后态——建议是路标,不是干扰。 社区流派 ★★★ AI 思考中指示器 AI 推理等待的形态选型:NN/g 响应时间三限定形态、shimmer 思考标签、三点脉冲与步骤卡的自动收起——等待被承认,而不是被装饰。 社区流派 ★★★ AI 流式响应 AI 回答的渐进渲染:未闭合 markdown 自愈、末尾光标、锁底滚动与用户上滚打断、两级节流——token 流到哪,版面稳到哪。 社区流派 ★★★ AI 流式表格 表格随 token 流生长:块级 memo 的行级结果、fixed 骨架锁列宽、表内滚动不撑破会话锁底——宽表也能流,版面不跳。 社区流派 ★★★
